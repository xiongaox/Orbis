# 人生建议

很多烦恼都来源于妄想。所谓妄想，就是指一切错误的判断，念头。或执着于一个错误的想法，或不切实际的想法。就比如总是去想，自己50多岁可能就要去世了，这个事情还未发生，且未必会发生，而因为妄想，让原本不确定的事情，变成思维上的确定，而给自己增添痛苦。

学佛就是要努力的去消除妄想、执着和分别心。妄想不除，则会成为我们觉醒之路中的障碍，会阻碍我们的智慧，影响我们对人事物正确的判断。如何才可以消除妄想？

有人说，不需要去理会妄想，随它来，随它去？这种说法并不正确，因为并非人人都是圣人，都能内心清净无染；如果不去管它，就会导致妄想越来越多，自然烦恼和痛苦也会越来越多。很多抑郁，都是从妄想开始。所以一定要通过一些方法，去控制自己的妄想，并且慢慢消除妄想，让内心清净，不受妄想的困扰和伤害。

具体操作方法如下：

1.当自己产生妄想的时候，比如总是去猜测，担忧，恐惧时。先去思维自己到底担忧的是什么，恐惧的是什么，去观察我们的妄想，直到观察到源头，就能自然消除。这个方法一开始比较困难，并非每个人都可以这样做到，但也不妨一试。

2.可以通过以念止念的方法，当自己妄念产生的时候，且因为这个念头而让自己痛苦，就要立刻觉察到妄念的到来，且通过念佛，诵经，观想的方法断除。可以念“阿弥陀佛”，因为佛号是清净无染的，能让内心安宁下来，只要坚持念佛，就能消除其他妄念，清楚内心的烦恼。

至于观想，则可以观想莲花，颜色可以选择白色和蓝色两种，且莲花发光，光非常明亮，莲花可以在自己头顶，也可以在自己眼前。只要专注莲花，就能让妄念消除。这个方法，适用于所有不良情绪产生之时候。用这个方法来降服情绪，让自己内心达到平和。非常有效。

就比如生活中和丈夫吵架了，要立刻意识到自己生起了愤怒，然后通过观想和念佛的方法，就能慢慢降服愤怒，情绪也自然被克服了。等没有情绪后，再去和丈夫好好谈谈，为什么吵架，以及各自都需要改正什么？只要坚持这样去做，家庭必然是和睦的。

我们要时刻觉知到自己是否生起情绪，是否产生了妄想，是否有执着心，是否有分别心。只要觉知到了，就通过念佛，诵经，或跑步，唱歌，爬山，拜佛，打坐等方法来降服。佛学中有八万四千法门，就是针对人的八万四千烦恼而生。

只要坚持一次又一次的练习，久而久之，就很难再生起不良情绪，心境也会变得更加平和。如此而来，家庭自然和谐美满，更加幸福。自身灵魂等级更高，则离恶道就会越远，也离痛苦就会越远。

这都是修行的方法，也是根本之法，适合所有人来修炼。
