# 命理提要

一、未月已经过了一大半，故而火气逐渐消退，而土气更旺。土是泄火的，故而日干丙火并不能得到未土帮扶，反而被未土消耗着。丙坐戌有气，时辰为卯木，，卯戌合而不化，则卯木有克戌土的力量，而卯戌相合属于互损，卯木也会减力三分。年支的巳火为禄神，在年太远而帮身效果并不是很大。丙在地支只有巳火，卯木，在天干则一片土金来耗克自己，所以丙火并不算旺。

这个八字由于未戌的出现，很容易判断为身旺。这里一定要注意一个问题，当未土，戌土没有被合化成功的时候，依然是土，不能当做木火来看，所以未戌对丙火自然也不存在什么太有利的生扶。八字喜见木火，所以在走五行为木火的大运还是不错的，忌神为土金水。

二、丙火日出生的人，都比较充满激情，热情好客，性格也比较乐观，但是也有急躁，做事情不冷静的缺点。天干辛金为正财，丙火左右逢财，并且丙辛合财。由于日干不旺，所以合财反而累身，并且合也代表追求，自己非常追求财富，故而在金钱上面野心是很大的，不容易满足，也容易因为金钱而让自己非常辛苦，内心压力很大。

女命伤官太旺，往往比较爱慕虚荣。天干财星透，丙辛合财，喜欢装扮自己，或者花钱比较厉害。书日：“女子透财，穿金戴银”。这也是一种虚荣心在作祟。八字身弱而食伤生财，自己的能力是无法支撑你的欲望和梦想的，故而会因此而非常苦恼，自己也会觉得很累。其实很多事情都是自己在为难自己，如果自己能放下，懂得知足，那么必然会更加幸福。

八字时辰为卯木印星，身弱印星为用，代表学习，文化。不过辛卯时辰，财星盖头，财来破印，没有官来生印，并且早年癸酉大运，卯酉相冲，印星严重受损。故而在学习上面必然波折很大，结果不太理想。不过身弱的命，虽然学习不顺，但是自己一定要坚持学习，不管学习什么，只要去学，终究是对你有利的。
