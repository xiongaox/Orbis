# 人生建议

当自己各方面所处于弱势的时候，一定要坚持学习，因为只有学习才能改变自己，也只有努力的去改变自己，才能改变命运。

我们所遇到的一切人，事，物都是和自身能量相匹配的。你自己越优秀，你遇到的人和接触的事情也会越优秀。只有知识丰富的人，才能看到常人所看不到的东西，也才能更有效的去把握机会。

你有一颗学习的心是非常好的，我也非常鼓励你去学习，但要把学习当一件重要的事情去做，并且要明白学习不仅仅停留在学校，我们生活中处处都需要去学习，只有学习才能使我们进步。

学习的看似为知识，其实更重要的是为了学习一种思维方式。因为思维方式会决定我们的选择，而选择决定着我们的命运结果。在人生道路中，处处都会遭遇岔路口，处处都面临着选择，所以选择对我们来讲是非常重要的。所以命运的好坏都是由我们的思维决定的。

身弱财旺之人，更加要坚持学习，提升自己的知识，掌握一门技术为上策。因为八字原局普通且大运不济，则很难依靠别人，那么就更要依靠自己了。而自己最能依靠的就是知识。只有知识才能破除无明，清除恐惧，增强自信，改变人生。

在42岁后当一切顺利的时候，要保持初心不变，不管有多好的机会摆在你的面前，也不能轻易的被欲望蒙蔽双眼。

当自己得到的时候，要学会让自己的心回到最初的状态。因为只有这样，就算失去了，也不会因此而痛苦，才能保持一颗平常心，不被无常变化所伤害。

至于学习易学，由于八字有太极贵人，则可以学习。但学习中的这十年只能学不能靠此赚钱，只有这样你才能学得更好，才会有所进步。财多身弱之命，一旦见财就会荒废学习，停滞不前了。
