# 来信

李老师您好！我还是本着锲而不舍的精神再给您写信。我虽不太懂八字，但一直关注您的公众号，很欣赏李老师一直无私为他人解惑答疑，也非常佩服李老师的易学知识！在人生事业和婚姻的十字路口，今天自己再次鼓起勇气给李老师写信求教。

本人女，生于一九九一年，农历九月初五，午时。今年六月博士毕业，刚参加工作，却在事业和感情上都遇到诸多困扰，四个月以来一直非常困惑，希望有幸获得李老师的指点，以求能稍微心安。

事业上，我今年六月博士毕业后，选择了一个自己喜欢的城市，成为一名高校老师。但是暑假时候，我经过对单位以及对自身、城市选择各方面深入的了解和思考后，决定还是放弃现在的工作，回到以前读书的城市工作。从暑假作出决定到现在都在找回原城市的工作，现已有一些眉目，应该在年底会回去，会读博后。但是当时做出这个决定真的很难，毕竟是第一份看起来很稳定的工作。有人会觉得我已27岁，应考虑找对象结婚了，换工作城市是在折腾。我还想在事业上努力一下，但从内心深处不知道回到以前城市后，自己事业发展究竟会不会顺利？

感情上，一直以来我的感情可以说都不是很顺利。我很欣赏能够学习到优点的优秀的人，每次生命里出现互有好感的异性时，总是出现一方会分离的情况』尤其最近两三年，遇到互有好感的也有不少，但是因为各种原因最终都未能在一起，每次离别都会为此苦恼很久。除此之外，令我困惑的是，我自认为自己一向还是比较保守的人，却经常会遇到己婚和有女友的异性的打扰。我也关注很多感情婚姻的文章，但是总觉得不够幸运，不能遇见合适的人，感觉有些悲观，很担心自己年纪越来越大，所以一直以来有人介绍相亲也都会去。

现在因为工作上的事情，我更把感情婚姻往后面排序了，但是这是我一直的困惑，想请教李老师我的感情婚姻的状况，非常感谢李老师您了。在这人生困惑的路口，已经第七次写信给老师了，很期待李老师百忙之中指点迷津，谢谢李老师，祝李老师万事顺遂！

# 八字详批

#### 坤造：辛未年，戊戌月，乙卯日，壬午时（空戌亥、子丑）

#### 大运：己亥，庚子，辛丑，壬寅，癸卯，甲辰，乙巳

# 命理提要

一、日干乙木，在戌月出生失令，月份戌土为财库，未戌三刑则财库打开。日支为卯木禄神，也为乙木的根，地支均为火土旺来消耗日干乙木，天干有壬水，但是并不算旺，属于身弱的八字。八字土旺为忌神，喜木制土为吉，所以在走五行为木的大运是最好的，水运也是不错的，而走火土金运都不是很理想。

二、原局戌为财库，有卯木合财为吉，卯木为禄神也代表自己，自己合住了财库，则财能为自己所用。并且时支午火也来合财库，故而钱财归入主位，则为自己的财。命局财富格局还是很不错的，一生会有比较好的财运。不过禄神合财，代表辛苦，工作上面操心比较大，或者是身体上面不是很轻松，比较累。

八字为正财格，则上班是最佳选择，正财当令做事情比较追求中庸之道，不喜欢过于的标新立异和表现自己，比较守本分，也肯努力，主勤奋，能任劳任怨。这样的性格，都非常适合在单位，企业，从事相对保守稳定的工作，这样对自己才会更加有利。从八字来看，不是很适合创业，并且正财太保守，日干较弱则做事情缺乏魄力，不宜去做创新性太强的事业。

至于做老师也是非常好的，从八字角度来看，在学校任教非常适合自己，如果换工作我依然建议你从事教育事业，或者是在一些企业单位，总之要在一个相对稳定的岗位之上才是最好的。并且在现阶段，一定要求稳，不要轻易的去变动。

三、年干辛金为七杀星，代表一开始的缘分，由于地支未戌三刑，则感情并不顺利。八字只有七杀而没有正官星，故而不太容易遇到太好的缘分。日支为禄神，则丈夫条件和能力都还是可以，并且夫妻同心而能互相帮助。

卯木合财则丈夫财运也不错，不过对象年龄一般会比你大很多岁，而且不是家乡的人，会是比较远的人，两人之间还是有很大差距的。比如年龄差距，家庭背景的差距，或者是文凭差距。你找的对象，必然是存在差距，不是那种太门当户对的人。

# 大运流年

你从小走的就是水运，水为八字当中的印，印为命中用神，故而旺学习利文化。加上后天的努力，以及家庭的影响，故而可以获得极高的文凭，到达学历的顶端。

19-29岁走的庚子大运，庚金为正官星，合住日干乙木。这十年缘分是有很多的，但是子水冲午火，自己容易挑剔，内心不满，而错过了很多相对比较好的缘分。

午火在八字当中代表想法，思想，被冲则思想不稳定，对待感情也不是很坚定。如果非要找两情相悦，且各方面都符合自己的条件的，则不太容易。故而你要降低要求，或者是在某一方面降低要求，人无完人，不能面面俱到。

2018戊戌年，在今年并非顺利的年份，所以在今年虽然参加了工作，但是做的并不是很开心，所以自己一直都想要变动。如果从运势角度来看，你这种变动之心，都是因为流年不顺导致的。既然是流年的原因，那么这样的变动，对你未必就有利。

2019己亥年，走印星年份，则一切都会顺利一些。而且亥卯未三合，财运也会有比较大的好转。在2020年进入辛丑大运，并非好的运气。

29-39岁走的辛丑大运，辛金为七杀星，大运和八字构成丑未戌三刑，八字本身土非常的旺，所以三刑会导致土更旺。而且壬水在地支无气，并且土旺会克水，不过好在大运有辛金来生水。但是这样的大运也并不吉利，所以你在这十年会比较不顺，内心烦闷，不安，快乐比较少。

辛金为七杀大运，七杀也为你命中的夫，选来选去，后面遇见的都不如之前遇见的，越来越差。身弱走七杀大运，遇见的人往往人品，综合素质，或者是对你的感情，都不是很好。感情方面还是比较坎坷的，自己要多注意。一定不要过分要求，要懂得去看对方好的一面，要找更加适合自己的。两情相悦的感情，往往都是不长久的，恋爱和婚姻是两回事。

39-49岁走的壬寅大运，为水木帮身，运气非常的好。会云开雾散好运来。你这样的运气，一直到晚年都是非常不错，所以你后半生非常的好。财运，事业，以及家庭都会有一个非常好的体现。特别是在事业财运方面，非常好，丰衣足食，也可以有富贵。

你八字原局不差，格局也挺好，加上后面的运气又走的很不错，所以不管你在什么行业内，都可以有一番作为，有不错的成就。总之你不用为你的事业担心，一生遇到的贵人也是非常多的，处处都可以得到别人的帮助而逢凶化吉，最大程度的达到你的理想状态。

# 人生建议

1.你的命运是非常好的，可以说是命好运也是很好的，但是有2020到2029十年败运，这十年内各方面的压力都会比较大。越是在这样的大运之下，越容易做出很多错误的决定，而对自己的后半生造成巨大的影响，所以在这十年内自己一定要求稳。首先工作上面要稳定，一定要在单位上班，并且尽量不要大幅度的变动自己的工作，如果工作不开心则自己要寻找原因，要懂得调节心态。

这十年要多学习，不断的充实自己，丰富自己，要少争，一切随缘。做好自己的本职工作，拿一份该自己得的收入，其他的都不要多想。这十年就相当于是刘邦做汉王期间，以练兵强大自己为主，等待时机。事业上面遭遇什么挫折，以退为主就好，也不要心生懊恼，因为你的好运还未到来。等你过了39岁你就一帆风顺，事业可谓是节节高升。加上你后天学历非常好，有比较好的底子，自身能力不弱，故而可以有较大作为和成就。

自己一定要有一个好的规划和定位，做事情既不能没有规划，也不能什么都由着性子，要有耐性且肯吃苦。做大事的人都必须要能承受孤独，只有不怕孤独的人，才配拥有成功。你现在的变动，如果是换到新的工作岗位，依然是同等职业，我觉得可以。如果是变动后没有工作了，就要谨慎。因为过了2020年，很可能你想找一份好工作都难了。不过之后几年流年还是很顺利的，比如2022年，2023年，2024年也有贵人和机会。

2.至于婚姻方面，根据我的经验，越是高学历的人，越不容易获得幸福的婚姻。为什么会如此呢？这是因为傲慢心充斥着自己的内心。因为自己学历高而看不起很多人，总觉得自己高人一等，找对象也是高高在上的气势，而不能谦虚的去看待这段感情。而且高学历的人，百分之80以上都是非常晚婚，这都是因为一路走来，总觉得他们都配不上自己，自己也不愿意轻易嫁出去。

这种心态并非好的现象，要明白能力的体现是方方面面的，而非仅仅是学历。但是高学历的人，往往看到的就是对方的学历，有一种看不起低学历的人，认为对方学历不如自己，人都要讲一个层次了。所以你才会很欣赏能够学习到优点的优秀的人，而看不到其他方面优秀的人，这样无疑会给你的婚姻选择加大难度。

一个男人有道德素养就是最大的优点，找对象更多要看是否有道德，而有素养的人并非一定要高学历，而很多高学历的人未必就真的有素养。当然读书多的人，看待事物的角度的确有所不同，但是往往因为过高过窄的角度也限制了自己的人生。你的命并不差，靠自己生活无忧没有半点问题。

寻找丈夫，更多的是寻找一个爱你的，你也喜欢的，并且对你好，真心过日子的，而不要追求什么土豪，大款，高知等。夫妻之间有一定差距，往往家庭会更加幸福，没有差距反而不利，这一点你要好好去想想。所以当下要做的，第一就是稳定工作，第二就是真心的去谈谈感情，考虑婚事了，不要拖延，因为过了2020年后走的七杀大运，不管是工作还是婚姻都不会那么顺利了。
