# 人生建议

婚姻中绝大多数的矛盾，都来自于两人都想尽办法的去改变对方。都希望对方能活成自己想要的那种人。特别是一些打着“爱”和“为你好”的旗号，要求对方做各种各样的改变。这种扭曲的情感，都源于自私和强烈的控制欲。

为什么不能把自己的婚姻过的好？是因为自己内心有太多不该有的念头，贪求太多，因得不到而生出各种嗔恨心，这都是矛盾的根源。

有时候我们去想想，为什么自己会生气？都源于自己的贪，贪图对方如何如何；比如贪图对方对自己更好，而这种好却永远都无法满足；贪图对象赚更多的钱，贪图对方更漂亮，贪图对方更贤惠等等。到最后才发现，自己所贪图的一切都无法真正的拥有；就算短暂的拥有最终也会失去，从而生各种抱怨，不满，以及负面情绪。如果能灭掉这种不该有的“贪”，就不会有那么的多埋怨，也就不会觉得婚姻是折磨，都能和谐的相处。

婚姻就如同两人合伙做买卖一样，合伙人为何会到不欢而散的地步？也都源于各自的贪。想要赚更多的钱，不想和对方分钱，总认为自己付出的才是最多的，而对方就好像是在那里坐着等钱一样，总认为自己是最勤劳的而对方是懒惰的。在家庭中也是如此，有时候想想，因为这些而发生矛盾，不都是因为自私和贪心嘛。

如果能降服这份贪心，且能让自己不再自私，变得更加大度，多为对方着想，多去改变自己而不是要求别人如何。如此而来，又怎会有不幸福的婚姻呢？

有句话是这样说的：“痛苦的婚姻大都基于这样一种误解，本来只是两个人各自生命的一小部分能够暂时契合在一起，他们便想当然地认为他们全部的生命可以彼此连结一生。”

这个世界无时无刻不在变化着，我们身处无常之中，谁也没有办法逃脱。自认为是永恒，却不知道生离和死别，是每一对夫妻最终都要经历的，只是时间早晚而已。人生短短数十年，却有不少的人花费了很大一部分的时间用来和另一半斗气，争吵，甚至在痛苦当中度过，想想都觉得可笑。要用无常的眼光去看待世间一切，就不会因为变化而烦恼。从结果出发去看原因，就不会在乎因的好坏对错。

就比如夫妻吵架了，如果自己能首先想到结果，比如自己要的结果是夫妻和睦，就能立马放下吵闹，连吵架的时间都省下来了，也就有更多的时间去做更有意义的事情，而不是浪费在你恩我怨，互相折磨之上。
