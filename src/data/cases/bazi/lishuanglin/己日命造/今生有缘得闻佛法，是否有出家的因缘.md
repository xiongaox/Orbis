# 命理提要

一、日干己土在申金月份出生失令，坐卯木受制，年月日都是忌神，且八字官杀非常的旺。原局官杀很旺，且官杀为忌，则喜印泄官杀生身，故而火为最佳用神，至于土也能帮身，所以土也是吉利的。八字喜火土为用神，而金水木均为忌神。

原局年支亥水为财，亥水生了乙木七杀，而乙木和甲木纠缠且均来克己土，年月的官杀是没有制约的，故而这样的官杀必然会对自己造成伤害，形成烦恼障。日支卯木为七杀被申金所制，且卯木生了巳火，巳火又生了己土，且能得到己土帮身，故而原局有一吉，也有一流通，所以也算晚年有福的人。

关于出家的缘分是很殊胜的，也是很奇妙的，更是一言难尽的。出家的功德也是大到无量无边，因为出家人可以更好地去传播佛法，向世人表法，从而普度众生，救众生于苦难。穿上僧衣则一言一行均代表着正法，代表着佛菩萨。

**出家有四种情况：**

1.身出心不出。这些人看似身体出家了，也穿上了出家人的衣服，住在了寺庙之中，但心还未出家，依然想着俗世的事情，想着名利财色寿。看似离开了自己的小家，却进入了一个更大的家（寺庙），虽然地方换了，但心依然在人间，小家造业小，大家造业大，在寺庙更容易造业。就比如古德所讲：“地狱门前僧道多”，就是这个道理。很多出家人，修了一辈子因为心不干净，而把自己给修入了恶道之中。

2.心出身不出。有很多在家大居士就是如此，虽然身在俗世，但心早已出家。并且在末法时期，在家居士成就的比出家人还要多，特别是在家女众成就的比男众要多。在家修行为什么会比出家人更容易成就？这是因为身在世间，更能体验世间的酸甜苦辣。就比如我们要修忍辱般若，在家居士更容易去体验和破除，而出家人则连体验的机会都没有。因为几乎所有的信众对出家人都是非常恭敬的，不会有言语的侮辱和怀疑来招惹自己生气，所以更难修行。

就比如我们要断除欲望，在家居士所面临的欲望诱惑更多，比如财，色，名等，在生活中处处会遇到这样的诱惑，若能抵抗并且断除这样的欲望，则修行上面就会有大进步。

这样说也并非出家修行就不好，因为出家人功德无量，主要是能守护善法，常住寺庙，给了众生一个更好的结缘佛法机会。但就修行而言，体验俗世百味，更有利助长修为。不过出家修行由于环境清静，长期熏陶，更容易保持清净心，也就造恶更少了。而在家居士，若修行不精进，稍有懈怠则诱惑百倍，更易堕落。

3.身心俱出。这样的人才能算是真正好的出家人，身出家心也出家。这就是佛法里面所讲的佛真实弟子，能够担当起弘法利生、续佛慧命的如来家业。

4.身心俱不出。这就是指很多在家学佛人了，不但身没出心也没出。虽然表面学佛，但学佛对自己来讲只是附带的，并非主要的，学佛的目的也是为了保佑自己发财，当官，或为了求平安而学佛。在一生当中，也有百分之99的精力都用在了追求名利之上，而仅有百分之一用于学佛修行，并且学佛动机还不纯净。

通过这四种情况，然后我们再扪心自问，就能清楚明白自己属于哪一种了。至于自己是否有出家的因缘？这种缘分并不能完全从八字就能看出来的，若能出家则是大福报所致，也是累生累世修持发愿的结果。一般如果缘分到了，自己心中都是有数的，并不需要去询问他人。若问他人，或内心摇摆不定，这都说明缘分并未到，心中还有很多事情放不下，还需要去体验。

如果自己看见受苦难的人，心中没有一点怜悯之情，杀害动物也没有一点悲伤，或听见大乘佛法也毫无感觉，没有救济世人的决心和愿力，或仅仅是为了逃避种种或一时兴趣而生出家之心，这都均非真正的出家缘分，也就说明缘分还未到，大悲心还未成熟。用上师索达吉堪布的一句话来讲：“有无缘分要看自己大悲种性是否成熟，空性智慧种性是否成熟”。如果带着邪念，愚昧而出家，往往会成为魔的子孙，误导世人，造无边罪恶。

二、接着来分析一下你的八字，通过八字看有哪些信息值得注意和参考。

八字时支巳火为用，巳火又为驿马又冲太岁，巳火为印也代表家，在时柱也代表远方。故而你必定要去远方安家置业，巳火冲了太岁，而太岁代表祖业，也代表出生地，故而属于远走他乡的命。己土为自己，己土坐巳火代表一体的，所以自己也会离开家乡，为奔波之命。故而你的命应该去远方最好，也能更加顺利。

八字喜印为用，故而要多学习才是最好的，知识可以改变你的命运。你八字有正官合身，且年柱有七杀星，也算官杀相混的命，一般官杀太旺的人，往往压力都是非常大，烦恼也是很多的，所以都非常喜欢落一个清净，不喜欢太嘈杂的环境。年支亥水为财，这个财被日支卯木合入了，这也说明你会去追求这个财，也代表在物欲上面还是容易执着，不容易放下。财也为妻子，所以还有感情之事，故而如果现在出家，后面必定会增添更多的烦恼，还有很多事情需要你去体验。

如果在世间，则必须要面对安身立命的问题，所以职业的选择也非常重要。你学习的是财务，从五行来看为金，十神来看为财。你八字金为忌神，财星也是忌神，所以这份工作并不太适合自己。但如果非要去做也并非不可，只是阻碍会比较大，或者是会给你带来更多的烦恼。你的命为正官合身，而且驿马+正印，所以更加适合上班，从事一份比较稳定的工作为吉，去外地工作比较好，选择南方，西南方，东北方大吉。

行业选择，以火为主的比较好，并且这样的行业要具备功德的，不容易造业的。所以可以选择一些服务性质的工作，能利益老百姓的，比如教育行业，一些咨询行业，医疗行业，福利院，养老院，公益组织等等，只要是利国利民的行业都是可以去做的。但欺瞒，作假，伤害他人的行业不去接触就好。

你八字还是有财运的，从运势来看也还算不错，但运势不太稳定，所以不宜做生意买卖，求稳是最好的。

至于在工作当中如何与人相处的问题，只要不把自己当另类，要懂得随顺众生，只要保持自心清铮，莫过于执着形式和外在，就可以很好的相处。我建议你读读《维摩诘经》这本经是维摩诘居士针对在家居士修行的一些论述，非常值得在家居士去学习和奉行。这本经可以解答你很多疑惑。

# 人生建议

1.不管是出家还是在家都是形式而已，而学佛追求的是果而非形式。但这些形式也并非就毫无意义，因为各种形式都是在向世人表法，从而感召不同根器因缘的人来接触佛法。比如有出家因缘的，则会在出家人的感召下出家；而没有出家因缘但佛缘很深的，则会被在家居士感召而学佛。就比如佛陀在世的时候，释迦牟尼佛就是表出家的法，而维摩诘就是表在家的法。所以在家修行，一定要认真研读《维摩诘经》，从中才能明白在家修行的方法。

如果是要出家，一定要明确出家的目的。若是抱有利他的大愿出家，并能不忘初心，坚持朝着这个方向努力着，必然功德无量无边。但如果仅仅是为了逃避种种，或一时兴趣脑热，则极易造业，甚至堕落。

你在当下最好的就是先学习，先从世间法开始，体验人间百味，因为一切世间法也不离佛法。用十年的时间来学习佛法，熟读《大藏经》，并且记录自己的心得，十年之后自有答案，一切的一切都能水到渠成，不需要请教任何人，你的路应该怎么走都会非常明了。

在家修行也能渡人，并且在家修行更好渡人。因为我们就身处俗世之间，能接触到更多的人，更能了解他们的痛苦和烦恼，更能做到应机说法，随缘渡生。希望你能好好体会一下。我是真心的希望着你能有所成就，从而去利益更多众生。

2.你的人生也并不顺利，若是身在俗世，必然会经历很多痛苦和磨难。不过大成就的人都是有大磨难的。只要你不怕磨难，能在痛苦中保持清醒，诱惑中保持正信，必然能更好的解脱出来。到时候你就算真正的成就了。
