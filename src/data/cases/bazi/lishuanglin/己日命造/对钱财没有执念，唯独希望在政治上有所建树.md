# 人生建议

官场，商场，职场均如战场，不是你损就是我伤。不论自己身处何地，要有一番作为，都必须要具备天时、地利、人和方能成功。

走仕途平台非常重要，自己所在的平台几乎决定了未来的发展。大平台有大机遇，也能接触到大贵人，自然前途也会更宽广；而小平台则不管怎么努力，都很难到一个较大的高度，除非自己是人中龙凤。除此之外，则为关系。在单位当中，很多时候关系比能力更重要；其次对领导的忠诚也比能力更重要。

我的一位命理老师经常和我讲，当官要当管官的官，莫当被官管的官。如果自己真的想为民做事，实现自己的政治抱负，就要到一定高度的职位才可以实现，如果作为一名基层干部，很多事情都是身不由己，甚至会做很多违心的事情来。所以并非做了官，就一定能为百姓谋福，还要看自己所处在怎样的一个位置来决定。

在从政之前，都是心如明镜高悬，一旦为官，则会渐渐忘却初心。就比如济公传里面有一个桥段，一人心系百姓疾苦，一心想要为官，好为民做主，但屡考屡败，终不得志，最后得济公帮助，凭借一篇狗屁文章而高中，初做官时处处为民，却阻碍极大，差点丢官，为了保全职位不得不欺上瞒下，各种贿赂，反而仕途一帆风顺，位至相国，但因作恶太多，东窗事发，而判斩首，方才醒悟，发誓再不想为官。

这个故事其实蕴藏很深的道理，也揭露了官场的现实，让人腐败的并非仅仅是人心的贪欲，而是制度的不完善，在有缺陷的制度下，很难有完人的存在。很多时候，我们的想法是美好的，但实施起来却处处阻碍。社会的复杂，很多都是我们无法想象得到的。

在官场之中，则为水至清则无鱼。过于清廉则无朋友，且招人陷害，处处受阻。若不得大贵人的提拔帮助，很难得半点升迁。所以啊，你现在想法是非常好的，我也非常随喜你的发愿。希望能实现人生抱负，让老百姓生活过得更好。但真正到了这一步，便会发现并没有那么容易去做。犹如过独木桥，没得选择，不过去就会丢进河里。很多时候，从此岸到彼岸只有一只船，不同流就会被抛弃，要么一起过河，要么就留你一人在对岸。

社会现实就是如此，各个领域都是如此，没有差别。因为水至清则无鱼，人至察则无徒。我说这些，并非是要你放弃求官之心，毕竟拿破仑说过：“不想当将军的士兵不是好士兵。”而是希望你能平常心对待，不强求，但也不懈怠。做好自己的本职工作，其实就是在为老百姓谋福。并非一定要升官掌权，才算为民做主。过于强求，则为攀缘，稍有闪失，就会给自己带来很大的灾祸，一旦步入官场，就要步步谨慎，处处小心。

越是去追求，往往越难得到；反而顺其自然，还会有意想不到的收获。你只需把本职工作做好，和同事之间处好关系，也要多为领导分忧。该你的，自然是跑不掉的。
