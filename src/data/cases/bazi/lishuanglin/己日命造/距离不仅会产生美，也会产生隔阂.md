# 命理提要

一、日干己土在巳火月份出生得令，八字地支火土很旺，地支巳午未对日干己土都有很大的生扶力量，天干虽然有克，不过己土得令，且得地，故而属于身旺之命。火土旺则喜金水平衡为吉，八字水来制火，金来生水为吉。由于命局火旺，所以用木不是很有利，因为木会生火，火为忌神。

命局属于身旺印旺，用神更喜食伤生财。命局当中庚辛为用，透天干为吉。地支有亥水，但是火土旺而水弱，有点财星被克。不过大运走金水都是非常有利的。命局身旺有食伤透，食伤可以生财，也代表智慧，聪明，丰衣足食。

二、食伤代表表现力，欲望，想法；食伤为用往往属于一个比较爱表现的人，并且追求财富的欲望比较的大，而且个人的想法非常的多，食伤透喜欢自由，不喜欢被约束的一个人，在工作或者是感情上面都喜欢自由。故而你更加接受自由恋爱，而不太喜欢被介绍的缘分，不是很喜欢相亲，内心也会比较排斥，比较倾向一见钟情的一个人。

八字年柱为财杀，七杀透而正官暗藏，不过好在命局是不显正官的，所以不构成官杀混杂。有财来生七杀星，也暗示你命中遇见的人基础条件都还是不错的。但是食神来克七杀星，七杀代表姻缘，食神代表你内心的想法，七杀被食神制服，代表你对感情的不满，缘分的不顺。你遇见的人，要么是比较远的人，要么就是比你大很多的。

八字属于独杀显透，而暗藏正官。往往透杀藏官，初次感情是会失败的，当然失败的原因也和自己有关系。食伤透的人太理想主义了，有的时候把爱情看得太简单了，或者是太理想化了，往往现实和你的预期是相反的，所以很难达到自己内心的满意，所以自己也会对感情产生厌倦，嫌弃，时间一长就会不满。

己未日出生，坐比肩为忌神，且未土本身就不吉，还被巳火，午火生扶，故而感情并不是很好。日支为比肩，则有争夺的信息，有印来生日支，印为忌神，则会因为长辈关系而导致夫妻感情出现问题，特别是婆媳关系你要特别的注意才可以。

日支坐比肩为忌神，夫妻之间矛盾会比较多一些，容易意见不合。所以这点自己要非常注意才行。

# 大运流年

13-23岁走的癸未大运，为比肩克财，癸水生乙木，伤了财的元神，并且走华盖大运，伏吟日支。所以感情运势并不太好，并且你八字也不适合早恋。第一段感情注定失败。因为乙木可以代表第一段感情，乙亥和辛巳天克地冲，则第一段感情会失败。所以也不要因为之前的感情失败，而有什么遗憾，这都是人生必然要经历的过程。

23-33岁走的甲申大运，甲木为正官，和八字为官杀混杂，八字食伤透最不喜见正官大运，而且甲木和申金构成了伤官见官。

女命走这样的大运是非常不利感情的。这种大运一般婚姻的不顺，和自己的性格有很大关系。伤官见官主不满，要求很高，脾气也比较冲动，所以不利感情的稳定。

甲木为正官则有合适的姻缘出现，2019己亥年，2020庚子年，2022壬寅年缘分都是比较旺的，可以把握。不过大运为伤官见官，感情并不是很稳定，吵闹会比较多一些。或者是夫妻会有聚少离多的情况。

你命局夫星在年离日干比较的远，并且有食伤来克七杀星，又年月相冲，所以缘分往往会比较远，交往后也很容易出现异地的情况。从你八字来看，更加适合晚婚，晚婚才会更加顺利一些。

# 人生建议

1.你还年轻，一次失败的感情并不能代表什么，自己一定要对婚姻充满信心才可以，要勇敢的接受新的感情。

并且你的命局来看，经历一次失败的感情对你以后的婚姻会更加有利一些，你也要从失败中寻找经验，吸取教训，再次面对感情的时候则可以有效的去规避，防止类似的事情再次发生。

异地恋不仅仅是对双方感情的考验，也是对各自人品的考验。太多原本相爱的恋人，因为异地而移情别恋或产生小三，距离往往无法产生美，而是产生隔阂，产生矛盾，当一个人内心正当孤独的时候，身边一旦出现一个关心自己的人，则很容易爱情转移。如果真心喜欢，在恋爱初期一定不要分开两地，只有在同一个城市，能经常相处，才可以让感情不断的升温，也可以更加了解彼此，明白对方是否真的适合自己。

2.你后面的运势来看不太利婚姻，所以面对感情的选择一定要谨慎，并且多经历几次感情会更好一些，可以排泄婚姻的不顺之气，也可以通过恋爱让自己变得更加成熟，理智。至于结婚，不要太早了，可以先交往着，至于举行则可以晚点。你可以先工作两年再谈感情也行，一切都不能操之过急。

3.你八字食伤透，印比很旺，走伤官见官大运，找对象不能要求太高，并且要注意自己的性格，为人处世都要随和一些，特别是面对丈夫要懂得理解对方，体谅对方，少点任性；这样你才会更加容易获得幸福，婚姻也才能更加顺利一些。
