# 人生建议

幸福的婚姻并非与生俱来，而是用心经营而来。

到底怎样的生活才是自己真正想要的生活？很多人穷其一生都在努力的追寻与探索，但到最后也不能获得。许多人一生反复的离婚，企图通过下一段婚姻来获得自己内心想要的幸福，但当自己真的步入新的婚姻时，才发现这依然不是自己想要的样子。

我们到底想要的是什么？若问问自己，能给出一个具体的答案吗？我想很多人，都是不可以的。当真的去问自己的时候，自己也不清楚想要的是什么，追求的是什么。即便要回答，也仅仅是用一些所谓的爱，体贴，关怀，多金等来敷衍自己。但当自己真的得到所谓想要的时候，此刻又会发现，这一切也并非自己真正想要。

有一大部分的人，在进入第二段婚姻后并没有获得幸福。但这个时候，因为颜面，也因为年龄的问题，而更多会选择隐忍，即便有很多人再婚后还不如第一段婚姻，也只有忍着。但忍着，并不代表新的婚姻给自己带来的烦恼就消失了，反而会更多，让自己更累，但又不得不忍着。

如果婚姻给自己带来的只有伤害和痛苦，又何必去追求婚姻呢？人活着，本可以轻轻松松的，自在且潇洒，为何却如此多的痛苦呢？这都是因为人啦，总幻想着下一个人会更好，且相信自己的幻想，而变得越来越不满当下，与当下相抗争，给自己带来无量烦恼。当我们仔细去观察就会发现，很多事情的本身并没有痛苦，而是因为我们与之相抗所带来的痛苦，所以痛苦的产生来源于抗争，而非事情的本身。若能学会接受，又何来好与坏的区别？

事情本身并无好坏，人也是如此，物也是如此。而一切好坏，都只不过是我们人为给定义的，或给打的标签罢了。所以任何东西的价值，并非本身就具备价值，而是在于我们人的心理价值所定。你认为他值钱，他就值钱，反之则一文不值。所以对待感情也是如此，幸福的婚姻或不幸的婚姻，也都是自己定义的。而婚姻本身，并没有幸福或不幸福的差别。

因为自己不满这段婚姻，就会选择逃避，抵抗，中途就会衍生出许多的矛盾，争吵，甚至家暴。这一切的一切，都是因为最初的不满，最初的抱怨所致。所以，要去改变这一切，要想获得真实的幸福感，唯有去改变自己的心，改变自己看待人事物的角度和思维，方能改变一切。

要知道啊。每个人的幸福都是本性具足的，我们只需要打开即可，根本无需外求。但凡是求，皆为苦。

人活着，更多时候并非仅仅是为自己而活。若为自己一时之快，不顾及他人，则会因自己的行为，而伤害到最亲最爱的人，就得不偿失了。很多东西，都是失去了才会发现他的宝贵，而当自己拥有的时候却不能察觉。

总之啊，珍惜当下的一切吧，好好去爱护自己的孩子，也好好的去维护好现在的家庭，用心过好现在的生活，才能从中获得幸福，若一味逃避只能徒增烦恼，让人生变得毫无意义，别把更多时间浪费在错误的寻找之上。
