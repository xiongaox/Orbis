# 来信

本人女，出生于阴历：1991年腊月三十，卯时，和老公于2015年结婚生子。其他的还算比较安稳，家庭比较幸福。但是我和老公一直工作上不太顺利。我是学护理专业的，今没有做相关专业工作，现做销售顾问之类的。经朋友介绍认识了我老公，实习完后就结婚生子了，直到去年阳历的9月份才出来工作，现如今出来一年多了，工作换了好几份，时至今日也没有一个稳定的工作。我老公从今年三月份辞职后就一直没有出去工作，一直想自己创业，但是由于没想好做什么，也不愿打工。在家待了大半年，我也一直瞒着我父母，他父母也一直念叨他，并且特别不同意创业。他受不了后直至今年的十月份才开始去做了滴滴代驾。但是做的也不是很好。

曾经找过算命先生为他算过命，基本都说是大富大贵的八字。还说格局很好，只是财运还没到。而且还说他以后挣钱了也会把我甩了，有外遇之类的。听了感觉很不是滋味。也不知道说得是否属实，想李老师帮忙鉴定。（我老公阴历：1990年四月初一，时辰：早晨的7-8点）

# 命理提要

一、日干己土在丑月出生得令，年支为未土帮身，时干丁来生己土，并且有卯木来生丁火，所以己土得到的生扶之力比较足，故而日干是不弱的。日干辛金得令，且有未土，丁火帮扶，故而为身旺之命，原局金是比较旺的，食神透不喜见丁火枭神，故而丁火是非常不吉的，不过好在丁火离食神比较远，而且有己土相隔，不能构成太大的伤害。

辛金为食神透，但是食神太多了，多了反而成了伤官，有克官的性质。日支酉金为食神，天干也有食神，所以食神多而不利。由于原局金比较旺，所以五行不需要再补金，故而喜水木为用，水为财星可以生官杀，木能制土为吉。

二、八字为**食神格**，这种组合的人都比较适合去做一些技术方面的工作，食神也有服务，咨询，教育方面的信息。所以从事和这些有关的行业都可以。食神透而身旺，则衣禄不错，且做一些和餐饮有关的工作也很适合。

八字时支卯木为七杀星，也代表丈夫。卯木不当令，且被日支酉金冲克，故而对夫不利。而且卯木临空亡，卯木力量本身就减半了，那么更容易被酉金所伤，且原局是没有水来救木，所以金克木，则木受伤非常严重。故而对夫不不利，这种组合代表丈夫不吉，婚姻的确是很容易出现问题的。

未土之中暗藏七杀星，也可以代表丈夫，不过有丑未相冲，则丑中的辛金克了未土之中的乙木，则七杀也受伤了，而且没有解救。所以不旺夫，从自己命格来看，丈夫就不太可能是大富大贵的。如果真的富贵了，那么你也是享受不成了，所以对象平凡普通一些反而是一件好事情，更有利婚姻的稳定和长久。日支为夫宫代表丈夫，日支为金本身为用，但是却冲了卯木，也属于金木相克的八字，不过由于金旺木弱，故而不属于金木相战，卯木是没有力量和酉金相战的，只能被酉金所伤。

食神太多则为伤官，故而伤官旺而克夫，则对丈夫是不利的。一般暗示丈夫运势不佳，或身体健康容易出现一些问题。

卯木来生丁火，丁火来生己土，而丁己为一体，丁下有卯，也代表离婚的几率是不大的，而且日月酉丑半合，不过八字为六冲之命，年月丑未冲，日时卯酉冲，冲合相见，故而运势反复，比较坎坷，并不顺利。

三、至于丈夫八字：【**庚午，庚辰，庚申，庚辰**】。

这个八字属于非常特殊的命局，天干四同四庚，地支双辰一申都是来助日干庚金的，只有年支有一个午火。那么午火为遥克，但是有辰土故而根本不能伤害庚金，反而给辰土提供了能量，从而生了申金，旺了日干。所以午火并不能起到耗克的作用，故而处于无用之地，所以八字为旺极之命。

一般这种特殊命格，要么就非常好要么就会非常差。在太平盛世，八字比较极端的人都不太好过。如果是乱世还有可能是一个英雄人物。在太平盛世时期，八字一定要平和流通，才为好命之人。一般从旺的八字都比较极端，那么人生命运往往也处于两个较大的极端。不过也由于年支有一个午火，所以八字只能算假从，一旦有五行来旺了午火，那么会克年干的庚金，走木火运则由假从到身旺，那么命运就非常糟糕了，因为原局没有一点财星，属于旺而无依之命。

原局辰中暗藏有乙木财星，财在辰土之中，申辰相合，故而也可以得到一些财，所以财运也是有的。在走33岁后走甲申大运，临驿马+偏财会有一些财运。只不过谈不上什么大富大贵。不过比劫克财，往往会通过一些非常手段获得钱财，故而也存在很高的风险，而且这种命格很容易去做一些投机，赌博，或者是欺骗的工作，自己也要多注意才可以。八字申金为庚禄，也代表自己的身体，被两个辰合住，合代表不自由，而且辰为天罗，属于天罗合身，驿马受绊故而有牢狱官非之象。

总之一定要注意我说的问题，切莫为了赚钱而去走偏路，一定要做正当的工作，才可以化险为夷，平平安安。至于后面财也是有一些，但是基本上存不住钱财，而且原局也不见财星。在目前我也是不建议去做什么投资，踏踏实实找份工作是最好的。但是比劫旺的人好面子，不服从管束，所以往往上班是不长久的。比劫旺而不见财星，而且比劫旺的从格并不算好。一般八字从官，从财，从儿是最好的组合。所以能掌握一门技术对自己一生会更好。

而女命八字来看，食神非常的旺，很适合去做护理工作，可以朝这个方向发展，因为这个行业也属于服务行业（食神也代表爱心，也有服务的特性），对你是比较有利。由于你大运走的并不是很理想，所以能有一份稳定长久的工作是最好的。

1、你们八字还是挺合的，用神互补，所以夫妻缘分还是不错。但是由于自身命局之中夫星受冲了，故而婚姻很容易遭遇挫折，自己也要多注意才可以。你八字也为纯阴之命，又为六冲八字，而丈夫八字也为特殊组合，一片比劫不利妻子。夫妻可以说属于对冲，也为硬配。丈夫在走甲申，乙酉大运都是克妻子的，而妻子也不断的来冲克丈夫。这种也属于硬配，换一个人恐怕是承受不住这种冲克的，往往会出现问题，不过你们这样则会好一些。

简单来讲，就是女克夫，男克妻。不过夫妻组合这样反而为吉，属于硬配。故而出现问题的几率会降低不少。

不过各自在婚姻方面都要多注意才可以。特别是丈夫，要更加懂得珍惜。丈夫的八字日支为禄神+驿马，一般妻宫临驿马，都代表妻子勤劳。驿马主动，妻子是坐不住的人。申金被辰合住了，属于马星被绊，往往是内心想动而没有行动。

2、至于工作方面，自己最好是上班为吉。至于丈夫也要做一些相对平稳的工作比较好。不要梦想什么大富大贵，先保障有一份收入再说吧。今年已经28岁了，马上三十了，年龄也不算小了，如果过了30岁后还是浑浑噩噩，自己又没有什么特别的才能，那么想要追求平稳都很难，更不要说大富大贵了。
