# 来信

我一生经历坎坷，曾经有个算命师傅说我八字的业障很重。我经历的灾难太多。我四岁丧母，母亲是乳腺癌去世，父亲在第二年因为对母亲一片痴心，思念母亲而自杀。

然后我和弟弟被大伯扶养，整个童年几乎都是在家暴的状态下战战兢兢的度过，在我小学五年级的时候，婶婶意外车祸去世，我那时候就怀疑我的命是不是克星很重。因为从小没有得到父母亲情关爱，我比较早熟，成年后就把这份对亲情的渴望转移到婚姻上，我出生地在安徽，19岁的时候跟了比我大16岁的丈夫，跟他来到江苏常州，虽然是跨省，其实是交界，路程只要一个多小时。24岁结婚，25岁生了儿子，本以为从此以后有了温暖的家，谁知道灾难还在后头，2005年，儿子三岁那年，丈夫车祸死亡。

我一个人带着儿子生活，接下以前老公留下来的印刷业务，开过棋牌室，我小时候就渴望有个温暖的家，始终摆脱不了这种孤独带来的恐惧感。在2011年认识一个男人，两个人三观合适，相处到2017年，我们商量着为了以后生活的和谐，计划再生一个孩子，可是怀孕六个月的时候产检宝宝染色体异常不得已引产，在引产的过程中大出血抢救过来的。

我在2011年到2014年这四年财运是好的，从2015年开始我的财运就不好，赚的钱投资股票亏损，在自己棋牌室里也输了好几十万，2019年实在是撑不下去把车子卖了。到现在是负债的状态，我这半辈子就是坎坎坷坷，起起落落。

幼年失去父母，中年丧偶，觉得自己命不好，有时又觉得自己是祸福相依的，因为受的都是精神上的打击。我儿子是我唯一最亲的人，我一定要把他培养成人，希望他高考时能够有个更好的学习平台，除了自己能够独立之外希望他能够做一个为社会国家做贡献的人，报答佛祖对我母子的庇佑之恩情。

# 命理提要

一、日干为甲木，在亥水月出生得令，亥水又为甲木长生，月干透出乙木助身，则甲木不弱。甲木坐辰土，而辰为水墓，冬季之辰水气更重，辰中暗藏的癸水和乙木也能生助甲木，则甲木自然不弱。

冬季之木为寒木，水气太重了，故而喜土去制水为吉。且寒木喜火，也喜见丙丁火来暖身。

> 用神：火，土。冬季寒命喜火暖身，也喜火来生土制水，土为财星，身旺可以担财，则喜财旺。
>
> 忌神：水，木。命局水太重则会损火，而木太重则会损土，均为不吉。至于**金则天干可以见，地支不喜，地支见金则会生水，反而不吉。**

命局丙丁不透，又缺金不显，财星混杂，命格一般。女命喜清不喜浊，一旦过于混杂，终究不吉。不管财星混杂，还是官星混杂均为不利。

二、父母居于年上，年为财星则损印，而印为母亲，则母亲不吉。且月支亥水为偏印，同性为母，则亥水为母亲。亥水所处状态非常不好，亥水被未土和辰土夹克，且被时支巳火遥冲，亥水在地支孤立无援。并且**亥水见辰则为入墓，又为财星克印，则母亲多凶。**

财星破印多损母，比劫克财多损父。当然至于结果具体如何，是多病，分离还是死亡等，也要看父母各自的命运，以及因果业力了。人与人相处都是因缘而聚，既然是因为缘，则有缘散之时，只是时间早晚而已。

母亲因病去世，和你的八字是无关的，因为八字只是因果的显示罢了。善因则得好命，恶因则得凶命。亲人的相继离世，也都是自己所要遭受的果报罢了，所谓生离死别之苦，只是你经历的比别人早了一点而已。每个人都会和所有爱我及我爱之人经历生离死别，只有时间的早晚。

三、原局夫也是不显的，年月日均无夫星，时支暗藏一个庚金七杀，不过**庚在巳火当中，也被巳火的本气丙火所克，则庚金受损，故而夫缘很差。**​甲辰日出生，自坐寡宿，一生孤独。​时支巳火为驿马，自然庚金也是临驿马的，则要远嫁才行。不过驿马也代表夫妻分开，聚少离多。最终还是孤独。

四、而求财方面，时支巳火去生己土，甲己相合而能得财。所以命中财运还是很不错的，年柱的财被月干乙木所制，也为劫财夺财，故而破财也是很大。但财星混杂，日支临偏财，则财星比较的多，多则贪心。也会因为贪心而损财。

当自己没有什么依靠的时候，就会把安全寄托到金钱上，想要得到更多的金钱，只有这样内心才能有安全感。但越是如此，往往损失也会越大。你八字有财，且财运不错，但大运比劫夺财，也会金钱损失。如果是做赌博，只会越陷越深，到最后甚至招来更大的灾祸。

# 大运流年

22-32岁走的戊寅大运，戊土为偏财星，引动日支辰土，寅木为比肩，八字不喜见比肩，则为比肩夺财。所以这十年运势并不算好，且寅木为驿马，故而奔波走动很大。

因为你八字不显示夫星，则以日支为夫。日支为辰，辰+寡宿为孤独，女人最怕寡宿，有孤寡的意思。辰为丈夫，则戊也有丈夫的意思，而大运戊坐驿马，则有奔波之象，财星被克也为破财之事。所以从大运来看并不算好。就算有财，也会损失。因为比劫夺财。而且财星被制，也会损夫。八字又不显丈夫，夫缘很弱，很难长久。

32-42岁走的己卯大运，前五年走己土大运，则为甲己相合，也能得财。但进入卯运之后，则为劫财夺财，破财不断。所以前五年还可以，后五年就各种不顺。

在42岁后进入庚辰大运，辰为华盖+寡宿。庚金为七杀，从巳火中透出来，但原局有乙庚相合，也有争合之象。所以这十年要论婚姻也不太好，很难在感情上得到幸福稳定。当然自己越是去追求，也就越难得到。

进入华盖大运，特别是寡宿伏吟，会更加孤独，如果你不能习惯孤独，或主动的去享受孤独，就会因此而非常痛苦。不过这十年结束了比劫夺财，故而求财会好很多。你命中财运是不差的，只不过漏财太厉害了。这都是因为大运比劫夺财导致的。

# 人生建议

人世间的一切，都是无时无刻不在变化着。过去有的，现在起了变化；而现在有的，将来终归消失，这就是诸行无常。

寿命，婚姻，爱情，财富等一切，都是无常，得到了就注定会失去。因为这一切都是因缘和合而成，一旦某一个缘发生了变化，则一切都会发生变化。我们之所以痛苦，皆因不明白无常的道理，就算明白这个道理，也不愿意去相信和接受。无常就是变化，这个世界唯一不变的真理，就是永远在变。我们总是幻想着会有恒常的存在，因为爱而生分别，因为分别而生执着，因为执着而生痛苦。

如果能了解世间的一切均是无常，就不会攀缘执着；如果能做到不攀缘执着，就不会患得患失，也才能真正自在幸福的活着。无常并非就是坏事，因为变好也是无常导致的，但有了所谓的变好，就一定有变坏。因为我们不愿意去接受变坏，总想着永远都去变好，才会有无数的烦恼。

就比如升职也是因为无常，但升职对我们来讲是变好了，故而会因此而感到喜悦。但一旦因为无常而降职了，就会因此而痛苦，因为我们不愿意接受变坏的事实。

生命也是无常，在时间的长河中，人的一生就是一刹那间。从生到死，又从死到生，不断的循环，从未止息。因为有生，就必然会伴随老，病，死。对我们来讲，因为他们是不好的东西，所以我们不愿意去接受，总是选择逃避，当真正遇到过后，而无法坦然面对，生出无量痛苦来。

在佛的眼中，这个世界都是不真实的，一切都是幻象。就如、《金刚经》最后一句话说：“**一切有为法，如梦幻泡影，如露亦如电，应作如是观**”。

和老人聊天，他们最喜欢说一句话就是，过去就如做梦一样，一眨眼人就老了。当我们去回忆过去种种时，不也是如梦一般吗？曾经不管多大的痛苦，多年之后我们再去回想，反而会因为当初的固执而觉得可笑，难道不是吗？点评过去发生的事情，人人都是智者；当处理当下遭遇的事情，则人人都是愚人。

很多人肯定会说啊，道理都是明白的，但当自己真的遭遇一些事情时，就处理不好。其实这一切都是因为无明啊，因为无明，而导致我们做出很多错误的判断，认为这就是对的，其实并没有对错，执着对或执着错，都是烦恼。而无明对应的，就是觉知。唯有觉知，方能解脱。

佛陀的含义，不就是觉悟的人吗？每个人都可以自我觉知，所以佛陀说人人均可成佛。所谓自觉，则为自我觉醒。明白道理而过不好生活，是因为忽略了一个重要的因素，那就是实修。就比如谁都知道清水加热就能烧成开水，但如果不这样去做，永远都得不到开水。读经，放生，拜忏，打坐等都是实修的法门之一，目的就是为了加深我们对一些道理的理解，形成惯性，当事情发生的时候，才不会迷失自己。

我说这么多啊，就是希望你能真正体会到无常的道理。也要时刻去观想万事万物的生灭过程，多去观想生老病死的过程，观想爱恨情仇的过程。当自己总是去如此观想，才能真正体会到无常，也才不会因为变化而痛苦，或不会执着于恒常。

今生所遭遇的一切果，都是过去所种下的一切因。命运越是坎坷，说明自己罪业越重，越要好好修行。有时候，经历一些大灾大难，反而能激发自己寻求解脱的欲望，若能如此，所谓的坏事也未必真的是坏事吧。生命中所遇到的一些人，并非都是来陪伴自己终老的，他可能就是来度化自己的。努力去参透无常的道理，就不会去追求那些变化之物了。

关于命运，了解为了改变。如果知命而尽信命，不如不知。一切都是因果，命运也仅仅是因果的一个显示罢了。执着命运，就会忽略因果，不去改变自己，就永远无法改变命运。

给你几个建议吧：

1.不建议再去生孩子了，好好抚养现在的孩子，其他的都不要多想了。

2.至于现在的感情，一切随缘，能维持多久就是多久。不要去执着这些。有缘则聚，无缘则散，来也好去也罢，一切都是缘，强求执着只会使自己痛苦罢了。因为本身姻缘就差，唯有看淡，才能自在。再说啊，不是还有儿子吗？有时候孤独的并非无人相伴，而是心无所安。

3.至于学习易学，是可以研究的。经历人生苦难之后，才能更了解生命的真义。

4.好好学佛，念佛，让自己的余生做一名清净善良的佛弟子。佛教的八万四千法门，对治我们的八万四千烦恼；唯有努力自修，才能真正根除烦恼，才不会被无明障碍，甚至被错误牵引，才能真正的远离痛苦，远离烦恼。
