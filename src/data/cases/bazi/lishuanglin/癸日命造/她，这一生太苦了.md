# 人生建议

世事无常，人生皆苦。知其苦能生灭苦之心，方能断除一切痛苦。

你一生所遭受的苦，是因家贫人微，又遭坏人欺凌，再又遇人不贤，遭受各种身体与精神的折磨。这一切苦痛，皆由过去所种因而决定。今生来到这个世间，更多的是还债吧。受苦的过程，也是一个消业的过程。

人生就是一场修行，每个人都会承受各种各样的痛苦和烦恼。如果没有痛苦，自己就无法醒悟。要消除这些痛苦最好的办法，就是把每一次苦都当做是修行，当做是上天对自己的考验，若是无法去改变，我们就要学会逆来顺受，而不是与之相抗。因为即便努力的去抗争，到最后也未必就能得到什么改变。把一切苦，都当做自己要偿还的债，就会发现，自己所遭受的苦，也不再是那么的苦了。

佛不度人，唯人自度。要把遭遇的一切坏事好事，或坏人好人，都当做是来度自己的。自己所遭受的每一分痛苦，都能让自己觉悟，而每一次伤害，都是一次渡劫。家庭就犹如一个道场，修行不需要去深山庙堂，而是在红尘中的一分一秒。如果有一天，自己能觉知人生的意义，那么闭眼的这一刻就是净土。我们在这个世界上，因每个人所种因不同，而遭受不同的果，因为各自的业力，而有各自的人生。不论自己遭受多么大的痛苦，不要怨天尤人，应该因受其苦，而更加坚定自己解脱痛苦的决心。很多事情，一味选择逃避并不能真正解决问题，而积极面对，才是正确的人生态度。
