# 人生建议

你说自己结婚后的阻碍和烦恼特别的多，甚至都快得抑郁症了。我们先要知道什么是烦恼，当自己冷静的时候，认真去思考一下自己烦恼的到底是什么？

何为烦恼，即迷惑也，人们因迷惑而造诸恶业，受种种的痛苦。迷惑也就是无明，无明而生无量烦恼。没有智慧去看透看破，就会被一些外在的人事物所牵动我们的心神，让我们生起情绪，给自己带来无量的痛苦。

一切烦恼，都是由六种根本烦恼而引起的。这六种根本烦恼，分别是贪、嗔、痴、慢、疑、不正见。当我们细想一下，自己的一切烦恼，无不是来源于此。如果能从根本断除，则一切烦恼都会消失。

佛学上常说：“智慧长，烦恼轻”。要想自己烦恼变得少一点，就要让自己增长智慧。有了智慧，则一切烦恼都不将是烦恼，一切痛苦也都不再是痛苦。有了智慧，就能去降服这六种根本烦恼，通过勤修戒定慧，而降服贪嗔痴。

要知道啊，每个人都有属于自己的烦恼，当我们去追溯这些烦恼的源头时，都不会离开这六种根本烦恼。如果自己不明白烦恼从何而来，就永远无法消除烦恼。当我们的心很容易就因为外界人事物所影响时，也就注定了烦恼永远不会离去。没有定力，就会因为一句话，一件事而暴跳如雷。嗔恨心，会使我们痛苦。当嗔恨心升起的这一刻开始，也就是地狱报显现的开始。当我们心中充满怒火，就会完全失去智慧，自己的所听所见也皆为恶的。

夫妻相处也是如此，没有豁达的人生观，就算换一个人，换一个地方，烦恼依然不断。娑婆世界就是如此，这本就是一个烦恼的世界，单靠逃避是无法解决问题的。唯有面对烦恼，战胜烦恼，把烦恼转化为菩提，才能让自己生活得更好。

不管是谁使我们痛苦了，我们都心生感恩，若能如此，则能消除心中怒火。把伤害我们的人，当做来磨炼我们的人。人啊，不经历风雨，又怎么见彩虹呢？过去因而造就当下果，但当下因也会造就未来果。不管是过去因还是当下因，都是我们自己造就的，这也就是说啊，要改变这个果，完全可以依靠自己。命运只是一个果，切莫执着沉迷，不然就会因为迷惑再生烦恼了。

婚姻一部分靠过去生的缘分，这个缘有善有恶，但还有一部分是靠自己去经营。就比如得到一颗优良的种子，如果播种到贫瘠的土地且不施肥浇水，也无法长出优良的果实来。再好的缘分，也可能因为自己的错误行为而一手毁掉。反之再差的姻缘，也可能因为自己的努力维护，而变得美好。

人这一生，处处都充满挑战。当遇到烦恼的时候，我们首先要去思考烦恼的根源，是来源于哪个根本烦恼，然后再通过智慧去消除这个根本烦恼，自然烦恼也就消失了。人们总是当下迷，过后觉。遇到事情，当下想不开，过一段时间后，又能想得开。都是因为当下生起了无明的情绪，而侵占了我们的智慧，让我们失去了正确的判断。
