# 命不能乱算，好命都给算差了

命主生辰: 1983/09/20 22:00 (GMT+8)
性别: 坤造
日主: 辛金
格局: 身强
令地: 得令 失地

民间有一句话：“命越算越薄”，这句话并不是说命会被算薄了，而是因为找一些技术不佳或者心地不善的师傅，容易因为他一些不正确的建议，而左右了自己的选择，影响了自己的前程，所以算命真的不能乱找人算。下面我们看看今天这个案例：

# 来信

您好，李双林老师！希望有幸您能抽取到我，帮我看一下以后的发展。我是北方人，但是这十年在南方创业，不算大富大贵，也算小康生活。但是去年开始生意就开始下滑，感觉不太好。这两年我也找了好几个人看风水看八字，得知自己的命不太好，没有财又克夫，晚年也好像不太好，子女也不孝顺。后面也没有什么财运了，说我也差不多就是退休的状态了。所以我也很惶恐，在今年结束了生意回老家，家里父母身体也不太好，想尽孝也想多培养孩子。因为在创业这十年很辛苦，压力也很大，没有太多时间陪孩子。

我和我老公自己在一线城市现在有3套房子，不算父母的房子，还有即将要拆迁的房子。但是好像我命里不该有这些，明年我可能是岁运并临的一年，特别不好，我也担心婚姻家庭孩子出问题，但是目前我们感情还可以的，但是算命算的我害怕。

我想让您帮我看一下，我后面是不是要守住，不要投资？能守住就己经超出本命了？希望您能帮我指点一下，我后面到底要发生什么事情？我怎么可以避免改正？

我的坤造是癸亥，辛酉，辛亥，己亥。我老公是辛酉，丁酉，乙巳，辛巳。

# 八字详批

#### 坤造：癸亥年，辛酉月，辛亥日，己亥时（空子丑、寅卯）

#### 大运：壬戌，癸亥，甲子，乙丑，丙寅，丁卯，戊辰

# 命理提要

一、辛金为自己，在酉金月份出生得令，月令为禄神，属于建禄格，并且天干透辛金，则金是不弱的，金是非常的旺。天干又有土来生金，属于身旺之命。八字金非常的旺，喜水来泄身，木来耗身为吉，所以水木为用神。八字水是很旺的，金水相生，食伤泄秀，属于金水有情之命。这种组合是非常好的。

伤官旺为用神，不喜见官杀，所以八字是不能有火的，有火则会水火相战，格局就很差了。你八字正好不见半点火，就算暗藏的火都是没有的，所以属于食伤旺而不见官杀，为清纯之格。女命贵在清吉，所谓清吉就是纯而不杂，八字为金水两旺之象，且金旺有水来泄秀，并且食伤没有受到伤害，则满盘用神，格局是非常好的，八字可以说是很棒的命。

二、至于这位师傅说你克夫，没有财，子女不孝，晚年不好；理从何来呢？我想有这几个原因：

1.看到伤官旺了，就断克夫。而没有考虑到，八字并不见官杀星，所以伤官旺而不见夫星，怎么能说是克夫的呢？

2.看到没有财星就说没有财运，典型的半吊子断命法，拿起半截就跑。八字的确没有财星，但是食伤为用，且年柱食神透天干，食神为财神，食神也代表衣禄，福气，女命见之大吉。女命食神透而为用，主福禄双全。并不是八字没有财星就没有财运，命局十神财星只是物质的代表，并不是财运的唯一符号。而且在十神财富层次当中，财星的层次是最低的，食伤相对高一些，官杀则更高。按照钱财数量来看，则财星如果是十万，食伤就是百万，官杀为千万。所以如果八字中食伤成局，则格局财富层次更高，如果见财反而普通了。可见不懂命理，害人不浅。

3.至于断子女不孝，我想可能是通过日时自刑来判断的，食伤旺为用神，暗示后代人丁兴旺。但是日时自刑，的确有点不利，主要是晚年。你在66岁后走的戊辰大运，土来克水了，的确有点不利。晚年运势弱点，这点没有断错。至于你的财运都是非常好的，也不存在克夫的情况。

# 大运流年

26-36岁走的甲子大运，属于食神生财，所以财运非常好。水木为用，而这十年正好走用神大运，故而做什么都会比较顺利，即便是过程波折，结果都是吉祥的。

2018戊戌年，在今年土旺克水，并且酉戌穿了禄神，而禄神代表自己，故而今年运气不算好，所以事业停止了。

2019己亥年，和八字一共构成四个亥水，自刑比较严重一些，不是很理想，而且明年和今年都是交脱运的年份，所以这两年变动都大一些。故而你在2018年，2019年都会有比较大的变动。

36-46岁走的乙丑大运，丑为土也是金库，旺了辛金，乙木为财，有制枭神的作用，这十年的运气就不如之前十年顺利了。所以从大运来看，未来十年的确要求稳，守住现在拥有的，保守发展，可以适当投资，但是要保守发展。你原局不错，故而依然有财，只要谨慎点，保守点，不会有任何问题。

46-56岁走的丙寅大运，为财官大运，运气也还是可以的，中年吉祥。不过这十年为空亡大运，有点美中不足。

你八字好就好在原局不错，并且有甲子十年旺运，你在这十年已经积累了足够的本钱，为你的后半生打下了一个非常好的基础。后面的运气虽然弱点，但是只要在这个基础之上，保守点，稳住发展，后面都是非常不错的，将来是非常好的。

你八字食伤很旺，只能做生意，创业，所以你回到老家，依然要以生意投资为主。从八字来看，非常适合做点餐饮、服务、咨询、养殖方面的工作。由于是枭神贴身，则偏门为主。所谓偏门，就是很少人去做的，或者是别人不是很看得起的，不是被大众熟知的行业都为偏门。

人的运势是十年一个大轮回，一个人一生能有十年旺运已经非常不容易了。一般这样的运气，来的早比来的晚好。而你的甲子大运来的非常早，故而可以打下良好基础，后半生靠此已经足以。你的命可以多养几个小孩，对你非常好。八字食伤为用，孩子多则有福。

# 人生建议

1.命运笔于是一副牌，命好则拿到手上的牌比较好。运气是你摸牌的时候能否拿到想要的牌。至于结果，除了要有一副好牌和摸牌的运气，还要看打牌的人是怎么玩的。不要一副好牌，结果打成了一副烂牌，就不值得了。当然保守点并没有什么不好，因为你的命食伤很旺，很容易激进，傲慢，做人一定要谦虚。后面的运气只是不如之前旺，并非就很差。所以相对之前保守点就好，投资永远不要超过自己存款的40%，给自己留余地，并且选择一个可以持续发展的行业，一定会非常好的。

2.你和你丈夫的八字日柱是天克地冲，你丈夫八字为从格，层次也不错，但是运气不如你好，你运气比较好一些，夫妻搭配也能有一番作为。八字不错也代表能力较好，运气好则代表机遇多，可以把握机遇。但是你们八字有冲克之象，所以在一起容易有矛盾，不合，故而也是要注意夫妻感情。日柱天克地冲，要么感情就很好，一旦差就会非常无情和决绝。适合聚少离多的相处方式，平时也要多注意感情。在属猪，属蛇的年份，夫妻适当分开一下比较好。

3.总之你的命运都很好，并非差命，而是让很多人羡慕的好命，运气也挺好的。不要有什么悲观意识，了解了不错就好好的去努力，前途一半是天注定，一半是靠自己，你还年轻，还有大好未来，不要辜负了上天给你的好八字，加油！
