# 人生建议

一定要知道自己想要的到底是什么？命运产生于追求，有的东西我们怎么求都求不到，那么就要学会放下，如果执着于此，就会生诸多烦恼和痛苦。

就比如你的婚姻，如果想要得到稳定，长久，幸福的婚姻，是非常困难的。既然求不得，那就不要去求了。放下对美好婚姻的奢求，也就不存在婚姻结果的好坏。

婚姻就是一场修行，既然是修行就自然不会那么轻松顺利。在婚姻的历程当中，有快乐也有痛苦，有欢笑也有哭泣。自己是否能坚持走到终点，关键还是要看自己的这颗心，是安住在哪里。

如果心住在幸福上，就受不了半点痛苦，稍微有点不愉快，就会难以忍受，这时候宁可放弃婚姻，也不愿意坚持。但如果自己的心能不落在幸福上，也不落在痛苦上呢？就不会因为感情的变化，而生烦恼。

对方好也罢，坏也罢，都是人生的过客罢了。到最后不是你先走，就是他先走。每对夫妻都会经历生离或死别。只是时间长短罢了。若能看明白这一点，又何必去执着对方的一些变化呢？

有的事情是自己必须要去经历的，因为这都是自己要偿还的债。如果对方愿意改变，自己选择原谅，这个事情多年之后也就不是什么事情。一切当时的痛苦，都会随着时间的推移，而慢慢消除。

一定要明白无常的道理，因为这个世间没有任何东西是不变的。要放下小我，就不会总是因为一些事情而伤害到这个我。当这个我都不在的时候，又谁来受这些痛和苦呢？

当然要一下子做到这些非常困难，所以我们才需要修行。通过自修，来慢慢改变自己，让自己一步一步的走向觉悟。当自己有所觉后，就不会因为外境的改变，而生情绪，生痛苦。心就能真正的入定，如如不动了。

没有谁的人生是一帆风顺的，古人云：“人之命运，不顺者十有八九”。佛陀讲，人生即苦。有时候想想，还真的是苦。要想消除这些痛苦，并非是无尽的追求外境的满足，而是追求内心的满足。看淡，放下。简单的四个字，虽难做到但能做到。关键是看自己，是否愿意去修，愿意去改变。有了智慧，一切痛苦都将烟消云散。所以外境我们很难改变，人定胜天只是大多数人的一种美好愿望。因为真正能胜天的又有几人？

唯有改变自心，要学会内求，方能熄灭诸苦。不会因为变化，失去，求不得而痛苦。
