# 负债百万，什么时候可以还清

命主生辰: 1987/08/06 20:00 (GMT+9)
性别: 乾造
日主: 丁火
格局: 偏弱之命
令地: 失令, 失地

# 网友来信：

成年后丁亥年当兵入伍山西大同，辛卯年调回唐山，我是后知后觉的人，以前都没想过以后工作问题，后来发现在部队干部和战士转业后有很大区别，在甲午年想转变成干部，但为时已晚，总感觉差一步。乙未年选择了退伍，自己考公务员。经过这六年的考试，目前也没有达成所愿。

壬辰年到现在炒过股，和家人开过饭店，和战友开过车辆租赁，一起开过店等等，都以失败告终，现在背负银行，个人债务不到100万。

丙申年到现在单位上班至今，目前没考上公务员还是临时工，己亥年结婚，当年小孩出生。庚子年债务危机，辛丑年全面逾期，这几年过的日子太艰难，还好我媳妇虽然看我这样生气，但还没有离开我，也几次帮我。

> 分析下几个问题
>
> 1、我喜用神是什么，以后可以在生活上多倾向于用喜用神。
>
> 2、我什么时候能把债务都还完，现在日子过年很艰难，也愧对父母媳妇孩子，想尽快翻身。
>
> 3、我能否当上公务员，或能否有稳定正事的工作。

# 八字详批：

#### 乾造：丁卯年，丁未月，丁亥日，庚戌时（午未空）

#### 大运：丙午，乙巳，甲辰，癸卯，壬寅，辛丑，庚子，己亥，戊戌，11岁运。

# 分析命局：

丁火日主生在未月失令，未土的本气为己土，主要起到泄身之用，未土为热土，暗藏丁火，有一定助身之用，坐亥水失地，而年支卯木是生扶日主的五行，地支亥卯未三合，但合而不化，而且卯木又被合拌难以助身，地支戌未相刑，泄身力量较强，年干和月干丁火来帮身，时干庚金来耗身，为偏弱之格。

# 分析喜忌：

丁火日主偏弱，以生扶日主的木火五行为用神，以泄耗日主的土金五行为忌神，五行水虽然克身，但在地支生木为吉。天干喜见木来生火，由于乙庚相合，相对而言，更喜见甲木，天干也可见火来帮身，地支土旺，也喜见木来疏土，火来助身的同时也会生土，非为最吉。

# 分析事业：

丁亥日出生，日坐亥水为正官，丁亥暗合，事业心较强的一个人，地支未土食神当令，地支戌未相刑，把土冲旺，食伤较旺，也代表野心和欲望不小，另外一方面也代表想法较多，较难专心于某个领域。而地支伤官克官，做一份工作久了很容易厌倦不满，对人对事挑剔，内心不太安分踏实，也有一些浮躁，为不利事业发展的地方。

年干和月干丁火比肩帮身为用，地支亥卯未三合，代表人缘不错，人比较讲义气，也可以得到他人相助，但丁火是从月令未土和时支戌土中透出来的，未土空亡，以年柱为太极点，戌土也空亡，因此丁火比肩也跟着空亡，代表贵人不实，也就是说虽然别人对自己有帮助，但真正需要出力的时候就不行了，难有实质性的帮助，更多还是要靠自己去打拼。

时干庚金正财透出，地支没有财库，庚金坐戌土燥土之上，有脆金之象，也代表为人是较为慷慨，对钱财缺乏一些观念，理财能力缺乏，开支花销大，不聚财。

时干庚金为正财，正财入门户，代表可以得到这个财，也代表是依靠上班所得的钱财，而戌土虽暗藏辛金偏财，但戌未相刑，辛金有损，所以没有太多的偏财运，想要去求偏财快财得不到，反而容易破财。

结合大运来看，现在走的甲辰大运，天干甲庚相冲，财星逢冲，地支卯辰相害，卯木受损，财运一般，容易破耗，转癸卯大运，和壬寅东方木运，运势尚可，财运会有一定提升，有望改善经济窘境。

日支亥水正官可代表事业，财官印全，适合上班，但原局虽然有庚金财星，却不能直接生助到亥水，而且亥水左右被未土和戌土夹克，地支伤官见官，这些组合都是代表事业运不强的信息，想得到正式体面、稳定的工作较为困难，也有事业变动多、容易犯口舌之象，即使能考上公务员，也较难进入理想的部门或岗位，升职有局限性。况且伤官克官的组合，也代表自己适应不了这样的工作氛围，自己自难适应，很难坚持下去。

你现在走的是甲辰大运，天干甲木正印透出，但和庚金财星相冲，和命局卯木正偏印同见，印星不纯一般也代表学习三心二意，容易分神，在学习上难有好的收获，学习效果也不好。地支卯辰相害，损了卯木印星，也代表考学运不太理想。能考过的概率不大。

目前情况来说，一方面要降低标准，加强努力，另一方面，现在的单位可以继续干下去，可以尝试去在工作之余学习一门过硬的技术，未来进一些大一点的企业或平台为好，到了壬寅大运，有机会工作稳定下来。

# 分析大运：

**31岁—40岁**

甲辰大运，此大运地支辰土被天干甲木盖头，甲木正印和卯木偏印构成正偏印同见，学习孕事不好的，学习效果也是事倍功半，地支卯辰相害，卯木印星受损，也代表考学运不太好，公务员较难上岸。而卯木印星受损，天干甲庚相冲，财运也不太理想，容易花销破耗。

**41岁—50岁**

癸卯大运，此大运行水木，天干癸水七杀透出，和命局构成官杀混杂，事业运依然不强，容易发生变动，不太稳定，地支卯戌相合，伤官有制为吉，总体财运有所提升，收入有增加，加强努力，多付出，有望缓和负债问题。

**51岁—60岁**

壬寅大运，此大运行水木，天干壬水官星透出，且在地支有亥水根，总体事业运有所提升，丁壬相合，正官合身，事业趋于稳定，不过，天干三个丁火争合壬水官星，事业上也有竞争，能平稳过渡为好，好在丁火被合拌，庚金财星得到解救，地支寅亥相合，总体财运尚可，可安度晚年。
