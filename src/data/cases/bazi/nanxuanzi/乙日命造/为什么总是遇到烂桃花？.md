# 分析喜忌：

中和偏弱以生扶日主的水木五行为用神，以泄耗日主的火土五行为忌神，金虽克身，但在地支生水为吉。地支申金和酉金较旺，喜见水来泄金之力，地支有亥水，也喜见木来作根。天干喜见水来生木，单独见木，木来旺火，且金木相战，有所不利。
