# 网友来信：

小的时候家里穷，奶奶腿脚也不好，爷爷常年打药，大姐自小脑瘫不能动，常年母亲照顾，二姐在我八九岁的时候去当了跆拳道运动员，因为经常出去打比赛，所以父母经常给我姐姐打钱，使的家里更加拮据，有几次家里都没有钱了，出去借钱给姐姐，当然我姐姐也得了很多奖牌，后来她工作了，跟人打架赔了很多钱，让我也很不放心，小时候上学因为长的小天天被欺负，再加上我父亲还给我起了一个电视上，经常能听到的名字，所以经常被人嘲笑，导致我非常的自卑，因为那时候家里穷，就想着赶紧出去打工挣钱补贴家用，初三的时候吧，就像钻了牛角尖一样，上课听不进去，还被同学嘲笑名字，觉得活着没意思，内心总是反复责怪自己，内耗严重，睡不着觉，早醒，有些抑郁情绪，还总是招zang东西。

一度想要自杀，有一次想的最强烈的时候，我爸在医院陪我爷爷，他感应到了，心难受，头晕脑胀的，给家里来了电话，我妈妈把我觉得活着没意思之类的事跟他说了，后来去读了个中专航空铁路那方面，每隔一段还是会焦虑，在北京实习每天都是一样的重复着没有意思的工作，后来辞职，五月中旬的时候回到家，想给眼睛做一个斜视手术，医生不准让带镜子矫正。

做完手术以后，父母找舅舅舅妈给我找人安排一个跟我所学对口的工作，但是我内心十分纠结，我不想父母，因为我欠别人人情，他们真的已经年老一把年纪，还要因为我而求人，而且我觉得我没有那个能力可以胜任那份工作，没自信，我想自己出去打点工，攒到一定的金额了就回家陪父母，虽然不太现实，但我的确有这个想法。

我自己都觉得奇怪，也没有经历什么大风大浪，就是不想活着，觉得活着很累，没有意义。怕死后，父母年老没人管，再受到邻居朋友的非议，所以一直没有去做，再加上我也很好奇，我以后的人生会是什么样。

# 分析事业：

年干甲木为用，但甲木被申金戳脚，为忌神制用，用神无力，月干癸水也为用神，癸水得酉金生扶不弱，为忌神化用，用神有力，也为“一权当贵”的组合，为吉利之处。

地支酉金七杀当令较旺，年支又见申金官星，官杀较旺，乙庚相合，乙木日主去合了正官，事业心较强的一个人，虽有月干癸水来通关生身，地支巳火来制官杀，但官杀的力量较强，还是体现为精神压力较大，容易有思想包袱，在学习生活和工作上并不轻松，受到很大限制，忧虑忧愁比较多，容易往坏处想，较为胆小懦弱，缺乏魄力，做事犹豫不决，有时候性格也比较极端，对外人还能隐忍，对熟悉的人容易急躁冲动，耐心不足。

乙木日主在地支无强根，又官杀较旺克身，也比较没有主见，做事不够坚持，遇到困难扛不住压力，容易打退堂鼓。官杀较旺，乙庚相合，正官合身，做事一般比较讲原则，给人感觉有正直正派的一面，但也体现为性格上的死板，而地支巳申相合，伤官克官，内心也有叛逆的一面，可以说有的时候自己也比较矛盾，容易内耗严重。
