# 印星多且旺的人

命主生辰: 2003/09/26 0:00 (GMT+8)
性别: 坤造
日主: 壬水
格局: 正印格
令地: 失地, 得令

# 网友来信：

从小父母便对我寄予厚望，虽家庭并不富裕，但努力给我创造良好的教育环境，我自小成绩也很优秀，在班级中名列前茅。但进入高中以后，总是达不到理想的高度，让我感到气馁，人际交往也处理的并不好，时常感到与同学们格格不入，孤独感和自卑感笼罩了我整整三年。后来高考试卷难度骤升，我发挥失常，进入了本地一所二本院校。高考后的那个夏天我终日以泪洗面，无法接受这个事实。

进入大学以后，和同学们相处的非常融洽，早已不复往日的自卑，但还总是不甘心这一结果。如今已入学半年，但高考失利这件事依旧像一根隐刺扎着我。但我深知，自己已无退路，只好向前进。如今开始学习雅思，为未来出国读研做准备，也在做一些可以提高自己能力的兼职，积攒工作经验。

在恋爱这方面我也是小白，我将自己归为不开窍，因为这么多年来不但不懂怎么与男生交往，连对某个现实的人动心都是从来没有的事情。虽对恋爱不太热衷，甚至有点抵触，但看到身边的人都投入到恋爱之中，面对自己的情况还是有点怀疑和不解的。

我自己还是一个事业心比较强的人，从高中毕业就开始兼职赚钱。自小家庭经济状况就比较拮据，所以钱能带给我莫大的安全感，最开心的，就是兼职结束发工资的时刻。但如今社会就业压力巨大，我常常想从现在就为未来做些准备，却不知从何下手。

> 想问先生的是:
>
> 1、我适合出国读研吗，也许会去马来西亚、中欧、南欧等花销较低的国家，如果可以的话，可以留在当地工作吗？
>
> 2、我未来的事业和财运如何呢？
>
> 3、我未来的婚恋状况如何呢,婚姻是否顺利？

# 八字详批：

#### 坤造：癸未年，辛酉月，壬寅日，庚子时（辰巳空）

#### 大运：壬戌、癸亥、甲子、乙丑、丙寅、丁卯、戊辰、己巳，6岁运。

# 分析命局：

壬水日主生在酉月得令，坐寅木失地，月干透出辛金来生扶日主，时干庚金也是生扶日主的五行，时支子水来帮身，子水为壬水日主的羊刃，帮身力量较强，并在年干透出癸水，也来帮身，年支未土来克身，但未土来生酉金，反而间接助身，壬水日主在天干得势，加上命局“我党”大于“异党”，依然为偏旺之格。月干辛金正印从月令酉金中透出，为正印格。

# 分析喜忌：

偏旺以泄耗日主的木火五行为用神，以生扶日主的金水五行为忌神，土虽克身，但在天干地支生金不吉。地支酉金当令，喜见火来克金，但火来克金的同时也会生土，所以也同时喜见木来疏土。天干金水两旺，喜见火来制金，木来泄身。

# 分析学业和事业：

原局为正印格，月柱辛酉干支一气为印星，时干庚金也为印星，印星有保护的意思，印星贴身的人，能够得到身边人的疼爱。

但印星多且旺，就好比是保护过度了，这不让你做，那不让你做，所以印星旺没有制化的人，做事也容易顾虑多，怕这怕那，犹犹豫豫，然后什么都不做，做事比较保守，求稳，魄力不够，宁愿一成不变，也不愿意求新导致犯错。

也因为保护过度，容易以自己为中心去考虑问题，养成依赖心，容易依赖别人，缺少对自己的长远规划，容易依赖别人的心理，也容易缺乏安全感，难免会有些自卑。

壬寅日出生，日坐寅木为食神本来为吉，但食神泄秀力量太弱，又被酉金印星所制，食神代表开心快乐，才华才能，被制则代表让自己开心的阀值比较高，容易闷闷不乐，很难真正的开心，同时也代表做事思维不够灵活，欠缺灵敏，所以在考学方面也打了折扣，加上正偏印同见，也代表容易三心二意，不够专心。

月柱辛酉干支一气为正印，地支未土来生酉金，为官印相生的组合，一般为人都比较正直正统，官印相生流通生入日主，有一定事业心，但印星太旺，也有一些固执，容易钻牛角尖，遇到一些事情，容易反复在心里纠结，自尊心较强，比较好面子，心理承受能力不够强，不够大度，容易给学业和事业带来不利。

正印格，时干又见庚金偏印，正偏印同见，印星为忌，不见财来制印，故整体考学运并非太理想，多考取比较二流的学校，较难上重点，尤其日支寅木食神为用，但被酉金所制，也代表才华较难完全施展出来，即使学到很多东西，上了考场也很容易发挥失误，发挥不出真实水平。

你现在走的是癸亥大运，干支一气为比劫，代表学业和事业上竞争较大，容易遇到强有力的竞争对手，把自己比下去，

2023癸卯年，地支卯木伤官泄秀，但卯酉相冲，故考学运一般。2024甲辰年，天干甲木食神透出，2025乙巳年，天干乙庚相合，庚金被合拌，印星纯净，且地支巳酉半合，财星克印，考学运稍好一些，有提升学历的想法，要把握住这两年。

至于出国留学一事，没有太明显出国之象，不过壬寅日出生临金舆，且印旺为忌，能离开家乡也为吉，出生地的东方，南方，东南方比较旺你。马来西亚、中欧、南欧三地，中欧和南欧在你出生地的西北方，不是有利你的方位，马来西亚在南方，属于利你的方位，可以考虑。

印星旺，壬寅日出生，日坐寅木食神为用，未来能往教育、文化、技术等方面发展为好，地支官印相生，八字为正印格，未土官星临国印贵人，也非常适合上班求财，不过不见财来生官，官星无力，也代表事业运不太强，所以能走职称、技术路线等较好，尤其地支寅木暗合未土官星，更加代表如此。

财星藏而不显，可以寅木食神为财，壬寅日出生，日坐食神为用，代表可以衣食无忧，但寅木被酉金所制，也代表难见大财，能满足于一般的财为好。现在走的癸亥大运，运势一般，未来的甲子、乙丑、丙寅大运，会逐步变好，事业也有发展的机会。

# 分析婚姻：

原局不见财星，唯有年支未土暗藏丁火正财，日支寅木暗藏丙火偏财，藏而不显，且地支子未相害，未土和暗藏的丁火有损，女命财为情根，无财或财弱，代表在感情上不解风情，有时候可能别人已经在暗示自己了，自己却领会不到，让对方以为自己无意，打了退堂鼓。或者说的也已经比较清楚了，自己又没有什么感觉，后知后觉，对感情不那么上心，有些木讷。印星旺比较注重精神世界，注重感觉，对感情也会有些被动，比较保守等。

时支子水为桃花，临红艳煞，代表身边还是有一定异性缘分的，只不过，烂桃花也多一些。年支未土为官星，可以代表丈夫，官星在年，代表未来丈夫多为外地人，上班之人，不见财来生官，且子未相害，未土有损，代表不太助夫。原本婚姻宫寅木食神为用神为吉，但因为被酉金克制，导致打了折扣。

2026丙午年，地支午未相合，未土官星被合动，2027丁未年，财官相生，地支未土夫星出现，这两年有遇到缘分的运气，要好好把握。2028戊申年，寅申相冲，红鸾星入命，有结婚的运气。

# 分析大运：

**16岁—25岁**

癸亥大运，此大运干支一气为比劫，比劫来助身，故整体运势不太理想，学业和事业上竞争较大，容易犯小人，也容易错失良机，自己不易把握住，好在寅亥相合，旺了寅木食神，也有机会提升学历和文凭，要自己主动把握为好。

**26岁—35岁**

甲子大运，此大运天干甲木食神透出，食神泄秀，故整体运势要稍好一些，可以施展才华，做出成绩，事业上有一定机遇，自己可以把握住，也可以得到贵人相助，但地支子未相害，代表事业上竞争还是不小，也要注意口舌是非之事。

**36岁—45岁**

乙丑大运，此大运地支丑土被天干乙木盖头，为伤官克官的大运，且地支丑未相冲，夫星逢冲，此大运要注意夫妻关系，易有不和，夫妻之间也容易聚少离多。好在天干乙庚相合，庚金偏印被合拌，印星纯净，故事业运尚可，有升职发展机会。

**46岁—55岁**

丙寅大运，此大运为食神生财的大运，天干丙火财星透出，丙辛相合，辛金印星被合克，地支寅木食神泄身，故整体运势依然不差，有升职发展机会，贵人运好，收入有所增加，较为理想。
