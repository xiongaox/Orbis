# 分析命局：

己土日主生在子月失令，坐未土得地，年支未土来帮身，但地支子未相害，未土有损，帮身力量不强，时支午火来生扶日主，但子午相冲彼此消耗，整体命局生扶力量因为失令不是太强，年干辛金来泄身，月干和时干庚金也是泄身的五行，但依然为身弱之格。

# 分析喜忌：

偏弱以生扶日主的火土五行为用神，以泄耗日主的金水五行为忌神，五行木虽克身，但在地支生火为吉。八字子水当令较旺，地支喜见土来制水，也喜见火来生土，天干金旺成势，最喜见火来克金生身，单独见土，虽可帮身，但也来生金不吉。

# 分析事业：

年支和日支未土为用，但地支子未相害，子水当令，未土有损，帮身力量较弱，时支午火也为用神，但子午相冲，午火也被削弱一些，为忌神制用，用神受损，为不足之处。

天干见两个庚金伤官，年干辛金为食神，食伤的人有奉献精神，容易为他人着想，加上地支比劫旺生食伤，官杀藏而不显，也比较喜欢自由，不喜欢被约束管束太多，自制力一般，也有些叛逆，有时候容易任性，冲动，比较喜欢新鲜事物，不喜欢按部就班。时支虽然有午火，但被子午相冲，命局五行火力量弱，有时候做事情容易缺乏积极性，且热情度不高，己未日出生临华盖和太极贵人，内心比较喜欢安静。

食伤透出在日干左右容易胡思乱想，思虑较多，也会因为想得太多让自己烦恼，也比较追求精神享受，寻求精神上的满足，不仅仅满足于物质。天干食伤透出为忌，人也有傲慢的一面，有时候容易自命不凡，目中无人，也有一定虚荣心和自尊心，月柱庚子，伤官生财，也代表求财的野心和欲望较强，比较注重物质。

不过时柱庚午，庚金伤官有午火印星来制，己未日出生临华盖，也比较聪明机灵，有一定领悟力，加上子水偏财当令，也代表情商不低，有圆滑的一面。己未日出生为六秀日，一般也代表比较聪明和相貌俊秀，一般长相不差。

己未日出生临华盖和太极贵人，年柱也临华盖和太极贵人，时柱庚午，庚金伤官有午火印星来制，故从事医学是适合的，可以在该领域施展才华，做出成绩，故可以坚持下去，午火印星入门户，能在大的平台上班为好。

你有换工作的想法也可以，但建议是继续从事医学相关，你现在走的是癸卯大运，地支卯木旺了午火，整体运势不差，2025乙巳年，2026丙午年，行南方火运，运势较好，这两年会有一些不错的机会，可以好好把握。

月柱庚子，伤官生财，子水财为偏财，也有经商的信息，但也要等待时机，49岁后进入乙巳大运，丙午大运，那个时候去做比较适合。

而月令子水为偏财，虽得庚金伤官生扶，财有财源，但子水空亡，财空易散，又地支子午相冲，子未相害，子水财星受损严重，故也代表花销较大，容易财来财去，尤其子午相冲，财星来冲克印星，也代表容易因为父母、身体、房子、车子等而花销。

# 分析婚姻：

月令子水为偏财，女命财为情根，加上己未日出生临八专，代表情欲较重的一个人，容易动情，但也容易感情受伤，天干庚金伤官透相随，在择偶上也有自己的标准，在婚姻感情上会有些理想完美主义，容易挑毛病，相处久了难免会对另一半挑剔不满，发生矛盾，是要注意的。

而且天干食伤旺，天干出现官杀的时候会被食伤克，地支又有午火印星未土比肩，地支出现寅木卯木官杀的时候，也容易被合，不利于感情落实。

原局不见官杀，唯有地支未土暗藏，未土为官杀墓，未土伏吟到婚姻宫，地支子未相害，婚姻宫受损，代表容易经历失败的感情或婚姻，年柱和日柱临华盖和太极贵人，也为不利的体现，但好在地支午未相合，婚姻宫先害后合，代表往后婚姻相对和顺。

以食伤代表子女，天干见庚辛金食伤透出，故理论上有两儿一女，时柱庚午，庚金伤官有午火来制，午火临天乙贵人，代表未来子女发展较好，不过，地支子午相冲，午火被冲克，且子未相害，在备孕上也易有不利，能做好调理为好，逢猴年和鸡年选择备孕较为有利，逢牛年和马年不宜备孕，要尽量避开。
