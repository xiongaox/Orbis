# 八字详批：

# 分析命局：

己土日主生在巳月得令，坐巳火得地，年支和时支巳火伏吟来生扶日主，巳火为己土日主的羊刃，生扶力量较强，时干己土来帮身，唯有年干辛金来泄身，但年柱辛巳暗合，辛金被巳火合克，泄身力量不强，月干癸水来耗身，但癸水坐巳火之上虚透，且辛金元神被制，耗身力量不强，故为偏旺之格。

# 分析喜忌：

己土日主偏旺，以泄耗日主的土金五行为用神，以生扶日主的火土五行为忌神，木虽克身，但在地支生火不吉，在天干可见。地支四个巳火伏吟，火势太旺，虽然喜见水来制火，金来生水，但不喜见亥水，构成巳亥相冲，较为不利，而且原局巳火太旺，容易触犯火怒，也会越冲越旺，反生不利，故地支不宜见亥水，子水稍好点。

# 分析事业：

巳火当令较旺，地支见四个巳火伏吟，地支一片火，火旺成势，火炎土燥，由于年干辛金来泄身，年干月干辛金癸水，金水来耗身制火，所以构不成一气专旺格，虽然有辛金和癸水来调侯，但力量太弱，整体命局有一些偏枯，且辛金和癸水受损无力，忌神力量太过强大，虽然原局非贵格，若行金水运会较为顺遂，但行火运亦不差，这个后面会作说明。

地支四个巳火伏吟，天干己土伏吟，伏吟较多，主慢，代表迟缓，加上年柱辛巳暗合，印克食神，会导致性格比较固执死板，在变通性上较为缺乏，不够灵活，反应容易慢一拍，智慧不开，很难施展才华，即便学到很多知识和技能，也很难很好发挥出来，在考学上造诣不会太高，也很容易错失良机。

地支巳火伏吟较旺，同时又都是正印，印星太旺，内心会体现出保守的一面，遇到事情容易想得多，顾虑多，自我设限，做事不够坚持，依赖性强，缺乏魄力，而错失一些机会。同时命局五行火炎土燥，性子偏急，容易冲动，有时候也容易走极端，是要注意的。

天干辛金来生癸水，为食神生财，但癸水财星在天干虚透无力，为虚浮之财，且地支没有财库，辛金虽为财源，但年柱辛巳暗合，辛金财源被制，财富等级不会高，也难见大财，且多为财来财去，很难聚财，赚到的钱会因为各种原因花出去，但小财是可见的。

食神生财，食神和财星为用，且五行火旺为忌，适合从事技术，服务，餐饮等相关工作，无限性喜金水，也适合学习金融、法律、财会等方面工作，尤其地支四个羊刃，日时临国印贵人，从事法律方面工作是比较好的，可以在一定程度上化解羊刃太旺带来的不利。

《相心陚》中讲到：金神贵格，火地奇哉，有刚断明敏之才，无刻薄欺瞒之意。柱中有火，不行火乡难发，原局火无力，逢火运显贵。另外也有“金神遇火，威镇边疆，但忌见刑冲破害”的说法。
你的命局日时均临金神，还是有一些福气的，但具体还是要看用神运势是否有力。也从另一个层面说明很适合偏武职的行业，能有机会选择大学生入伍，投笔从戎，或者有机会能转国防生，会有一些发展的机会。

只可惜的是，结合大运走势来看，一路走的官杀、比肩、财星大运，行财运在喜忌上较为有利，不过51岁后进入丁亥大运，地支巳亥相冲，羊刃逢冲，金神逢冲，不太理想，影响格局层次。

# 分析婚姻：

原局不见正财，只有月干癸水偏财高透，天干辛金来生癸水，为食神生财的组合，财星较为纯净，对待另一半比较关心爱护，内心也比较渴望感情，印星较旺，有时候在感情上有一些优柔寡断，容易钻牛角尖。辛巳暗合，癸水虚透，难找到各方面满意的对象，另外癸水滴水斗火，坐巳火羊刃之上，妻星元神受损，也要注意妻子身体健康。

命书中讲到：天干一字连，孤刑祸绵绵，地支连一字，两度成婚事。首先我们要知道，任何断语都要结合具体组合情况下定论。这句断语之所以这么说，有一定的道理。
因为不管天干一字连，还是地支连一字，这样的命格多五行之气不太平衡，人生多有难如意之事，而且地支四个伏吟，本身就有婚姻感情反反复复，容易遭遇失败感情之象。
