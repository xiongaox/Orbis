# 网友来信：

小时候，父母挣钱养家压力大，为了方便，他们带哥哥，爷爷奶奶带我。因为我比较乖巧懂事，做事有计划，所以父母很少为我操心，主打放养式教育。也可能是因为生活时间短，沟通少，我不太主动给他们打电话。现在父母年龄也大了，我意识到儿女要主动打电话多问候，现在聊的时间久一些。和我哥基本不打电话，他已经结婚有娃了。

我学习还不错，高中从县城去省会上学，大学在省会211师范类就读，获得挺多奖学金。毕业后很想留在省会，但没能留住，最后签约省会隔壁的地级市，在一所重点公办高中当老师，已工作5年，工作期间又读了在职教育硕士。

对待工作，我会尽力而为，不求事事做到最好，但结果也不能太差。我也希望得到别人的认可，但是反馈比较少。工作学校管理太严格，老师们几乎没有生活。疲惫至极，会想除了当老师，还能干什么，好像什么也干不了。

恋爱上，大学和高中同学在一起，男友在外省求学，目前已经异地恋8年。两个人感情很好，啥事都有商有量，基本不吵架。有时间了就会一起去旅游。大学时男友家里知道我两谈恋爱，是反对意见，当时反对的理由是觉得我眼界窄，面相不大气。现在时间也长了，他妈妈柔和了，他爸态度不明。两个人还没正式见过家长，不过打算把这事提上日程。

> 以上是我的个人经历，主要涉及到原生家庭，学业工作和恋爱结婚这几个方面。现在我的问题是：
>
> 1.工作方面，教育行业是否合适我？如果不转行，继续深耕下去是否有好的发展。如果转行，有没有适合的行业？我个人对心理学，人际关系还挺有兴趣。但是不知道是否能以此为营生。同时自己也想搞个副业，多挣点钱，这辈子财运如何？
>
> 2.恋爱结婚方面，男友读博结束后想去江浙沪发展，比回老家发展好，而我目前是在北方。所以依旧还是要解决异地这个问题。那和这个男友是否能走到结婚？何时结婚比较好？
>
> 3.子女和本人健康方面，时柱神煞有流霞，且时柱空亡，都说不利于生育子女，和子女关系淡薄，晚年会孤独。是否真是这样？如果真的想要孩子，有什么建议？本人3年也骨折了两次，是不是因为命带流霞，经常有意外？如何减少意外？
>
> 4.解析问题：若时柱空亡，对命局有何影响？我的命格属于七杀格？还是伤官格？查询庚子日柱也是下等日柱，对于原命局，为趋吉避凶，日后应该注意什么？

# 分析喜忌：

偏弱以生扶日主的土金五行为用神，以泄耗日主的水木五行为忌神，火虽克身，但在地支生土为吉。寅木当令，得子水生扶较旺，喜见金来制木，但金来制木的同时也会生水，故也同时喜见土来制水。天干喜见土来通关生金，也喜金来帮身。

# 分析事业：

月干庚金为用，但庚金坐寅木之上虚透无力，且被丙火所制，为用神无力，时支辰土也为用神，但在地支孤立无缘，且空亡，难以直接得到丙火生扶，力量较弱，好在时干庚金坐辰土之上有力，且没有受损，为吉利之处。

原局为七杀格，年干为丙火七杀，年支和日支为子水伤官，丙火被子水戳脚，子水被辰土所制，七杀和伤官均有制，且时支辰土临华盖，故而比较聪明伶俐，有一定领悟力，年支子水临月德贵人，内心相对比较仁慈善良，身弱以比肩为用，同时五行金主义，一般懂得团结他人。
