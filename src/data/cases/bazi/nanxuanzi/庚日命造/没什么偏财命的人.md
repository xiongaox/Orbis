# 没什么偏财命的人

命主生辰: 1993/06/28 10:00 (GMT+8)
性别: 乾造
日主: 庚金
格局: 偏旺之命
令地: 失令, 得地
神煞: 魁罡

# 网友来信：

我是个北方的男生，从小家里有点偏爱吧，高中还曾一度叛逆休学、复读。直到癸巳年家里突发变故，父亲突发疾病离世，突然就好像失去了一切，母亲只能打多份工，补助还在上研究生的姐姐和即将上大学的我。那时候母亲总说，等姐姐研究生毕业就好了。大学里我很努力，各种比赛、学生会、拉赞助，忙碌充实。

丁酉年我大学毕业，尝试过创业，最后亏本收场。戊戌年我就选择了去北京找工作，毕业那会找的一个女朋友，后来因为异地和经济原因，庚子年的时候也分手了。赚钱心切的我便开始尝试炒股，最后不但仅有的那点存款归零，甚至还负债了。

辛丑年我又换了一份工作，来了一个南方的城市。入职半年，还在公司楼下发生了车祸。这是一家从0到1的公司，前期工作强度很大。车祸休息了一个月就回归岗位，经常熬夜加班，后来发生过几次加班加到心脏痛送急诊的情况。但是在这个公司，发展一直不是很顺，直属领导还有意排挤。

壬寅年我遇到了现在的女朋友。我很珍惜，也想在这个城市扎根，但是面临买房、养家糊口，没有家底的我又着急了。7月做了一个车祸遗留问题的手术病假在家，趁着有空闲时间，我又进入了股市，又亏了一笔。现在我开始质疑自己是不是没有偏财运？买什么亏什么。两个月病假结束后，我返回岗位，直属领导提出来协商解除合同，但因为工伤没有办结，领导更是强制要求我继续请病假，直到工伤办结，领了补偿金走人。在工作上，我有自己的志向，也想多赚点钱，可以让母亲和姐姐也能轻松点。

> 我想问几个问题：
>
> 1、我从事互联网行业，这个行业是否适合我？南方的城市是否适合我？
>
> 2、我未来的工作发展会怎么样？收入和经济水平，我是不是没有什么财运？
>
> 3、我现在的女朋友是我的正缘吗？什么时候有机会结婚？

# 分析命局：

庚金日主生在午月失令，坐辰土得地，月干戊土来生扶日主，年干癸水来泄身，天干戊癸相合，合而不化，癸水泄身力量不强，年支酉金来帮身，时干透出辛金，也是帮身的五行，时支巳火来克身，但地支巳火和午火旺了辰土，反而间接助身，故依然为中和偏旺之格。

# 分析喜忌：

中和偏旺以泄耗日主的水木五行为用神，以生扶日主的土金五行为忌神，五行火虽克身，但在天干地支生土不吉。八字午火当令较旺，火旺生土，地支喜见水来制火，同时也喜见木来疏土。天干喜见木来疏土，也喜见水来泄身。

# 分析事业：

年干癸水为用，但天干戊癸相合，合而不化，癸水被合克，为忌神制用，用神无力，为不足之处，而且五行喜木而不见木，土旺没有制化，也为不足，但好在癸水坐酉金之上有力，也为忌神化用，为吉利之处。

庚辰日出生，临魁罡贵人，又午火正官当令，劫财较旺，人比较要强，加上癸水伤官透出，性格比较率直一些，也比较上进，有一定事业心，不甘落后与平庸，但午火当令，时支见巳火，原局较为燥热，也会体现为压力较大，容易急躁冲动，有时候脾气不太好，容易走极端。

年干癸水为伤官，伤官高透，年支酉金为羊刃，代表野心和欲望较强，不太容易得到满足，也代表做事有一些好高骛远，或者急于求成，印星较旺贴身，戊癸相合，印克伤官，也会导致比较死板，做事不擅长变通，有时候疑心较重，敏感，多疑，钻牛角尖，不够豁达。

年干癸水伤官高透，但戊癸相合，癸水伤官被合克，也代表个人才华不易施展，能做出的成绩较为有限，也代表贵人运较为缺乏，升职和发展的机会不多，自己不容易把握住，做事求稳比较好。

庚金日主被两个偏印和一个劫财贴身，均为忌神，而癸水用神在年，离自己较远，又被合克，代表工作环境不是很理想，压力和烦恼较多。

命局辛金和酉金劫财较旺，代表事业上竞争阻碍较大，要注意同事关系，容易同事之间关系不好，或因此而招惹小人是非，同时也代表容易走捷径心理，但也容易因此破财，不适合去搞一些高风险投机的事情，容易破财。而且庚辰日出生临十恶大败日，也是容易财来财去，花钱大手大脚，留不住钱钱的信息。

原局不见明的财星，唯有日支辰土暗藏乙木正财，原局不见偏财，偏财也比较弱，得到的财多为工资财，地支官印相生，杀印相生，也是代表多靠工作，权力职位等来获得钱财，没有什么偏财运，而且癸水伤官财源被合克，也代表财运不大，可以说虽然欲望交代，有求快财投机的想法，但投机以及做生意都不太适合，不适合去创业做生意。

年干癸水伤官为用，比较适合技术方面的工作。印旺无制，也适合从事保守稳定的工作，能在大一些的企业从事技术工作比较适合，能稳定就好。你现在从事互联网行业，五行属火，南方也属火，火在命局虽不为忌，但旺了辰土，没有起到好的作用，故而从事该行业不太适合，可以再看看其他机会。方位上，出生地的北方，东方，东南方更加旺你。

你现在走的是乙卯大运，干支一气为正财，乙庚相合，正财合身，故多赚取工资财，没什么偏财运，故不宜再去盲目投资，很容易亏损破财，尤其卯酉相冲，更加代表如此。

后面的的甲寅大运，为偏财的运气，但也不大，癸丑大运，财运有所下滑，总体都是适合稳定求财。
