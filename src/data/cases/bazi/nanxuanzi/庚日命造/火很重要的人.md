# 分析命局：

庚金日主生在寅月失令，坐寅木失地，年月寅亥合木，亥水被合化，年干透出乙木也来耗身，春季木旺金囚，耗金力量较强，月干戊土和时支辰土来生扶日主，不过，土薄而木重，又不见火来通关，土生扶力量较弱，时干庚金来帮身，为偏弱之命。月干戊土枭神从月令寅木中透出，为枭神格。

# 分析喜忌：

庚金日主偏弱，以生扶日主的土金五行为用神，以泄耗日主的水木五行为忌神，火虽克身，但在天干地支生土为吉，木旺土死金囚，土木相战，故能有火来通关为吉，火为命局的通关用神，五行木旺为病，也喜见金来制木帮身，单独见土，木土相战不为最吉，火土同见为吉。

# 分析事业：

时干庚金比肩帮身为用，懂得团结他人，也可以得到他人相助，有一定贵人运，天干乙庚相合，为仁义之合，寅木偏财暗藏丙火七杀，藏而不显，一般来说是比较正直，较为和善，野心和欲望不会太大，懂得知足。

天干乙庚相合，地支寅亥相合，八字合多，寅木临天乙贵人，代表有有一定人缘，但由于庚金日主被戊土枭神贴身，时支又见辰土枭神，月日均临孤辰，五行又不见火，故而人比较内向孤僻，而财旺克印，印星无力，也表示容易缺乏安全感，易于自卑，人也比较敏感。

五行火藏而不显，火弱之人天然有追求光明之意，且月日均临太极贵人，月干戊土枭神贴身，对神秘文化，偏门冷门文化比较感兴趣，也有这方面的悟性。不过，地支寅亥合木，亥水食神被合化，财星较旺来克印，在学习能力和考学运上并非太理想。

你早年走的是丁丑大运，和丙子大运，天干丙丁火透出，一方面可以起到暖局之用，另一方面，火来通关财星，旺了印星，故而在一定程度上弥补了原局的不足。

2020庚子年研究生毕业的话，多为2016丙申年考研，天干丙火透出通关，地支申金来制财，故而可以考上研究生。

但2019年至今，就没有这么好的运气了，2019己亥年，2020庚子年，地支水旺生木，2021辛丑年，印弱无力，2022壬寅年，2023癸卯年，2024甲辰年，均为财旺的年份，尤其2023年后已转乙亥大运，也是财旺的大运，考公的话较难上岸，最早要等到2025年，有一些希望，2026年较为稳妥，不过这个时候年龄已经偏大了，即使上岸，也失去了年龄优势，在起跑线上也不占优势。想换工作也建议这两年考虑，有一些机遇，在此之前能求稳为好，不宜大动。

丙火七杀藏而不显，财星太旺无制，且财星克印，戊土和辰土枭神较弱被制，故而事业运不是很强，即使进入公职队列，也较难有太好的发展，升职较为困难。

戊土和辰土枭神为用，适合围绕印星求发展，财星太旺，自己很难担财，有财来财去之象，也代表求财辛苦，能从事金融财会方面工作比较适合，五行属金，比较旺你，也顺应“财来财去”之势，有利财运和事业，不过，这么说并非让你马上转行，而是能转向去考会计资格、经济金融方面的证书，对你事业发展有利。

你研究生的学的法学方面专业，也不建议放弃，见戊土和辰土枭神，庚金日出生，也比较适合偏武职方面职业，从事法学、法务、律师方面工作也是可以的，能进一些大的企业、公司、平台、事务所等工作为好，也可以考虑法律为主业，通过金融财会辅助，可以增加收入，当然这是比较理想的状态，若不具备这个能力，专心在法律方向求发展最好。

枭神格但木旺克土，土木相战，枭神无力，为命局之大“病”，且庚金生于正月，天气尚寒，不见火来暖局，也没有火来通关，属于有“病”无“药”。
