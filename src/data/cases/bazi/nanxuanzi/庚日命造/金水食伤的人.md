# 分析命局：

庚金日主生在午月失令，坐申金得地，时支巳火来克身，地支巳申相合，有一定克身之力，但年支见辰土来通关午火，泄掉了午火之力，年干透出庚金来帮身，帮身力量不弱，时干辛金也是帮身的五行，月干壬水来泄身，午火被壬水盖头，克身力量也有减弱，且“我党”多于“异党”，依然为中和偏旺之格。

# 分析喜忌：

原局中和偏旺，以泄耗日主的水木五行为用神，以生扶日主的土金五行为忌神，火虽克身，但在地支生土不吉。天干一片金旺，喜见水来泄金之力，天干有壬水，也喜见木，由于乙庚相合，甲木稍好一些，地支辰土泄火之力，喜见木来制土助火。

# 分析事业：

庚金为矿石金，同时五行金旺，喜见丁火来炼金方可成器，原局不见丁火，但月令为午火也可炼金，而庚金淬炼要成器，也喜见壬水来洗金，月干见壬水也为吉，从调侯上看组合较好。

但五行组合来看，金多金旺，独见壬水，也有一些金多水浊的问题，而且午火生辰土，用神化忌，壬水虽然为用但虚透在天干，而年干庚金为忌坐实，也有一些“病”重“药”轻，整体而言虽然有一定福气，但能做出的成就会有限。

庚金日出生为阳金，日坐申金，年干又见庚金，月令午火为正官，壬午暗合，壬水食神去合正官，故人性格非常要强好胜，事业心很强，不会轻易妥协服输，有一定自制力和约束力，行为有尺度。

月干壬水食神泄秀，且为金水食神，月柱壬午临天乙贵人，年柱庚辰临华盖，人比较聪明伶俐，领悟力不弱，加上时柱辛巳临天医，也懂得付出，可以吃苦，为吉的一面。

不过，庚申日出生，日坐申金为禄神，但申金被午火和巳火夹克，且巳申相合，申金被合克，也为破禄，且申金禄神也可代表自己，被官杀所制，官杀混杂表示生活环境不太理想，压力较大，想做的事情总会有阻碍，内心会拿自己缺点和别人优点比较，容易自卑。

官杀混杂，负面情绪较重，有时候性格容易走极端，把一些问题往坏处想，尤其壬水食神见辰有入墓之象，也有心情容易压抑，抑郁寡欢之象，这是要注意的。

结合大运来看，你早年走的是辛巳大运，和庚辰大运，第一步大运辛巳，巳申相合，申金禄神被合克，加重了原局官杀混杂的问题，故早年过得不开心，环境较为压抑，且福气较薄。

而这两步大运天干庚辛金比劫高透，也代表学业和事业上竞争会很大，容易遇到强有力的竞争对手，自己也容易错失机会，天干金多水浊，也会对考运有所影响。

2022壬寅年，地支寅巳申三刑，内心更加焦躁不安，自卑压抑，好在壬水来泄金之力，所以考学运还是不错的。

命局为食神泄秀的组合，月干壬水食神为用，虽虚透无力，金多水浊，但天干有旺金来生水，壬水也有元神保护，故可以围绕壬水食神来谋发展。壬水食神在现实生活中可代表晚辈、子女、学生等，命局为金水食神，食神高透，一般而言，口才不差，才华可以得到施展，适合从事教育文化相关工作，你现在考教师编也是正确的选择，也有机会上岸。

庚申日出生，日坐申金为禄神，日禄本为福气，但巳申相合，有破禄之象，故也代表福气少了几分，财运自然不强。原局不见财星，唯有辰土暗藏乙木正财，藏而不显，且在年支，离自己较远，很难得到这个财。月干壬水食神泄秀，壬水也可为财，故而唯有踏踏实实付出，把自身实力做强，才会有更好的财运，也为小财可见，难见大财。

结合大运来看，现在走的是庚辰大运，行印比运，总体财运较为一般，辰辰自刑，乙木财星跟着受损，容易花销破耗。未来走的己卯大运，戊寅大运，为东方木运，地支财来生官杀，总体有利事业，但财不大，易破耗，转丁丑大运，丁壬相合，壬水被合绊，财运走低，故能选择上班求财是最好的。

以月令午火官星代表丈夫，时支见巳火七杀，为官杀混杂的组合，先见正官，后见七杀，代表容易遭遇婚外桃花，也代表自己在感情上不够坚定，容易动摇，尤其地支巳申相合，巳火七杀被合入婚姻宫，也有感情上的争夺，婚姻也容易发生变动，这是要注意的。
