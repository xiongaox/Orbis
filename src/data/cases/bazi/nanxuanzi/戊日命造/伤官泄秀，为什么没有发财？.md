# 网友来信：

记忆中的童年在父母的陪伴下是很快乐的，虽然家中不富有，但是我可敬的双亲凭借他们的辛苦劳动换来我们一家四口的温饱，在村中还算有中等的水平，小时候不懂父母的苦，等到双亲都已故去才明白当年为我们的付出是真的超过了一般的父母给予的爱，这种爱又不是溺爱，我觉得父母给我的家教真的挺好的，让我以后的人生受益一辈子，也让我感恩他们一生，谢谢他们不仅养育了我，还给我这么健全的人格，我也全部承袭了他们质朴善良大气的性格。

小时候总有人当面或者背后说我智商低，不聪明，到长大了我都一直觉得他们讲的没错，虽然读书成绩不错，还是数学尖子生，但是总觉得是真的智商不如别人高。近些年我才逐渐的有了自信，或许是因为已经经历了太多的生活磨难了，现在的我再也不是当初的傻傻的小女孩，当年只有父母才会无条件宠的人。我虽然成绩很好，却没有考上理想的高中，也就没有什么文凭，初中毕业后听了别人的话读了二年中专，财务，什么都没学到，白白浪费了父母血汗钱。

因为没有扎实的财务知识，加上我也不太喜欢财务，后来根本没有从事过这一行，都是赚的辛苦钱，上班做最底层的普工。到哪都不如意，性格不活泼，沉默寡言，不擅长交际，一点都不像我父亲那样能说会道，也不像我母亲那样什么都做得好，所以每份工作都不长久，总是赚不了多少钱，心中郁郁寡欢.壬辰年底熟人约我一起进厂，在厂里做了六年整，好不容易熬到社保买满了十五年就出来了。因为先后经历了父母弟弟离世的痛苦，这些年我的心性有了一些改变，开始喜欢关注命理。

戊戌年底我跟朋友说明年我一定能赚到钱，不错，是赚了二三十万，但是我只看到见水的财运没有看到比劫林立这一年我个人已经亏损了三十多万了。老公身体不太好，时不时的要出点断手断肋骨腰间盘突出的小意外，现在的经济越来越不景气，做什么都不好做了，儿子越来越大，家境越来越贫，我已经越来越心灰意冷了，对不起我故去的父母，对不起我两个儿子，也对不起自己的人生。之前也有请过命理师帮我看，都说能给我一颗定心丸吃，以后一定会有钱，再也不要找人看财运了，可是我真的已经看不到翻身的希望了。

请帮我看一下无财即使伤官泄秀也无法改变贫穷的局面吗？是否真如那两位命理师所言我以后一定会很有钱？如果是，转机会在哪一年？现在我只想早日还清欠债为好，再考虑建房娶媳心情就舒畅一点了。
