# 有玄学缘分的人

命主生辰: 1991/10/15 22:00 (GMT+8)
性别: 坤造
日主: 戊土
格局: 伤官格
令地: 得令, 得地

# 网友来信：

我和老公都是同一个培训班的老师。之前他在一个IT公司做技术工作，我在这个培训学校。我觉得我的单位不错，所以后面让他辞职转行也到了我单位，并督促他考证、手把手带他出师。他也很争气，目前是我们当地小有名气的书法老师。

我在本单位有10年了，老公也有6年了，我是个中层管理，兢兢业业，很感恩我的校长，也为学校培训了十多位稳定的老师。虽然工资比较稳定，但  确实没有太大发展，且非常劳累。

> 我有三点疑问：
>
> 1、我适合出来单干吗？什么是好的时机？
>
> 2、我和老公适合一起创业吗？他会和我共进退吗？（老公还算很听我的安排，但是中途有一段时间我和他意见不合，因为他稳定之后就有点不思上进、不爱学习，我总想管着他，导致我们关系有点紧张。因为我及时沟通目前缓和很多。工作和生活上，合作的还算比较好。）
>
> 3、我的妈妈非常命苦，这辈子没怎么享福，经济条件很差。我一直都很重视我妈妈，这几年我给她盖了新房，让她终于住上了新房（之前她住的特别差。爸爸意外不断，执拗固执，不心疼人）。我经常给她买衣服鞋子，袜子内裤内衣都会给她买。冰箱手机也都会买我力所能及最好的。只要有空都会回老家陪伴我妈妈。
>
> 我目前想自己创业、想提升收入，也是想提升我妈妈的生活质量，不让她因为钱的问题流泪。另一方面我33岁了，又有点想生二胎，我生二胎目前没有人帮我带，我的公婆人非常好，但是婆婆在长春帮忙带他们的老大的两个孩子，公公在湖北我们这里帮我带我儿子，两人长期分开。我如果再生一个，他们又开始带，我实在不忍心。我们自己带也确实没那么多精力，除非我不上班了。我老公执行力不错但决断力很缺乏，都是听我的。我也有点担心因为生孩子耽误了工作机会。我又想对老人尽孝，抓紧时间努力工作让我妈妈过的更好。又纠结生不生二胎，感觉生一个也不错，不知道如何抉择。
>
> 4、我对玄学很有兴趣，文章说空亡、十灵日的人比较适合学习玄学，我看我好像有，不知道是否有缘分呢

# 八字详批：

#### 坤造：辛未年，戊戌月，戊午日，癸亥时（子丑空）

#### 大运：己亥，庚子，辛丑，壬寅，癸卯，甲辰，乙巳，丙午，9岁运。

# 分析命局：

戊土日主生在戌月得令，坐午火得地，月干透出戊土来帮身，年支未土也是帮身的五行，地支戌未相刑，把土刑旺，帮身力量较强，年干透出辛金来泄身，时柱癸亥干支一气来耗身，但戊土日主得令得地，依然为身旺之格。年干辛金伤官从月令戌土中透出，为伤官格。

# 分析喜忌：

偏旺以泄耗日主的金水五行为用神，以生扶日主的火土五行为忌神，木虽克身，但在地支生火不吉。戌土当令较旺，喜见金来泄土之力，也喜见水来制火。天干喜见金来泄身生水，也喜见水来耗身，木来克身。

# 分析事业：

时柱癸亥干支一气为命局用神，但天干戊癸相合，两个戊土争合癸水，癸水被合克，癸水有损，地支亥水孤立无援，土旺，不见金来生水，为不足之处，但好在年干辛金透出，辛金得戊土和未土生扶不弱，为忌神化用，用神有利，也为吉利，所以组合不差。

五行土厚为病，地支戌未相刑，得午火生扶不弱，月干透出戊土，均为忌神，虽有辛金伤官泄秀，但依然有土重金埋之象，体现为个性固执倔强，也有一些任性，比较要强好强，自我意识较强，比较好面子，但好在年干辛金伤官泄秀，有时候也有一些温和之气，懂得付出，为吉利之处。

五行土旺成势，地支戌未相刑，把土刑旺，土厚无制，有时候也容易急躁冲动，不过五行土厚之人，一般也比较踏实肯干，懂得吃苦耐劳，所以依靠自己的辛勤努力，也有机会做出成绩，尤其年干辛金伤官为用有力，没有受损，也代表有机会在事业上发光发亮，可以小有所成。

天干戊癸相合，两个戊土争合癸水财星，为比肩夺财的组合，容易因为亲戚朋友而破财，另外也代表不适合何人合伙，也不要去做一些高风险投机的事情，以及为人担保等事，容易平吃亏破财，破财开支花销比较大。

从你的组合来看是不太适合去创业的，尤其合作创业更加不太适合。另外，年干辛金伤官为财源，难以直接来生财，贸然创业，也很容易遭遇失败。你的命格，能安安稳稳上班为好，辛金伤官透出为用，也比较适合从事教育文化、培训艺术等相关工作。

丈夫乾造：【**己巳，戊辰，己未，己巳**】，己土日主生在辰月得令，坐未土得地，月干透出戊土来帮身，年干和时干透出己土来帮身，年支和时支巳火来生扶日主，命局没有一个克泄耗日主的五行，故而为从旺之格，以生扶日主的火土五行为用神，以克泄耗日主的金水木五行为忌神。
丈夫命局从旺，但现在走的乙丑大运，未来走的甲子、癸亥大运，大运均破格反背，整体运势并非太理想，一旦破格，命局用神均变为忌神，比劫太旺，更加不适合创业、合作求财等。

丈夫五行土旺，是你的忌神，你的五行土旺，由于丈夫运势反背，也是他命局的忌神，喜忌不能互补，在一起的话，对对方运势没什么帮助。你们的八字戊癸相合，巳午未三会，午未相合，巳亥相冲，戌未相刑，辰戌相冲，从这个层面来看，也不宜合作创业。

戊午十灵日出生，年柱、月柱和时柱均临太极贵人，月柱临华盖，月令为戌土，代表对神秘文化比较感兴趣，也有一定这方面的缘分，能在工作之余当作一个兴趣爱好则可。

# 分析大运：

**29岁—38岁**

辛丑大运，此大运辛金伤官透出，伤官生财，可以施展才华，做出成绩，整体财运尚可，也有升职机会，要把握机遇。但地支丑戌未三刑，也要注意事业竞争，小人算计，口舌是非之事，凡事不可冒进，能稳中求进为好。

**39岁—48岁**

壬寅大运，此大运为财杀相生的大运，天干壬水财星透出，财星高透，花销较大，不太聚财。地支寅木七杀旺了印星，印星旺了比劫，整体运势较为一般，升职发展机会不多，财运不是太理想，能上班为好。

**49岁—58岁**

癸卯大运，此大运天干癸水财星透出，戊癸相合，两个戊土争合癸水，竞争依然比较大，且依然钱财花销大，此大运不要去投资创业，很容易亏损。地支卯木官印相生，事业依然适合平稳过渡，能退则退为佳。
