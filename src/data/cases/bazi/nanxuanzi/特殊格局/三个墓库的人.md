# 三个墓库的人

命主生辰: 1989/01/23 10:00 (GMT+8)
性别: 坤造

格局: 从弱格
令地: 失令, 失地

# 网友来信：

我是家中长女，从小父母感情好对我们也很疼爱，姐弟感情也很好。我认为弟弟们给我的人生带来了好运气，他们真的很懂事、性格也很乐观，他们是我的弟弟又是最好的朋友。2010年国庆节期间母亲突发脑溢血去世了，我才忽然懂得攒钱很重要，从此省吃俭用，我小弟批评我对自己很抠门。大学毕业后我回到出生的县城，工作稳定，工资不是很高，但是够用，所以要节俭地用钱。工作上很注意向身边的老同事学习，但是沟通上没注意方式方法，忘记了讲人情味，怕出事就很讲原则，同事们也向我提过建议，我可能一直没改过来。

直到30岁后，相亲遇到的男士转告我，同事们对我的负面看法，并且让相亲对象生畏了，我独自痛哭过，开始调整心态，安慰过父亲，希望他不要担心我的人生、也希望不要责怪我大龄未婚让他在亲朋好友面前失了颜面。好朋友和关系好的同事说过我有点自卑、不自信，其实我觉得自己这样挺好的，内心不自卑、挺自然啊，不会羡慕别人的家境和对象。因为从小我妈妈会鼓励我、开导我（妈妈以前在村里干了十年的妇女主任），她觉得我长相差不多、认真读书考大学、父母弟弟家庭氛围也好；另外人生因缘和合，福报和贡献不同，自然能享受到的也不一样，别必要太强求财富、事业、婚姻。总的来说，我对目前境况是满意的。

我妈妈去世时，弟弟们才十六岁，我享受了比他们更多的母爱，我打心底是心疼他们的，他们高中毕业后先是在佛山、东莞厂里做事，过了两年后大弟弟去了武汉服兵役，小弟弟去了参加高考读了大专，再过两年，大弟弟退伍也去了同一所大专读书。在县城买了房，结束了租房，至此我家的情况才开始好转。我爸爸很乐观，年轻时曾经在福建服兵役，现在也有几个能出门一起玩的朋友、会坚持散步养生。

俗话说，命里有时终须有，命里无时莫强求，我自身有做得不对的地方，在工作上的方式方法伤害过同事情谊；在感情上一定是男方先表白，我才会迈出一步，对不喜欢的人一定是拒绝的，不敢贪图别人的钱财，相信不义之财怎来的最终会怎么走，相信因果报应，我希望感情是真诚、坚定、明确、光明磊落的。我还是希望今生能成家生子的，这样父母家人都好受些，我的伯父、姑姑、叔叔和姨妈、舅舅们、表姐表哥表弟、堂弟堂妹都对我很好，不会说让我难堪的话。

# 分析喜忌：

从弱以克耗日主的火土五行为用神，以生扶日主的金水五行为忌神，五行木虽泄身，但在天干地支土木相战，也不是很好。从弱之格的命局，弱不受生，所以不喜生扶的，只有顺从弱势才比较好，官杀当令，也喜顺从官杀之力，喜财来生官杀，最忌的是有印比来帮身，造成岁运破格，会导致较为不利。

但结合大运走势来看，一路走的是比劫、印运，大运均是反背，从格破格，所以当身弱看，以金水为用神，以木火土为忌神。

# 分析事业：

地支七杀当令逢冲，内心会有一些破坏心理，比如会有些报复心理，加上原局从弱，性格也容易走极端。但天干戊癸相合，正官合身，为人还是正直，做事有原则讲规矩的，有责任心，同时五行土旺也比较厚道，只是有时候也会有些自我矛盾。

丑土七杀当令，丑未相冲，七杀攻身，年柱戊辰干支一气为正官，官杀混杂，大运又破格，平时精神压力较大，内心的负担较重，也容易缺乏自信。

原局正官合身，加上五行土比较旺，也是代表性格会有些比较的固执僵化，做事想事容易一根筋，有的时候也会太过于讲原则，缺少变通，让人觉得缺少一些人情味，而不利人际关系，容易在职场上吃亏。不过正官合身的人一般也比较容易知足。

从格的命局容易出成就，但能够达到要求的从格，那是少之又少的，就好像现实生活中大富贵的人少，是一样的道理。

你的命局虽然为从格，但原局官杀混杂，，时柱丁巳正偏财同见，又见乙木食神来乱局，所以虽然为从格，但五行不纯，就拉低了层次。最重要是大运一路均反背，大运对你发展没有太大助力，所以整体层次是不太高的，未来发展也容易受限，能满足于上班求财，追求稳定比较好的选择。

地支丑未相冲，时支巳火财临驿马，时柱丁巳财星骑马，戊癸相合，戊土官星在年，这些组合都代表是外出发展会更好一些， 方位选择出生地的北方，西方，西北方比较旺你。原局不见印，也多为白手起家之命，凡事都要靠自己，也适合一些经常出差，走动较多的工作。可以找一下这些方面的工作，有机会能外出置业为好。

由于大运破格，当身弱看，官杀攻身，最喜见印星来化官杀生身，加上月干乙木食神透出贴身，癸未日出生日坐未土为食伤库，适合做文化教育方面，比如去学校当老师，也有助你的运势，人际关系相对单纯。尤其36岁后走的辛酉大运，庚申大运，均为印旺的运气，能去学校发展也有机会做出成绩。

# 分析婚姻：

年柱戊辰为官星，地支丑土和未土为七杀，为官杀混杂的组合，故身边异性缘分不差，七杀近而正官远，也代表身边烂桃花要多一些，大运多破格，官杀攻身，也容易遇到动机不纯的人，自己要多留个心眼为好。先官后杀，也容易在婚后有其他异性干扰婚姻，也是要注意的地方。

月柱乙丑临寡宿，时柱丁巳临孤辰，四柱均见太极贵人，地支见三个墓库，都有感情上孤独之象。年柱戊辰为正官，戊癸相合，正官合身，官星在年，能外出，更加容易遇到正缘，或者丈夫为外地人的概率大一些，年龄多比你大。地支丑未相冲，婚姻宫和七杀逢冲，婚姻环境不是太好，夫妻矛盾较多，且另一半会较为强势，会让你感到压力。

2023癸卯年，天干戊癸相合，戊土夫星被合动，有遇到的运气，但由于现在走的壬戌大运，地支四墓库全，一顿乱冲，故婚姻感情多比较坎坷，比较难成，要到2024甲辰年，流年和大运酉辰相合，才有机会遇到，2026丙午年，地支午未相合，巳午未三会，有结婚的运气。
