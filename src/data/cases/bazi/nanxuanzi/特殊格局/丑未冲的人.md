但是工作后不顺利，又延续了各种苦闷，反正就是各种不顺，人际方面等等都不顺利，工资待遇也低的可怜，工作很累，家庭生活前几年各种吵，恨不得吵的离婚，我从小到大是一个非常传统非常保守的人，跟异性基本绝缘，但是从戊戌年开始感觉自己跟变了一个人一样，当然也没有什么异性缘，只是觉得自己思想发生了一些颠覆性的变化，因为一直在单位待着不顺，从戊戌年开始想着考博离开，戊戌年没考上，己亥年考上了，说没有努力是假的，也付出了，但是觉得付出的不够多。

还有之前一直觉得我老公不好，觉得自己亏，可是从18年开始越来越觉得自己老公很好，遇到他是我的幸运，从初中到现在，不知道为什么，只要一有压力我就容易活在抑郁中不能自拔，经常内心很痛苦，很苦闷，经常患得患失，经常苦闷不堪。

我想劳烦帮我看看，我还有未来吗，我还能毕业吗，我是辞职读博，如果毕不了业，原来的事业单位因为年龄原因是肯定进不去了，以后的工作怎么样，还有有人说我偏官太旺，不好，想问下婚姻怎么样，不会有些烂七八糟的事吧，身体事业怎么样，我现在有一女，还有再要一个二胎，因为学业的事，也迟迟没要，所以我一直活在苦闷中。

# 分析命局：

癸水日主生在丑月失令，坐未土失地，时干戊土来克身，而且戊土坐下午火生扶不弱，年干丙火和时支午火来耗身，年支寅木来泄身，只有月干辛金来生扶日主，辛金坐丑土金库有气，本不能从，但天干丙辛相合，合而不化，生扶力量大打折扣，故而可看作假从。

# 分析喜忌：

命局从弱，官杀得令较旺，所以为从官杀，假从则受大运影响喜忌，当大运来帮扶日主，命局为身弱，以金水为用神，以木火土为忌神。当大运来克泄耗日主时，命局为假从弱，以火土为用神，以金水为忌神，以木火土为用神。

# 分析学业与事业：

有的人看到从格就认为好，其实从格的要求是很高的，除了对大运要求高，对本身命局组合要求也高，你的命局虽然为假从格，但地支丑土和未土为七杀，时干戊土为正官，构成官杀混杂。而年支是寅木伤官，伤官来制杀，土木相战，五行之气较为极端。命局虽然是假从，但是五行比较杂乱，影响了格局层次，难成贵格。

命局丑土七杀当令，日支是未土，丑未相冲，把土冲旺了，时干又见戊土正官，月干虽然是辛金，但辛金被丙火合克，难以起到通关之用，导致官杀来克身，性格上容易压力大，思虑顾虑多，压力不能很好的排解，闷在心里，容易抑郁想不开，甚至孤独自闭，即使表面看起来风平浪静，但内心也是烦躁不安，久而久之易滋生精神方面疾病，是要注意的。

命局官杀混杂，年支寅木伤官来制杀，为人是比较聪明的一个人，但也比较敏感，多疑，自尊心很强，对外界的反应比较敏感，很在乎别人对自己的看法，内心想的比较多，但顾虑多，想的多，也导致自己经常心思不定，想要这又想要那，对现状产生不满，导致事业不稳定，变动较多。

年干丙火为正财，月干辛金为偏印，时干戊土为正官，财官印全且全部透出，戊癸相合，去杀留官，戊土坐午火财星之上，财戴官帽，财官入门户，可以得到这个财和官，从事公职或考事业单位是很适合你的。

你从10岁上运后走的是庚子大运，运行金水助身，命局身弱，天干庚金正印透出，官印相生，印星来通关为吉，早年精神压力较小，学习成绩较好，得父母疼爱，快乐较多。

20岁后开始走的是己亥大运，地支亥水作为癸水日主的根，癸水弱而不从，此大运为身弱之命，命局本身官杀旺克身，而大运又天干己土七杀高透来攻身，精神压力较大，负能量重，忧愁多，比较敏感，容易自卑，缺乏自信，大运不佳，但流年逢印星高透通关的时候则比较好，可上研究生。

30岁后开始走的是戊戌大运，大运干支一气为正官，癸水日主顺从弱势，可为假从，以火土木为用，天干戊癸相合，正官合身，可以考取博士，能够得到官方的证书和文凭。

但大运虽好，从流年来看，2020庚子年，2021辛丑年，2022壬寅年，2023癸卯年，均有金水相助，则不利于学业，癸卯年较难毕业，多要深造一年，2024甲辰年有望毕业。

# 分析婚姻：

命局官杀混杂，官杀攻身，官杀代表女人的男人和感情等，官杀攻身则会因为感情和婚姻而感到很大压力，产生很多烦恼，也代表丈夫比较强势自我，对自己关心体贴较少，婚姻幸福感不强。年支寅木伤官来制七杀，自己也很容易对丈夫不满挑剔，久而久之夫妻感情容易僵化。

地支丑未相冲，七杀互冲，婚姻宫被冲，感情不安宁，夫妻之间容易产生矛盾隔阂，在感情上很容易受到伤害，也容易因为一些小事而生闷气，放在心上排解不出去，自己和自己过不去。命局日坐华盖，月柱临寡宿，内心容易孤独，感情上比较独立。

命局官杀混杂，但好在戊癸相合，官合身，可以有一段较为稳定的婚姻，但地支丑未相冲，午未相合，七杀和婚姻宫逢冲合，容易中年婚姻发生变动，但先冲后合，婚姻先苦后甜，平稳过渡可一婚到底。

年支寅木伤官星代表儿子，日支未土中暗藏乙木食神代表女儿，丑未相冲，木库冲开，可以得到一儿一女，要二胎是可以的，2022壬寅年，2023癸卯年，2024甲辰年，子女运均不差，可以考虑要孩子，40岁后转丁酉大运，午酉相破，子女宫受损，那时候就没什么子女运了。

# 分析健康：

日主癸水太弱，女命代表生殖能力，土旺克水，要注意肾脏泌尿系统，生殖系统疾病。命局土厚，要注意皮肤，脾胃，乳腺增生，肿瘤等方面疾病。月干辛金被合克，要注意肺呼吸道方面问题。尤其是官杀攻身，容易精神方面疾病，另外因为容易想得多，负能量得不到及时发泄，会导致睡眠容易不好，影响身体健康是要注意的。

# 分析大运：

**30岁-39岁**

戊戌大运，此大运干支一气为正官运，官重压身，癸水日主顺从弱势，可为假从，以火土木为用，天干戊癸相合，正官合身，可以考取博士，也有机会考取理想的单位，要沉下心多学习为佳。但地支丑戌未三刑，婚姻容易矛盾冲突多，感情较为冷淡，婚姻压力较大，事业上也要注意口舌是非。

**40岁-49岁**

丁酉大运，此大运地支酉金被天干丁火盖头，地支酉金印星出现，命局身弱，以金水为用，但酉金被丁火盖头，地支午酉相破，财星破印，则运势较为低迷，酉金受损且空亡，事业上不易施展才华，难得贵人相助，升迁机会小，能求稳为好。

**50岁-59岁**

丙申大运，此大运地支申金被天干丙火盖头，申金印星助身，命局身弱喜金水，但申金空亡且被财星所制，事业上发展空间不大，成绩平平，寅申相冲，驿马逢冲，求财比较辛苦，比较忙碌付出多，财运较为一般，也要注意颈椎健康。

**50岁-59岁**

乙未大运，此大运地支未土被天干乙木盖头，为食神制杀的大运，命局顺从弱势，以木火土为用神，乙木食神坐未土有入墓之象，要注意颈椎、神经系统、肝胆方面疾病。地支未土引动命局丑未相冲，也要注意脾胃，乳腺增生，肿瘤等方面疾病。
