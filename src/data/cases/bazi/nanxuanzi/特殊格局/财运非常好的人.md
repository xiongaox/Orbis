# 网友来信：

自己一直在思考关于人生未来发展走向。迷茫居多，实际行动起来比较困难。

原生家庭，父母学历都较低，母亲稍好，还有个弟弟差六岁。父母节俭，自己年幼时学习较差，好在喜欢画画，母亲也一直在支持。青少年时期父母教育自己方面比较简单粗暴，长大也能理解。前两年还会有吵骂，近来好些，但是很多时候和父母沟通起来还是比较困难，多数时候不想说话。近来感觉母亲心性身体有些变化，多年理发生意，戊寅春月，七杀重。父亲以往暴躁，近来心性变化很大。拆迁家庭房产较多，母系帮助多。虽然有，但祖父在赠予产业方面差强人意，只是当年给了些地。我也因此对父系这边姑姑们疏远，叔叔残疾也罢。命里无时莫强求。

爱好广，喜欢美食和做食物，会很多运动项目，小学到大学都拿过不少小奖。丙申年艺术成绩发挥好，是凭借艺术特长考上大学。大学恋爱6年，自己西北的，女友东南，家庭也还不错，但有个领养子。庚子年毕业至今，自己工作没落定，就分开了，已半年多。在她家住了两年。自身比较重感情但也很现实。会有点吝啬，但有时花钱大手大脚。目前是不想再陷入一段感情里。

之前在教育私企工作几个月，工资待遇不错，奈何自己能力不足，与人沟通交流弱。目前想考教师编制，求稳定。考编学习中很难沉下心来去学，又想着考研，年龄也不小了，周围朋友同学也都有了自己的路线，自己还在家，也很着急。容易被各种情绪，外界环境影响到，意志力薄弱，自己很多时候想要得到一个确定。对于未来又会有很多悲观的想法。

大概知道自己没有木，又是火日，地支很多土，不知道是好还是不好。看到“见丁比出干，难合格局，常人，且主骨肉浮云，六亲流水”；不太理解这句话的“丁比出干”。我的是这样吗？虽然知道人生在世，安稳下来也很幸福，但自己还有心有不甘。

“庚金须带甲，无甲命贫苦”，“丑日戌时刑，伤妻害子”有什么化解方式。

# 分析命局：

丁火日主生在丑月失令，坐丑土失地，地支丑土伏吟，年支丑土来泄身，时支戌土也是泄身的五行，地支丑戌相刑，把土冲旺，泄身力量较强，戌土本暗藏丁火弱根，但由于丑戌相刑，丁火有损，月干癸水来克身，时干庚金来耗身，唯有年干丁火来帮身但被克泄，所以可以看作从，丑土食神当令较旺，也为从儿格。

# 分析喜忌：

从弱以泄耗日主的土金五行为用神，以生扶日主的木火五行为忌神，水虽克身，但在地支水土相战不吉。地支丑土当令，从儿最喜见食伤，也喜见食伤生财，而不喜见太多官杀，食伤和官杀相战不吉。天干喜见土来生金，金来耗身。

# 分析学业和事业：

原局从儿，地支三个丑土食神伏吟，食神较旺，时支又见戌土伤官，性格上会有些任性，容易傲慢，也会比较挑剔的一个人，自尊心较强，比较好面子，食神太旺，容易想得较多，思绪较乱，胡思乱想，月柱癸丑，食神来制官星，比较喜欢自由，不喜被束缚太多。时柱庚戌为伤官生财的组合，也代表个人的欲望野心不小，不容易满足。

丑土食神当令较旺，伏吟地支，食神旺代表一种享受，比如吃喝上的享受，精神上的享受等，一般都喜欢吃喝，注重美食，也容易长胖。食神也代表精神享受，加上地支三个丑土食神临华盖，更加代表会注重精神上的追求，一般都有一定想象力，喜欢思考，时支戌土临天德贵人和月德贵人，人懂得付出和奉献，有仁慈之心，为吉的一面。

原局为从儿格，地支一片食伤，本来口才和表达能力是不错的，但地支丑土临华盖，华盖重重，而且时支戌土伤官临寡宿，代表会偏内向一些，很多时候更倾向于喜欢安静的一个人，在与人打交道上略为缺乏。

但在艺术方面有一些天分，地支见丑土和戌土，华盖重重，也有比较深厚的宗教和易学缘分，一般都会对神秘文化感兴趣。

原局从儿，适合从事一些与文化教育、咨询培训、艺术传媒、技术等相关的工作，你艺术专业出生，未来能靠艺术方面发展为佳，加上时柱庚戌为伤官生财的组合，地支华盖重重，也代表是靠自身技艺吃饭。退而求其次，也可以去从事教育文化相关职业，食神旺，喜欢传播自己的思想，也有学生、徒弟、晚辈之意，是适合你的。相对考研来说，考教师编制目前相对更加适合你一些。

“见丁比出干，难合格局，常人，且主骨肉浮云，六亲流水”这句话出自《穷通宝鉴》，单独拿出这句话来分析你的命局，属于有一些断章取义。

因为结合这句话前后文来看，分析的是子月的丁火，而你的丁火日主生于丑月，显然是不符合自身情况的，所以不必纠结。

“庚金须带甲，无甲命贫苦”这出自盲派命理，《造化元匙》中也说：“甲不离庚，庚不离丁，丁不离甲。”这里说的是一个组合，日主为丁火，需要甲木来生扶，而见甲木的同时，最好见庚金劈甲，来引发丁火，也就是劈甲引丁。但对于你的组合来说，能顺从弱势是最佳的，喜见土金，木并不喜见。
所以一些断语要看情况的，不能生搬硬套，特别是对命理没有基础的时候，一些断语容易给自己带来不必要的烦恼。
