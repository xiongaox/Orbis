# 网友来信：

我叫XXX，出生的时候还下了一场小雨。我一出生，爸爸就下岗了。爸爸过了两年才找到一个临时工干。小时候我经常生病，爸爸每天都带着我找医生，把全市的角落都跑边了，还是不能治好我的病。那个时候工资也低，一个月就几百块钱，为了治好我的病，花了不少钱，直到我四岁的时候才遇见一个医生，把我的病治好了。后来我上小学，直到大学一年级，一直遭受校园暴力。我本来天赋就不高，这么一弄，学习就更不行了。甲午年上高中开始，知识很难，就学习不好了。丁酉年高考，理科也就考了481分（满分300分的理综，我就160分左右。其中物理考了40分，化学也是）。其实当时我是喜欢文科的，但是因为听说理科找工作好找，就选择理科，希望以后有工作了好养父母。然后本来是可以在四川读一个公办二本的，我妈非要听她那些亲戚的，于是让我去山东龙口读一个民办三本。

上大学第一年和舍友关系也不好，亲戚也没有按照许诺的让我入党。于是我大二就去当兵了，想着能够有一个出路。结果发现我当兵也不适合，因为体能不行，身体协调性不好。于是只能两年退伍。本来以为当了兵，总能在学校入党吧，很可惜，什么都没有。而且当兵之后我感觉我学习方面更差了。在学校运气也非常不好，于是大三的时候就开始思考命运，就开始在网上看那些命理学习的东西。感觉命运很奇妙，我看我同学的也能看出来他们的性格，以及他们以前发生的事情。我感觉自己的命不好。

壬寅年5月的时候还被人讹。后来我考研，也没有考上，主观原因是我不努力+没有天赋。然后自己算到乙巳年我爸爸可能会去世，没想到这个月就走了。我很伤心。爸爸一直担心我，没有工作，没有对象，还没有钱，走的很突然，根本就没有想到他会走。他就希望我能有个编制，有个对象，结婚生子。现在妈妈觉得在四川没有亲戚，决定回山东。我是不想回去，不想和那些亲戚在一起。现在的我，没有工作和对象，还没有钱。可是我不能摆烂呀，因为我要对我妈妈和奶奶负责，所以我都不知道该做什么样的选择，才是比较正确的（因为我学的不好）。

> 所以我就想知道，我有进入编制的命运吗（毕竟很多人难过就是因为没有稳定的工作和钱）？如果代价太大（比如需要一直呆在家里不工作考，或者去山东，或者考到了异地的乡镇），我就直接进厂打螺丝去。因为管吃住能存下钱，好给我妈妈和我奶奶，如果有假期还能给爸爸祭拜一下。

# 分析命局：

甲木日主生在子月得令，坐辰土失地，年支卯木为甲木日主的羊刃，帮身力量较强，并在时干透出乙木，也来帮身，地支卯辰相害，辰土有损，耗身力量弱，时支亥水也来生扶日主，年干己土来耗身，但被卯木戳脚，月干丙火来泄身，但也被子水戳脚，泄身力量较弱，故依然为偏旺之格。

# 分析喜忌：

偏旺以泄耗日主的火土五行为用神，以生扶日主的水木五行为忌神，五行金虽克身，但在地支生水不吉。子水当令较旺，又见亥水和卯木，故地支喜见土来制水，更喜见燥热之土，不喜寒湿之土，也同时喜见火来生土，天干喜见火来泄身，也喜见土来耗，金来制木。

# 分析事业：

日支辰土为命局用神，但地支卯辰相害，辰土有损，年干己土和月干丙火也为用神，但己土被卯木戳脚，丙火被子水戳脚，为忌神制用，用神有损，命局用神均被忌神所制，而忌神没有强有力的制化，所以组合较为一般。

从另外一个角度来看，甲木为大树之木，生在子月为寒木，寒木喜向阳，故而喜见丙火来暖局，月干见丙火为吉，可以起到调候之用，丙火透出，也有一阳解冻之象，可以驱除寒气。所以丙火也为命局的调侯用神，但奈何被子水戳脚，故而也打了折扣，另外是大运流年如果有损丙火，也是不利的。

甲木的特点本身就有些固执直接，加上为冬季寒木，又原局身旺，更能体现固执执拗，耿直爽快的特点，不过月干丙火食神泄身，也有一定转圜的余地，也有温和的一面。子水印星当令，时支又见亥水偏印，印星较旺，且正偏印同见，也会体现为性格保守，顾虑较多，缺乏决断能力，有时候比较小心眼，也容易三心二意，杂而不专。

以月干丙火食神为用，若丙火食神不受损，则可以取得比较理想的成绩，考学运也会较为不错，有机会获得高学历高文凭。但丙火坐下子水，丙火被子水戳脚，丙火食神有损，故也打了折扣，不易施展才华、做出成绩。命局用神全部被制，自己也容易错失良机。

天干丙火食神泄秀，丙火为命局最重要的用神，因为命局偏寒，有的时候会悲观厌世，而火代表光明希望，丙火是比较重要的。

同时行业选择也可以围绕丙火来求发展，木火相生主文化，丙火食神也有奉献、传播的意思，故可以考虑从事文化教育培训、传播咨询等相关行业，地支子水和亥水印星为忌神，但有财星来制，甲辰日出生，日坐辰土为印墓，也代表适合发展教育文化。丙火食神也主技术，丙火有力，也可以考虑从事设计、策划等方面工作，丙火透出也主名气和荣誉，有机会获得。

所以照此来看，你有想进入编制的想法是可以的，但能进学校是第一选择，今年癸卯年，天干癸水来制丙火食神，考学运不佳，较难上岸。

明年甲辰年，比今年考学运稍好一些，可以加强努力，2025乙巳年，2026丙午年，2027丁未年，这三年属于考学运比较好的时候，可以把握机遇，有望取得编制。

至于公务员、事业单位方是不适合你的，原局不见官杀，同时丙火食神透出，内心更加喜欢自由一些，即使勉强进入，时间长了也比较不适应，相对更加适合偏自由一些的工作和岗位。至于进厂打螺丝也是不适合的。

月干己土为财星，甲己相合，正财合身，但年柱己卯，己土被卯木戳脚，且地支卯辰相害，为劫财克财，财星有损，加上甲辰日出生为十恶大败日，代表钱财不聚，花销较大，能养成存钱的习惯为好。

至于父亲去世的时间，男命以偏财为父，日支辰土可以代表父亲，地支卯辰相害，辰土有损，有父亲不吉之象，2023癸卯年，地支卯木引动，故这一年会去世，而非2025年。
