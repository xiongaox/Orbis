# 网友来信：

无论是父亲还是母亲，在两边家族里都非常疼爱我。用长辈的话说，从小听话好带，从不无理苦恼，平心静气，讲道理。即便是丙戌年确诊一型糖尿病，我都不曾为此悲观过、自暴自弃过。癸巳年暑假，因为游泳中暑，诱发了酮症酸中毒，情况已经到了要送进ICU的地步。也许是冥冥之中有贵人相助，后来是省人民医院的主任的及时相救，让我脱离了生命危险。

再后是我高考考上本省的一所二本学校，我自认为高三这种学习态度还能考个公办本科就已经不错。而中大有位医生跟我说：“做什么事情都应该全力以赴。你应该用一种全力以赴的态度去做一件事情，这样你才会明白，有的事情不是你光努力就能达到的”。听完此话，从大一其实就树立了考研究生的志向，我决意以身尝试这句话是不是真理。后来在己亥年，以超过3分的成绩通过了目标院校的初试线而进入复试。与我缠身了16年的糖尿病相比，我却格外地把这次研究生入学考试看得格外重要。甚至我舍弃了一些身体的健康进行备考。

然而最终复试以差4名落榜，而我也因为目标院校复试时间太晚错过了调剂的时间被迫再考了一年。在第二年备考的时候，我逐渐开始想不开，后来还患上了中度抑郁，一度想要轻生。原本出成绩的时候，觉得自己考不上目标院校了，立马就坦然接受了事实。而因为疫情，目标院校到了庚子年的5月份才出分数线（2月份出成绩），此时才草草按照目标院校的复试要求进行复习。最后在复试当天，父亲还阴差阳错进入我复试的房间，使我受到惊吓还影响了发挥（复试期间摄像机内不允许出现其他人，否则视为作弊）。为此我一直恨他入骨。

后面回想，一直没有理解为什么老天爷要让我失望之后再给我希望，最后再让我的希望破灭呢？我时常跟我母亲说想一了百了，我的母亲经常跟我说：“在你年纪轻轻的时候（7周岁）就让你患上糖尿病，从此每天三餐都要打针注射胰岛素，说明上天对在进行考验；而你的父亲在工作后修了家里全部的祖坟，是积了阴德的。虽然他爱你，关心你的方式不对，这次对你造成了伤害，但也不必恨他。你是来报恩的。”其实我内心知道一切都是我的问题，归罪于父亲是不对的。后面我读了等经，结合着对外扫相“一切有为法，如梦幻泡影，如露亦如电，应作如是观”、对内破执“应无所住，而生其心”的观点，逐渐为自己找到了解脱的道路，也慢慢地不再恨我的父亲，也不再执着于985名校。

而现在我也考上了研究生。虽然是个普通院校，但也比我的本科院校好。我是调剂过来的，从我本来的通信院调剂到了食品安全院。这里的老师只是因为学科交叉需要电子信息的学生，但他们并不能给我学术上的指导，也没有师兄师姐指导我，一切需要我自学。而现在研究的内容，也与我本来想从事的通信方向走远了，倒是与程序员越来越接近。我也感觉与学术走远了。
