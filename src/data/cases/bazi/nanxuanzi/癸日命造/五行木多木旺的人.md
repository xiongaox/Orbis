# 分析命局：

癸水日主生在亥月得令，亥水为癸水日主的羊刃，有一定助身之用，坐巳火失地，地支巳亥相冲，且亥水被乙木和卯木泄气，帮身力量有所打折扣，年支和时支卯木来泄身，并在天干透出乙木，也是泄身的五行，年干己土来克身，依然为偏弱之格。

# 分析喜忌：

偏弱以生扶日主的金水五行为用神，以克泄耗日主的木火土五行为忌神。地支亥水当令，巳亥相冲，亥水有损，且被乙卯木泄气，故喜见金来制木生水，单独见水，来帮身的同时也会生木，非为最吉，天干喜见金来制木生水，由于乙庚相合，更喜见辛金。

# 分析事业：

亥水当令较旺，同时又为癸水日主的羊刃，说明是比较固执的一个人，同时也代表比较固执倔强，比较争强好胜，遇到事情不会轻易妥协认输，不过也代表在事业上有一定的冲劲。

不过命局有乙卯木食神多且旺，代表也有温和的一面。不过食神太多也代表喜欢自由，有的时候容易懒，想得多做的少。可以说是一个又想做点事情，但又有些空想幻想，缺乏一些行动力，会有些自我矛盾的人。

乙卯木食神较旺，食神代表思想，也代表创造力，但“物以稀为贵”，太多了就会走向反面，食神一个的时候能够聪明机灵，思维上乘，食神太多反而有死板僵化的一面，同时食神多且为忌，也容易胡思乱想，而且食伤属于是幻想一些美好的东西，有些脱离实际的，一旦回到现实的时候又容易被打回原地，心理落差大，会有些任性的一面，需要别人迁就你。你出现情绪上的困扰，多因为食神过多过旺所致。

癸巳日出生临孤辰，性格偏内向一些，见乙卯木四个食神，且不见印星来制食神，乙木食神透天干且相随，乙木是从卯木中透出来的，卯木临文昌贵人，一般口才不差，但食神太多，也容易口无遮拦，容易言语无情，或者给别人无形中造成伤害，得罪人等，是要注意的地方。

月令亥水为驿马，癸巳日出生，日坐巳火为驿马，命局见两个驿马，且巳亥相冲，驿马逢冲，也为驿马重重，代表较为奔波，也代表比较辛苦劳累，加上食神旺为忌，也代表操心操劳较多，适合做一些多动的工作，适合外出发展，出生地的西方，北方，西北方比较旺你。

年干己土为七杀，七杀虽为忌神，但被乙卯木包身所制，亥月水旺木相，木来克土，己土七杀虚透无力，食神制杀太过，性格也偏懦弱一些，缺乏威仪，做事缺乏魄力，少了干大事的素质，七杀代表规矩、束缚，也代表对这些容易反感。己土七杀也可代表事业，也代表事业运不强，较难取得太理想太体面的工作，容易发生变动。

食神较旺，食神透天干相随，非常适合从事技术相关。八字喜金水，且驿马逢冲，也可考虑做一些物流、交通、航运、金融等方面的工作，而且巳火为命局独财，财临驿马为动财，也适合去从事会计、出纳等与钱打交道较多的工作。八字喜印而不见印，能进大一些的平台上班为佳，加上食神过多，也可考虑教育文化相关行业，能进学校，会比较旺你。

至于创业之事，日支巳火为正财，不见偏财，正财多为工资财，且癸巳日出生，日坐巳火，暗藏丙火正财、庚金正印、戊土正官，均为正星，代表更加适合上班，而且食神生财，身弱财旺不担财，代表求财辛苦，收获有限。地支巳亥相冲，劫财冲财，也代表花销较大，不太聚财，所以能上班为佳。
