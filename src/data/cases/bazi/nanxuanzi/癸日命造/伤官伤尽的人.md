# 网友来信：

我自小受父母护翼长大，虽脾气固执倔强，却也是父母眼中的好孩子。爸爸勤朴憨实，妈妈勤洁聪慧，他们彼此包容，10岁的我本以为童年会这样无忧无虑的过去。

可就在乙酉年，爸爸因一场突如其来的车祸致右腿截肢。那段时间尽管父母在我面前强作欢颜，但笼罩父母的悲伤在我的幼小心灵还是感触到的，那种阴霾至今在我心底挥之不去。后来爸爸凭着坚强和妈妈一起努力拼搏撑起这个家。

乙未年我士官学校毕业，顺利进入部队从事航海轮机工作，我的家又充满了欢声笑语。在部队我没有辜负父母的期望，我不怕吃苦，努力做好自己，得到了领导们的认可与表彰。辛丑年国庆节我和我的同桌妻子结婚。

俗话说“铁打的军营，流水的兵”。辛丑年九月我决定退伍不再续签留队，想回归社会趁年轻早点谋发展，我完全不顾父母的反对和部队领导的规劝，毅然决然的递交了辞职报告。

退伍在家的那段时日我迷茫过，懊悔过。后来在家人的帮助下我现在铁塔电网工作，虽然薪水比在部队低的多，但我不怕辛苦，努力工作，很快得到了领导的好评。

# 分析事业：

地支亥水伏吟，为羊刃，羊刃重重，表示性格是比较固执倔强的，遇到一些事情争强好胜，自尊心强，尤其地支巳亥相冲，羊刃逢冲，也容易急躁冲动，这是要注意的。

对应于你2007丁亥年，2019己亥年有意外伤害，本命年也为亥年，依然要多注意。而早年能进入士官学校也较为适合，能从事偏武职的行业，也可以为自己挡去灾祸，能继续留在部队是比较好的选择。

不过留在部队的话，不太适合航海方面的工作，五行忌水，能避开为佳。而电网工作五行属火，是比较适合你的。而且食伤泄身为用，除武职以外，也很适合一技傍身，有过硬的技术技能对于事业发展较为有利，而比劫较旺，也适合偏体力方面的工作，可以坚持做下去，但也要注意意外伤害。
