# 人生建议

做任何事情，都先要有一个目标才行，要方向明确，这样自己才不会在前行的道路中迷路。所以你现在也是如此，要先为自己树立一个目标，并且自己，要努力的朝这个方向奋斗。针对你现阶段来讲，学习比什么都要重要的多。因为现在的学习成绩，会直接影响到你将来的方方面面。至于感情等，都不是当下最重要的事情。

每个人都需要拥有一个实际可行的梦想，有了这个梦想，我们所付出的一切才不会觉得辛苦。为梦想而努力，只要能有一点点进步，内心也是充实和幸福的。不管中途出现多大的阻碍，有了梦想的牵引，也不会轻易放弃。

**为什么很多时候我们觉得学习会非常累？**

这要看是为自己而学，还是为天下一切受苦众生而学。当完全是为自己而学，或为赚钱而学的时候，就会觉得非常辛苦。但如果能有为天下人而学的胸怀时，则一切辛苦也将变得云淡风轻。当然，学习也是建立在兴趣的基础之上的，爱好是最好的老师，如果没有爱好，学习的过程也是非常枯燥乏味且痛苦的。所以只要能真正建立起兴趣爱好，且有救济天下病苦的大愿，那么所付出的一切努力，都会觉得非常值得，且不会认为是辛苦。

很多时候我们一开始非常努力的去做一件事情，但中途遭遇一些阻碍就放弃了，这都是因为我们没有一个明确的目标，就很容易被外在的人事物所干扰而影响我们的选择。就比如我们行走在路上，如果内心并不知道要去哪里，或有一个终点也并非自己很想去，一旦中途有人告诉自己，走另外一条路可以达到更美好的地方，那么自己也多数会改变路径的。

就比如我有一位表姐，英语系毕业，毕业后在一家公司做翻译，一开始工资非常低，据说只有800元不到，但为了能赚快钱就选择去做工地，一个月可以有好几千，现在每每说起，都后悔不已。如果当时留在这家公司，必定工资也非常高了，而且工作也非常体面，最起码也可能是一名英语老师。

所以很多人在前进的道路中都很容易放弃自己最初的选择，这也就是为什么，越来越多的大学生毕业后并未从事本专业的工作，而是跨专业工作的原因吧。

很少有人是真正因为兴趣而去努力，而多数的人都是盲目的跟风，听说什么专业前景好，什么行业工资高，就去学习这个专业。最后才发现并非自己真心喜欢的专业，学了多年也一无所获，又因迫于生计而不得不去从事专业以外的工作。

任何成功，都源于兴趣和坚持。所以，不管经历什么阻碍，都不要轻易放弃最初的选择。事业也好，爱情也好，不管是哪方面的追求，都注定了会经历各种阻碍。有时候，一些阻碍不但不会对我们造成伤害，反而会因为阻碍而使我们变得更加优秀，更加勇敢。不要害怕困难，做任何事情都要有坚定不移的决心，且方向明确，不要气馁。要有越战越勇的精神。

说这些就是想要告诉你，不要对未来看的太美好，也不要对未来看的太悲观，困难是每个人成长道路上必不可少的。要有信心，恒心，不要轻易放弃，不管以后发生什么，都要坚定自己的选择，也唯有如此，才能走出属于自己的一片天地。
