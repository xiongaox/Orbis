# 一女问自己是否怀孕了？

## 盘内信息

**公元**：2009年6月15日10时37分47秒 阳9局

**干支**：己丑年丨庚午月丨辛卯日丨癸巳时

**旬空**：午未空丨戊亥空丨午未空丨午未空

**值符**：天芮丨**值使**：死门丨**旬首**：甲申庚

## 求测人问

一女年命庚戌，尚未婚配，近期月经不正常，自己很担心是与朋友交往不慎怀孕了，找我求测一下，我断没有怀孕。

## 奇门分析

日干辛金为求测人落震三宫，辛+辛伏吟天庭，临玄武，主自己不明确，为自己的错误或失误自责。胎地在亥，落宫虽然临开门但克日干宫，为没有怀孕之象。

辛金子嗣壬癸水，壬临杜门壬入墓击刑，没有怀孕，癸落宫临天芮星为胎息宫，胎息宫逢空亡，又临死门，庚金、癸水入墓，综合看没有怀孕。

## 反馈

7月9日反馈：确实没有怀孕，是虚惊一场。
