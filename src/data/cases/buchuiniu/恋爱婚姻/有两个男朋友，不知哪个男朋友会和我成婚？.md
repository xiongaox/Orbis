# 有两个男朋友，不知哪个男朋友会和我成婚？

## 盘内信息

**公元**：2007年11月28日13时16分6秒 阴2局

**干支**：丁亥年丨辛亥月丨丙寅日丨乙未时

**旬空**：午未空丨寅卯空丨戌亥空丨辰巳空

**值符**：天任丨**值使**：生门丨**旬首**：甲午辛

## 求测人问

女方为1985年（**乙丑**）生人，两个男子，一个是1983年（**癸亥**）生人，一个是1986年（**丙寅**）生人。

## 奇门分析

乙为女方，代表求测人，又代表1985年生人落巽宫，83年癸生人落坎宫，83年此男较喜欢女方，为男追女。

但癸下临己，己未地户主私欲，表明这人欲望很强，有自私的一面。

宫中逢杜门，表明此男方对女方隐瞒了一些实际情况。

1986年丙寅男落九宫。乙奇落宫生丙奇落宫，求测人比较喜欢此男子，为女追男。

丙落宫帝旺，临开门既表示他同意和女方在一起，也表明此人处事坦荡，对女方不保密。

丙临天辅星旺相，说明此人有知识、有文化，比较文雅。

乙下临丙，为此男年命。

综上所述，女方选择丙寅年生的男子作为配偶比较好。
