# 人生建议

如果你要学习周易术数这方面的知识，我可以给你几个建议：

1.先要学习命理知识。当命理知识都掌握后，才可以去学习卦理，最后才可以学习风水和择日。只有这样去学，你才能少走弯路，并能学的更好。

2.在掌握易学基础之后，你才可以去拜师。如果自己还是一个小白，一定不能去拜师。因为这个时候，你还没有分辨师傅正邪的能力，就很容易被误导。而且师傅对弟子的影响非常大。你越相信他，他对你的影响就越大，你能接受到他的信息也就越多。如果师傅是很正的，那么自然非常好，但如果遇到一个邪师，你这一辈子也会跟着毁掉。

因为先入为主，我们受到第一个老师的影响是最大的。但如果自己掌握扎实的基础后，再去拜师，就能分辨。好的师傅会选弟子，好的弟子也要懂得挑选师傅。

3.学习的过程，80%是靠自学，其余20%靠师傅指点。如果不能养成自学的能力和习惯，就算师傅非常高明，自己也不能学到太多的知识。自学就是多看书，当然书籍的选择一定要善，因为书也有善恶。如果要学有所成，除非自己悟性极高，否则都一定需要师傅的指引。师傅起到的作用，就是梳理你的知识，为你指明方向，解答自己的一些问题。其余都全靠自己。

很多朋友都会问我，学会需要多长时间？这个问题其实没有答案，因为全看个人。自己花费的精力，时间，以及个人的悟性都会决定学习周期的长短。当然最快也需要一年才可以熟练。对于大多数人来讲也就两三年的时间，差不多就能熟练掌握了。

我们学习八字，奇门遁甲，大六壬，六爻，以及梅花易数卞紫微斗数，或风水学的内容，比如玄空风水，天星风水等等。一般而言，选择三类即可。不需要都去学习，因为个人的精力和时间有限，都学只会消耗更多的时间。而且博而不专，杂而不精，反而学不好。我的学习科目是八字命理+奇门遁甲+玄空九星。以这三个为主导，也是主要研究学习的内容。这些学会过后，就可以应对一切事情。命，圭卜，风水都会。所以选择非常重要，但不管后面你选择什么，八字是一定要学的，这是所有术数的基础。

至于卦的选择：奇门遁甲，大六壬，太乙神术，梅花易数，六爻，小成图等等。选择一个就可以了，要选择自己喜欢的，以及更容易操作的就可以。其功能都是一样的，学术无高下，关键在于使用的人，这些都是工具。

至于风水，不管选择哪一个，都必须要学习三元风水，并且要以此作为主导。我选择这三大类，也是走了很多弯路后才锁定的。上面我说的类别，基本上我都一一学过，包括风水的全系，但最后选择出最适合自己的，以及实践最应验的学术来作为终身研究方向。

4.学习一定不能过于着急，我有两个亲戚也很想跟我学习，在我指点后开始看书。但都非常着急，总是问我还要学多久才可以。一定要记住，学习是一个漫长的过错，对有一些人来讲甚至是痛苦的。但只要自己爱好，一旦进入就能体会到其中的乐趣，特别是卦，会越学越有趣，甚至沉迷其中，这方面的学习，不比打游戏的瘾小。

我曾经在看书的时候，都是白天看了晚上看，而且晚上很多时候都会看通宵。没有睡意，也不觉得困。当然，我当时学习的时候还非常年轻，精力也比较旺盛，这个时候学习记忆力也是最好的，而且心无杂念，一心就学习，也不会为了生活而分心。

所以学习最好还是在早年的时候，如果进入社会了，一方面要赚钱，一方面要学习，心里面琐事也非常多，所以很难静下心来。也很难学的好。所以要学习静坐，让自己的心静下来。免去一些不必要的社交，多留点时间给自己，才能更好的去学习。

我上面所讲都是自己过来的经验，你要好好体会。之所以说这些建议，也是因为我发现你还是比较适合去学习和从事这门行业的。

至于做这个行业是否能出名或赚钱，这一切都是个人的运势决定的。但你要明白一点，只要有技术，就一定能赚到钱，只是多少的问题。在未来这个行业会越来越规范，老百姓辨别能力也逐渐提升，所以靠江湖伎俩已经无法生存了，故而必须要好好钻研学术内容，不断的提升自己的专业知识，才能开辟一条属于自己的道路来。
