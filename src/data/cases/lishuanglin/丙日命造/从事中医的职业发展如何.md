# 命理提要

一、日干丙为太阳火，在戌月出生，戌月已入深秋，丙见戌为墓库之运，火光昏暗，最怕土旺。地支见两个戌土，时干透出一个己土，则土气不弱，故需甲木来制戌土，则甲木为喜。丙火为阳火，也喜见壬水，则壬丙水火既济，更能滋养万物。甲木虚透，也喜见癸水来滋润甲木，更能去生丙火。不过原局是不见癸水的。时支暗藏亥水，可惜不透。为透甲而藏壬，为印透杀藏，难得贵气，不宜走仕途。

丙火在秋季出生，比较喜欢壬甲，八字有甲，且时支暗藏壬水，则格局还算可以。从旺衰角度来看，甲木为用来生丙火，但甲木虚透则印星无力，也为学习阻碍不顺。命局有印制去多余食伤，只要大运增加印的力量，则一帆风顺。

> 用神：木，火。因为丙火在秋季出生，阴气渐长，故而依然需要火来助身放光。木为最佳，可用木。如果见水来生木也为吉。则水木并见为喜。地支更喜见木，而天干可以见水木火。

> 忌神：土，金，水。水太多，也会损伤丙火。而金会损木，土会泄身助金损印。故而土金为最不吉。

二、命局偏印贴身，则很适合学习一些冷门学术，比如中医也很适合自己。木为用神，且中医五行为木，职业非常适合自己。

医生为三教九流之中九流行业，也应了偏印之象。而中医为冷门，相比其他专业学习者较少，越是偏冷科目，越适合自己。因为你八字偏星很重，不宜走寻常路，而应该走大家都不走的路，更容易成功。

月支戌为华盖星，日柱临空，这样的组合都很适合从事学术研究，故而从医是很适合自己的。丙火为太阳火，可以驱除昏暗晦气，故能帮助别人消除疾病。

但印星无力，甲木虚透而无根，唯有时支亥水来生甲木，但离甲木太远而无力助甲。印星为用时，虚透则学业不顺，求学之路比较坎坷，故而自己需要付出更多努力才可以应对运势的薄弱无力。

三、而婚姻方面，暂时先不要着急寻找。日支坐申金偏财为忌神，偏财+驿马。并没有起到太好的作用，则早婚早恋都会受伤，而且还会影响到你的工作和学习。时支亥水为七杀，申亥相穿，日时不合，也为感情动荡。

日支为驿马，则有远嫁之象，或找远方之人为夫。但日支为偏财，你择偶标准，往往更加注重外在，而忽略了内在。比较容易被有才华的，或嘴巴甜的，长相帅气，多金之人吸引。而很少看重内在，看重人心善恶。但你婚姻是可以稳定长久的，只不过姻缘迟点，并且迟吉早凶。

故而这个时间段，如果总是遇不到合适的，就先放下，不要去追求，一切随缘就好。身边有合适的，不错过，但也不要太在乎，身边没有也不刻意追求。等你学有所成，工作之后，自然会有好的姻缘。

而且你将来所在的平台越好，你的学识层次越高，那么你遇到的对象也必然会越好。我建议你找一名同职业的人，这样可以互相帮助，互相成就。因为作为女人，要成就一番事业，丈夫非常关键。要么丈夫就是你事业道路上的助手，要么就是绊脚石。

如果自己的职业和丈夫的职业有冲突，是很难两全的。所以选择对象，一方面要考虑人品，另外一方面要考虑对方的职业。而且职业对一个家庭影响也非常大。一个家庭的走势，几乎都是受职业的影响。可以说，什么样的职业，就有什么样的人生。

# 大运流年

20-30岁走的壬申大运，天干见壬水为喜，壬水可以生助甲木，地支申金也为驿马，而驿马为动，也为外出之意。

1.这十年很适合外出，去远方求学，奔波点反而为吉。

2.你八字日支为申金，自坐驿马，也为外出发展之命，走出去会更有前程。如果在家乡，会更多不顺，要么就劳碌辛苦。

3.女命日坐驿马，有远嫁之象。且七杀在时支，也为远的意思，因为时柱为门户，则出门才可以遇到合适的姻缘。

不过大运壬申，毕竟为金水大运，好在壬水生甲木，而申金生壬水，甲木生丙火，也算流通。大运本身没有损原局用神，故而不凶，但也非大吉。身弱又走克泄大运，自己会非常辛苦，身体也不太好，容易睡眠不佳，体弱无力，精神状态不佳等。这都是因为大运损耗自己所致。这样的大运，更要加强学习，锻炼强大的意志力。否则就很容易流于懒惰，懈怠，软弱。

如果是求学，壬申大运还算有利，毕竟壬水助印，帮助了印来生身，故而利求学，虽然过程不顺，但结果也吉。如果是求财，恐怕不太顺心。当然对于年轻人来讲，最重要的并非求财，而是学习。在未来社会，最值钱的永远都是知识。万物有价唯有知识无价。有效的利用自己所掌握的知识，就可以换来财富。

2020庚子年，庚金克了甲木，好在大运壬水通关，损害不大。且引动日支申金，而申金为驿马，故而在2020年是比较动态的一年。由于你还在学习阶段，故而不会体现为工作方面的事情。则更多体现为学习上的不稳定，或走动比较多的一年。并且压力很大，花钱也会比较多。财官都会损身，则今年身体也不太好，会吃药多一些。

在2021辛丑年，丙火最不喜见辛金，因为辛为丙火的死地，丙辛相合则黯淡无光。犹如天狗食日一般。所以2021年对于自己来讲相当不顺。且流年地支丑生了申金，也丑戌三刑，辛金合住丙火，故而不顺。但只要好好学习，其余事情都不要多想。比如感情，求财，工作等一切都不要去追求，学会顺其自然，那么也不会有什么太大的烦恼。但如果在这些年份，去追求学习以外的事物，往往不太顺利，而给自己带来烦恼，甚至麻烦。

2022壬寅年，则冲驿马为动。具体体现哪方面，要根据这一年自己追求所定。

至于在30-40岁走的辛未大运，也并非旺运。所以你在40岁之前都非常平凡，很普通。要求财很辛苦，但小财是有的，大财难求。所以在40岁之前，你更多需要去努力的是学习，要研读古籍，跟明师学习，不要满足于学校的知识。等40岁后，当运势好转时，你才会有更大的能力去承载更大的机会，才能有更大的成就。

机会分大小，大的机会只会留给更有能力的人，而能力不足的人，就算运势再好，也顶多把握一点小机会罢了。就比如，没有当大官的能力，就算给了这个官，自己也当不了。

从40岁开始，走庚午大运，庚金为财，会损甲木，但好在庚金虚透，且劫财制财，故而能得财。所以财运会非常好。你八字只有偏印，求学的方向，我建议你可以选择一个方向作为主要研究。比如内科，骨科，儿科（包括推拿），又或者是妇科等。所谓术业有专攻，选择一个类别作为主要研究，然后以此作为标签，成为这个领域中的专家，你会更有前途。不建议什么病都看，而术无所长。

从40岁开始，基本上一直到晚年，运势都非常棒。而且你八字格局组合也还算可以，故而你后半生还是有成就的。能在一个领域内有所建树。

# 人生建议

一、当自己经历过疾病后，再去从医，更能理解病人的痛苦，明白作为医生的使命。医生是一份非常神圣的职业，也是积功累德的事业。

中医是中华传统医学技术，诞生于原始社会，在春秋战国时期中医理论已基本形成，之后再由历代先贤们的不断总结和完善，而形成了一门理论体系完善且庞大的学问。中医治疗手段主要包括有中草药、针灸、推拿、按摩、拔罐、气功、食疗等方法。

中医在最近几十年中一直都饱受争议，出现了很多关于“中医无用”“中医是迷信”“废除中医”等言论。可以说啊，中医在当下的发展饱受阻碍，再加上中医治病效果缓慢，且服药麻烦，不比西药方便，而被大多数老百姓所放弃。

传承数千年的文化，不可能因为一些人的言论就被完全否定了。任何好的事物，都是在追求其他新鲜之后，慢慢又会被拿起。就比如中国人多数崇洋媚外，认为国外的一切都好，只要是进口的就一定是质量最好的，这种观念也会随着时间的推移，慢慢转变。就比如中医也是如此。

越是到未来，中医会越被人们重新认识，甚至重视。中医的市场，也必然会越来越大。

二、如果要从事中医事业，要抓住当下时代的脉搏，要从治未病入手，从养身入手，从治疗亚健康入手。这样更能得到人们的认可，也更有市场前景。当然自己研究的方向，也必然要围绕这个去做才可以。

所谓：“上医治未病，中医治已病，下医治大病”。而中医要发扬的就是治疗未病的精神，要让人们直接不生病，没有疾病。让疾病在萌芽阶段就被扼杀。要发扬中医的长处，才能让中医文化发光发彩。

现在市面上专业的中医不多，大多数的医生在开药的时候都是中药+西药一起。听起来更有道理，名曰：“中药固本，西药解病”。其实这样去做，只会让百姓人觉得，中医是可有可无的。而治疗疾病过程中，很难有人做到完全使用中医手法，在我们当地可以说是极其少见的，都快消失了。但我也问过一些中医师，就连老中医也不得不学着去给人输液，开西药，打针。因为如果不这样去做，中医根本无法生存。

所以啊，作为一名中医师，不但要精研医术，救死扶伤，还要努力的弘扬中医知识，让大家都能正确的认识中医，了解中医，并相信中医。当然，西医并非就毫无意义，西医在当今社会可以说是功德无量，救人无数。所谓各有所长，一口否定任何一门学术，都是愚者之言。

三、我从小的愿望就是成为一名中医，虽然目前没有实现，但依然对中医有浓厚的兴趣。也真心的希望我们老祖宗留下来的中医文化能传承下去，不要在我们这个时代走向消亡。因为这是无数人的智慧结晶，也是无数先贤们的心血啊，我们不能辜负了他们。只要走向中医这条路，就肩负着要复兴中医的使命和责任。

过去数千年里，中医扮演了非常重要的角色，也解救了无数病苦之人。科学的发展，的确方便了人类的生活，但给人类带来的副作用也是巨大的。古人认为科技是“奇巧淫技”，并非毫无道理。人类从有文明开始，已经5000年甚至更久，但从科技时代开始，人类想要再平安的生活5000年是不可能的。地球已经快被贪婪的人类掏空了，这就是逆天，也必将遭到自然的惩罚。在未来，会有更多的天灾，人祸等着我们。
