# 人生建议

一、所得一切果，皆源自造因。你所遭遇的一切，经历的一切都是由自己所造前因所致。没有这样的因，就不会有这样的果。当我们身处不顺之时，更多的不是抱怨，而是反思和忏悔。反思自己做错了什么，并且用笔给记录下来，然后真诚的去忏悔，并发誓再也不犯同样的错误。

对于命运较好的人来讲，即便是犯了一些错误也不会立马出现不好的结果。但对于命运不那么好的人来讲，稍微有点错，就生无量果啊。遇人不良，也都是因缘而聚。缘有善恶，而这一切也都是自己亲手种下的。待因缘具足之时，则果报现前。

未婚先孕是多么愚昧的做法啊。如果对方并非良善之人，当你怀孕后不但不会珍惜你，反而会更加看不起你。得不到会更加渴望，得到了会毫不珍惜。做为女人一定要自爱，不能轻易的奉献自己，在婚前更不能轻易的怀孕。我见过太多未婚先孕的案例，婚后都那么的不幸福，遭受着各种的折磨和伤害。

你自身婚姻就非常不好，那么就更要谨慎选择对象，更多的是去了解一个人的品行，不能被表面所迷惑。很多男人在婚前和婚后都是不一样的，婚前的温柔和善良在婚后就再也不见了。所以不能被暂时的美好所迷惑，要学会去看清楚一个人的本性才可以。特别是对于婚姻本就多磨的你来讲，更要如此。

如果和丈夫离婚了，你要再婚并不困难。但要在婚姻上面获得幸福是很难的。因为这一切都有定数。即便婚姻状态并不是很美好，很如愿，但是否会因此而感到痛苦，还是由心来决定的。当你只是看到痛苦的时候，那么你的人生必然是充满痛苦的。反之当你看到的都是快乐和美好，那么你的人生也必然会充满了喜悦。要明白一切外相和感受，都是由我们的心来决定的。越是在自身婚姻本就不幸的时候，越要懂得学会看淡，放下，用一个平常心去对待这一切。不要执着什么，更不要计较什么。一切都是假象，都是短暂的，不是长久的。

人生就形同乘车，夫妻也只不过是乘车的伙伴而已，只不过是一起多坐了一些站台罢了。但当我们下车后，谁也不会在乎谁了。我们一生会遇到很多人，丈夫，父母，子女，朋友，同事等等，这些都只不过是过客罢了。肉身也只不过是我们暂时寄住罢了。要学会时刻去观想，你所遇到的一切都是短暂的，是虚假的，不是真实的。这并不是实相。

只要如此去想，就能慢慢看淡，放下，并且从不幸之中走出来，让自己的心灵得以解脱，获得快乐。我们之所以痛苦，都是执着了不该执着的人事物。爱了不该爱的人，我们会因此痛不欲生，甚至付出生命。当我们起了贪心，执着心，嗔恨心都会生很多的痛苦。
