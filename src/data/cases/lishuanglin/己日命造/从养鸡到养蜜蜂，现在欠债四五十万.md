# 命理提要

一、日干己土在巳月出生得令，巳火为夏季，天气渐热，己土为干燥之土，最喜癸水调候，也喜丙火之光，方能生长万物。原局没有癸水，只有壬水，则层次稍次。夏季壬水枯竭，故而需要庚辛金来生水，时支临申金来生壬水为用。八字有庚壬金水，虽然不比辛癸，但也能得富。但很难大富，也不得贵。

己土最喜水火透出，天干有丁火，壬水。但不比丙癸，则己土处境一般。不过也能小富。如果见丙癸，则为水火既济，则能大富。

月柱丁巳火来生己土，为忌神旺相，地支无水来制火，则喜见水制火为用。八字喜见财星为最佳用神，其次可以见食伤来生财。年月日均为忌神，唯有时柱壬申为用，则时柱大吉。也为晚限较好。时柱也为子女，则孩子优秀，晚年有福。

> 用神：水，金。至于木可以制土，但木也会生火，则木作用不大。
>
> 忌神：火，土。天干最怕土，因为会损壬水，地支最怕火，因为会损申金。

年支辰为财库，不过财库在客位，时干壬水见辰入墓，而辰在外，则外出去了，也为消耗很大，为主位的财到客位。不过地支有申辰相合，故而也可以合入这个财，但这样必定非常折腾，也代表求财过程很辛苦，并不顺利。因为自己要得到这个财，首先是壬水进辰墓，又申金去合辰库，比较转折，而不直接得财，则为辛苦。

命中没有偏财运，故而付出比较多，得到相对少点。也为求财辛苦。而偏财则可以付出少量劳动，便能得到更大的财。

命格为身旺财弱，且财被合出去了，也为破财，花销很大。丁壬相合，为印重财弱，则为强合弱走，故而丁火合走了壬水，丁为印，则有钱了就要买房，置业为吉，多孝顺母亲。则能聚财一些。

正财不喜透出，财透则为众人之财，也为漏财之命。男命不喜财透，财透则不存。好在年有财库，且财库合入，也能小富。
