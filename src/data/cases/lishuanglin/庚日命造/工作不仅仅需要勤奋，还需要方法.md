# 命理提要

一、日干为庚金，为顽石之金，在亥月出生失令，又为寒冬之时，故而为寒金。亥月出生，则为金寒水冷土冻之命，急需见丙丁火来暖身，方可解冻。若无丙火则不能解其寒冷，格局将很一般，层次不高。

原局唯有戌土之中暗藏丁火，但由于丁火不显，故而无法制金，藏而不显等于无。戌土去制亥水，但由于水多土寒，故而戌无力制亥水，反而会被亥水所耗。且时支见卯木去合克戌土，卯戌相合，由于卯木得令，故而为木旺土衰，则必然损土。所以卯木并未起到好的作用，反而克损了戌土印星，也为用神受损。

命局喜印，而见戌土与己土贴身，但这两个用神均被卯木所伤，且原局缺火，则用神没有元神，故而格局一般。

> 用神：土，火。由于食伤太重，故而水多为病，最喜见土来制水，其次也喜火来生土暖身。至于金虽然可以帮身，但并未起到克制忌神食伤的作用，则金不算最吉。
>
> 忌神：水，木。最怕是木，多见会损印星，而水多也会生木寒金，依然不吉。故而水木干支均不可见。

八字最大的问题，就是不见火，则原局太寒，庚金无制而无法成器，则八字比较平凡。

二、时支卯木为财，但卯木临空，则有财空之意。

而财对应的是经济，收入，也代表妻子。故而会因为这些，而给自己带来非常大的苦恼。财星克印，会体现为因为求财而伤害健康，并且在求财过程中会遭遇诸多不顺，对自己阻碍非常大。能化解这种克的，唯有见火才可以。由于原局并不见官杀星，则印没有生扶，故而印非常的弱，用神过于虚弱，会体现为机会比较小，不容易把握机会，也会体现为工作当中缺乏大的贵人帮助。

年月食伤太重，而土弱，则为食伤旺而无制，在性格上也存在较大的惰性。食伤多则思虑太重，很多事情也是想得很多，但做的很少，缺乏实际行动的一个人。年月有亥亥自刑，一般八字有自刑的，都要注意一下身体，也容易去做一些伤害自己的事情。

# 人生建议

聪明的工作比勤奋工作更加重要。

一个人要获得事业上的成功，不仅仅需要勤奋，还需要方法。甚至做事的方法，比勤奋更加重要。所以当自己不管怎么努力，都依然止步不前，甚至不进反退时，就应该思考一下，自己当下所做的事情，是否是正确的。

什么样的工作才是真正适合自己的呢？

1.兴趣是最好的老师，所以好的工作一定要是自己喜欢的。如果去做一份不喜欢的工作，即便收入再高，也不能因为工作而获得开心。如果为钱而工作，则为金钱的奴隶，不仅总会因为工作辛苦而抱怨，还会因为不喜欢而不花费太多精力去创造。

一份好的工作，一定要是自己喜欢的，当然最起码不能是自己讨厌的。因为只有做自己喜欢的事情，才能做得更好，而且不怕辛苦，也更能坚持长久。当然，并非每个人都能找到一份热爱的工作，即便当下的工作我们并不喜欢，也要努力让自己去爱上这份工作。只有这样，才能在这个行业中有所发展，也才能让自己少点抱怨。

2.要做自己擅长的事情。

做一份工作，不仅仅要感兴趣，还要擅长。所谓擅长，不但要真正去懂这个领域，知道如何去做，还要让自己的兴趣符合这个行业的特点。

就比如有一些行业是偏向安静的，而有一些行业则偏向奔波。如果自己喜欢奔波，却做了一份安静的行业，则会让自己非常难受。让一个炒菜的大厨去做修车，肯定是做不好的。所以一定要懂得去发现自己的长处，以及性格特点，然后再去寻找与之相匹配的行业，才能在这个领域有所发展。

每个人都有属于自己的天分所在，只要能发现自己的天分，且善于运用，就能让自己的能力得到最大程度的施展，就能有所作为。

3.要做解决人们需求的工作。

这也就是所谓的风口，其有大小之分。大的风口，能成就首富级别的人物，而小的风口虽不能有大成就，但也能小有作为。就比如在一个新的小区门口开一个小型超市，销售一些生活用品，并且配送到家，可以通过微信直接卖货，虽不能赚大钱，但也能因此改善生活。这也是一个风口。需求的人越多，则市场越大，事业成就也必定越大。

所以不管是开店，还是做技术，都要仔细去思考这个问题，自己所选择的行业，是否能解决别人的需求。有的时候，当实在没有需求时，也可以创造需求，就看自己如何去设计了。

所以选择具体做什么工作，不仅仅要考虑八字运势，还要考虑以上三点。当运势好的时候，则会有更多机会出现，而这些机会都更加适合自己，但机遇出现和能否把握住并非一回事。要知道，机遇只留给有准备的人。如果自己并没有准备好迎接机会，就算再好的机会出现，也会因此错过。

至于妻子总是无理取闹，我在前面说过了，并非真的无礼。所谓贫贱夫妻百事哀，很多时候，一切矛盾都源于经济上的压力。生存是一个非常现实的问题，每个月的固定开支，是必须要拿出来的。所以要解决这些矛盾，除了更加理解包容妻子之外，还有就是要更加勤奋的去工作。除了勤奋，还要懂得如何去工作。

如果时间充足，也可以身兼数职，比如在下班之后，可以跑跑外卖，先要让生活好起来，解决基本的生活保障，让妻儿无忧，之后再去慢慢考虑发展的问题。

至于下一步到底做什么，不要着急下定论，可以先去学习，慢慢的你的思维眼界就会打开，也就能看到更多机会。你中年运还是不错，所以未来一定会慢慢好起来的，只要朝这个方向努力，不要放弃，就一定不会太差。
