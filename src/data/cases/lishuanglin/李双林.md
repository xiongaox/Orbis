# 李双林介绍

李双林，生于南充，知名风水命理学者。
自幼爱好易学，跟随多名老师学习，凭着超高的天赋以及与术数的缘份，对风水命理等术数均有独到的见解。

## 基本信息

- **中文名**：李双林
- **别名**：柳明先生
- **出生地**：四川南充南部县
- **民族**：汉
- **国籍**：中国
- **宗教**：佛教
- **代表作品**：《五诀秘要》《李双林通胜》《双林命稿》
- **擅长**：八字命理、奇门遁甲、玄空风水
- **籍贯**：四川南部县
- **拜师**：李太安，杨元通，释洪戒
- **参师**：侯明清，邓月贵等

## 学艺经历

李双林早年体弱多病，三天两头就会去一趟医院，由于健康反复无常，家里长辈想到了寻找方术的办法治疗，也因此接触了很多民间术士，从此就对传统文化充满好奇，一直都希望能一探究竟。

最早是在当地接触了一位盲人算命先生，先生说他未来必然会名扬天下，但是八字缺木所以一定要改名字，最初名字为涛，水旺主凶，说用这个名字会多灾多病，最后改为现在的名字。

接触到易学是当时祖上有一本《算命不求人》，被他拿去研究学习，从此就陷入一发不可收拾的地步，当时才十岁左右。并且表现出超强的悟性和天分，可以对很多术语无师自通，在不到十岁就学会了一些简单的看命方法，也经常被亲戚要求看看运气。每次都会去地摊边看看有没有喜欢的书籍，有喜欢的就会买下来,然后回家研究。

人生的第一位老师是他母亲的干爹，名李太安，阆中市元山人，当时跟着他居住在元山寺中，白天看师傅手稿，晚上抄师傅手稿，边看边抄足足有三个月的时间。李太安主要研究的是民间葬礼，也就是阴阳先生的工作，所以在易学上面并没有学到太多的东西，由于感觉没有自己想要学习的内容，所以决定下山回到家中。李太安也成了他的启蒙老师，虽然学到的东西不多，但是知道了应该怎么去学习，明白思路后就自己买书，开始了漫长的自学之路。

正式研究四柱第一本书是看的《四柱预测学》，整日苦读，每天晚上都是看到很晚才会想到睡觉，基本掌握了论命的口诀，但是看来看去依然不得要领，后来才知道这本书籍只有口诀没有技法，就算倒背如流也不能准确的看一个八字好坏。正在苦恼的时候，接触到了第二本书籍,那就是《千里命稿》,明白了旺衰的判断方法，也了解如何推命，也因此掌握了看命技法。后来又看了《子平真诠》《滴天髓》《三命通会》《命理探原》《神峰通考》等古代名著。全面的了解了口诀和技法的使用。

风水上面熟读了《沈氏玄空》《青囊奥语》等著作，感受到了玄空风水的神奇之处，于是决定潜心研究玄空风水。再后来接触了《神奇之门》《开悟之门》《奇门旨归》《奇门秘籍》等书籍，正式迈进了奇门遁甲的大门。一直以来紧守八字命理，玄空风水，奇门遁甲这三种学术，从未有过杂学，在这些基础上又看了很多当代名家的书籍共计百本，以及网上各种预测案例，从而整理归纳出自己的心法口诀。

在家里闭门看书长达一年的时间，之后拜访了民间老师侯明清，跟随了一段时间后就外出求学了，去了成都、香港、西宁等地拜访一些学者能人，由于他看书比较多，基本知识点都已经掌握，所以在交谈之中就可以学习到很多东西。后来遇见了真正指点他的老师邓月贵，1939年出生，属于纯粹的命理爱好者，擅长八字六爻。

由于见他比较年轻，又非常刻苦实属难得，所以愿意将自己多年的经验和体会全部和他分享。也正因为邓月贵的指点，他在易学命理上面才真正的掌握核心。所谓真传一句话,假传万卷书，很多书籍看的再通透，都很难体会他真正的含义，必须要有人从旁指点才可以。

在学艺当中，遇见很多的贵人指点，加上他刻苦爱思考，易学成绩突飞猛进，因为对易学的独到见解，很多研究易学多年的长者都来向他请教。每次外地，他都会去摆摊的算命先生哪儿坐坐，花钱算算自己的八字，如果对方有技术就表明自己的身份兴趣，然后互相学习切磋，如果没有技术也不会刁难，而是给钱走人。也正因为这样的方法，学习到很多民间论命的技巧。但是路漫漫其修远兮，学术方面，永远都是没有止境的。

## 从业经历

- **2013年**：被聘为四川省风水学会副会长，高级风水师，同年在南部县晓霞路开设风水馆，成为风水馆馆长。
- **2014年**：成立四川易初文化传播有限公司，担任董事长。
- **2015年**：正式入驻今日头条、一点资讯、凤凰星座等平台,成为一名风水命理作者，并且受到知音网邀请为入驻专家。
- **2016年**：加入了腾讯媒体、新浪媒体等，并且创办了李双林易学网。
- **2017年**：开设了语音讲课，成为各大媒体原创作者。
- **2020年**：发布新书《五诀秘要》。
- **2022年**：发布新书《双林命稿》，创立"三元天星"派。

## 就业风格

以严谨科学的态度对待易学，以辩证的观念看待易学，不迷信，不轻信。在易学上面，从不误导他人，用专业学者的眼光，指点他人找到方向，获得希望，在人生的道路上面不会迷茫。

提倡通过修心来改变自身命运，所谓相由心生，境随心转；通过易理推算告诉他人命运好坏，需要注意哪些问题，然后帮助他人了解自身弱点，明白自身长处，再自我调节和控制，扬长避短，从而达到趋吉避凶的目的，这也是李双林一贯做事风格。

对待风水的态度依然是不盲目，风水建立在命运基础之上，所谓一命二运三风水即是如此。从不吹嘘和夸大风水效果，也不会借此为客户改命造命，一直以来都是提倡科学风水观念，即风水是命运的衣服，是辅助命运的手段。风水可以让吉则更吉，凶则小凶或不凶，但绝对不能改变命运的本质。

在易学道路上面，一直都是小心翼翼，面对求测人开口也是万分谨慎，从不敢胡乱说话，也不敢说没有把握的话，怕因为一句错误分析误导了他人。在建议上面，从不提出一些违反人文法则的建议，破坏人伦的言语。一直都是以周易为辅助手段，目的是让人们生活的更好。
