# 人生建议

但凡遇到这种命格，我都会建议其看淡婚姻，因为唯有如此，才能减少一些因为婚姻而带来的烦恼与痛苦。于是有朋友就会问了，看淡婚姻，到底是看淡什么，又该如何去看淡呢？

1、要看淡对另一半的输赢成败，减少过高期望。

并不是每个人都能嫁给一个各方面能力都非常优秀的男人，如果总是要求另一半要如何如何，不仅会让自己活的非常辛苦，还会因此制造无数的夫妻矛盾，导致家无宁日。

作为男人来讲，谁都希望自己事业有成，各方面都非常顺利。但因各自因缘福报不同，所求未必如愿。有的时候，作为妻子如果对丈夫要求太高，会让对方也活的非常累，久而久之，就会对婚姻失去信心。

要适当的看淡另一半的事业成败，不管是成功还是失败，都不要太在意。任何事情本身是没有好坏吉凶的，是因为我们总是认为一些人事物没有达到自己内心的期许，而心生不满，从而生种种烦恼。

2、要看淡另一半对自己的态度。

总是有很多人，因为对方一句话，一个所谓的态度而大发雷霆，甚至因此走向离婚的地步。

人与人不一样，每个人处理事情的态度与方法因为各自认知不同而不同。有时候，自己认为一定要这样做，但对方偏偏不会这样做，其实不管怎么做都是对的，只是因为不合我意，而存在了所谓的对错，这种对也好错也罢本身也都是不成立的，是自己主观定义出来的。我们总是自己给自己设置诸多障碍，然后自己在这些障碍中怎么都走不出来。

特别是在结婚之后，更要看淡这些，每个人都有自己的不良习气，对方有，自己也有。多关照自己，多要求自己，才能越来越好。结婚多年后，我们总会因为一些小事而埋怨对方，说对方变了，不爱自己了。其实人还是这个人，变的只是自己的心。

要明白无常的道理，多去观照无常，就不会因为一丝变化，而心生不满。明白无常，就能接受一切变化，自然也就不会有什么抱怨了。

3、不要去攀比，要学会看淡他人的生活。

不要总是盯着别人的幸福看，因为当别人不幸福的时候你并不在身边。人们总是会把好的一面，展示给外人看。我们总会错误的认为，身边的人都比自己过的要好，但却不知道当自己在羡慕别人的时候，还有很多的人在羡慕自己。生活本身是非常平静的，没有好坏，是因为有了比较，才出现了好坏。

就比如在过去几十年中，不少农村结婚后的女孩子，出去打工几年后，便会回家与丈夫离婚。这是因为有了比较，就诞生了不平衡，也就有了痛苦。

对于男人来讲也是如此，总见别人妻子好，总是用别人妻子的行为态度来要求自己的妻子。这些啊，都是没有智慧的行为，也是非常愚昧的做法。不要去羡慕任何人的生活，就算对方真的过的好，这也是他们自己的福报，要明白人与人是不一样的。虽然总是说人人平等，但人从出生这一刻开始，其实就注定了不平等。我们既要努力奋斗，又要懂得知止，人生唯有接受，方能幸福。

不要总是想着去改变对方，要知道，改变别人比改变自己还要困难千百倍。与其痛苦改变别人，不如学会改变自己，因为当自己改变后，与之相应的一切也都会发生改变。我们所遇到的一切，都是自身磁场感召而来，一切都是吸引法则，要想感召好的人事物，就要让自己变得更好，唯有如此，才能彻底改变。所以要学会看淡婚姻，既要好好珍惜，又要学会看淡，如果失去了就要学会放下，因为该你的跑不了，不该你的求不来。

执着于失去，不仅不能拥有，反而会失去的更多。只有放下失去的，才能察觉到拥有的。要明白一切事物都成两面，得到即失去，失去即得到。得到的越多，对应失去的也会越多，反之失去的越多，得到的也会越多。总是盯着失去看，就永远不能感受到自己拥有了什么。

世界上最宝贵的，是我们拥有的一切，而不是失去的一切。因为不论多么宝贵的东西，只要不是你拥有的，都与你毫无关系。故而珍惜自己所拥有的一切，才能过的幸福。
