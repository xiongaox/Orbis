# 人生建议

你一定要有一技之长，才能在事业上面有更好的发展。我不太建议你去创业，能为别人做就最好是为别人做，这样可以降低自己的风险，也能让自己更加稳定一些。如果创业，则亏损非常的大，因为自己的运气并不具备，若无他人帮助，很难有所发展。

比劫合财也能代表有财，但被七杀阻碍了，所以求财过程并不会太顺利，而且结果财也不大。故而在金钱上面不要有太大的欲望，要懂得满足，才能减少诸多烦恼。要明白人生的乐趣重在努力的过程，而非结果。只要自己去努力了，尽了自己最大的能力，至于结果如何都要看淡一些，不要太执着于结果的成败好坏，只有这样你才能活的更加洒脱自在。而且往往越是不追求结果，越容易获得想要的一切。要注重过程，而过程就是在种因，只要过程做好了，自然就能得到理想的果。

大运不善，往往很多事情是看不到结果（希望）的，更容易气馁，所以这个时候只要能积极面对过程，一步一步的去努力，一切也都会好起来的。你的命要有大的财富是很难的，但小财通过自己努力是没有任何问题的。你在晚年的时候会非常不错，所以后福很好，要有信心。
