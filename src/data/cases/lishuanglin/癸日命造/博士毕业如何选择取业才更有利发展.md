# 人生建议

这也算一个非常不错的命局，再加上自己能获得较高学历，必然助长原局层次，让命格更加具有贵气。

一生财运都是不错的，但不要去做风险投资。不建议独立创业，最好是在单位。因为自己年轻时期大运并不算旺，中晚年会比较好。这样的运一般都特别符合上班人员，年轻的时候运气普通，但工作稳定，收入平稳，生活幸福。老年有退休金，悠闲自在，福气满满。

至于婚姻不能太着急但也不能不上心，有合适的还是要把握才可以。不能为了工作或学习就完全搁置了婚姻，这样也是不好的。后面的大运食伤都比较重，所以容易野心大，这一点要特别注意才可以，不然也很容易因为野心大不容易满足，而生很多烦恼。

特别是在择偶和择业上面，一定不可以要求太高，否则累的还是自己。人生可以活得很轻松，所以没有必要把自己弄的那么累。

自己八字不错，但运势早年不强，故而在事业上面不要太高的追求，普通点更好一些。自己的早年运和晚年运都是不错的，因为八字原局大限年柱和时柱为用神，故而早年运和晚年运大吉。而青年中年阶段，会有一些波折，不过问题都是不大的。只要注意一点，莫贪心，多知足，那么一切都好。
