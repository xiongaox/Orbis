# 人生建议

1、对于一个五岁孩子来讲还并不清楚什么是“性”，所以经常用手摸下体只是一种生活上坏习惯，不算什么邪淫。因为邪淫的前提条件是先有淫心后有淫事，并且所淫非人，非地，非道。至于坏习惯都是能戒除的，就和现在很多小孩子喜欢吸手指是一样的。所以也不要想得太严重了，以免自己吓自己。但孩子的任何不当的行为，都应该引起重视，才能尽早的去改正，避免这样的事情再次出现。

现在早熟的孩子越来越多的，究其主要原因还是饮食的问题。在饮食上面过多的大鱼大肉，食用太多的垃圾食品，都很容易导致孩子早熟，特别是女孩子更加严重一些。另外一方面就是各种爱情电视，以及手机上面各种爱情小视频，这样对孩子的心灵冲击也是很大的。我经常听到一些女孩子，在4岁就开始规划自己将来要找什么样的对象，说的还头头是道；有些不明事理的家长还因此而觉得自己孩子多聪明。其实这并非一件好事情，因为找对象并不是一个几岁孩子应该思考的问题。这也说明现在很多孩子的心理年龄远远超过了自己的实际年龄。

我们知道了原因就可以去规避。首先就是饮食方面，一定不要认为给孩子每天都吃肉，就对身体好。其实人体需要的营养是有限的，并非吃的越多就越好。营养过剩也会带来很多危害。所以一定要控制好饮食，三分肉七分菜。每个星期最好是一天肉一天蔬菜，不要每天都吃肉食。而且现在的肉食并不健康，特别是猪肉4个月就出栏了，正常情况是需要长一年的。吃的肉食都是催熟的，孩子吃太多必然也会把自己的身体给催熟了。还有就是吃蔬菜，尽量多吃当季的菜，至于不当季的偶尔吃一下就可以了。所以饮食非常重要，万病皆从口中入。早熟也是一种病，而且对一个人伤害非常大，会缩短孩子发育的周期，导致不长个子，以及早恋，过早性行为，对生理和心理的伤害都是极大的，而且是永久的。

我顺便说一下，如果让孩子吃素不但对健康好，还会增强智力，并且不会导致营养不良。有时间可以了解一下素宝宝，包括刘德华的女儿也是素宝宝。至于我本人吃素很长时间了，并未有任何营养不良的情况，而且还比之前更健康。这也说明人体需要的营养完全可以从蔬菜中获得，而非一定需要靠肉食。所以把肉食作为一种零食就好，而非主食。

2、另外一方面就是孩子所闻所见，作为家长一定要进行筛选。不要让孩子过早的去看都市爱情片，主要是父母就要做好榜样。不要当着孩子的面看一些爱情片，会让小孩子对爱情充满好奇，就会去探索，特别是青春期的时候，朦朦胧胧的，很容易因为内心渴望“爱情”而早恋，甚至过早偷吃禁果。并且父母也要给孩子灌输一个正确的爱情观，包括性要大胆的给孩子讲讲，让孩子明白其中的利害关系，对孩子的成长都是非常有利的。除此之外，就是父母要陪伴在身边，可以起到一个好的监督作用。

至于女儿如果再次出现用手摸下体的事情，你可以先言语呵斥，不听话可以适当体罚，直到改正为止。现在很多专家说不能打孩子，民间俗话说到教棍之下出好人，这句话是有道理的。适当的体罚，可以让孩子更加深刻的记住犯错的后果是很严重的，如果只是言语教育，很多孩子并不吃这一套，并且对于小孩子来讲她并不能听进去那么多道理，也无法理解，只有挨板子才是最直接的。

3、其次就是孩子的命运方面，从八字来看并不是很理想。年轻时代都不太顺利，只有晚年才会好点。所以父母在教育上面，除了思想品德教育之外（立德），就是知识文化的教育（立业）。女孩子一定要具备善良和自律，善良的女生不管在哪里都是受欢迎的，并且会有更多的人愿意帮助她。而自律的女生不管是在感情上面还是工作上面都懂得什么该做什么不该做，从而减少很多错误的行为。自律也等同于洁身自好，不管是在思想上面还是身体上面都是如此。

一定要让孩子受到良好的教育，学校环境是非常重要的。越是八字不好的孩子，越要在一个好的环境当中，这样可以减少因为环境不善而对自己造成伤害。并且作为妈妈一定要在身边陪伴才可以，对孩子最好的爱，其实也就是父母的陪伴。
