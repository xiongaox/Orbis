老师我八字中适合干这些不？我想做什么都是一定要做出成绩来，因为我以前缺乏自信，现在我在改变，希望老师看看我以后在当地或者说以后能不能有名声和干这个行业的前途，望老师指点指点，谢谢！

# 命理提要

一、日干为癸水，在申金月份出生得令，不过坐卯木泄气，时辰为火土也是来克癸水的。八字戊癸相合，但是合而不化，属于争合，为一癸合双官。日干癸水虽然当令，但是并不得地，也不得势，只能按照身弱来看，则八字喜金水为用神，木火土为忌神。

由于日干癸水太弱，虽正官合身，却不担官杀，容易胆小，体质偏弱。月令申金为印代表学习，也代表文化，印星当令且有官杀来生，所以非常利学习。命局属于典型的当令不旺，看旺衰不能仅仅考虑月令，要学会全局考虑，如果只是看月令，则会过于偏颇而失去准确性。

二、在事业上面，日支坐食神利技术，我的八字日支也坐食神，所以你要学习一门技术是非常好的。而且八字有印，也代表文化学术，易学行业也属于文化行业，是需要看大量的书籍，背大量的口诀才可以，所以对学习能力要求是极高的。如果学习能力太差，则会导致学习结果必然不理想，学不好自然也会把事情做不好。八字中有印，也暗示喜欢学习，对学习是不排斥的，有学习的主动性。

八字出生在午时且坐卯木，地支中子午卯酉为四正，八字有子午的都可以学习风水。你八字时辰为午火且为桃花，桃花也代表喜欢你的人，也暗示相信你的人。从这个信息来看，是可以学习的，但是阴阳先生和易学是没有太大联系的。民间的阴阳先生，虽然大多数都在看风水算八字，但是他们对风水和八字的了解都非常肤浅。虽然你爷爷在当地名气不错，但是我这样说你一定不会反对，你去验证一下你爷爷在易学上面的知识，会发现是非常浅薄不足。这是因为阴阳先生的学习过程，和易学完全是不一样的。

**阴阳先生：**

一般指民间主持丧葬的师傅，主要业务是以丧葬为主。也就是有人去世了，就需要阴阳先生来主持，一般工作为安排葬礼，选择坟地，择日出葬，赶秧煞，以及回秧等。有部分阴阳先生为了赚更多的钱，还会包揽灵堂搭建，穿衣剃头，销售花圈纸钱等业务。

阴阳先生的学习主要是以符咒为主，会背诵大量的咒语和民俗四言八句，因为在出丧的时候需要用到，比如盖棺咒，封钉咒，起官咒，安葬咒，呼龙口诀，撒五谷等等。后面棺木出来后，还要在停尸房打煞，帖符纸，防止家中异响怪异等。还要推算七单子，写路引，引魂幡，地契文书等。因为我最早也是学习的这个，所以这套流程我是非常了解的。

而在易学上面却基本上只是一个很肤浅的了解。比如安葬，大多数都是翻书选择朝向，按照六十仙命葬山这个来选择，择日也是翻翻黄历，标注为日子就出丧，然后懂点简单的形象法风水。基本上有百分之90的阴阳先生，不懂风水（只能算知道），不懂八字命理，看八字是根据生肖和察言观色，不懂卦理（极少数懂），罗盘只会一层或者是两层看法（极少数懂水法，至今我没见过，都是吹牛）。当然并不是说阴阳先生就是假的，只不过各自做的事情不一样，工作类型不同而己。

**易学行业：**

则是以测算为主，属于理派学，推理学。推算命运，则需要系统的学习八字论命方法，以及六爻，奇门遁甲，梅花易数等。如果学习风水，则会选择三元，或者是三合，金锁，八宅等专注研究。一般不涉及道法和丧葬工作。

在四川的阴阳先生是最乱的，可以说是样样懂门门瘟，为什么这样说呢？

我就是四川人。四川在这方面并没有明显的分工，不像沿海城市，法师和风水师是分的很清楚的，而不是混为一谈，各研究各的专业，各自精通。四川的阴阳先生是集法师，风水师，算命先生，葬礼主持人等于一体的。所谓杂而不精就是这个道理。做了法师的工作，也做了风水师的工作。人的精力有限，哪能都研究好。所以有部分阴阳先生就法师不像法师，风水师不像风水师，惹内行嘲笑。

三、你八字为正官合身，正官为工作，合代表你是有工作的人，坐食神也为有技术且靠技术吃饭，有印为用也代表有文化。种种信息也看出你可以从事这个行业，但是阴阳先生和易学工作是不一样的，容易顾此失彼，所以你自己要做好选择，也要看你更加喜欢什么。埋葬死人煞气是非常重的，所以大多数的阴阳先生家庭都是不完整的，是不幸的。如果你没有足够的福报，我是不建议你去做这个行业的。

我最早也是学习这个，但是内心并不喜欢，所以最后放弃了，而投身易学研究。今日看来我的选择是正确的，也希望你能选择自己喜欢的，更加适合自己的。阴阳先生做事情，张口闭口就是神鬼，这点是我最反感的。我是一个非常辩证的人，做事情讲究的是理论，只要不能用理把我说服，我都会持怀疑态度。当然学易就必须要有这种态度才可以，否则会步入迷信旋涡，而无法自拔。

# 大运流年

17-27岁走的丙午大运，为财来生官，大运并不吉祥。而且你八字年柱为偏财+七杀，也为凶神，早年走忌神大运，则可代表出身并不富裕，家庭也不太好。所以在将来更多也是要靠自己，而无法依靠到家人太多。

你现在还非常年轻，如果现在就投身丧葬，必然会导致阴气加重，不利婚姻。而且做丧葬行业，很多事情是要半夜就走，这样会影响睡眠，如果去晚了生意就被抢了，生意好则每天都在接触死人，加上你八字命弱而运也弱，所以这样下去，必然会不断的消耗你的阳气，对你的健康造成危害，影响到你的身体。

你还非常年轻，还要结婚生子，不要过早踏入这个行业。否则会影响到你的后代，你的婚姻，甚至你的健康。我这不是危言耸听，我是过来人，你一定要听我的建议。至于你要学习易学，则百无禁忌，只要想学都是可以的。易学是文化知识，你可以先学习。如果你要做丧葬，等你过了40岁再做最好，孩子大了，家庭稳定了再做。

27-37岁走的乙巳大运，也是消耗自己的运气。这十年运气并不是很好，不过你晚年大吉。反而这样也很符合这个行业的状态，就是胡子越长越吃香。从你一生运气来看，并不是很吉祥。那么命弱运弱，则最好有一技之长，但是要发财很难，不过可以养活自己。

# 人生建议

一、现在不要从事阴阳先生，也要停止跟着你爷爷跑，如果他真的为了你好，会让你选择其他行业，而不是继承阴阳先生。这个行业，一般做一代是最好的，做两代甚至三代会导致一代不如一代。

葬坟属于做阴宅，一旦坟墓位置选择不好，害了主人则也是给自己造了罪过。所谓医生杀人一个，阴阳杀人三代，就是这个道理。一旦坟墓葬的不好，则三代都会跟着受祸。但是有的时候也有天意在里面，而并非完全人为，但是事情因为自己而起，必然自己也是要承担因果的。

二、其次就是很容易触犯阴邪，比如你选择的地方有古墓，有其他阴灵守护，如果你用了则自己也会遭殃。如果你运气很好，则自己平安，但是也容易报应到子女后代身上。好风水你也不敢乱讲，据说好风水都是有鬼神守护，如果给了不该给的人，风水师也是会付出代价的。所以阴宅风水不要乱看，没有把握不要去做。

你可以自己去观察，但凡是从事阴阳先生，后代都没有好的，这是铁定的规律，一定不会错。有部分后代好但自己会不好，当然这里面也有因果和各自福报命运的影响。这个我就不多说了，怕你接受不了，就此点到为止，你也可以和你爷爷沟通一下。

三、我觉得你现在应该以平常工作为主，如果要刚出入社会就从事这个行业，是需要足够天分和因缘的。我在几岁的时候就能给别人看命和看病，有一种天生的记忆在里面，学习过程也是非常顺利，看一眼就懂了。如果你没有这个缘分，太早从事并非好事情，没人会相信你，行业路途是非常艰苦的。毕业后应该先找工作上班，回归到正常的轨道。要听女友的，考虑对方感受。但是你可以不放弃学习，这个不影响你工作和生活。你可以先学习易学，或者是阴阳先生的一些咒语也可以学习，背诵。等时间到了，你再从事这个行业，现在做有点早了。一定要听我的，其他的就不多说了，我泄露的已经够多了，把这个行业的底都给抖出来了。
