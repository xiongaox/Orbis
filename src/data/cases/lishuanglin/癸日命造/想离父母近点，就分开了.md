# 来信

我是女生，目前也喜欢女生，昨天和对象说了现实问题，我哭了好久好久，感觉看不到希望了。我目前在她所在的省份读书，以前心很大，想离开父母过自由的生活，但这次放寒假回家，看到我妈老了很多，尤其是送我回学校那天，在火车站看到母亲的背影，眼泪一下子就止不住了，我那一刻才理解了朱自清的《背影》。我想回家了，想离父母近点，她说那就分开吧，可是我也舍不得现在的对象。

我想让李老师测下她的八字，想看她以后过得好不好，辛苦不辛苦。目前也因为工作的原因十分不稳定，现在在找工作中，想问问老师她以后会不会有一个好的工作，她学历大专，护理专业，很善良，但爱吃，我现在已经可以长素，但她无肉不欢，我多次说过可以一个星期吃素一天也好，被否了，我一直在读地藏经，最近总是回向给她。她有个弟弟还在上大学，我想让她花钱活动一下进医院有个稳定的工作，但是她不想增加父母的负担，拒绝了。她的八字是坤造：甲戌丁卯癸巳壬子（空午未）。

提问时间：2019年3月13日（星期三）上午9:32。

# 命理提要

我们在这一生当中，受到最多的痛苦来源于一个“情”字，有亲情，友情，也有爱情。其中爱情是最让人痛苦的，也是最容易因此而生痛苦的。不管你爱谁，只要你爱了，付出了感情，那么就注定了会因此而受到伤害，不管这段感情是正确的还是错误的。同性相爱在当今社会并不少见了，根据一项社会调查，大约占5%左右。也就是100人当中，就有约5个人有这样的情况，有的是天生的，有的则是因为后天因素造成的。但在世俗人的眼里，这样的心理是痛苦的，不过快乐还是痛苦都是活给自己的，而不是给别人看的。我看到你如此关心对方而非自己，又是吃长素的人，非常具有善根，所以抽选做为案例分析，希望能为你解开心中的困扰。

一、她是癸日出生的人，癸在卯月是不旺的，坐巳火泄身，年月日时都不见生扶，全部都是耗泄自己的五行。只有时柱壬子来帮扶日干，所以八字为偏弱的命，木是最旺的又来生火，故而木火最旺。则喜金来制木泄火生身，水来制火为吉。则八字喜金水为用神，而木火土均为忌神。原局当中壬子为用，则水为最佳用神，故而最怕土来克自己，故而见土为最大的忌神。

二、一般有同性取向的八字，都有一个共同点，多数都是身弱而比劫为用，往往比较喜欢同性一些，或者是和同性更加有缘。但是这也不能代表一定就喜欢同性，只是一个共同点之一，我看过不少类似的案例，发现都有这样的特点，不过并非所有事情都能在八字当中找到答案，特别是一个人的思想追求，往往受到后天的影响更大一些。八字乃一个人的先天命运，我们可以理解为前世所种福报深浅的体现，而人生中所经历的一切人事物都是缘，在先天命运+各种后缘的相互影响之下，就会产生一定的果。这也就是因缘果的规律。

同性取向对自己来讲并没有什么不好的，但世俗的眼光和言论往往会让自己痛不欲生。所以越是这种情况，就越要学会看淡身边人的看法，要活出自己来。就比如金星一样，只要自己开心，其他都不重要，照样能活的精彩。太在乎他人的看法，不管你是优秀的还是平庸的，你都会深陷痛苦之中，不管你怎么去努力，总还是会有人在背后议论你。我说这个，也就是想告诉你，大胆去追求自己想要的生活，不要太在乎他人的看法。能在娑婆世界相遇，必定前世有极深的缘分，不管这段缘分是好是坏，都要好好珍惜。要懂得惜缘，解缘，然后断缘。

她的八字用神集中在时柱上面，也暗示晚年还是很不错的，但在年轻的时候也比较多波折一些。因为年月日都是不显用神的，而且早期的大运走的也不太理想，所以早年阻碍会比较的多一些。子水为用，但在地支没有金来生水，故而身体方面也比较弱，体质一般。要特别注意一下属马，属羊的年份，以及属牛的年份也不太好，这些年份会损害子水，而子水为禄神，往往会引发健康方面的问题。

三、女孩子首先是看婚姻，并非同性取向就不会结婚，我有很多这样的客户，都有属于自己的家庭和孩子。但至于过的是否幸福，就另当别论了，不过这一切也要看自己的追求。年支戌为正官星，正官为夫也代表丈夫，正官在年离自己比较的远，又卯戌相合，故而缘分并不是很好。卯木为食神，来争夺丈夫，一般有食神来合正官，往往代表对象会和年龄比自己小很多的人有瓜葛。不过卯木也代表子女，孩子和夫相合，也暗示夫子同现，或为了孩子而结婚。

年干透伤官星，一般女子伤官透出的人性格都是比较孤傲的一个人，伤官会克戌土，所以对感情并不是很有信心，伤官克官，除了性格问题，就是内心容易排斥感情。或要求会比较高一些。

日支巳火为正财星，巳火之中暗藏正官星，正官入夫宫也暗示了能有婚姻。所以从八字组合来看，结婚的几率还是很大，也就是会走比较世俗的道路。她的八字是不算差的，但是早年弱一些，不过后半生都非常不错。

# 大运流年

20-30岁走的甲子大运，子水来生甲木，所以这十年主要是体现甲木的性质。甲木为伤官星，一来会克官杀，二来也会生财。由于八字是不担财的，所以财星越旺对自己往往越不利。而且走伤官大运，想法也比较的多，工作上面也不太容易稳定，感情方面也不太顺利。伤官代表一种叛逆，固执的性格。

2019己亥年，在今年冲了巳火，也代表感情变动的意思。而且和日柱是天克地冲，所以在今年对于自己来讲，变动是比较大的。不过今年运势比去年好很多，故而找工作更容易找到合适的。

这十年子水为禄，走禄神大运会比较辛苦一些，但财运一定是有的。30-40岁走的癸亥大运，为比劫大运，故而大运不错。适合求财。不过不利婚姻感情。如果自己并不是很追求婚姻，那么也能过的很好，因为财运不错。适合发展事业，在经济方面不会有太大的烦恼。

不过在50岁后一直到70岁都是非常棒的运气。所以观察一生大运来看，都是很不错的。这样的大运都非常适合求财。

八字为食伤生财，丁火为偏财星，和时干壬水相合，也代表这个才可以被自己合住，并且有财库，又被食神合住了，所以能得到财。所以命中财运是不错的。但并不是很利感情，主要是大运冲克比较的多，而且八字原局夫星逢合。如果这方面看的比较淡，一心在事业工作上面，也能过的非常开心，充实。

八字时柱为用，且有食伤，所以也有孩子。时柱为用，晚年比较有福的命。这个八字是不错的，故而你也不要太担心她的未来。相反，我还挺担心你以后的。因为我能感觉到，你经历的波折会比她多很多。所以好好为自己的将来规划一下吧，既要随心，也要随俗。
