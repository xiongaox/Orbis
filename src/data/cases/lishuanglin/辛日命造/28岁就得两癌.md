# 命理提要

一、日干为辛在卯月出生失令，春季木旺金弱，地支又见寅卯木，则地支为木党成势，木多必然损金，犹如树木太多而钝斧。唯有年支申金来助身，但申金在年太远，且被地支寅卯木所消耗，则根气太弱。天干年月见壬癸水，时干透出一个庚金，不过时干庚金坐寅木是无根的，则虚透之金，帮身力量非常的弱。八字木多为病，继续旺金制土，或见土来生金助身方能为吉。

地支见申金，但没有土，则没有印来生身，且地支金木相克，由于木多金少，则为木旺克金，反而损工日干之根。年月透出壬癸之水，也是泄身的，也喜克制为吉。因为辛金为珠宝金，不喜见旺水，否则会水多金沉。故而水势太多则需土来截流方可。

> 用神：土，金。地支土金都喜见，见土可以生金，见金则可以制木。天干则更喜见土，因为见土则可以制壬癸水，从而保护辛金，不被壬癸水过于消耗。
>
> 忌神：水，木，火。水木为最大的忌神，不喜多见。至于火也非常不吉，因为见火则会克金，吉少凶多。

二、分析健康，主要是看用神是否受损，如果原局用神受损比较严重，则身体健康就容易出现问题。当然对于年轻人来讲，更多时候是体现为财运不好或婚姻不顺，并非一定就体现为疾病灾难。也正因为这个原因，即便是看出不利健康，也不会联想到癌症上去，故而很难通过八字预测出来。

并且要明白一个道理，八字仅仅是决定一个吉凶方向，至于吉凶的结果并非完全由八字所决定的。世间没有任何一种东西，能百分百的影响结果如何。就比如氢气+氧气才能得到水一个道理。单凭氢气或单凭氧气都无法得到水。所以很多结果的产生，是在多重因素的综合作用下所形成的。

日干辛金在原局是非常弱的，最主要是缺印生身，且地支财多耗身，都会损害健康。年支申金为地支唯一用神，申金要去制寅卯木，但申金力量太弱了，而且申金还生了壬水，导致自身能力被泄掉了一部分，且水本就有生木的作用，所以申金明着来制木，而背地却有助水之力量。所以最大的问题，是因为申金无助，地支木盛金衰，导致申金受损。

日干辛金所处的状态也非常不好，八字没有印，缺乏保护神，且用神受损，忌神无制。都会体现为灾难，波折，疾病等。当然具体是体现什么，则看个人因缘了。年轻人的不顺，更多还是体现为工作感情之上。至于多病多灾，一部分是运势不当导致的，另外也为风水家运所致。

八字缺土，而土对于自己来讲是非常关键的，土对应人体所代表的就是脾胃。且日干为辛金，年支申金为庚金，庚辛金则为肺和肠道。木太旺而无制则为肝胆。八字木多土衰，则脾胃有伤，且命局缺土更体现为脾胃虚弱，易生疾病。并且肺部，呼吸系统，肝胆方面，肠道都是不吉的，这些地方都很容易生病。地支有金木相克，也为刀兵之伤，一般体现为受伤，车祸，手术等危险。

# 大运流年

在13岁之前走的壬寅大运，冲了申金，且干支均为忌神不吉。早年运势不好，则更多是体现为家庭不吉，父母不合，健康不好。由于日干太弱，且大运不助，小时候身体也比较虚弱，也总是生病，磕磕绊绊的。

13-23岁走的辛丑大运，这十年相对还算比较平安，没有什么太大的问题。因为干支均为土金，有助身的作用。所以在13岁之前，自己也很不顺利，不过小时候的运势不好，很大一部分都体现到父母身上去了。

23-33岁走的庚子大运，庚金引动年支申金，申金去冲克寅卯木，但木多金衰，不但金无法制木反而会被木所伤。且大运子水能助寅卯木，更加旺了木而损了金。这十年大运并不吉祥，且子卯相刑，也为刑伤之象。

2016丙申年的时候，就和八字原局寅申冲，冲克很大了，这个时候己然有病。

2017丁酉年之时，和月柱癸卯，日柱辛卯均为天克地冲，非常不吉的年份。

不过年轻人走这样的大运，往往人生会遭遇大的变动，波折，破败等。而你却体现为疾病。这也说明，你要偿还的债，更多是健康债。过去生杀业太重，而今生得多病甚至寿短之报啊。

生病也好或遭遇其他不顺也好，都是自己的业报。由于种下的因有所不同，而得到的果报也自然不同。故而即便八字相同，运势相等，就算均为不顺，但也各有各的不顺，这就是因为各自虽然运气相似，但所受的业报并不相同。越是这样，越要积极忏悔，行善，放生，吃素来改善未来的命运。业由心造，自然也由心所转。如何消业转业，佛陀开示了很多方法。比如行善，做功德，诵经等等。

2018戊戌年，有印助身，治疗过程还是比较顺利的。

2019己亥年，则亥卯相合，增加了木的力量，又天干己土虚透无力，反而受损。所以也相当不利。再发疾病。从你大运来看，稍微不吉就以疾病的形式来体现，以后更要注意才可以。

2020庚子年，大运也是庚子，则为岁运并临。庚子大运并非吉祥之运，又见庚子年，则凶相重叠，更为不吉。就看你之前所生之病，是否已经受完，否则疾病再生，反反复复。

在2022壬寅年，伏吟时支，旺了木而冲申金，非常不吉的年份。以及在2023癸卯年依然如此。所以这两年灾难很大，多病多灾，极易反复。

33-43岁走的己亥大运，亥卯相合，寅亥相合，均为水年旺木，木多损金。不但不能助身，反而大运透印，而印弱受损，反而不吉。

所以你未来十年大运也非常不吉。要偿还的债还非常多啊。一定要理性的看待这个问题，并要因此而更加积极努力的去修行，广结善缘，多做布施，修心修口修身，方能重罪轻报，大灾化小，小灾化了。若不能如此去修，则病重反复，难治难愈。要熬过了43岁，进入戊戌大运后，才能好起来。

如果在其他方面灾难大一点，受的苦痛多一点，则健康方面就会好一些。比如孤独，贫穷，感情不顺，或其他等。

# 人生建议

不管是从八字分析还是从奇门分析，以后健康的发展都非常不吉，大有转移复发之象。所以啊，一定要更加注意自己的身体，要努力的通过身口意三方面去改善，从而转凶为吉。

关于得癌症，并非一定要有家族病史。因为这种疾病在过去本就少见，而现在则是越来越多，可以看成是一种当代普遍发作的疾病，得病人数也是一年比一年多，且年龄也越来越小。

为什么人类的疾病越来越多？这一切都是杀业太重所致，人类为了满足自己的口腹之欲，肆意宰杀，且毫无悔意，认为理所当然。就一个小城市来讲，每天要宰杀的生命也是成千上万。老子说万物有灵，动物犹如人类一样，都是有思想有感情的。我们人又何尝不是动物的一类呢？从动物角度来讲，本为同类，却残杀弱者，召来无数怨灵。

我们经常会听到关于动物报恩的故事，也会有动物报仇的故事。由此可见，它们是一定有思想的，且能有如同人类一般的思维方式，能知晓善恶，懂得好坏。如果我们去杀害它们，能不遭到动物的仇恨和诅咒吗？

因为人类肆意的宰杀，再加上人类的贪欲，为了利益而用尽各种手段。就比如前两年所曝光的“僵尸肉”，以及去年曝光的“黑作坊快餐”，制作过程可以说是极其恶心，还有今年的“野味”。人类就如恶魔一样茹毛饮血，各种生吞活剥，恐怖至极。比如去年抖音特别火的生吃小老鼠，人性的扭曲，已经把这种残忍的行为当做了艺术，各种摆拍，发朋友圈，成了炫耀的工具。以及生吃章鱼，蛇，鱼等等。为了博人眼球，甚至生吃蝙蝠，恐怖至极。

很多时候，我们虽然没有直接去宰杀它们，却因购买而间接的帮助别人去宰杀，形成了共业。那么这个果报，也必然会报应到更多人身上。我见过很多动物灵附到人体的，大家听起来觉得不可思议，但这些事情并非虚假存在。有的动物去世后依然会来报仇的。或转生为自己的子女，朋友，家人，来折磨自己，甚至杀害自己。

人类多病，全因杀业过重。错误的饮食文化，营养观念，害了自己。比如觉得野味会很补，甚至生吃能治病等歪理邪说。

首先要意识到生病的源头是什么，八字仅仅是运势方向，并没有注定结果就一定如何。当下的果是过去的因所致，而未来的果是当下的因所致。所以啊，我给你几个建议，希望对你有所帮助：

1.要多忏悔，忏悔自己身口意所犯下的过错，并要从此以后不再造杀业，且多吃素，饮食清淡。要尽量少吃或不吃肉，如果实在无法断除，那就选择三净肉，从多到少，再从少到无。因为病从口入，要身体健康就得肠道清净。吃的东西太乱，太杂，只会增加身体负担，从而导致身体多病。

3.平时要加强锻炼，提升自身元气。从中医角度来讲，如果自身元气充足，则百邪不侵。疾病也为邪气。并且你八字身弱财旺，日干无力，也要加强锻炼，提升身体素质，从而更好的去抵抗疾病。

食伤透出都比较喜欢美食，口腹之欲难除。且财星多，注重享受。一旦疾病除去了，一段时间就容易忘记过去的痛苦，而继续犯错。我没有一下子就建议你吃素，但希望能慢慢如此，唯有这样才是最好，因为不吃才是最究竟的放生。
