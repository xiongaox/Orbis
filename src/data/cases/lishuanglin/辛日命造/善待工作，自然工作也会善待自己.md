# 人生建议

1 .找工作就和找对象是一样的，并非见面就都能一见钟情，而是相处时间  
久了，慢慢产生感情。

工作也是如此，并非一开始就要立马喜欢这份工作，而是在工作的同时，  
去寻找工作的乐趣，从而慢慢爱上这份工作。一份工作是否能让自己做得开心， 关键是看自己为钱工作还是为梦想而工作。如果仅仅为了金钱，就很容易因为  
工资不高，或福利待遇不如我意，而对工作产生厌恶。但若能因为梦想兴趣而  
工作，即便收入发生变化，也不会因此而丧失对工作的热爱。

现在越来越多的年轻人，找不到钟意的工作。并非工作本身的问题，而是 自己的问题。自己的要求越来越高，高不成低不就，辛苦的不愿意去做，待遇 好的无能力去做，从而失去了很多好的工作机会，也会导致自己在职场道路中， 频繁变动，甚至一波三折。

这就和找对象一样的，若总是去想着对方能给自己带来什么，而不考虑自 己能付出什么，最终只会让自己对另一半产生厌恶，从而对感情失去信心。但 如果总是想着自己能为对方付出点什么，能去做点什么，则天底下没有不幸福 的婚姻。

工作也是如此，如果总是想着索取，而从来不去考虑奉献，再好的工作也 无法让自己满意。心里总想着别人的工作好，就不能很好的面对自己的工作。在工作中，付出和奉献是最让人开心的。人去工作，并非仅仅为了赚钱， 而是为了实现自我的价值。尽心做好自己的工作，把自己的才华充分发挥到工 作中来，就是在实现自我的价值。所以大多数的人，事业观和婚姻观都是有问 题的。一味只想索取，是永远无法真正得到的，反而会因此增加更多的烦恼， 让自己活得非常辛苦。

付出了不一定有回报，但不付出就一定没有回报。这句话绝对是真理。认 真对待自己的工作，那么工作也必然会回报于己。让自己满意的工作，并非是 靠索取得来的，而是自己培养出来的。培养一个好的工作心态，培养一份喜爱 的工作，善待工作，自然工作也会善待自己。

万物有灵，任何东西都是有灵的，杯子有灵，书本有灵，电脑有灵，山川 树木也均有灵。那么工作也是有灵的。把工作当朋友，当爱人，当知己，当亲 人，自然会因工作而开心，因实现自我价值而欢喜，从而获得快乐的工作。
