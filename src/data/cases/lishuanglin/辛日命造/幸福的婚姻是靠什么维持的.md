# 人生建议

一段好的婚姻，除了要夫妻共同经营之外，也最好能门当户对。所谓门当户对，是指两个人的家庭经济情况，两人的三观，各自学历，长相性格，工作兴趣等都不要有太大差距，如果在某一方面存在差距，也一定要在另外一方面来弥补，否则就会造成婚姻中的不平等，若又不懂得如何去维护婚姻，就会因此给婚姻造成伤害，甚至让婚姻走向分离。所以门当户对的婚姻是幸福的前提，这也是一种平衡。

夫妻俩人在家庭的地位，绝对和原生家庭好坏以及自身赚钱能力是成正比的。人类的世界和动物世界并没有太大区别，就比如一个狼群之中，说了算的绝对是战斗力最强的。

当然人类和其他动物最大的区别，除了这些之外，还有就是爱。在家里面，两人的地位也由爱来决定，谁爱谁多一点，那么被爱的人自然地位就会高一些。所以，除了经济之外，也和人有关系，以及处理事情的态度有关系。

但爱很多时候，都是建立在这些外在因素基础之上的，不过两者也是互为表里。所以夫妻之间一旦差距太大，势必会造成地位的不平等，就会存在一个无限付出，而另外一个无限伤害，时间长了，终究会给两人都带来伤害。所以我经常告诫一些人，寻找对象要找合适的，不要高攀。就比如穿鞋一样，穿着舒服才是最好的鞋子，而并非一定要是什么名牌。如果强行进入一个并不属于自己的圈子，也会让自己活得越来越不像自己，甚至活得让自己都不认识自己。

婚姻是人生大事，选择对象也是极其重要的，我们的命运有非常大的一部分都是受到婚姻的影响。可以说，婚姻好，则一切都好，不论男女都是如此。大多数的烦恼，并非来源于财运不佳，或工作不顺，而是来源于婚姻的不幸福。比如妻子的不理解，丈夫的伤害与责骂等。

当一个人能在婚姻之中获得幸福时，即便在外受到什么委屈和伤害，也能因为在家的幸福而抵消，所以家是一个疗伤的港湾。不论在外面受到什么样的折磨，只要回到家，都能让伤口康复。但前提是要有一个幸福的家庭。所以婚姻的质量，决定人生所有幸福的指数。只要夫妻恩爱，即便遭受贫穷与疾病也能过得快乐。而幸福的婚姻，首先要两人尽量门户相当，其次都能用爱去对待另一半，各自也都能去反省自己，那么天底下将不会有什么不幸福的婚姻。

寻找与自己同世界的人，相处才不会累，这样的婚姻才能稳定长久，只要懂得满足，一样活得幸福。人与人是不一样的，因为思想，出身，各自圈子的不同，导致两人根本无法融入到一起，而成了异世界的两人，不管各自怎么努力，也很难让心融入到一起。
