# 可以一婚到底的人

命主生辰: 1975/04/20 12:00 (GMT+8)
性别: 坤造
日主: 丙火
格局: 正印格
令地: 失令, 失地

## 网友来信：

我小时候家境不错，亲戚都住平房的时候，我家已经住楼房了，我上面有一个大我三岁的姐姐。我母亲是老师，爸爸是事业单位工作。癸亥年母亲因病去逝后，家境就不行了。

我学习也不行，后来考了一个职高就出来工作了。癸酉年进入了一家事业单位上班，有了事业编，工作期间也通过业余学习，拿到了大专文凭，这样顺风顺水了几年。己卯年生了一场病，事业就不是太顺了，壬寅年各种原因被迫离职。失业后，也比较迷茫，甲申年就远嫁到了南方。

老公家境不好，起初生活很困难，我根本照顾不到娘家。丁亥年父亲病逝，辛卯年姐姐也去逝。工作上，我一直是自己单做销售类工作。戊子年开始，也算生活不那么困难了。但心里总是有个结，觉得爸爸姐姐早逝，都是因为自己远嫁才导致的，所以一直比较郁闷。己亥年生了癌，至今治疗3年多。生病后，我工作上就也消极了，但这时候老公到是事业发展好了一些。

现在老公是我唯一的亲人，我们是丁克。我就想帮我看看，我婚姻会不会稳定，毕竟我生了这种大病，家里又没亲人，没有什么依靠。我的身体能不能慢慢好起来？

我求的真不多，只希望婚姻稳定，身体健康~

之前有一个老师帮我看了，说我是火旺，忌火和木。但我后面的大运好像也不是太好。
