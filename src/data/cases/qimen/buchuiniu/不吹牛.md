# 不吹牛介绍

不吹牛，本名杨传顺，民间实战派奇门遁甲专家。
师承当代奇门名家幺学声老师，以其网名“不吹牛”在网络易学界广为人知。他创办了“不吹牛预测网”，并在多个易学论坛活跃，留下了大量的实战案例和教学资料。

## 基本信息

- **本名**：杨传顺
- **网名**：不吹牛
- **师承**：幺学声
- **擅长**：奇门遁甲（时家奇门）
- **代表作品**：《不吹牛奇门》系列讲义
- **身份**：易学讲师、职业预测师

## 学术风格

杨传顺老师的奇门风格深受幺学声老师影响，注重实战与易理的结合。他的断语风格由繁入简，直指核心，不尚空谈，正如其名“不吹牛”。

1.  **注重象意读法**：擅长通过宫位内的星、门、神、仪组合，进行细腻的象意解读，能够还原事情的细节。
2.  **强调多重取用**：在分析案例时，往往不局限于单一用神，而是多角度、多维度的选取用神（如年命、日干、时干、相关方位等）进行交叉验证，以提高准确率。
3.  **理法严谨**：推崇传统奇门理法，重视九宫、八门、九星的旺衰生克关系，对于“击刑”、“入墓”、“空亡”、“门迫”等格局的吉凶判断非常敏锐。
4.  **实战为王**：积累了海量的实战案例，其教学资料多以真实案例为基础，通过复盘解析来传授技法，具有很强的实用参考价值。

## 主要贡献

不吹牛老师在网络上公开和传授了大量的奇门遁甲知识，其整理的《不吹牛奇门》系列文档（如一期至九期讲义等）在易学爱好者中流传甚广，被许多初学者视为入门和进阶的宝贵资料。他通过大量的网络实测案例，验证了奇门遁甲在现代生活中的应用价值，涵盖了婚姻感情、工作事业、求财经营、失物寻找、健康疾病等多个方面。
