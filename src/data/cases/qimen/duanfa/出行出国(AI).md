# 出行出国 (AI总结版)

## 核心用神

### 出行人
- **日干**：本人求测。
- **六亲关系**：代人求测时按六亲取用。
- **年命**：辅助参考，判断生命危险。

### 目的地与方向
- **所往之方**：目的地所在的宫位。
- **开门**：出国/出行的核心用神，代表出行动态。

### 审批与机构
- **年干**：录取单位、上级领导（出国留学等）。
- **天辅星**：考试院（需考试才能出国的情况）。
- **值符**：主管领导、顶头上司。
- **值使门**：具体批准机关。

### 证件与手续
- **景门**：文件证书、出国护照。
- **丁奇**：证书、手续。
- **六合**：护照签证（另一说法）。

### 道路与交通
- **景门**：道路。
- **伤门**：车辆、船只。
- **休门**：水路。
- **九天**：航线（乘飞机）。
- **开门**：飞机。

## 出行吉凶判断

### 吉兆（可出行）
1. **所往之方吉**：
   - 临吉门（开休生景）、吉神、吉星、吉格
   - 生或比和日干/年命落宫

2. **用神自身吉**：
   - 日干/年命落宫得吉门吉星吉格
   - 即使克所往之方，也可前往

3. **值符所在地**：
   - 所往之方是值符落宫 → 意想不到的好事
   - 但值符空亡则扫兴

### 凶兆（不宜出行）
1. **所往之方凶**：
   - 遇凶神凶格凶门冲克日干/年命 → 大凶
   - 落空亡或临凶象且为用神墓地 → 不可去

2. **用神自身凶**：
   - 日干/年命逢空亡、入墓、击刑、凶神凶格

3. **特殊凶象**：
   - 临玄武 → 易被盗、丢失物、被骗
   - 临天蓬星 → 破大财
   - 临甲子戊 → 肯定花钱
   - 临击刑 → 刑伤、纠纷
   - 临伤门 → 磕磕绊绊
   - 临白虎 → 有阻隔、遇警察

## 日时关系断法

### 日干与时干关系
- **日干克时干**：所去之地无害。
- **时干克日干**：所行之地多有不利。
- **时干临空亡**：不吉。
- **日时临玄刑、入墓**：大凶。

### 天地盘关系（出行为客）
- **地盘生比天盘**：利客。
- **地盘克天盘**：不利客。

### 陆路（乘车）
- **景门**：道路。
  - 临三奇 → 道路吉
  - 逢羊刃 → 防失盗
  - 丙+庚 → 防火灾惊恐

### 水路（乘船）
- **休门**：水路。
  - 临三奇 → 水路吉
  - 乙+辛/辛+乙 → 有风雾
  - 癸+丁 → 凶灾
  - 丁+癸 → 沉溺
  - 入墓 → 阻隔难行
- **伤门**：船只。
  - 伤加休上 → 浮
  - 休加伤上 → 沉底、沉溺

### 航空（乘飞机）
- **九天**：航线。
- **开门**：飞机。

## 出发时间判断

### 行期远近
- 日干时干**同落内盘** → 近期出
- 日干时干**一内一外** → 行期远
- 日干时干**同落外盘** → 行期更远

### 具体时间
- 以**开门落宫地盘所落之时**为具体出行时间
- 值使门落宫数定应期
- 时干落宫临二天/九天判断

### 能否成行
- 日干克时干 → 不能出行
- 时干克日干 → 能出行
- 日干在外盘 → 出行
- 时干在内盘 → 不去
- **伏吟局** → 不去
- **返吟局** → 半途返回

## 归期判断（庚格法）

### 庚格规则
- **阳日**：看庚下之干。
- **阴日**：看庚上之干。

| 格局 | 应期 |
|------|------|
| 庚+年干 | 年内归 |
| 庚+月干 | 月内归 |
| 庚+日干 | 当日归 |
| 庚+时干 | 本时归 |
| 不格（乙庚合/庚入墓/临空亡）| 不归 |

### 其他归来信号
- 用神生日干 → 归来
- 用神临马星冲/逢马星 → 归来
- 用神临丙+戌、戌+丙、庚+丙 → 归来
- 临九遁 → 马上回家
- 用神反吟 → 必归
- 用神伏吟 → 不动

### 凶兆（不归/有难）
- 癸+丁 → 路上有灾难
- 丁+癸 → 音信全无
- 临天芮星 → 生病在外
- 飞干/伏干 → 不想归来
- 五不遇时 → 人不归
- 天网四张 → 不归

## 出国专项断法

### 需考试出国
1. 先按"求学考试"断法判断考试能否通过
2. 景门为试卷，天辅星为考试院，年干为录取单位

### 出国动态
- 开门为用神，看有无动态符号
- 有动态符号 → 容易成功
- 伏吟局 → 难动，需冲才能动

### 出国利弊
- 看所往之方与用神的生克关系
- 看所往之宫的状态（吉凶格局）

### 审批手续
- 值使门/值符/年干与用神宫、景门宫的关系
- 看日时关系判断能否办成
