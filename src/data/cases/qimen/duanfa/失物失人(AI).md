# 失物失人 (AI总结版)

## 一、一般失物

### 核心用神
- **日干**：失主。
- **时干**：失物。
- **类象用神**：具体物品（如戊为钱财，伤门为车）。
- **值使门**：辅助参考。

### 能否找回判断

#### 可以找回
1. **日时同宫**：物品没有丢失，可以找到（即使临空亡也不易丢失）。
2. **时干生日干**：时干落宫旺相生日干落宫 → 能找回。
3. **返吟局**：好找。
4. **伏吟局（原地未动物品）**：物品在原地未被发现。

#### 难以找回
1. **时干落空亡、墓绝之地**：难找回。
2. **伏吟局（外出丢失）**：难找。

### 吉凶格局

#### 即使时干不生日干也能找回
| 格局 | 含义 |
|------|------|
| 戊+丙 / 丙+戊 | 龙返首 / 鸟跌穴 |
| 庚+丙 | 贼必来 |
| 丁+庚 | 行人必归 |
| 戊+丁 / 丁+戊 | 吉格 |

#### 即使时干生日干也难找回
| 格局 | 含义 |
|------|------|
| 丙+庚 | 贼必去 |
| 乙+辛 | 龙逃走 |
| 乙+己 | 日奇入墓 |
| 癸+癸 | 天网四张 |
| 壬+壬 | 蛇入地罗 |
| 辛+癸 / 癸+辛 | 天牢华盖 |

### 丢失远近

| 情况 | 位置 |
|------|------|
| 日干、时干同落内盘 | 近处（家里、单位） |
| 日干、时干同落外盘 | 远处（外边） |
| 日干内盘、时干外盘 | 丢失在外边 |
| 日干外盘、时干内盘 | 丢失在近处/家中 |

### 是否被盗判断

#### 被人盗走
- 时干/类象用神临玄武 → 可能被偷或自己忘记
- 被玄武/天蓬星落宫所克 → 被人盗走
- 类象用神生玄武落宫 → 物被人盗

#### 自己丢失
- 时干不见玄武 → 多为自己丢失

#### 盗贼性别年龄
- 玄武乘**阳星、临阳门、落阳宫** → 男人
- 玄武乘**阴星、临阴门、落阴宫** → 女人
- **旺相有气** → 青壮年
- **休囚无气** → 老年人

## 二、行人走失

### 核心用神
- **日干**：走失时间起局时，日干为走失之人。
- **六亲关系**：问事时间起局，按六亲取用。
- **年命**：辅助参考。

### 走失方向

| 用神 | 方向含义 |
|------|---------|
| 六合落宫 | 刚走失的出走方向 |
| 值符/值使落宫 | 途中落脚点 |
| 用神/年命落宫 | 最后找回或死亡方向 |
| 杜门 | 有意躲藏的方向 |
| 返吟局/用神逢空亡 | 对冲之宫 |

#### 特殊人群走失方向
- 小孩走失 → 六合落宫
- 女性走失 → 太阴落宫
- 阳遁看天盘，阴遁看地盘

### 走失远近
- 用神落**内盘** → 近
- 用神落**外盘** → 远
- **返吟局（刚走失）** → 很快能回
- **伏吟局（刚走失）** → 走不了
- **伏吟局（时间长）** → 不会回来

### 在外安危

#### 平安信号
- 用神旺相，星门奇仪组合良好
- 得年/月/日/时干落宫相生 → 有人帮助

#### 危险信号
- 用神落休囚之宫 + 凶门凶星凶神凶格
- 入墓、逢空、六仪击刑
- 用神落墓绝之地 → 死亡或受困

#### 区分关键
- **九星旺相** → 虽落墓绝死门，也能逢凶化吉
- **九星囚废** + 死墓绝 + 死门 + 太阴/九地/九天 → 危险极高

### 归与不归

#### 容易找回/归来
- 体用比和、同宫
- 时干生日干
- 用神生比关系人
- 日时同宫临空亡 → 也能找回

#### 不易找回
- 日时相克
- 日干生时干

#### 八神判断
| 八神 | 含义 |
|------|------|
| 太阴/九地 | 有人潜藏/有意潜藏 |
| 九天 | 远走高飞 |
| 玄武 | 被人拐骗勾引 |
| 螣蛇 | 被人盘查、纠缠、羁留 |
| 白虎 | 有凶灾或刑伤（下有朱雀主有信） |
| 值符/六合 | 遇贵人帮助，安然无事 |

#### 伏吟/反吟
- **伏吟** → 不思归
- **反吟** → 多能回

#### 落宫位置
| 落宫 | 可能位置 |
|------|---------|
| 临年干 | 长辈家中 |
| 临月干 | 朋友家中 |
| 临时干 | 晚辈家中 |
| 乾宫 | 大都市 |
| 坤宫 | 农村、田野 |
| 坎宫 | 河沟 |
| 震巽 | 树林 |

### 找回时间（应期）

| 情况 | 应期 |
|------|------|
| 逢庚格 | 年格年内，月格月内，日格当日，时格本时 |
| 用神旬空 | 填实或冲实 |
| 用神临马星 | 马星动或冲马星 |
| 临击刑/冲格 | 遇合用神之时 |
| 逢合格 | 遇冲 |
| 用神入墓 | 冲墓 |

## 三、车辆丢失

### 核心用神
- **伤门**：车辆类象。
- **时干**：失物。
- **玄武/天蓬星**：盗贼。
- **日干**：失主。

### 是否被盗
- 伤门/时干临玄武或天蓬星 → 被人偷去
- 伤门/时干被玄武/天蓬星所克 → 被盗可能性更大
- 伤门/时干落宫生玄武/天蓬星落宫 → 被人盗走

### 能否找回

#### 能找回
- 伤门/时干与日干同宫
- 伤门/时干生日干
- 吉格：丙+戊、戊+丙、庚+丙、丁+庚

#### 难找回
- 凶格：丙+庚、乙+辛、乙+己、癸+癸、壬+壬、壬+癸、辛+癸、癸+辛、丁+癸

### 盗贼判断
- 玄武乘阳星、临阳门、落阳宫 → 男人
- 玄武乘阴星、临阴门、落阴宫 → 女人
- 旺相有气 → 青壮年
- 休囚无气 → 老年人
- 天地盘之干 → 衣服颜色

### 能否破案
- **捕盗用神**：伤门、白虎、庚、值使门
- 这些宫象旺相冲克玄武落宫 → 易破案
- 星门伏吟 → 难破
- 反吟 → 能破或案犯作案时被抓

#### 庚格破案
- 庚下临年/月/日/时 → 案子能破
- 不格 → 难破

### 失主运气
- 日干/年命落宫旺相 + 吉星吉门吉神吉格 → 运气好，失物能得
- 甲子戊逢击刑、入墓、落死绝、辛+戊等 → 有失财象，难回
- 生门克日干 → 不利财
