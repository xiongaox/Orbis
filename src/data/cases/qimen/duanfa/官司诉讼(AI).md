# 官司诉讼 (AI总结版)

## 一、官灾刑事

### 核心用神
- **甲午辛**：犯罪嫌疑人、有过错之人。
- **日干**：当事人求测。
- **六亲关系**：亲属代测时按六亲取用。
- **年命**：重大问题必查。

### 被囚禁/羁押信号
- 用神下临辛金 → 被囚禁
- 甲午辛/用神/时干**入墓** → 正在关押
- 甲午辛临**螣蛇、白虎、庚、伤门** → 被羁押/看管
- 临**杜门** → 被监视监控，有判刑可能
- 用神落**巽宫/兑宫** → 容易被判刑
- 辛金/用神落入**墓绝之地** → 容易被判刑

| 戊+庚 / 庚+戊 | 天乙飞宫，换地方 |

### 判刑情况

#### 判刑信号
- **辛为天狱，壬为地牢，癸为天网**
- 辛+壬、辛+癸、壬+辛、癸+辛 → 有牢狱之灾
- 辛+壬（癸）→ 误入天网，冲破可出狱
- 壬（癸）+辛 → 罗网蒙头，囚禁时间长
- 庚金落宫克辛金宫 → 一定被判刑
- 庚+辛、庚加罪人年命/日干 → 必遭正法
- 辛+辛（六仪击刑）→ 罪责加重

### 罪行轻重
- 开门宫**生**甲午辛宫 → 法官怜悯，不加罪
- 二宫**比和** → 罪轻
- 二宫**相冲突+凶格** → 罪必重
- 甲午辛落**空亡或得吉格** → 赦免其罪
- 用神年命旺相+吉门吉星吉格 → 罪轻
- 星不旺相+门不吉+无三奇+格局凶 → 大凶
- 再犯击刑 → 有刑罚之苦

### 刑期/应期
- 以**庚格**定结案时间（阳日看庚下干，阴日看庚上干）
- 刑期长短：值使门落宫数 或 时干落宫数

## 二、民事官司

### 核心用神
| 用神 | 代表 |
|------|------|
| 值符（天盘）| 原告 |
| 天乙（值符原地盘星落宫）| 被告 |
| 开门 | 法官/仲裁机关 |
| 六合 | 证人/证据 |
| 景门 | 诉状/起诉书 |
| 丁奇 | 传票/判决书 |
| 惊门 | 律师 |

### 诉状判断

#### 诉状质量
| 临象 | 诉状情况 |
|------|---------|
| 吉星吉神三奇吉格 | 言辞真切、文雅、诚恳 |
| 凶星凶神+己庚辛癸+凶格 | 言辞凶恶 |
| 螣蛇 | 有虚假或牵连他人 |
| 玄武 | 颠倒黑白、瞎话连篇 |
| 天芮星 | 有点毛病 |
| 景门落坎宫（火入水乡）| 写的不好 |

#### 诉状递交
- 景门逢空亡 → 没递交
- 景门天干逢冲 → 已递交
- 景门天干逢合 → 被合住没递交
- 值符逢空亡 → 没起诉

### 立案/受理判断
- 景门旺相+吉格+不被开门冲克 → 能立案
- 景门克开门、开门生景门 → 会被受理
- 景门被开门冲克 → 证据不足，难立案
- 景门入墓 → 情词不明，不能立案
- 景门空亡+玄武/螣蛇 → 凭空捏词，不能立案
- 开门空亡/天干逢合 → 法院不理会
- 开门克景门、景门生开门 → 法院不受理

### 胜负判断

#### 原告胜
- 值符落旺相之宫+吉门吉格吉星
- 有力冲克天乙落宫

#### 被告胜
- 天乙落旺相之宫+吉门吉格吉星
- 有力冲克值符落宫

#### 和解信号
- 值符、天乙两落宫**比和** → 协商解决
- 值符生天乙 → 原告撤诉/求和
- 天乙生值符 → 被告求和
- 两落宫相生 → 可能和解
- 大局**伏吟**（原被告同宫）→ 拖拉后和解

### 法官判断
- 开门生值符或比和 → 倾向原告
- 开门生天乙或比和 → 倾向被告
- 开门生六合 → 重证据
- 开门既克原告又克被告 → 公平判决
- 开门既生原告又生被告 → 主持调解
- 开门入墓 → 法官糊涂
- 开门空亡 → 未开庭/不受理
- 开门伏吟 → 审理时间长
- 开门反吟 → 另换法官审理
- 开门临天蓬星 → 可能是贪官
- 开门乘玄武 → 法官徇私情

### 证据/证人判断
- 六合生助/比和值符 → 对原告有利
- 六合生助/比和天乙 → 对被告有利
- 六合冲克值符 → 对原告不利
- 六合冲克天乙 → 对被告不利
- 六合空亡 → 证据不足/没有证人
- 开门冲克六合 → 法院不认定证据
- 六合临螣蛇 → 证人忧疑/证据不实
- 六合临玄武 → 假证/伪证
- 六合临合格 → 证人多/不愿多讲
- 六合临杜门/死门 → 证人不肯作证

### 律师判断
- 惊门得奇 → 律师优良
- 惊门空亡 → 没有律师/心有余力不足
- 惊门克用神 → 律师不尽心
- 开门生惊门 → 法官认同辩护
- 开门克惊门 → 法官不认可辩护
- 惊门临螣蛇 → 律师狡猾
