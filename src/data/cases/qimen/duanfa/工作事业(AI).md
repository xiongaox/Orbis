## 一、官运升迁

### 升迁吉兆
- 日干/年命落**旺相之地**，临吉星吉门吉神吉格
- 开门/杜门/值符/年干/月干/时干落宫旺相，得吉格**生助**日干落宫
- 日干临值符 → 上司提拔
- 年干生日干 → 领导喜爱
- 月干与日干相生比和 → 同事融洽
- 时干生日干 → 手下人拥护

### 降职凶兆
- 开门/杜门落**休囚之宫**，不得吉星吉格
- 开门/杜门落宫**克**日干/年命落宫
- 年干/值符落宫**克**日干/年命 → 上层关系不好
- 月干/时干落宫**克**日干/年命 → 群众关系不好
- **开门克用神** → 必降调

## 二、工作变动

### 调动信号
1. 八门九星**反吟** → 能调动
2. 开门临**马星**或受马星之冲 → 能调动
3. 日干/年命临马星或受马星之冲 → 能调动
4. 日干/年命与**太岁相冲** → 必调动
5. 用神宫中有**乙+辛（龙逃走）、戊+庚/庚+戊（飞宫）、庚+壬（移荡）** → 必调动
6. 开门宫中有**冲格、临九天、螣蛇、天冲星、空亡、击刑** → 有变动
7. 门反吟而星伏吟（或反之）→ 单位内部调整

### 辞职信号
- 开门宫中有**六仪击刑** → 辞职
- 开门落**坤八宫入墓** + 日干年命同宫 + 庚在艮宫击刑 → 必辞职
- 开门宫与日干年命宫**对冲** + 时干/值使门有乙+辛 → 辞职

### 革职信号
- 开门落**艮宫入墓旬空** + 冲克日干年命 + 日干年命无三奇有凶象 + 与太岁相冲克 → 必革职

### 退休信号
- 开门宫**冲克**日干/年命宫 → 必退休
- 时干/值使门有**乙+辛** → 退休

### 处分判断
- 天地盘日干宫没有庚 → 不会处分
- 日干/时干宫中有庚，或被庚宫所克 → 一定处分
- 开门宫中有庚 → 处分且公开
- 有庚但有杜门 → 秘密处分

### 不会开除信号
1. 大局伏吟 → 不动，只处分不开除
2. 日干与开门同宫 → 不会开除
3. 日干与年干相生 → 不犯上，不会开除
4. 开门/日干不临马星或受冲 → 不会开除

### 变动利弊（主客法）
- **天盘克地盘**（客克主）→ 调动有利
- **地盘克天盘**（主克客）→ 不调动有利
- 天盘生地盘 → 利主不利客
- 地盘生天盘 → 利客不利主

## 四、应聘求职

### 用神
- 开门：文类企业
- 杜门：武类企业
- 日干/年命：个人运气
- 时干：事件状态
- 日干下临地盘干翻宫：单位发展情况

### 能被录用
- 开门宫**生**日干/年命宫
- 日干与开门**同宫**
- 开门旺相临吉格吉星吉神，生助日干

### 不会录用
- 开门落宫**入墓或逢空亡**
- 开门宫**冲克**日干/年命宫
- 时干/值使门落空亡
- 时干/值使门宫中有死门、杜门、庚、凶格

### 找工作判断
1. **看开门状态**：开门好 = 好工作
2. **看开门与日干关系**：
   - 开门旺相生日干 → 找到理想工作
   - 开门休囚但生日干 → 找到一般工作
   - 日干生开门 → 心情迫切，不一定能得
   - 日干休囚被开门克 → 找不到工作
3. **看时干状态**：时干凶 → 事难成
4. **看值使门**：值使门凶 → 执行难度大

### 辅助判断（年干关系）
- 年干生比日干 → 太岁生扶，这年顺利
- 日干生年干 → 尊重太岁，有利
- 年干克日干 → 不顺，多阻滞
- 日干克年干 → 犯太岁，旺相则辛苦有成，休囚则有灾

7. 值使门凶、克日干/时干 → 不良信息

## 六、职业选择

### 判断方法
1. **日干/年命落宫**：宫象代表适合的事业类型
2. **时干落宫**：现状与发展趋势

   - 开车 → 伤门
