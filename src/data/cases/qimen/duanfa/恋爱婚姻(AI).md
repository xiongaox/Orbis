# 恋爱婚姻 (AI总结版)

## 核心用神

| 用神 | 代表 |
|------|------|
| 日干 | 求测人 |
| 时干 | 对方/所问之事 |

## 一、桃花运判断

### 桃花信号（任一符号处沐浴之地）
- 庚/乙处桃花位 或下临之干处桃花位
- 时干处桃花位 或下临之干处桃花位
- 日干处桃花位 或下临之干处桃花位
- 日干相合之干处桃花位
- 年命处桃花位

### 桃花性质
- 带桃花 → 愿意接触异性
- 带桃花+玄武 → 风流事
- 带桃花+己/辛/壬/癸同宫 → 不检点行为
- 不带桃花 → 桃花运来得晚

---

## 二、日时关系（追求阶段重点）

| 关系 | 含义 |
|------|------|
| 日干生时干 | 主动积极找，关心此事 |
| 时干克日干 | 不顺利 |
| 时干生日干 | 比较顺利 |
| 日时比和 | 不太费劲 |
| 日干克时干（日干格局差）| 态度不够积极 |
| 日干克时干（日干格局好）| 有能力控制 |
| 日时都在内盘 | 事来得快 |
| 日时都在外盘 | 事来得慢 |

---

## 三、乙庚关系（恋爱阶段重点）

### 顺利成婚信号
- 乙庚旺相 + 吉星吉门吉神吉格
- 乙庚**相生或比和**
- 乙生庚 → 女想讨男欢心
- 庚生乙 → 男想讨女心扉

### 难成/关系差
- 乙庚**相克** + 凶门凶神凶星凶格
- 乙克庚 → 女不肯嫁/对老公不满
- 庚克乙 → 男不肯娶/对老婆不满
- 乙生庚但庚空亡/临死门 → 女爱男但男无意
- 庚生乙但乙空亡/临死门 → 男爱女但女无情

## 四、六合（婚姻用神）

### 六合落宫吉凶
| 临象 | 含义 |
|------|------|
| 开门/休门/生门 | 好 |
| 合格 | 较好 |
| 惊门 | 打闹争吵，不一定不成 |
| 杜门 | 路途不畅/有隐瞒（已婚者临杜门一般无大问题） |
| 死门 | 难成/婚灾 |
| 景门 | 各怀心事/游戏婚姻 |
| 伤门 | 容易受伤害 |
| 临庚 | 婚事不顺，容易夭折 |
| 临癸/己 | 有不检点行为 |
| 空亡 | 未有婚姻/名存实亡 |

### 六合与介绍人
- 六合真空 → 没有介绍人
- 六合临年干 → 长辈/领导介绍
- 六合临月干 → 朋友/兄弟姐妹介绍
- 六合临景门/癸/丁 → 网恋
- 六合生乙 → 介绍人向着女方
- 六合生庚 → 介绍人向着男方
- 六合克乙/庚 → 介绍人不给介绍

## 九、专项断法

### 婚前同居
- 男方：庚 + 乙（恋爱对象）或 庚 + 丁（非恋爱对象）相生比 → 可同居
- 女方：乙 + 庚 或 乙 + 丙 相生比 → 可同居
- 日时相生比 → 可同居
- 玄武克日干 → 偷情事也不宜

### 能否保密
- 临杜门 → 能保密
- 杜门落乾兑受克 → 暂时能保密
- 临开门 → 保不住密

### 网恋判断
1. 日时关系判断安全
2. 景门落宫判断消息真假
3. 乙庚下临对方 → 对方可能已婚
4. 庚落内盘+格局差 → 不吉

### 说媒成败
- 六合为媒人
- 六合生乙 → 向女方
- 六合生庚 → 向男方
- 六合临玄武/螣蛇克乙/庚 → 欺瞒说合
- 值使门为家长
- 值使门与乙同盘内 → 女方家长
- 值使门与庚同盘内 → 男方家长
- 值使门克六合 → 家长不同意

### 追求成功信号
- 日时相生比+吉星吉门 → 能追求上
- 乙庚相生比+吉星吉门 → 能成婚
- 乙庚相生比+年命相生比 → 白头偕老
- 乙庚相生比+六合相生 → 追求更顺利

### 对方可能已有对象
- 男性求测：乙下临庚/丙/丁 → 对方恐已有婚约
- 女性求测：庚下临乙/丁/丙 → 对方恐已有婚约
- 时干下临时干之合干 → 所追求的人可能名花有主
