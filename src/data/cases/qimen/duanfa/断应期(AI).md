# 断应期 (AI总结版)

## 核心原则

### 基本规律
1. **远慢断年月，近快断日时**
2. **先定地支，后配天干**
3. **先以值符定应期，后以值使定应期**

### 时间单位选择
| 预测事项 | 时间单位 |
|---------|---------|
| 终身运气 | 年 |
| 一年的事 | 月 |
| 月内的事 | 日 |
| 一天的事 | 时辰 |

---

## 一、值使门定应期

### 落宫数定期限
- 值使门落宫的**后天数**为事物成败的期限
- 如：值使门落兑宫（后天数7）
  - 以年断：伏吟约8年，反吟约4年
  - 以月断：伏吟约7-8月，反吟约3-4月
  - 以日断：可断17天或27天

### 瞬间事件（当天当时）
- 值使门定应期**非常灵验**
- 如：反吟局，值使门落震三宫 → 约30分钟内

### 不知时间单位时
- 使用**先后天数并用**
- 先天八卦数：乾1、兑2、离3、震4、巽5、坎6、艮7、坤8
- 后天八卦数：坎1、坤2、震3、巽4、中5、乾6、兑7、艮8、离9

## 二、内外盘/伏吟反吟

### 阳遁
| 位置 | 宫位 | 空间 | 时间 |
|------|------|------|------|
| 内盘 | 1、8、3、4宫 | 近 | 快 |
| 外盘 | 9、2、7、6宫 | 远 | 慢 |

### 阴遁
| 位置 | 宫位 | 空间 | 时间 |
|------|------|------|------|
| 内盘 | 9、2、7、6宫 | 近 | 快 |
| 外盘 | 1、8、3、4宫 | 远 | 慢 |

### 伏吟/反吟
- **伏吟局**：空间近，时间慢
- **反吟局**：空间远，时间快

### 日时关系
- 日干时干**均落外盘** → 远、慢
- 日干时干**均落内盘** → 近、快
- **一内一外** → 比较远、慢

## 三、成功类应期

**条件**：判定事物可以成功

| 情况 | 应期 |
|------|------|
| 用神旺相当令 | 旺相之时 |
| 用神需生 | 能生之时 |
| 用神需克 | 克住之时 |
| 用神旬空 | 填实或冲实之时 |
| 用神入库 | 冲库之时 |
| 用神逢刑冲 | 合时 |
| 马星当令/被冲 | 马星动时 |
| 值使门落宫数 | 该数年/月/日/时 |

---

## 四、失败类应期

**条件**：判定事物必然失败

| 情况 | 应期 |
|------|------|
| 用神休囚死墓绝 | 该时 |
| 忌神旺相当令 | 用神受克之时 |
| 用神旬空 | 填实之时应空失败 |
| 用神被合 | 刑冲时 |
| 用神逢刑冲 | 合时 |
| 马星当令/被冲 | 马星动时 |

## 五、破获找寻类应期（庚格法）

### 庚格三种用法

**方法一：庚临年/月/日/时干**
- 天盘庚 + 地盘年/月/日/时干

| 格局 | 应期 |
|------|------|
| 年格（庚+年干） | 当年内 |
| 月格（庚+月干） | 当月内 |
| 日格（庚+日干） | 当日 |
| 时格（庚+时干） | 当时辰内 |

**方法二：阴阳日看庚上下干**
- **阳日**：看庚下之干（地盘为庚，看天盘干）
- **阴日**：看庚上之干（天盘为庚，看地盘干）

**方法三：时干用神看庚上下干**
- **时干临阳星**：看庚下之干
- **时干临阴星**：看庚上之干

### 庚格失效情况
- 庚格所在宫**逢空亡** → 不成立
- 庚格所在宫**乙庚同时出现** → 贪合忘克，不成立

## 六、用神宫状态断应期（按优先级）

### 1. 用神宫逢空亡
- **冲空或填实**为应期，**先遇为应**

### 同气相求原则
| 用事时间 | 倾向应期 |
|---------|---------|
| 子午卯酉（四正） | 子午卯酉时 |
| 寅申巳亥（四马） | 寅申巳亥时 |
| 辰戌丑未（四库） | 辰戌丑未时 |

### 顺转盘 vs 逆转盘
- **顺转盘**（符号顺时针变化）→ 空亡定应期准确
- **逆转盘/反跳盘** → 应期可能是空亡宫天盘干出现时

### 2. 用神宫临马星（不逢空亡）
- **冲马星或马星动**为应期

### 3. 用神宫临墓库（不逢空亡、不临马星）
- **冲墓或入墓**为应期

| 场景 | 应期 |
|------|------|
| 钱财返回 | 冲墓 |
| 老年人生病危险 | 入墓 |

### 4. 用神宫临刑冲（不逢空亡、不临马星、不临墓库）
- **逢合**为应期

#### 六仪击刑特殊情况
| 格局 | 应期 |
|------|------|
| 甲寅癸落巽宫（击刑入墓） | 以墓断，入墓或出墓为应 |
| 甲子戊落震宫（子卯刑） | 常应卯戌合（戌）或子午冲（午） |
| 甲申庚落艮宫（马星刑墓并存） | 可能应申月、丑月或寅月 |
| 甲辰壬落巽宫（击刑入墓） | 往往入墓为应 |

### 5. 用神宫逢合（不逢以上情况）
- **逢冲**为应期

#### 天干相合
- 对冲之宫当令为应期
- 或地支相冲为应

#### 六仪暗支与地盘地支相合
- **冲外来之支**为应，本宫地支难冲

### 6. 无以上情况
- 按**长生、生旺、墓绝**定应期
- **生逢生日，克逢克日**

### 7. 伏吟/反吟局
- **伏吟局** → 以冲为应期
- **反吟局** → 以合为应期

## 七、值符定应期

### 原则
- 必须需要值符办的事情 → 以值符定应期
- 必须需要值使门办的事情 → 以值使门定应期

### 值符相冲法
| 情况 | 应期 |
|------|------|
| 甲子值符加离九宫（子午冲） | 应丑（子丑合） |
| 甲午值符加坎一宫（子午冲） | 应未（午未合） |
| 甲寅值符加坤二宫（寅申冲） | 应亥（寅亥合） |
| 甲申值符加艮八宫（寅申冲） | 应巳（巳申合） |
| 甲戌值符加巽四宫（辰戌冲） | 应卯（卯戌合） |
| 甲辰值符加乾六宫（辰戌冲） | 应酉（辰酉合） |

**规律：逢冲以合为应，合去外来之支**

### 值符相刑法
| 情况 | 应期 |
|------|------|
| 甲戌值符落坤（戌刑未） | 应卯（卯戌合） |
| 甲子值符加震（子刑卯） | 应丑（子丑合） |
| 甲寅值符加巽（寅刑巳） | 应亥（寅亥合） |

### 值符逢空
- 以**出旬**（填实）为应期
- 阳与阳比，阴与阴比

---

## 八、值使门时效性

### 时限控制
- 值使门控制事件的**整体时限**
- 好事坏事都有时限性

### 应用
- 问"要多久才有结果" → 看值使门落宫数
- 值使门落3宫 → 3个月或3天（看事情性质）

### 注意事项
- 用神与值使门同宫 → 事情已经开始
- 用神临值使门但逢空入墓 → 事情未必开始
- 问"选择什么时间有利" → 用神临值使门，现在做最有利
