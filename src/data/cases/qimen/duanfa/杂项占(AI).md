# 杂项占 (AI总结版)

## 一、商业类

### 出租转让

#### 承租方求测（想租/买入）
| 用神 | 代表 |
|------|------|
| 日干 | 承租方（求测人） |
| 时干 | 出租方 |
| 值符 | 租房人 |
| 生门 | 房子 |
| 甲子戊 | 成交价格 |

- 时干生日干 → 对方愿意出租
- 时干克日干 → 事情不顺利
- 生门与值符比和/生门生值符 → 大吉
- 甲子戊与生门的关系 → 能否赚钱

#### 出租方求测（想租/卖出）
| 用神 | 代表 |
|------|------|
| 日干 | 出租方（求测人） |
| 时干 | 承租方 |
| 生门 | 出租方要价 |
| 甲子戊 | 承租方出价 |

- 时干克日干 → 货好转出，能租出去
- 时干生日干 → 货恋人，不好转出
- 开门生日干 → 店恋人，出租迟
- 值使门逢死门/临庚 → 难出租成

#### 用神
| 用神 | 代表 |

| 时干 | 标 |
| 月干 | 竞争对手 |

#### 能中标
- 时干旺相+吉格，生日干宫
- 时干与日干同宫
- 时干与日干比和
- 日干旺相克时干宫

| 关系 | 含义 |
|------|------|
| 日干克时干 | 我方能控制对方 |
| 时干克日干 | 对方不利于我 |
| 日时比和 | 谈判顺利 |
| 时干生日干 | 谈判对我方有利 |

#### 调解矛盾
- 甲子戊为劝和之人，庚/丙为矛盾双方
- 甲子戊生/克双方 → 可以劝和
- 一方克甲子戊 → 调解不成
- 庚丙都生甲子戊 → 和解

## 三、奇门数字

### 三种数系
| 类型 | 数字对应 |
|------|---------|
| 先天八卦数 | 乾1、兑2、离3、震4、巽5、坎6、艮7、坤8 |
| 后天八卦数 | 坎1、坤2、震3、巽4、中5、乾6、兑7、艮8、离9 |
| 五行数 | 水1/6、火2/7、木3/8、金4/9、土5/10 |

### 生数与成数
| 五行 | 生数 | 成数 |
|------|------|------|
| 水 | 1 | 6 |
| 火 | 2 | 7 |
| 木 | 3 | 8 |
| 金 | 4 | 9 |
| 土 | 5 | 10 |

### 取数原则
- 静态事物：旺时取大数，衰时取小数
- 动态事物：利客取生数（小），利主取成数（大）
- 利客 = 天盘受生不受克
- 利主 = 地盘受生不受克
