# 求学考试 (AI总结版)

## 核心用神

### 考生取用
- **日干**：本人求测时，以日干为考生。
- **六亲关系**：代人求测时按六亲取用：
  - 父母测儿女 → **时干**
  - 同辈/同事代测 → **月干**
- **天芮星**：泛指学生群体，测学校升学率或整体考学情况时参考。
- **年命**：辅助参考，结合生克关系断吉凶。

### 学校与机构
- **年干（太岁）**：代表**国家级/官方**录取学校、高等学府。古人"进京赶考"须通过太岁测试，故年干象征最高等学府。
- **天辅星（文曲星）**：
  - 代表考试院、招生办、考场。
  - 也可代表**普通学校**。
  - 文化主宰，与学业直接相关。
- **值符与天辅/年干同宫**：多为**重点学校/名牌学校**。

### 考官
- **值符**：主考官、监考官（直接领导/主管人员）。
- **值使门**：副主考官、副监考官。

### 试卷与成绩
- **景门**：试卷、试题。需区分文理科时，景门主**理科**。
- **丁奇**：文章、文采。需区分文理科时，丁奇主**文科**。也可代表考生个人的才华表现。
- **分数断法**：
  - **景门落宫数**：百位数
  - **丁奇落宫数**：十位数
  - 需结合不同考试的总分范围灵活判断。

## 录取与落榜判断

### 顺利录取的条件
1. **考生自身旺相**：
   - 考生落宫处旺相之地
   - 得**三奇**（乙丙丁）
   - 得**吉门**（开休生景）
   - 得**吉星**（天辅、天心等）
   - 得**吉格**（龙回首、鸟跌穴等）

2. **学校/考官生助考生**：
   - 天辅星落宫**生**考生落宫
   - 值符落宫**生**考生落宫
   - 年干落宫**生**考生落宫
   - 三者生助越多越好

3. **考生克制学校（实力压制）**：
   - 考生落宫旺相且得吉局
   - 考生落宫**克**天辅星/值符/年干落宫
   - 凭自身实力攻克考试，亦可录取

4. **被动录取（无吉助但被生）**：
   - 考生落宫休囚，无吉门吉星吉格
   - 但得天辅/值符/年干落宫生助
   - 可被录取，但学校层次一般

### 名落孙山的条件
1. **考生状态差**：
   - 考生落宫**入墓**
   - 考生落宫**逢空亡**
   - 考生落宫处**死绝之地**
   - 遇**凶门凶格凶神**

2. **被学校/考官克制**：
   - 天辅星落宫**克**考生落宫
   - 值符落宫**克**考生落宫
   - 年干落宫**克**考生落宫

## 成绩与试卷判断

### 高分/好成绩
- 景门、丁奇落宫**旺相**
- 得吉门、吉星、吉格
- 考生落宫**生助**景门/丁奇落宫（尽心尽力答卷）
- 天辅/值符/年干落宫**生助**景门/丁奇落宫（成绩被认可）

### 低分/差成绩
- 景门、丁奇落**休囚之宫**
- 无吉门吉星吉格相助
- 临**天芮星**（病星，主错误）
- 落**墓绝空亡**之地
- 被天辅/值符/年干落宫**所克**（不被认可）

## 特殊断法

### 公务员考试（分两关）
1. **笔试关**：套用上述"求学考试"断法，看考试成绩能否进入面试。
2. **面试关**：参考"工作事业/应聘求职"断法。

### 武举/投军
- **甲申庚**：代表箭。
- **甲午辛**：代表的（靶心）。
- 甲申庚与甲午辛落宫**相冲**：箭中的，主命中。
- **天冲星**：代表武士。
- **值符**：代表帅主。
- 天冲与值符**相生**：一见即投合。
- 天冲与值符**相克**：定不收录。

## 古籍等级判定（遁甲元灵经）

### 殿试甲第
- **太岁**：天子/主考
- **月建**：主考官
- **日干**：举子
- **景门**：策论

| 等级 | 条件 |
|------|------|
| **鼎甲** | 景门旺相 + 得三奇 + 太岁生日干 |
| **二甲** | 景门不得三奇，但太岁/月建生日干 |
| **三甲** | 不生日干，又无三奇 |

### 岁考等第
- **天辅**：文宗
- **日干**：士子
- **六丁**：文章

| 等级 | 条件 |
|------|------|
| **一等** | 六丁旺 + 天辅生日干 + 三奇 + 开休生景吉门 |
| **二等** | 六丁旺 + 天辅生日干（无三奇吉门）|
| **三等** | 六丁旺 + 天辅不生日干，或天辅生日干但六丁不旺 |
| **四等** | 六丁不旺 + 天辅克日干（但有三奇吉门）|
| **五等** | 六丁不旺 + 天辅克日干 + 休凶宫 + 无三奇吉门 |
| **六等** | 得死门及诸凶格，大不吉 |
