# 生意财运 (AI总结版)

## 一、业务谈判

### 用神
| 用神 | 代表 |
|------|------|
| 日干 | 求测人（我方） |
| 时干 | 对方/所谈业务 |
| 景门 | 合同 |
| 丁奇 | 合同/信息 |
| 值使门 | 招标负责人/事情执行 |

### 日时关系
| 关系 | 含义 |
|------|------|
| 日干生时干 | 我要多与对方言好 |
| 日干克时干（旺相）| 我能制住对方 |
| 日干克时干（休囚）| 我对对方不满意 |
| 时干生日干 | 对方有诚意，买卖易成 |
| 时干克日干 | 对方不满，买卖不成 |
| 日时比和 | 公平交易，能成 |

### 合同判断
- 景门逢空亡/丁奇入墓 → 签不成合同
- 景门临玄武、螣蛇 → 签了也难落实

### 信息真假
| 临象 | 含义 |
|------|------|
| 景门临蛇、武、空亡 | 假信/不确切 |
| 壬+辛、庚+壬、丁+辛 | 消息假或不确切 |

## 二、中介求财

### 用神
- 日干 = 买方（或求测人）
- 时干 = 卖方
- 六合 = 中介人

### 成交判断
| 关系 | 含义 |
|------|------|
| 日时相生比和 | 双方公平交易，能成 |
| 日时相冲克 | 交易不成/很难成 |
| 六合生日干 | 中介人向着买方 |
| 六合生时干 | 中介人向着卖方 |
| 六合被日时同克 | 过河拆桥，甩掉中介 |

### 六合状态
- 六合入墓/刑冲/落衰死之地 → 中介能力不行
- 六合旺相+合格 → 易成功

| 时干克日干 | 房子对你不利，不要买 |

## 四、买货求财

### 用神
- 日干/年命 = 买方
- 时干 = 货物
- 戊 = 本钱
- 生门 = 利润

### 货物质量判断
| 临象 | 含义 |
|------|------|
| 时干临吉神吉星吉门吉格 | 好货 |
| 时干临值符 | 高档、贵重、货真价实 |
| 时干临天芮星/螣蛇/玄武 | 假冒伪劣/走私/腐烂 |
| 时干临六仪击刑/伤门/刑格 | 残次或破损 |
| 时干临九天 | 畅销货/外地货/名气大 |
| 时干临九地 | 存放时间长/老物件 |
| 时干逢合 | 积压货/搭配销售 |
| 时干逢冲 | 销售快/结构不协调 |

### 能否赚钱
1. 看甲子戊和生门的关系
2. 时干与生门同宫/生生门/比和 → 能赚钱

## 五、卖货求财

### 无明确买货人时
| 关系 | 含义 |
|------|------|
| 日干生时干 | 人恋货，不舍得卖，难卖出 |
| 日干比和/同宫时干 | 能卖出，但有留恋 |
| 日干克时干 | 着急卖，但成交迟缓 |
| 时干克日干 | 卖出必速 |
| 时干生日干 | 货恋人，脱手不易 |
| 时干宫逢冲格 | 销得快 |
| 时干宫逢合格 | 积压或受阻 |

### 有利无利
- 时干宫生甲子戊或生门之宫 → 有利
- 时干与生门或戊二者相冲克 → 难获利
- 时干宫乘凶神凶格克日干宫 → 必赔本

## 六、合作求财

### 用神
- 日干 = 求测人
- 时干 = 合伙人

### 判断
| 条件 | 含义 |
|------|------|
| 日时同宫+合格 | 合作好 |
| 日时同宫+冲格 | 合作不好 |
| 时干生日干 | 对求测人有利 |
| 日干生时干 | 对合作人有利 |
| 日时比和 | 公平合作 |
| 一方逢空亡 | 难成 |
| 一方临玄武/螣蛇 | 容易变卦 |
| 日时落对冲之宫 | 不成 |
| 日时某方遇六仪击刑 | 出现问题 |

### 是否分手
- 日干、月干一内一外 → 分手
- 均内盘或均外盘 → 不分开

## 八、竞争对手

### 用神
- 月干 = 同行/泛指竞争对手
- 时干 = 直接冲你来的竞争者

### 竞争判断
| 关系 | 含义 |
|------|------|
| 月干克日干 | 同行对我构成压力 |
| 月干生日干 | 同行对我有益 |
| 时干克日干 | 竞争对手对我不利 |
| 时干生日干 | 对我有利，可和谈 |
| 日干克时干 | 我方不惧对方 |

### 对手比我强的地方
- 月干所克之宫 = 你不如人家的地方
- 如月干克杜门 → 人家技术比你好
- 如月干克开门 → 你的销售不如人家

### 对手未来决策
- 月干（或时干）下临之干翻宫 = 其未来决策
- 此宫克日干 → 其决策会影响你

## 九、招投竞标

### 用神
| 用神 | 代表 |
|------|------|
| 日干 | 投标者 |
| 时干 | 标 |
| 月干 | 竞争对手 |
| 值使门 | 招标负责人 |

### 能中标
- 时干旺相+吉格，生日干宫
- 时干与日干同宫/比和
- 日干旺相，克时干宫

### 不能中标
- 时干死墓绝+空亡+凶格，克日干
- 时干/日干有死+壬格局
