## 十、应期判断

### 基本规则
- 用神逢空亡 → 冲填实为应期
- 六仪击刑 → 逢合为应期
- 入墓 → 出墓/冲墓为应期
- 临马星 → 马星动/被冲为应期
- 反吟 → 合为应期
- 伏吟 → 冲为应期

### 远近判断
- 病星落内盘 → 近期
- 病星落外盘 → 久远
- 值使门落宫数 → 期限
