## 六、阳宅预测要点

### 大环境（值符）
- 值符旺相+吉格 → 大环境好
- 值符逢空/刑格/凶格 → 大环境差
- 值符九星决定持久力

### 小环境（生门）
- 生门代表房屋质量、居住质量
- 生门与日干（年命）生克关系 → 对居住者影响

### 现状（时干）
- 时干代表房子现阶段状态
- 时干临吉生日干 → 现阶段好
- 时干临凶克日干 → 现阶段凶

### 日时关系
| 关系 | 含义 |
|------|------|
| 时干生日干+三奇吉门 | 最佳环境 |
| 日时比和 | 协调，但要看格局 |
| 日干克时干 | 能镇住房子，平安 |
| 日干生时干 | 泄财气精力 |
| 时干克日干 | 不适应此风水 |
| 时干临凶冲克日干 | 大凶之宅 |
