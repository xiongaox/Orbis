## 三、命运局起法

### 起局原则
1. **原命局**：出生时间起局
2. **大运局**：每九年一个大运，按时柱顺排
3. **流年**：结合三者关系来断

### 命局断法要点（张志春法）

1. **辨男女阴阳**：男命阳遁顺，女命阴遁顺
2. **看值符值使**：
   - 吉星照命还是凶星
   - 值符与日干所临星的生克
   - 值使门与日干所临门的生克
3. **看大局**：
   - 天显时格（六甲之时）较平稳
   - 星门伏吟/反吟
4. **竖看日干落宫**：
   - 完全合局 → 大富大贵
   - 基本合局 → 富贵
   - 半合局 → 中层人士
   - 失局有气 → 下等脑力劳动者
   - 完全失局 → 穷苦之人
5. **开休生三吉门** → 发展方向
6. **日干所临星门** → 适宜职业
7. **生门与日干** → 财运
8. **开门与日干** → 官运事业
9. **休门/六合/乙庚** → 婚姻家庭
10. **天辅星/天蓬星** → 受教育情况
11. **天芮星/死门/伤门** → 身体状况
12. **年干/乾坤宫** → 父母
13. **月干/时干** → 兄弟姐妹/子女
14. **值使门** → 寿限

## 五、断局纲要

### 第一项：用神落宫状态
看天时、地利、人和、神助、格局、宫利六要素

### 第二项：相关人落宫与生克
知己知彼，明确双方状态

### 第三项：日时关系
| 关系 | 含义 |
|------|------|
| 日干克时干 | 有能力办成此事 |
| 时干生日干/比和 | 办事顺利 |
| 日干生时干 | 追求此事 |
| 时干克日干 | 事情难办 |
| 时干临吉克日干 | 不成但无凶 |
| 时干临凶克日干 | 不成有祸害 |

### 第四项：专有用神
如测提升看值符、开门与用神关系

### 第五项：不同事项不同符号
根据具体预测事项选择对应符号判断

### 第六项：吉凶转化
物极必反，考虑能生能克、虚实旺衰

### 第七项：远近快慢
- 阳遁：1、8、3、4宫近快；9、2、7、6宫远慢
- 阴遁：相反
- 反吟：空间远、时间快
- 伏吟：空间近、时间慢

### 第八项：全盘看+外应看
留心周围动静，来人举止都提供信息

### 第九项：环顾全局，制定策略
> "急则从神缓从门，动静先后分主客"

## 六、流年流月断法

### 流年整体运势
1. 值符 → 大趋势、贵人、大环境
2. 值使 → 执行力、人和
3. 年命天干落宫 → 全年天时地利人和
4. 太岁年干落宫与年命生克 → 是否得运

### 流月运势
1. 流月干天盘落宫为主
2. 流月支落宫为辅
3. 流月宫与年命宫关系定该月运势
4. 空亡看对冲宫

## 七、论旺衰

### 十天干旺衰
以十二长生判断：长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养

| 状态 | 含义 |
|------|------|
| 长生、冠带、临官、帝旺 | 地上旺相 |
| 沐浴、衰、病 | 地上弱态 |
| 死、墓、绝、胎、养 | 地下状态 |

### 九宫旺衰
以正五行时令看：同我旺、生我相、我生休、我克囚、克我死

### 九星旺衰
1. 落宫状态（空间）
2. 月令状态（时间）

> **久远之事落宫最重要，短暂之事时间最重要**

### 八门旺衰
同我为旺、生我为相、我生为休、我克为囚、克我为死

### 八神旺衰
- 一般不考量旺衰（跳出三界外）
- 作用神时按正五行判断

## 八、过去现在未来

| 时态 | 看什么 |
|------|--------|
| 过去 | 退星落宫、地盘日干、时干地盘、退门 |

### 名词解释
- **进星**：日干所临之星加值符顺/逆转
- **退星**：九星地盘
- **隐门**：日干所临之门加值使门顺转
- **退门**：八门地盘
