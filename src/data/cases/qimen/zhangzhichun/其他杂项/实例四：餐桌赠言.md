# 实例四：餐桌赠言

安徽宿州易学科技应用学术研讨会期间，一些专家学者与会务人员一起在小餐厅用餐。5月22日晚餐开饭后，我和杜新会又来到小餐厅。同桌就餐的有江苏省周易文化研究会会长、南京大学哲学系教授李廉先生，陕西省周易研究会常务副会长、手相大师陈鼎龙先生，杭州市周易研究会副会长兼秘书长任易德先生，湖北十堰大学党委副书记李玉瑞先生，以及会议主持人高飞等同志。大家刚坐在餐桌边，菜还未上，不约而同地发现今晚餐桌上多了一个陌生的女同志。该女同志，中等身材，体型丰满，年纪约三十多岁，来后就坐在杜新会身旁。

我悄悄问身边的高飞同志：“这位女同志是谁？”

高飞说：“这是我夫人。”说着，就将餐桌边的各位专家一一介绍给他夫人。

刚介绍完毕，著名手相专家陈鼎龙就以明察秋毫般的眼睛一直盯着高夫人，笑吟吟地说：“高夫人，我送你几句话。”于是陈鼎龙从面相角度，说高夫人如何如何好，如何如何心地善良，但发起脾气来可不得了，敢把电视机、冰箱都砸了，等等。

这时，杜新会伸出左手，悄悄在手上起奇门格局。挨着他坐的高夫人见杜新会看手，以为他会看手相，于是把她的手伸过去，说道：“杜老师，陈大师给我看了面相，你给我看看手相，也送我几句。”

杜新会把高夫人的手挡回去，幽默地说：“我这手上有反光镜，不用看你的手。我也送你几句。第一，你是做生意的，原来有公职，现在不干了，自己做点买卖，应该是做烟酒生意的，对不对？”

高夫人马上说：“对，对。我原来在纺织厂工作，现在自己开着一个门市，卖烟酒等日用品。”

杜新会说：“但你的生意做得不好，赔了本，现在压了一百箱高档烟酒卖不出去，对不对？”

高夫人惊讶地瞪大了眼睛，说道：“哎呀！杜老师，您说得太准了！”

杜新会又说：“不仅如此，你昨天还为一件口舌是非事伤心生气，而且掉了眼泪……”

这句话更仿佛说到她的心里，高夫人不禁黯然神伤，几乎又要掉下泪来，但她马上控制住自己，问杜新会：“杜老师，你也没有看手相，怎么说得这么具体、这么准？”

杜新会笑着说：“我手上并没有什么反光镜，即使有，也照不出这么具体的事来。我是跟我们张会长学的奇门遁甲，我用奇门遁甲在手上起局预测出来的。”

于是，高夫人和大家都感叹奇门预测的神奇。陈鼎龙还同我们探讨了在飞机上如何确定方位、如何预测的问题。饭后，高夫人又跟我和杜新会到我们俩住的宿舍，进一步预测了一些事情。

杜新会是怎么测出高夫人上述这些具体事情来的呢？下边具体分析一下这个时间的奇门格局：

## 盘内信息

**公元**：1997年5月22日18时30分0秒 阳5局

**干支**：丁丑年丨乙巳月丨甲子日丨癸酉时

**旬空**：申酉空丨寅卯空丨戌亥空丨戌亥空

**值符**：天禽星丨**值使**：死门丨**旬首**：甲子戊

## 分析：
（ 1 ）怎么知道高夫人原来有公职，现在不干了，自己做烟酒生意的？

日干甲子戊代表高夫人，落坎1宫，临休门，说明休息了；又开门为公职，在乾6宫逢空亡，说明不干公职了。甲子戊为资本、为钱财，日干临之，说明她是做生意的；甲子戊落坎宫，坎为水，又临丁奇，丁为火，丁下又临癸，酒为水、烟为火，所以断她是做烟酒生意的。

（ 2 ）怎么知道高夫人做生意赔了本，压了一百箱高档烟酒卖不出去？

甲子戊为资本落坎宫，生门为利息落8宫，生门克甲子戊，必然赔本。日干为人，时干为货物，日干戊落宫生时干癸落宫，人恋货卖不出去；时干癸临杜门，也主卖不出去，又临天蓬破财之星；八门伏吟也主囤积。地盘癸在坎1宫，坎水主一、六数，故断是一百箱。上乘值符主高档、贵重，故断是一百箱高档烟酒。

（ 3 ）怎么知道高夫人昨天为口舌是非事伤心生气，而且掉了眼泪？

高夫人坐奇门宫的震位，震3宫临天心星克宫，伤门伏吟，上乘太阴，主阴私之事，己+丙火悖地户凶格；又日干所在坎1宫，丁+癸为雀投江凶格，主口舌是非，昨天正是癸亥日，癸水克丁火，丁火又为眼睛，所以断她流了泪。
