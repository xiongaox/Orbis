# 人生建议

先天的秉性是什么，佛家把它称为习气。

那么什么是习气呢？有大德是这样比喻的，瓶子中装有酒水，当倒掉酒过后，即便是滴酒不剩也残留着酒的气味，而这个气味就是习气。

我们今生与生俱来的性格，就是过去世就残留的习气，虽然轮回了，换了一个身体，但这种根深蒂固的习气还没有断除。这也就是为何每个人从小的性格就与众不同，有人温和，有人暴躁，有人喜欢安静，有人喜欢嘈杂的原因。

那么如何断除习气呢？就比如带有酒味的瓶子，我们只要把它放到一个角落，然后不去理会它，时间一长气味自然消除。所以只要我们不去理会习气，就能慢慢断除习气。

每个人都有自己的性格缺点，而这些缺点或多或少都会对自己的生活造成影响，所谓性格决定命运就是如此。一个人性格缺点越大，则人生越会不顺。

所以降服自己的性格缺点，才能从根本上去改变命运，让人生更加顺利。

你八字食伤太重，并且克了官星。则不论和谁在一起，时间长了都会心生不满。一开始你会看到对方的优点，但时间长了则看到的更多是缺点。这个时候你就会内心排斥，不愿意去理解和包容对方，一旦出现点不顺心的事情，就会爆发出来，从而导致婚姻出现问题。所以性格对一个人来讲是非常重要的。因为直接决定着婚姻结果的好坏。

夫妻双方如果性格互补往往还好，有时候你的缺点在一些人眼里也是优点。但能遇到这样的人，并非人人都有福气的。

如何才能改变自己的性格呢？

1.首先要学会忏悔，并且要每日忏悔，反省自己今天的所思所行。

2.通过学习古代先贤的智慧，明白何为对错，树立一个正确的是非观，并且通过学习来增长智慧，从而破除更多的无明，而降服不善的习气。

3.平时可以练习静坐，因为静坐可以让心静下来，长期练习则能增加定力，增加抵抗诱惑的能力。在这个社会行走，定力对我们来讲是非常重要的。

4.如果脾气上来了，要学会通过念佛，持咒，读经来降服。如果实在无法排泄内心的愤怒和不满，可以通过唱歌，大吼，跑步来排解。只要找对方法，并且坚持这样去做，假以时日这些不良的习气都能慢慢的被断除干净。到时候你的气场就会更好，你所感召而来的人也自然会更适合自己。
