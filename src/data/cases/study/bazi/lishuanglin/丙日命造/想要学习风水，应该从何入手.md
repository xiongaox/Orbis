# 命理提要

一、日干为丙火，在午火月份出生得令，透甲木来生丙火，所以丙火在原局是不弱的。因为午火为丙之阳刃，阳刃在月令的帮助是非常大的，如果月令得禄刃，再有一个干支生扶即得旺相。

在地支则午火为忌神，有食伤泄为吉，地支喜水为利，夏季出生比较炎热，喜见水调候为用，也喜金来生水；最怕木火为忌神，因为木会生火来克金，至于地支见土也不必，因为地支本身土就不弱，不需要再补。

天干甲木来生丙火，甲木为忌神有辛金财星制甲木为吉，甲木坐午火不旺，则辛金可以制住甲木。有壬水调候，壬水不能被克，所以不喜土来克水，喜金水相见。所以天干和地支都不喜见土，故而走土运并不是很理想。而走金水运相对比较好一些。

二、原局当中，食伤非常的旺，所以会从事技术方面的工作。而且食伤多的人也可以从事咨询方面的工作。食伤在地支更多代表技术，而在天干则更多代表表达以及口才，比如演艺等。年干辛金为正财星，有伤官来生财，所以财源还是不错，而且正财制了枭神，故而正财发挥了好的作用。丙火为自身遥合辛金财星，所以这个财能被我所得，故而也是有财运的。不过正财喜暗藏不喜透，透则不存，故而也不聚财，漏财非常的多。八字只有一个财星，独财为真财，也代表能有一份相对平稳的收入，并且原局来看财运还是可以。八字喜见财，但是财在年比较远，丙火要合财需要付出更多辛苦，财远不能轻易获得，并且财在年也为远方之财，故而一定要走出去才可以获得财。也代表经常会出去求财的意思。

所以你有财运，但是财在远方。由于是自己合财，所以这个财是通过自己的劳动赚来的，这样的财毕竟要勤俭才可以富家，否则也是很难存住，到最后依然困难。所以一定要养成勤俭的习惯，这样对你的事业财运才会有较大的帮助。

八字甲木为偏印，一般偏印代表的是非正统学术，非主流的学术，偏门，冷门。而且偏印，七杀同时出现更加代表如此。官杀为工作，七杀也有偏门的含义。甲木被辛金财星制住，为财来制印，故而可以学习一些风水方面的知识，并且可以学会。由于偏印被财制住，将来也可以靠此技艺赚到钱财，改善生活。你八字时支为华盖星，华盖临七杀也有偏门发家的意思，并且食伤非常的旺，代表会从事技术方面，而做风水也属于技术行业，并且有枭神贴身，枭神在十神当中属于最大的神秘星，所以枭神挨着自己，往往和一些神秘文化，玄学，宗教有很深的缘分，且日时均为童子星，故而这种缘分是很深的。所以你可以去学习风水知识，并且将来可以从事这份工作。

至于童子星，我这里就不再讲了。在之前已经多次阐述童子星的真正影响，你可以去翻看一下。

三、至于婚姻方面，你八字年为财故而妻子是在远方，你要找对象一定要走出去才可以，去很远的地方。如果是在本地寻找则不容易。八字日时伏吟，且辰辰自刑，也暗示了感情并不顺利。最大的问题是日时均为寡宿，主孤独之象。这种组合都是不利婚姻，主晚婚。

# 大运流年

23-33岁走的辛卯大运，辛金为财在大运虚透，卯木非辛金之根，所以大运当中的财是非常不稳定的，摇摇欲坠。辛卯大运，卯木为花草，小树，而辛金为你的财，财在花草之端，能撑起的财也是非常少的。丙火来合财，所以也能赚到一些财，但是都非常少。地支卯木和辰穿，未合。更多伤害了原局当中的土，土受损且火更旺，非好运。所以在这十年当中，并不是很顺利，工作当中阻碍也非常大。也比较辛苦。

2019己亥年，为甲木长生，而甲木为偏印主学习，长生代表开始。所以你在明年会有比较好的学习机会，或者是有拜师的机会。自己好好把握。如果有学习风水的决心，我觉得是可以去学习的，对你有利。

有己土来生辛金，为伤官来生财，己土也是未土，有生则代表有感情的付出。故而明年也会遇到一个你喜欢的，或者是有接触的姻缘，好好把握。

33-43岁走的庚寅大运，和这十年差别不是很大。不过财会比现在多很多。而你相对比较好的，就是在中年了。如果去学习风水，将来从事这个行业，那么最好的阶段也是中晚年了。因为这个行业虽然说年龄和知识无关，但是对于大多数人来讲，年龄的确是非常好的一个招牌，而这个行业的特点也差不多就是年龄越大越受欢迎。

# 人生建议

如果你要学习风水，我给你几个建议，希望对你能有所帮助：

1.你现在快28岁，从年龄来看学习已经比较晚了，因为这个阶段人的记忆力和学习能力都有很大的下降，并且这个年龄能坐住去学习的人是很少的，所以需要花费更多的精力和时间。自古易学风水行业的先贤都是幼年就开始学习，比如郭璞20岁就已经非常出名了；杨筠松十七岁登科及第，后担任国家掌灵台地理事；李淳风出师也不到二十岁，并修改了《戊寅元历》；韦千里复旦大学文学系毕业，20岁就已经是易学奇才等等，自古所有行内先贤均是从小就开始学习，而非成年之后，且成名于年轻时期。

所以如果要学习风水易学文化，最好就是从小开始学习，这个时候人的接受能力是最强的，更容易精进。所以出生社会后再来学习，往往会因为记忆力衰退而吃亏，故而在学习上面要花费更大的心血和功夫才可以。且一定要有明师指点才行。学习之前要先有决心，给自己定一个目标，一年内必须要学会什么且熟练掌握，有目标的进行，才能有更快的进步。

2.风水学属于学术类，要先掌握丰富的理论知识，然后才可以去实践。实践是建立在理论的基础之上，说不出来也就做不出来。就比如学医，我们先要明白药理，病理等，然后才可以去临床实践。如果什么道理都不知道，何来实践呢？现在有很多“大师”说自己讲不了，但是做得了，这都是不靠谱的。因为这是知识性的而非木工、石匠，是纯手艺的。

所以第一步就是先看书，要看大量书籍，心中有数后才可以去拜师。只有这样自己才可以去分辨真假，判断对错。从而在学习当中不至于被引入误区。如果什么都不懂就去拜师，若遇庸师，则很容易被第一个师傅给带偏，导致最后要么学错了，要么学无所成。所有风水大家，都是从看书学习开始。

书籍是真理，就和学佛一样，一定要信法不信僧，要有这样的观念才不会被误导。任何道理，若无典籍应证则观点就存在质疑。就比如僧人讲法，若违背经典，则也必须要引起谨慎。当熟读经典后，他们所说是对或错则一清二楚。3.首先要学习识峦头：《葬经》《撼龙经》《疑龙经》《都天宝照经》《龙脉经》《玉髓真经》《地理全书》《地理人子须知》等。

然后学习三元理气（为主）：《青囊奥语》《天玉经》《地理辩正疏》《玄空六法》《沈氏玄空》《玄空地理秘中秘》等。

再学习三合理气（为辅）：《地理五诀》《地理末学》《天机一贯》等。

如果要学习择日：先买一本《玉匣记》看一下，了解一下常见的神煞，但是不用全部记忆，只需了解，不过一定要读完。然后再读《三元择日法》等，要明白乌兔择日，太阳到山到向，这个在风水上面运用比较广泛。

如果要从事丧葬地理，还需要熟读《三元总录》等。

4.在学习过程当中，有一些书会存在冲突，这个时候你用笔记录下来，然后在看完所有书后答案自然明了，如果自己还是不明白，就可以去请教明白的人。上面这些书看完后，你才可以去看其他的书籍，至于现代人写的书不能轻易看，特别是初学者，因为也非常容易被误导。经典看完后再去看，你就能做到心中有数，便知对错。这个时候再去拜师，师傅稍加指点，或告知一些核心东西，你就能立刻明白，总之最后一步一定要拜师，因为书是理论，而师父是告诉你如何实践。不过这些书如果能很好理解，你的理论就已经非常扎实了，这个时候只需要知道如何去用，跟着师傅跑一年就可以出师了。如果你按照我说的去学习，一定可以学有所成。但是看完这些书且能理解记忆，至少需要三年时间。我上面说的只是必读书籍，除此还有很多书是需要去学习的。

我愿意做一个引路人，告诉大家应该如何去学，以上所讲可以说是千金难得，基本上把整个风水学当中最核心的东西都说了，一些做风水开班的老师是最怕大家知道这些的，一个好的师父也就是告诉你该看什么书，应该如何去看，然后从旁指点。如果有心人能按照这个顺序去学习，必然会有所成就，其风水技术一定能超过当地百分之99的先生。

上面这些学完过后，至于能否灵活运用，融会贯通这就要看个人的天分和悟性了。这是学不来的，关键是看先天是否具备这样的慧根。如果要在风水上面达到最大突破，还需要学习三式，占卜以及命学。因为地理属于“地学”，而择日属于“天时学”，八字命理属于“人和学”全部学习则天地人都能知晓，这样才算一个完整的术数大师，然后再去从事这个行业，必然可以造福一方，为民谋利。若一知半解，欺蒙拐骗，则会害人害己，报应子孙。

以上都是我个人的学习经历以及感悟，对所有想要学习风水的人指明方向，如此而来必不会迷，也不会走弯路，更不会上当受骗，且能助大家更快的成为风水学专业人士。
