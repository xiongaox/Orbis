# 命理提要

一、丙在子月出生失令，地支有申子辰三合水旺，水为官杀攻身，幸得甲木通关，所以甲木属于非常重要的五行，也是非常关键的，是整个八字的命脉。原局官杀特别的旺，都来攻克日干，全靠甲木化煞生身，所以甲木是万万不可被伤害的。

八字喜木为最位用神，由于冬季出生命局较寒，故而也能用火。所以用神为木火，而忌神为土金水。丙在地支没有一点根气，地支一片潮湿之气，所以就算地支走火运，也无法利益日干丙火，天干则见木火都是不错的。甲木不可被伤，则不喜岁运见庚，辛，己。否则甲木受损，官杀必定群攻丙火，引发灾难。

二、从八字原局来看，甲木非常重要，木损则灾难至。因为除了甲木，没有任何一个干支来救丙火。当用神唯一的时候，往往也是非常危险的。身弱则见印为寿元星，故而甲木就是自己的寿元星，一旦甲木受伤，则疾病灾难必至。

原局暗藏了很大的灾难信息，一旦岁运出现庚，辛，己。其中特别是见己土，因为甲己相合，则会导致甲木失去作用，而无法起到化煞生身的作用，从而官杀就会直接来攻击丙火。而庚辛因为天干有癸水，所以对甲木的损伤是较小的。故而大运最怕见己土透出来合甲木。因为甲木是用神，我在之前的文章也提到过，用神被合是最危险的，因为一旦被合用神就会失去原本拥有的作用。

从原局来看地支申子辰三合水旺，且丑也是湿土，一片湿气，中医认为万病皆从湿寒起，八字太潮湿也代表易病。丙火无根，全得甲木来生，而水多木漂，也导致甲木为湿木，生火的力量也是不大的，故而原局暗藏危机。一旦有岁运引化，后天风水不善等就会导致重大疾病或意外灾难发生。

# 大运流年

34-44岁走的戊辰大运，戊癸相合，而导致癸水不来生甲木，并且戊也是来消耗丙火的。地支辰和原局申子三合，增加了水的力量。而且戊辰都是土，为食伤大运。又怀孕生子则增加了食伤的力量，导致更加削弱丙火的力量。诉以得病是从戊辰运开始的。这个运就已经非常不吉的，各方面的运势也不是很好。

八字时柱逢空，且食伤为忌，不太适合多生孩子。而且戊辰运并非好的运，生孩子只会加重食伤的力量。特别是生儿子，对自己伤害更大，因为伤官为儿子，儿子是己土。

44-54岁走的己巳大运，己土出现了，而且己土坐巳火有力，则己土来合甲木，导致甲木无法起到通关的作用。就比如官杀为一群恶狗，而甲木就是一位来帮助自己驱赶恶狗的人，但这个时候有另外一个人拉住了这个帮助你的人，而导致无人来驱赶恶狗，从而导致自己被恶狗所伤。在行己巳运就是如此。

而巳火为禄神，丙火在原局是没有根气的，地支也没有木，所以大运见巳火，反而被原局金水反伤。而且禄到寿到，禄神就代表寿。一旦大运出现禄神，再流年来伤，则健康有大损。

2016丙申年的时候，申子辰三合，这一年就应开始得病了。从怀孕开始就被病魔缠身。

2017丁酉年，丙见酉为死地，流年是非常不好的。丙火不旺的时候，最怕见酉金和辛金。属于日落西山。并且从2017年开始进入己巳大运，而己土也合住了甲木，导致甲木无法来帮身，而被官杀攻击。

在2018戊戌年，由于土旺而制了一下官杀，则这一年能挺过去。

但在2019己亥年的时候，则大限明显。流年己，大运己双双来合月干甲木，且流年亥冲了大运巳火，而大运巳火为丙火的禄神。天干甲木为寿元星被己土合住，地支巳火为寿元星被亥水冲克。所以今年凶多吉少，很难挺过去。特别是在今年的农历的四月己巳，五月庚午，六月辛未，以及在农历的十月乙亥，冬月丙子。

2019年开始就走忌神大运，2020庚子年也非常不吉，在2021辛丑年也凶不可言。所以这三年都很难熬过去。

如果能过了2022年，则可以再活人。但这种情况的几率是很渺茫的。

# 人生建议

一、这个八字我分析的非常惆怅，也因为自己无能为力而深感痛心。一旦得了癌症晚期，基本上就等于是宣判死刑缓期执行。结局都是大家可以预料的，留下的只是时间长短的问题。现在的人得癌症的越来越多了，而且越来越年轻化了，我身边也出现了不少年纪轻轻就身患癌症去世的人，深感无常就在身边，人永远不知道下一秒到底发生什么。我亲自经历了亲人的离世，上午都好好的，但下午就阴阳两隔。让我深感生死无常，人生多苦。所以我们活着的人，都要更加珍惜现在的每一分每一秒，要去做更加有意义的事情；每天一觉睡醒，要感恩我今天还活着，还能陪伴家人左右。

**得癌症是否一定是八字决定的吗？**

**答：** 不是的。八字只是决定了运势的好坏，而并没有决定在这个运中要发生的具体事情。当走衰运的时候，可能体现为生病，住院，破大财，贫穷，犯官非，离婚，人生多不如意事等。但并菲一定就是得癌症。八字决定了质，但并未决定量。所以程度大小，则因人而异。

**那么为什么在运势差的时候，会得绝症呢？**

**答：** 这是因为我们自身没有很深的福报啊，平时也不懂得如何去修福报，家中也没有一个福报很深的人来庇佑自己。所以一旦走衰运的时候，各种灾难都可能会出现，很难逃得过去。而福报比较大的人，就算运势差一些，也有躲过去的机会。所以我经常劝诫大家，最好的改命就是修行，最好的消灾就是行善。

古人云：“一人得道鸡犬升天”，家中有一个人在修行，那么一家人都会跟着沾光。如果妈妈懂得修行，子女也能得到福荫。所以修行不单单是为了自己，也是为了爱我的人和我爱的人。

何为修行呢？就是依照佛法修正自己的行为。多行布施，多去帮助困难的人，为自己积累福德。要懂得持戒，不要杀生，不去害人等等。我在之前文章提到了六度波罗蜜，大家可以去看看。只要自己福报深厚了，必定子孙得利，六亲得福。并且自己通过修行也能去影响亲人，特别是影响子女，把自己的德行能传承下去，让家风更加纯正，这才是给孩子最大的财富。
