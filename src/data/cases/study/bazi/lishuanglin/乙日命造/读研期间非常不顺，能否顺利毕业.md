# 命理提要

一、日干乙木在丑月出生失令，地支有丑戌三个土，时支一个子水来生乙木，天干有甲木帮身。出生两天后则进入立春，故而也尚有木气，但毕竟失令失地故而不旺，属于偏弱的命。冬季出生寒气较重，故而原局喜见火为吉，乙木左右为丙丁透出，而丙丁为忌神且虚透为吉，丙丁为日月二星，同时出现围绕乙木左右大吉。

时支子水为印，但子丑相合则让子水的力量大大的削弱，命局土重为忌神，则喜木来制土助身为吉，水来生木为用。则八字喜水木为用，忌火土金。但由于地支有子水，故而地支见金也是不怕的，但天干不能见金，否则会克甲乙木不吉，而土则不管是天干还是地支都不能见，至于火则天干可以少见，地支不可见。故而天干可以见水木火；而地支可以见金水木。至于土则干支均忌。

二、看学业主要是分析印，食伤，正官星。

印代表文凭证书的意思，食伤代表智慧，学习能力；而正官则为荣誉的代表。

身弱重点看印，以及忌神是否有制。身旺则重点看食伤以及正官星的状态。当然最重要的还是要看第一步大运和第二步大运走的如何，是否有助学业。如果原局组合的很好，而大运不吉，也学习非常不顺，阻碍很大，反之原局不好而大运走的好，虽然顺利但很难有大成。

原局子水为印可以代表学习，不过子水被丑合克，故而学业受阻，子水在时支出现，则越往后学习阻碍越大。不过乙木左右为食伤二星，这个组合是非常不错的，食伤也代表才华可以得到体现。丙丁火在地支是无根的，由于丙丁为忌，则无根为吉，也代表自己可以驾驭丙丁二火，所以丙丁火能起到一个照耀八字，暖局的作用，故而丙丁也可以代表文凭，故而属于双文凭。

三、一般食伤相随都不喜欢过于体制，太约束的工作，更加渴望自由点的行业。而食伤也有传播，讲解，技术，才华的意思。天干一片木火，又在冬季出生，则为木火通明可以取暖，这样的组合是非常利文化的。有食伤相随的八字一般都比较适合做老师，从事教育工作非常有利。

年干甲木为乙木的依靠，乙木最喜见甲木，丙火。甲木为大树，乙木为藤萝，而藤萝要爬的更高则必须要有甲木的帮助才可以，要依附甲木而往上攀爬才能达到最高点，而丙火则为太阳光，丁为月亮，丙丁都是火来照耀乙木，而乙木有灯芯的意思，丁为灯火，子水为灯油，所以整个八字组合都是不错的。这样的组合，都很适合做老师，故而非常建议你朝教育方向发展。

月支见华盖星，并且华盖+食神，年柱为空亡。这样的组合并不太喜欢嘈杂的工作环境，喜欢清静，不喜欢过多的社交关系。所以商业肯定不太适合自己，官场也不适合自己了。如果要走官场，免不了各种应酬，见各种人，如果不去做则注定了默默无闻，如果去做更让自己反感。至于从商，你八字财多不担，不建议直接去求财。而且你八字是印合财，子水合财，那么印来合财也代表你的财是通过文化，知识获取的。并且你属于身弱喜印的八字，故而文凭越高对你的事业帮助越好，也会让你的命运层次越高。

如果以后出去上班，也会有很多不顺，社会是残酷的，并没有想象的那么轻松自然，竞争也是非常激烈的。如果是选择做老师，那么就再好不过了。教师的工作没有那么的约束，相对而言比较的自由，并且属于自己的时间也特别的多。这都非常适合你，也是你想过的生活。并且在当今教育兴国的背景之下，未来的教师待遇只会越来越好，教师的地位也会越来越高。

# 大运流年

9-29岁这二十年都是走的印星大运，你八字弱而喜见印，故而走印运利学习。特别是在19-29岁这十年，乙亥大运，亥水为驿马+印则外出求学。不过大运亥水临空，所以阻碍是有的，自己也容易放弃。但一定要坚持，不要轻易放弃求学，只有获得更高的文凭，你的未来也才会更好，这将是决定你一生的命运，一定要谨慎。

亥水为驿马，亥水逢空，而驿马+空亡则为假空，也代表外出不空。故而求学要去远点的地方，经常往外走也对你特别有利。

# 人生建议

1.你要先调整一下心态，然后好好的去努力，你的基础是不错的而且现在行运也还不差，所以能顺利毕业，但自己要用心呀。如果整日心不在学习上面，用浮躁的心去学习，再好的运气也是没用的。只要用心，就没有任何问题。研究生毕业后如果可以继续读博是最佳选择，博士毕业后未必一定去做科研，你可以做老师呀，可以在高校任教，这个时候你就会有更多的选择权利，那么你的人生也必定会更好。

你现在处于一个非常关键的阶段，命运重在选择，而选择大于努力。如果你选择研究生毕业后就和男友出去工作，那么人生必定是一番景象。如果选择读博后去高校任教，那么人生又必然是另外一番景象。因为你现在有读博的条件和基础，就不能放弃。

一定要明白呀，社会是残酷的，并没有那么轻松。在学校和出身社会完全是两种不同的生活方式，不要急于进入社会，应该先强大自己，再出去不迟。所谓“磨刀不误砍柴工”，自己条件越好，能力越强，将来选择的面就越广，这个时候就是你去选择别人，而不是别人来选择你。当自己成为被选择的这一类时，是很痛苦的，运气稍微不好就会被淘汰。

你现在走乙亥正印坐马的大运，一定要好好把握这步大运，努力的完成学业，要为自己定一个目标，并且发愿去实现它。如果过了29岁你想再去实现，就困难了。这个时候年龄和运气都已经不具备了。

2.其次就是感情的问题，这个时候你应该更多的心思花费在学习上面而非感情上面。因为这段感情，未必就是最适合你的。在学校期间的恋情一旦出身社会就会有很大的变化，现在不代表将来，不要天真的认为这就是将来。也不要轻易相信男友许下的任何承诺，因为此刻是真心的，但一旦出去后就会发生很多变化。

这个时候你更多的心思要为自己而努力，为了强大自己而努力，而不是为了谈恋爱而努力。只要自己优秀了，何愁遇不到优秀的男生呢？并且你的命的确要晚婚，早了反而不利。并且我看这个男孩的八字不是很好，损妻信息很强，对妻子也不好，当然现在看起来是没有问题的，不过本性要在结婚后才能知晓。比劫制财的男生，都性格脾气很差，而且对妻子不好，甚至容易暴力。

我并非让你分手，而是要看淡当下的感情，让感情成为你前进的推动力而非成为你前进的阻力。要有自己的规划和目标，不要被任何人所左右，要为自己的将来负责。你现在有很好的学习条件和基础，天时地利人和都是具备的，一定要坚定信念，不要放弃。人生还很长，现在的努力就等于是在给玩具车上发条，上的越紧就能跑的越远。

最后再提醒你一下，不要被眼前的感情所迷惑，不要被外人的意见所干扰，要坚定自己的选择，不放弃不抛弃，这样你的将来才会更好，人生才会更加精彩，也更有机会去做感兴趣的事情。
