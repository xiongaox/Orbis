# 命理提要

一、日干壬水在丑月出生失令，但由于地支见亥子丑三会，且丑为寒土，湿气很重，且为腊月中旬，故而丑也能助身。丑土之中暗藏辛金和癸水，都能对日干壬水进行生扶，特别是日时见禄刃双全，则水气力量很强，帮身有力。日干壬水得地支亥子丑水局帮扶，又得时干辛金来生，则日干不弱，为身旺之命。

冬季为寒命，最喜见火，无丙火则以丁火代替，月干透出丁火，本为用神，但丁坐丑无根，且丁火在地支没有得到半点生扶，则丁火太弱，难以暖身。丁火为财，也为身旺财弱之命。好在年干有甲木来生丁火，则得到一些生扶，还不至于断了财源。

> 用神：火，木。火为财星，可以暖身，木为食伤可以生财。至于土，虽然可以制水，但也生金，故而吉凶参半，地支可以见一点土，但天干不喜见，因为天干有辛金贴身，见之不吉。
>
> 忌神：水，金。原局水气太重，又见金水来生，则必然损财伤身，故而不论天干还是地支，都不喜见金水。

命局忌神太重，而用神无力，若大运不来生扶，则命格平凡。

二、年支戌为七杀星，月支丑为正官，属于官杀混杂。丑戌三刑，会破坏官杀的稳定，影响到婚姻。丑为正官，也为丈夫，但被日支子水争合，且时支见丑，故而夫星有被争合之象，这是要注意的地方。

原局有丁壬相合，子丑相合，原局日柱和月柱也为天和地合，一般这样的组合，婚姻都可以稳定。但由于官杀混杂，且夫星逢合，也会在婚姻中出现一些麻烦。日支坐阳刃为忌神，故而夫妻之间矛盾也会比较多，总有争合，自己性格也不太好，对象也是如此，往往互不相让，影响到夫妻感情。

三、丁火为财，被日干壬水合入，由于壬水坐子，则有力合财，故而可以得到这个财。但财太微弱，所以自己得到的也必然不多。而且财星外漏，也代表钱财破损，体现为浪费，不懂节约，花钱没有规划，不懂理财。

食神生财，则非常适合靠技术赚钱，如果要自己做生意，也可以做点技术性的小生意。比如餐饮，小吃，手工艺品等。如果单纯的做买卖，我不是很建议去做。

比劫太重，一般上班都不能长久，想法多，变化大，很难坚持，缺少毅力。日支坐阳刃，透食神，外表看着温和，实则内心执拗，固执的很。比劫太重，要想赚钱都会比较辛苦，很难轻松求财。并且比劫也是来夺财的，所以不宜合作，如果要做点小生意，独立去做最好，不要与人合伙。至于上班，也最好是围绕技术去做。或去做销售，都很适合自己的。

八字水比较多，聪明，而且食神透出，口才不错，表达能力很好，所以做销售也蛮适合自己。八字食神高透，本为大吉，可惜坐戌土无力，则福气减弱。

四、25-35岁走的甲戌大运，甲木透出可以去生丁火，戌土为财库，但戌为七杀，会来三刑丑土，乱了你的心。这十年主要精力可以放到家庭和孩子身上，一旦出去工作，就会有桃花。或因此而乱你的心，导致你对丈夫不满，而引发婚姻危机。这十年大运还算不错，会比之前要好得多。

原局官杀有刑，也为丈夫要多注意身体，日支为阳刃也是如此。或对象易有是非，官非等。要多注意。

在35岁后一直到55岁，这二十年都是忌神大运，运势并不算好，也必然会有很多不顺。但幸好你为女生，可以平凡一点。

1.工作上，有一份收入即可，不要要求太高，也不要过分追求。

2.婚姻方面，自己要好好珍惜，越是运势不好的阶段，越容易做出错误的选择，所以要时刻提醒自己，要谨慎自己的一言一行。

3.要多注意健康，一般坐阳刃，日时为忌神，天医星临阳刃，都会有手术，受伤，生病等。

如果命运比较弱，运势不强，只要安于求稳，踏踏实实，不要野心太大，做好自己能做的事情，不能做的事情不要去做，不要去冒风险，让自己处于平稳安定之中，则一生也可吉祥。很多多灾多难的人，都是因为野心太大，欲望太高，但能力和运气不够，而导致的。

至于子女性别方面，随缘即可。但凡是强求的，都很难有好的结果。

# 人生建议

财官印全，并不能说明八字就好，关键是要看财官印之间的配合，是否流通，是否起到好的作用，这个才是最重要的。你八字月干为财，可惜财星虚透，时干见印，但印星不喜，官星当令，可惜官杀混杂，最主要是大运不助，故而运势多阻。作为女生，能让生活变得简单一点，就尽量简单一点，有的时候复杂了并非就是好事。简简单单，才是幸福。特别是在事业上，有多大的能力，就去做多大的事情。在钱财支配上，亦是如此。有多少钱，就做多少事情。如果钱不够，就先去通过工作攒钱，等钱够了再去做事。

超前消费，是向未来的自己借钱，这种行为的确可以提前享受生活，但也存在极大的风险性。过度消费，毫无节制，且超出了自己偿还的能力，不仅不能改善生活，反而会给自己今后的生活埋下巨大的隐患。一旦无能力去偿还，就会因此招惹祸端。就好比是提前透支自己，把未来的钱借给现在的自己，现在用了，未来穷了。

人生需要规划，且要有合理的规划，不论事业，婚姻，还是钱财的支配，都需要规划。不要去听什么，要赚钱首先要学会花钱。这句话听着很有道理，但却不知让多少人因此而一摔不起。赚钱能力和理财能力同样重要，就好比一个是打江山，而另外一个则是坐江山一个道理。

你命局属于财星虚透，且财为用神，则有钱财破败之象。在35岁后走的癸酉大运，比劫夺财，必然经济上会遭遇大的挫折。这是最需要注意的地方。从35-55岁这十年，如何规划才是最好的呢？

1.工作上，学习一门技术，可以做点小生意，或开一个小店，投资小，风险低。如果去上班，也是可以的，关键是要先让自己的心安定下来。

2.要合理的去规划自己的钱财，不要轻易去做什么风险投资，更不要合作。要懂得控制自己的欲望，抵得过诱惑。

3.要珍惜自己的婚姻，运势不顺的时候，对于女命来讲是很容易体现为感情波折的，这是最需要注意的地方。

我经常说，人与人是不一样的，适合别人的生活方式未必就真的适合自己，所以也不要去羡慕别人，过好自己，才是最重要的。每个人都有属于自己的幸福，每个人也都是独一无二的，来到这个世间，每个人都是有价值的。

做好自己的工作，让自身能力得到最大程度的施展，实现自我价值，就是无憾且有意义的一生。
