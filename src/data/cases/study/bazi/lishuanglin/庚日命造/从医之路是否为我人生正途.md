# 来信

双林老师您好，我是一名在校女大学生，生于农历1999年正月22日凌晨4点57分左右。母亲素喜易学，略懂五行八卦，平日以双林老师为师，斟酌推敲老师所讲，有所收获便分析我的生辰八字，无奈资质、学识尚浅，对我命理一知半解，未能称心如意，特此请教双林老师。

母亲最是贤惠，余记幼时，母亲缠绵病榻五年之久，仍时刻心悬我和弟弟，以一己弱小之病躯，力挡风雨。女子本弱，为母则刚。犹记得，母亲心记我和弟弟饥肠未充，故强撑病体，面如金纸，起身做饭。我时尚小，不知其中艰辛！每忆及此，悲从中来。唉！不觉已泪眼模糊！春晖之情，最是深重。

我因喜好佛理，平日品读《坛经》，大有裨益，以惠能所讲，无论行、住、坐、卧，尽量力行做到。体会到修行无处不在，生活即修行。修行是修得一颗豁达之心，宽容之心，清净之心，智慧之心。自从学习禅宗后，心性也平和不少，对人生也有了更深的感悟。“相由心生，命由己造”有因才有果。了凡先生由于因缘际会遇到了云谷会禅师，对自己的命运有了全新的认识，最终实现了自身的升华。

从小父母感情不和，家庭风波不断。结缘不合，想是前世冤家。反目生怨，故来相对。二心不同，难归一意。自从我和弟弟长大成人，才有所改观。唉！前陈旧事，不提也罢。因家人体弱多病，自身体质也不佳，遂报考医学，学习岐黄之术。但医理精微，自非才高识妙，岂能探其理致哉？我资质愚钝，努力用功，才勉强考入大学。医学奥妙，中医更是博大精深。人命之重，贵于千金。我等愚笨如此，若有一人误于我手，岂不懊悔终身？不知从医之路是否为我人生正途，望双林老师指点一二。

# 命理提要

一、庚生卯月，失令气衰，春季木气正旺，又地支寅卯并见，木重金轻，则木多无用，需金来制木为用。原局日支申金助身，为坐禄之命，不过地支木气太盛，而损害禄神，故喜土来生金，金来制木为用。则八字喜土金为用，而不喜水木太多。至于火也会损金不吉。

故而八字喜见土金为用神，而水木火则均为忌神。庚金太弱，依靠申金来助，但申金和寅木相冲，而寅木得卯木月令帮扶，则木重金衰，故而禄神受损，又时干戊土透出来生庚金，然戊坐寅木之上，土受木克，年干己土也受木克，好在有丁火透出，则印有元神，官印相生，也还算吉。

二、地支见三财，财重身轻则不担财，又食伤不显，且比劫助身力量不强，故而不宜创业，适合上班为吉。

月令为正财，且来生月干丁火正官，为财官相生的组合，也为财戴官帽，且官印相生，又见印来贴身，故而能把财官之气引入自身，则能得财官之福。这样的命格，都比较适合上班，在单位会比较好。毕业后尽量考入医院上班，能拥有正式的工作，而且你一生机遇也是很不错的。

时支寅木为财，且财+驿马，故而属于动财，也代表你一生变动会比较的大。日时相冲，则在中晚年时期变动会比较大一些，早年事情则相对会比较稳定。

财+驿马+太极贵人+天医星。这样的组合都非常适合去做一名医生。八字有天医星的人，都非常适合去学习医术，或从事医学行业。天医星在命局太弱，则主身体不好，若旺则能为医生。如天医和财星在一起，则通过医术赚钱。

你八字天医星非常的旺，因为寅木得月令卯木生扶，又偏印贴身，都非常符合一个医生的特点。所以你选择医学是非常适合自己的，一定要坚持走下去，不要气馁。要相信自己一定可以学好，能救助很多的人，要有如此大愿才可以。不能怀疑自己的学习能力。

三、你还非常年轻，就能接触到佛法，且能读到《坛经》，并且体会到坛经中所讲的精华，又能一一的落实到生活中去，非常难得。这也是你累生累世所积累的善根所致，也代表你不但是有大福报的人，还是有大智慧的人，有非常深厚的善缘，这一切都会把你引导到一个好的方向，也会让你的人生越来越好。

听你所讲我非常欢喜，也为你感到高兴。所谓人身难得，佛法难闻。你年龄不大，却住着一个充满智慧的灵魂，人身和佛法你都得到了，希望能好好珍惜所得到的这一切，并不断地鞭策自己，要努力地去学习，并实修实证，来了证今生。

不过单靠禅宗修行，虽能解脱部分烦恼，但要完全解脱还是很难的。且禅宗需要上根气之人方能证得。建议走禅净双修的路线，能让你少走弯路，更快见佛道。且修禅要有师傅带领才可以，单凭自己研读，只能知字面含义而不知其根本含义。不过这一切都要看缘，缘分到了自然就能遇见。

四、年月构局为财官印组合，女孩子逢这种组合都是非常好的，代表稳定和吉祥。但八字也是有缺点的，就是禄神受冲了。禄神代表的是一个人的身体，主健康，也代表财源。地支卯木给寅木增加了力量，寅卯木都来克泄申金，则会导致自己身体不是很好，特别是在中年时期，因为日时主中年。

并且八字财星克印信息很强，年干己土为印可为母亲，时干戊土为印也可为母亲，但这两个印都被寅卯财星所克，则为财星破印之象。又戊土之长生为寅木，而寅木被申金所冲，则母亲身体不好。财印相克，也暗示了父母之间矛盾会比较的多。

但你选择从医，干着救死扶伤的工作，又能保持医德高尚，不刻意骗人害人，必然福德无量，阴德满满，自然一切命中不吉，都能随之消除。且能多闻佛法，依教奉行，时刻修正自己的心和行为，让自己处于一个善的频道之上，那么人生也必然会越走越顺的。人之命运，是先天和后天的结合，因缘果的体现，一半在天，一半在己。

要明白呀，世间之人，信佛者恒河沙数，而真正学佛者凤毛麟角。大多数人所接触的佛法也仅仅是方便之法，而究竟了意的佛法却无缘相见，或见而不识。我观你命，虽有冲而运助也，故而一生亦能多福，也能因此而救助无数之人。

从医之人，自身运数尤为重要，运吉则药到病除，运凶则良药也未必能除病。你后半生之运非常吉祥，必然能不断精进医术，救人度人。

五、月干丁为正官，八字独官透出，独官为真官。又官印相缠，且得财来生官，则官星的状态非常好。独官之人，对待感情都是比较专一的，但你命格日时相冲，又在29岁之前走己巳七杀大运，则会扰乱你的姻缘。并且在己巳大运之时，巳火七杀+驿马，故而感情多变。则婚姻迟吉早凶，不宜过早谈论感情。

八字印星贴身，但印稍弱，不过幸好你早年走印星大运，故而能保障学业顺利完成。应该好好把握这样的运势，而努力学习，不断求上，要精益求精，为将来的事业打下良好基础，才能在自己的人生中发挥更大的价值。

# 大运流年

9-19岁走的戊辰大运，为土来生金之运，土为印代表学习，早年喜印而走印运，则利学习。

19-29岁走的己巳大运，己土为印，也为学习。巳火来生己土，也为杀印相生组合。这样的组合利学习，求学吉。但巳火和申金相合，不过巳火为七杀星，故而这十年会遇到不太好的感情，而给你造成一定的伤害，故而面对感情要多多注意。在七杀大运，往往遇人都不太好。要有底线，可以谈恋爱，不要轻易同居。

29-39岁走的庚午大运，庚金透出，但为虚透之金，从大运来看较弱。所以你在39岁之前，都应该以学习为主，而不能太注重钱财，要学会看淡努力后的结果，要更加注重努力的过程。因为还没有到你辉煌的时刻。

在39岁之前，只要打下扎实的基础，过了39岁就能得贵人相助，走辛未大运时，土金帮身，能够担财，则财官都能为自己所用，财运会越来越好，工作运也会越来越吉。

从39岁一直到69岁这三十年都是非常不错的运气。在这三十年当中，只要努力去做，不忘初心，就一定能得到你想要的一切。名誉，职位，钱财都能获得。但一切都不能太着急，在39岁之前必然会有诸多不顺，也会很辛苦。

因为你是身弱财旺的命格，所以担财会比较的累。但只要你学会看淡利益，看淡结果，自然也就不会觉得辛苦了。多吃点亏，对你也是非常有好处的。过了39岁，该你的一切都会慢慢一一得到。

故而你的运是非常好的，前二十年和后三十年都是很不错的，中间十年稍微弱点，但也正因为弱点，才有更多的时间和精力去学习。

有时候我们只有在困境之中，才能悟到一些道理，而这些道理，是在顺境之中永远都无法明白的。逆境，顺境对于成功的人生来讲，都是需要的。

# 人生建议

一定要相信自己，自信是成功的基石。要努力的去学习，不要荒废任何一天，人生短暂，世事无常，莫等明天。为了将来能让更多的人解除病苦，就要更加认真的去学习，要发大愿，学医是为了天下所有病苦之人。

要认真的研读佛理，不断的培养自己的慈悲心，增智慧，消烦恼。用慈悲心去对待以后的每一个病人，把病人当做自己的爸爸妈妈，真心实意的去帮助他们。

医生是福德广大的职业，要有大福报的人才能去从事。我在幼年时期，曾有过做医生的愿望，但因种种因缘而未能如愿。不过病有两种，一者心病，一者身体病。心病有时候比身体病更加痛苦，我虽不能医身体，但能医心，也算实现梦想吧。

你能听闻佛法，且落实佛法，又选择如此福德广大的职业，我是非常高兴的。但能积大福报的行业，往往也容易造大罪恶，所以更要通过修行，不断的增长自己的慈悲心，增长智慧，才能让自己不走偏路，才能保持福德不退转。你命中财星太盛，又弱而不担财，财来耗身。将来必然会有无数的金钱诱惑，若不能保持初心，就容易被利益驱使而做违背道德之事，一次可能会觉得愧疚自责，但次数多了就会习以为常不觉有错。

故而不忘初心非常重要，要时刻守护自己的心，明白自己学医的初衷是什么，要时刻把病人当做亲人，用最真诚的心去对待每一位病人。通过修行让自己的心保持善良不变，才能远离诱惑，避免因为金钱而招惹是非。

除了品读《坛经》之外，建议你再好好研读《金刚经》，更能让你看明白，看真实，不被假象所欺骗，不会迷失自我。希望你能不迷正路修行，直取菩提上果，遍度法界众生，阿弥陀佛。
