# 人生建议

生气会让自己痛苦，也会让身边的人因为自己痛苦而痛苦。生气就是用别人的错来惩罚自己。或因为一些无关紧要的人事物而伤害自己。

**那么为什么总是喜欢生气？**

因为自己所在乎的人事物，原本是这样的，最后却变了一个样子，而改变后的是自己不满意的，也不愿意接受的，故而生气。归根结底，我们还是不能接受变化，也就是不明白无常的道理。这一切也都是因为自己心量太小了，容不下他人的错，也忍受不了别人的行为与自己的思维不匹配，故而生气。

生气的关键还是因为太看重这个我了，什么都是以我为中心来思考问题，那么就会发现身边的很多人事物都并不合自己的心意，故而因此而不满，抱怨，生了一肚子的气。

**那么如何才能降服爱生气的习性呢？**

1.要学会感恩。要感恩身边所有的人，帮助你的或来伤害你的人，我们都要心怀感恩。因为伤害我们的人，是来帮助我们成长的。玉不雕琢不能成器，太舒适的环境是不能成长的。但凡是有大成就的人，都是经历过大困难的人。

感恩父母，感恩妻子丈夫，感恩孩子，感恩同事，感恩朋友等等。只要能心中常怀感恩，你的心量就会慢慢变大，就不会因为某些事情而生起怨恨之心。

2.要学会理解。要把你所见的一切人事物都当做是自己的化现，他们就是自己，自己也就是他们，之间没有任何区别。要学会理解别人，换位思考问题。很多矛盾都是因为不理解而生，很多气也是因为无法理解而来。所以学会理解，就能消除很多不该有的嗔恨心。

3.要多回向。平时要多看经典，通过闻思修来完善自己。做得功德也都要多回向给身边的人，你越是讨厌谁，你就重点回向给他们。慢慢的，你的肚量就会越来越大，小我也会慢慢消除。到时候遇到问题，就不会仅仅站在我的角度思考了，也就不会有那么多气要受了。

学佛不仅仅是皈依，上庙，烧香，拜佛等。不能让学佛停留在表面的形式上，一定要从闻思修行一门深入。如果仅仅是搞形式，就会失去学佛的意义，也就不是真正的学佛了。

不管自己修什么法门，最终目的都是为了开智慧，除烦恼。而如何才能开智慧了，要从持戒开始，然后修定，当有了定力后，智慧也就自然而然的产生了。一定要明白无常的道理，就不会因为轻微的改变而生气。

要时刻提醒自己，火烧功德林，平时修的功德不管有多好，一场怒火也会让其化为乌有。如果自己实在因为某事生气痛苦，这个时候可以出去走走，或诵读《心经》，《金刚经》，也可以念阿弥陀佛。都能慢慢让自己的心境调整过来，从而放下生气。
