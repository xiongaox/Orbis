# 命理提要

一、日干戊为自己，在巳月得令，且为建禄，月干透出丁火来生戊土，且年月日均为火土两旺，则日干土必然不弱。夏季为燥热之土，故而急需壬癸水来调候为用，但原局缺水，只有地支辰土暗藏癸水，但藏而不透，故而调候无力。且旺土也无甲木来制，仅得时柱辛酉伤官泄身。

辛酉金为伤官，可以泄土，但原局土重则易金埋。有木方能疏土救金。原局伤官泄身，可惜没有水，则层次一般，格局不强。

八字为偏印格，不过偏印为忌最喜见财星耗身制火，由于命局有伤官一透一藏，故而水显也不怕被克。

> 用神：水，金，木。但月令为火重，则木弱则生火，强则制土，有利有弊。水木并见最好，因为湿木不能生火，更能制土。
>
> 忌神：火，土。见火损伤官，见土埋伤官。均非善运。

二、原局土比较重，为人稳重，做事踏实。伤官透出也非常聪明，伤官毕竟为用，故而伤官则体现多为积极向上的一面，非常机灵，头脑灵活，口才也是很不错的。因为伤官为金，而辛酉都是兑卦，也有说的意思，故而口才不错。如果要去做点口才事业也是可以的，比如咨询，或培训方面的工作。

命局年日均为华盖星+又临天医星+且有太极贵人。故而从事和传统文化有关的事业是可以的，而且你也有这方面的兴趣爱好，缘分不错。当然传统行业并非仅仅只有易学。如果你要走这条路也是可以的。

八字有坐华盖，则有这方面的天分，且有伤官，能说会道。表达能力也是非常重要的，学习易学，不但要很强的理解能力，还需要很好的表达能力，两者都缺一不可。且要为人稳重，做事踏实，诚信。日干为戊土，最大的特点就是沉稳，土代表诚信。故而是可以走这条路的。

之前的道人这样说你，也并非毫无道理的。不过从事易学行业，并非一定是算命呀。易学之下还有很多分类，比如风水，命理，卦理，相学等都是易学。一般选择一两个为主去做即可，不用都花费心血的去学，其他的了解即可。

由于八字没有财星，只有伤官透出，适合靠技术吃饭，不适合做投资，做生意。就算要做生意，也要做无本的买卖。所谓无本，并非完全没有本钱，而是投资比较小的。如果是走技术路线，则投资都比较小，且风险也很低。如果是做易学行业，则投资主要是在学习上的花费，买书，拜师等，至于从业投资都是不大的。

三、你婚姻运都还是挺好，辰中暗藏正财。所谓日坐正财早成家。故而婚姻来的不迟。其次辰酉相合，而酉金为辰的伤官，伤官是辰所生，则为孩子的意思。故而日时合，为家庭还算融洽。

不过在壬戌大运的时候，和年柱、日柱天克地冲，且财星透出受克，故而会有一些问题。不过这个年龄段，更多体现为健康方面，或妻子多病等。

# 大运流年

8岁到28岁都是走的戊午，己未大运。这二十年都非好运，不太顺利。早年运不强，也体现为出身普通，且早年学习一般。好在你八字财星不显，则土透也没有伤用，故而虽然不算好运，但也不凶。

28-38岁走的庚申大运，从2015年开始进入这步大运，也就是目前的大运。庚金为食神透出，地支申金和辰拱财，不过是正财。大运食伤泄身，可以展示自己的才华和能力。但财并不大。如果女命如此就好，男命八字还是要有财官为吉。不过这十年也还算平稳，还是不错的，比你之前运势要好很多。

2020庚子年，则申子辰三合水局，会有喜事，好事，或贵人帮助，好的机遇出现。自己好好把握。

至于在2018戊戌年，都是不太顺利的，酉戌穿，且年日冲戌，变动很大。自己平安，则体现到亲人身上。

月柱为忌神，则兄弟姐妹缘分不是很好。姐姐的离开，也是个人的因果，父母的债吧。

38-48岁走的辛酉大运，这十年更好一些。毕竟原局有辛酉，则伏吟时柱，力量更强，故而财运更好。所以你接着这二十年大运都还是可以，虽然不是最好的运，但也还算很不错。有什么理想都可以努力完成，实现的几率还是很大的。

如果你想要走易学这条路，那就好好学习，要多看书，等有了扎实的基础，一定要去请教明师，因为师傅会告诉你很多书上没有的东西。再实践一两年，就可以出师了。我看你有这方面的天分，且运势走食伤，要走技术路线才会有好的发展。而且头脑灵活，非常聪明，口才也挺好，是这块料，好好努力就行。学习过程是非常枯燥的，但只要有兴趣，也是快乐的。

48-58岁走的壬戌大运，这十年不太好，刑克妻子，也易破财生是非。因为大运壬水虚透，比劫夺财比较严重。这十年要多散财，方能免去灾祸。赚到的钱财，留一部分，然后另外一部分多做布施，灾难自然消除。

58岁后走的癸亥，甲子都是非常好的大运。正好年龄也大了，如果做易学，凭借年龄的优势也是最吃香的阶段。所以你晚年是很不错的。而且你八字原局，晚限为辛酉，也为用神，时柱为用也为晚年大吉。故而你晚年非常好，晚年的财比你年轻时候的财都还要大。综合来看，你大有从事易学行业的苗头。因为这个行业的特点是年龄越大，越红火。
