# 人生建议

一个人是否成熟可靠，和年龄有一定的关系，但年龄并非绝对的因素。因为一个人是否成熟，从小就可以看出来，根本不需要等到30岁，40岁才能体现。

成熟的男人，从一开始就非常成熟。而可靠的男人也是如此。如果这个男人不可靠，就算活到50岁，依然是不可靠的。本性如此，并不会随着年龄的增长而有太大的变化。而年龄改变的，仅仅是因为自己年龄大了，无法再花心罢了。就比如现在有很多老人，倚老卖老，利用社会尊老爱幼的观念，横行霸道。并非因为老人变坏了，而是因为坏人变老了。

所以年龄大的，不一定就成熟可靠。而年龄小的，未必就不可靠。关键还是要看这个人。年龄比自己略小几岁，是可以接受的。但差距太大，我也不建议的。一定要改变自己的思维，才能有新的转机。

条件好的男人或人品比较好的，自然不缺对象，很早就被挑走了。而留下的男人，有个别是为了事业而耽搁了婚姻，而大多数都是被挑剩下的，要么身体不好，家庭贫穷，事业太差，品性不良等。

并且女人随着年龄增长容貌也会逐渐变差，再也没有年轻时那样的青春貌美，甚至生育能力也会受到影响，因此也加速贬值。再加上因为年龄大，而见多识广，要求也越来越高。

这是非常难以平衡的，自己要求越来越高，而自身条件越来越差，陷入一个恶性循环之中。这个时候发现，越想找到理想满意的，越难找到。并非身边没有，而且出现了也看不上，就这样耗下去，发现年龄越来越大了，机会也越来越少。心有不甘，但又无法如愿。
