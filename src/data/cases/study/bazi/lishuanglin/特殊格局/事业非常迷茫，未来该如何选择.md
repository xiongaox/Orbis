# 来信

机缘巧合下拿着失业补偿金和几个朋友合伙做家居行业，那时真是一腔热血但是由于我们都属于社会经验不多，几年下来经营情况并不是很好，眼看投资也就打水漂，股东内部还有很多理不清的事，而对于40岁的我来说，一切又要重新开始，而我以前的同事很多也在面临裁员。

但是我自己知道，我内心还是不够自信的，甚至自卑，特别是遇见事情的时候，遇见比我更强势的人的时候，我会害怕，会逃避，公司拖欠工资，我也不敢开口，但是内心其实是非常的不舒服了，有时候不知道怎么才能变得更自信一点，更有能量一点。

# 人生建议

因为诸行无常，世间的一切都不是恒定的，而是变化的。那么输赢也自然就是常事了。有时候赚了未必就是好事，而亏了也未必就是坏事。一定要正确的看待人生的输赢成败，不要因为某一次的失败而对未来失去了信心。

要知道，不论多么优秀的人都会有失败的时候，投资也总有亏损。我只是希望你能看淡这些，就算亏了也要学会坦然面对。只有这样，你才可以拿得起也放得下，也才能继续更好的未来。

1、至于目前的事业，如果实在难以坚持就想办法退出来，或直接不做了。当然具体还是要结合你们的实际情况来决定如何去做。退出后就休息一年，正好明年也是冲克很大的年份，所以不做事也是最好的选择。在这年期间，你可以多去了解和学习新的行业，选择新的发展方向，再重新开始自己的事业之路。

你的命格并不差，财官相随，只不过运势不太好。那么在选择上面，一定要注意几点。

第一要选择轻投入的行业。

第一切莫合作。

第三不要做的太大，要降低风险。

第四尽量围绕服务行业来选择。

第五可以开店经营。你八字时支有印，时支临印都可以开店。

如果自己累了，也可以多休息几年在做事情。凡事都不能太着急，要打有准备的仗才可以。

2、至于自卑，遇到事情容易担心、害怕、矛盾、纠结、拖延、退缩或逃避。这一切都源于你内心的不自信。也是因为你自己在社会的经验不充足，缺乏历练所致。所以就算老板欠你工资，也不敢直接去要。这和你八字也有关系，毕竟日干太弱，往往都会缺乏魄力，做事不够胆量。

要改变这一切，就要学会尊重自己。并且要重新认识、理解和接纳自己。要通过学习来提升自己的知识和智慧，要知道，恐惧都来源于无明。我们都是因为不懂而害怕，因为害怕的太多而自卑。而知识是可以让我们自信起来的。知识可以战胜我们内心的恐惧。

通过学习来改变自己，是最好的方法，也是唯一的方法。其次就是要多结交一些正能量的朋友，你会因为他们而慢慢改变自己的。只要你能做到，坚持学习，多交正能量的朋友，你就一定能改变的。
