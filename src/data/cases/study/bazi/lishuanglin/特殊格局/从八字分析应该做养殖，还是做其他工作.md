# 来信

这次给您写信，确实也是现实的社会让我感受到了太多无奈，去年年底部队转业回来有安排工作，由于家里条件不好，而且家乡经济水平不高，工资也不高，没有好关系分到好的工作，最终选择退伍拿钱买了房。

今年10月底出来找工作，因为之前在部队一直都是炊事员，所以找的一个餐饮公司承包的几个学校食堂继续做厨师工作，踏入社会才感觉真是复杂啊，上了不到两个月班把我调了他们公司3个学校食堂，而且越调上班时间越长，经常义务加班而且没有加班费，现在一天要上12小时班，工资就四千一月，在一个地方人、工作都还没熟悉就又调个地方，感觉都是套路，所以现在打算辞职。

去年老婆家爸妈想办一个养殖场，钱不够问我意见，因为现在养殖业还可以，所以我投资了一笔钱建了个养殖场，上半年在家帮忙弄了半年，但是收益慢，加上都在家没有收入，装修房子欠了10来万，所以出来上班的。现在两个小孩，老婆在家带小孩就我一个人挣钱，压力特别大。现在真不知道做什么好，我是在家搞养殖，还是在外面上班做厨师或者改行做别的，还请老师给点建议，万分感谢！

之前找家里算命的看过我八字，以后会吃国家饭，确实在部队这些年是这样，还说我以前运气走的不好，今年开始运气到50多岁财运很好，但是现在没有一份稳定的收入，请李老师为我指点迷津，谢谢！男1988年农历5月29日上午9点30左右。

# 八字详批

# 命理提要

一、这是一个比较特殊的命造，在分析的时候非常容易出现错误。全局六个土，两个火，而金水木都是不显示的，属于五行两旺之命，这种八字组合是非常极端的。

日干为土，未月得令且透劫财帮身，年月日都是土来帮身，时辰为火也是来帮身的，所以八字属于从强格。旺不受克，也不喜泄耗。用神取火土为吉，因为火土已经非常旺，物极必反只有顺势而行方吉，反之则不吉。故而只有在走火土大运的时候运气才会有好转。

八字原局当中，食伤不显，财星是暗藏的，从强格则当身弱看，财星暗藏也算有财。不过这种五行极旺之命，往往人生不会太顺利，会有很多波折坎坷的事情发生。

二、比劫太旺的八字，是比较适合当兵的，所以如果能留在部队是最好的。而且比劫旺的命，多数也会从事一些体力方面的工作。因为比劫就代表身体劳动。故而自己的工作类型，必定是辛苦的，不会太轻松。八字有印贴身，印为用神也可以代表财星，印代表单位，所以若是能留在单位则非常好，反之则不太吉祥。

之前部队分配职业，你就应该接受，不管好坏都有发展，自己出来后找工作肯定是处处碰壁，而且很长时间没有在社会当中闯荡过，所以更容易受亏。不过适应了，就会好很多。

时柱临印星，时辰代表的是门户，而印代表门面，房子。所以你是可以开一个店的，做点餐饮方面的工作，小吃，早餐，或者是快餐之类的。更好的利用你的特长来做这个事业。至于你从事养殖行业，并不是很利，因为做养殖风险比较的大，而且你运气走的并不是很好，最主要的是你八字极旺，比较极端，所以不适合去做一些变化性太强的工作。养殖行业是非常富有变化性的职业。而如果你去开一个小店，夫妻一起来经营，相对比较稳定。只要地段选择的好，并且符合当地人口味，价格合理，干净卫生那么就一定会有发展，虽然未必能赚大钱，但肯定生活会滋润很多，比你现在会好得多。

# 大运流年

29-39岁走的壬戌大运，和八字原局年柱，日柱发生天克地冲，逢冲则动，所以你进入这个大运工作就发生变动。

壬水为财属于忌神，戌可以帮身为用，但是冲了辰，用神冲用神并非好事情。而且大运戌临空亡，走的是空亡大运，则多做少成之运。并不顺利。并且走比肩克财的大运，都会比较的辛苦，主劳累的运气。

壬水也为父亲，大运比劫克偏财星，且八字原局没有偏财则怕出现，所以这十年父亲容易有灾难，生病，不好的事情发生，要多注意才可以。让父亲尽量不要去做危险的工作。

2019己亥年，亥水为偏财也为父亲，亥水出现则容易受伤。并且八字有辰墓，有入墓之象。且巳亥有冲。所以明年要注意父亲的健康方面。以及也很容易出现破财的事情。所以投资上面是要非常谨慎才可以。留点钱做一些更有价值的事情最好。

你在后面几年的运气都是很一般的，所以工作上面必定不是很顺利，一方面要坚持，另外一方面也要求稳。并且对行业不能太挑剔了，权当锻炼自己，也要多学习，为以后独立做事打下基础。

你八字有印，印在八字当中为母亲。巳火在壬戌大运入墓，而且2019年巳亥冲。所以明年你自己，父母都容易不吉，如果长辈不好自己就没有什么事情。不过一般年轻人的冲克，都会应在长辈身上，所以要更多注意父母健康。

你后面走的大运都是水木大运，从五行来看不是很有利，并非好的运气。故而一生运气都非常平常。

如果还有选择机会，你若能留在部队，或听从部队安排而有一份稳定工作，那么你的以后就会顺利很多。但是你选择了补贴金而放弃了工作，这种选择是非常不明智的。工作好坏，要去做了才知道，没去你永远不知道这个岗位有多少福利，所以你选择补贴金更主要的还是因为钱多一些，当然也觉得出来找工作并不是一件困难的事情吧，不过金钱的确可以快速解决一些当下的问题，比如房子的问题。

# 奇门遁甲分析

干支：戊**戌年甲子月癸酉日癸亥时**

阴遁七局；旬首：甲寅（癸）

1、戊为自己，戊在兑宫临死地不旺，不得地利，目前的环境并不太适合自己。临惊门代表担心，九天为志向高远，但是由于戊并不旺，则代表好高鹫远。想的是很远，很多，也有很多规划，但是却无法去落实。戊+戊为伏吟局，也代表道路闭塞不通，以守为吉，进为凶。简单说就是暂时不宜做任何投资，应该以上班为主，先上班，学习一些社会的经验，然后再去做事情。

大局是伏吟的，伏吟也代表刚刚开始，进展很慢。所以在工作当中，必然不能很快速的实现自己的目的，过程是非常持久且缓慢的。并且伏吟局也代表能力得不到发挥，宜被动求财为吉。所以也更加适合先上班比较好。

日干也为自己，日干在坤宫临死墓之地，也不得地利，而且天芮星不吉，天时不利，大局伏吟也为天时不利，临死门也暗示你做事情比较死板，固执，不懂变通，且人际关系不足，所以人和也不得。故而失天时，地利，人和则不宜轻举妄动。至于你去做养殖，我是非常不建议的。

开门代表你的工作状态，开门在乾宫伏吟代表稳定，临九地也代表稳定，而且开门和年命宫比合，且是挨着的，并且日干时干都来生开门，也代表主动获得的工作。所以你最终能有一份稳定的事业。但是不能立马实现，需要一个过程。

结论：应该先上班比较的好，结合八字来看等有了一定经验和人脉然后就可以开一个店，做点餐饮之类的小生意，也是非常不错的。你先要定一个目标，然后就要朝这个方向努力，并且要多去考察当地人的饮食习惯和口味，自己也要多模仿做的比较优秀的人，更要在模仿中创新。

# 人生建议

你不太适合做养殖，至于父母是否可以不好讲，总之你是不可以的，既然都建好了，就让父母做吧，你就要离开这个行业。在29-39岁走的壬戌大运和八字原局日支相冲，冲的也是配偶宫，而且你八字财星不显，大运比劫夺财，也是要多注意夫妻关系。很容易因为金钱，你工作的问题而吵闹，所以要更加努力才可以，否则家庭不太和睦。

你在以后开一个小店做点餐饮，烧烤，早餐之类的都非常好，现在外卖行业发展，只要你肯去做，味美价廉，并且菜肉新鲜，你就一定可以做起来。我们当地有一个老奶奶做冒菜，在一个并不当旺的街道租了一个门面，每天就靠外卖一年也有非常不错的收入。所以只要肯干，愿意去做，就会有很大的机会。做餐饮，入驻到各大外卖平台，然后只要味道和卫生把控好，你就能做起来。

但是在做之前最好去找一份对应的工作，先学习经验，学习运营模式，向当地生意最好的一家学习。等自己觉得可以去做，并且能非常熟悉这个行业过后，你就可以去做了。夫妻一起来做，每天虽然忙碌又辛苦，但是会觉得非常幸福，这样对你们的婚姻也是很有帮助的。
