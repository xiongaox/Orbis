# 人生建议

一、命运一半在天，一半在己。

影响命运的根本因素，是心，是思维，是念头。要改变命运，只需要去改变自己过去的固有思维，就可以改变未来的一切。因为选择决定未来，而思维决定着选择。我们所遇到的一切人事物，都是由自己的心识所感召而来的。心识为善，则一切皆善；反之心识为恶，则遇见一切也终将为恶。

先天命运虽然多凶，但并非自己这一生也都会非常凶，八字定性但并不定量，故而吉的程度以及凶的程度，都是自己左右的。就比如虽然有凶，但也分为大凶，中凶与小凶。若为小凶，固然有不吉，但也不会有太大影响，甚至可以被忽略。就比如婚姻不善，可体现为吵闹，分居，离婚等很多情况。但至于具体表现为什么，则要看自己的选择了。

念头决定着我们处理婚姻关系的方式方法，从而决定着婚姻的最终走向以及结果。

二、从你八字来看，婚姻运的确非常坎坷，要想获得非常圆满幸福的婚姻很不容易，但并非就不能有幸福的婚姻。只要你能明白一点，那就是幸福在于心而非事。

若要追求外在事情上的幸福圆满，则天下将无幸福可言。但若能幸福在心，由内而外的散发着幸福感，则即便事情上有所不足，也内心具足快乐。

越是命运坎坷，越要懂得修心，修行。也唯有如此，才能去改变，也才可以逢凶化吉，以及遇难成祥。要知道，吉凶是相对的，而好坏也是如此。人生一世，任何拥有都预示着会有失去，而任何失去也预示着会有拥有。

失去=得到，得到=失去。这也就是舍得的智慧。所以不管自己人生失去了什么，或什么有所缺失，都不要过于执着，或为此而痛苦，而要想到，你在失去的同时，也一定会有得到，要多珍惜当下得到的，拥有的，而放下自己失去的，以及无法得到的。得到爱情，就好好珍惜，如果失去了就学会放手，这样的人生，才能更加洒脱，自在。

三、《心经》讲：“照见五蕴皆空，度一切苦厄”。

要如何做才可以度脱痛苦与灾难呢？

只要明白世间一切人事物均为无常，且五蕴皆空的道理，就能破除一切烦恼与灾难。

何为五蕴？

色蕴、受蕴、想蕴、行蕴、识蕴。

色蕴：一切物质，可见之物。

受蕴：一切感受，包括好的感受，坏的感受以及没有好坏的感受。

想蕴：自己的一切想法，念头。因为感受而生起的思维。

行蕴：因为念头而引发的一切行为。

识蕴：是指六识以及末那识，阿赖耶识。

时常观想，这五蕴都是无常的，都是会变化的，从生起就注定了会消失，而非恒常，则能因此解脱烦恼痛苦。

我们之所以会痛苦，都来源于妄想和执着。而妄想执着，就是错误的以为一些事情，可以为我所得，或能永远为我所得，因而生无量烦恼。一定要好好修心，才能减少人生的不悦，让自己活得自在一些。也要多放生，多做功德，广结善缘，才可以改变今生的命运。

1、在工作上，一定要求稳，不建议去做什么生意，即便要做也时机未到。要让自己的人生变得更加稳定，才是最佳选择。

2、至于感情方面，要降低要求，懂得珍惜，也要努力的去改善自己的性格缺点，要更加懂得圆融之道，也要多为另一方考虑，才能使家庭更加和谐。

3、不要过度追求财富，以及物质方面的欲望。因为求而不得为苦，过于强求则为灾。一切灾难，都来源于过度的追求。一切放下，则万般自在。
