# 来信

我在学校工作，27岁这年结婚，家庭经济都很稳定，丈夫在的时候也算相濡以沫。2019年2月1日本是平静的一天，结果丈夫外出吃饭突发心梗就离世了，还没来得及从巨大的悲痛中反应过来，更让人措手不及的是各路债主讨上门来，我根本不知道丈夫在外面做了些什么，我们俩本来都有稳定工作，经济根本没有问题，我到现在也不知道他干了什么。只觉得悲痛之余有深深的背叛感。

李老师，我和丈夫结婚的时候，我就说服了自己好久，总觉得不够爱这个人。但是丈夫人踏实对我好，我也就接受了，婚后我专心在家相夫教子，他走了以后儿子正好上一年级，学习也不是很好，一直也没有告诉孩子他爸爸离世了，实在不忍心告诉孩子这么残酷的现实。出了这件事情以后我在想我从来没有做过缺德的事情，怎么会有这样的果报。

我的生辰八字是1985年5月27日早八点半，丈夫的八字是1983年十月初九晚7点多，顺便说一句，丈夫一直就在生病，不是这儿得病就是那儿得病。以上八字均为阴历。

# 命理提要

一、日干甲在未月失令，地支土多木衰，癸水虚透生甲木无力，则日干偏弱，为**身弱财旺之格。**

>
> 忌神：火，土，金则均为忌神。但天干不怕金，而地支最怕见申金，会破禄损身。

二、命局夫星不显，则和丈夫缘分薄，也代表婚姻迟，夫妻感情比较淡。年支丑中暗藏辛金正官，则夫星在年，但临空亡，也体现为夫不吉。而且夫星在墓库之中，一般会体现为丈夫个子不高或身体多病。

**丑未相冲，则未土中的丁火克了丑中的辛金，构成伤官见官，故而不利丈夫。也体现为丈夫不吉，对象有凶。**

日支临孤辰，也有孤独的意思，而且八字丑未辰都有，为墓库旺，也有孤独的意思。寅辰相见，也为龙虎相斗之命，会引发是非，甚至官非，也为不合，口舌之事较多。

**分析：** 乙木在亥月得令，年月都是水旺，则乙木也就跟着旺了。八字水多则木漂，乙木又不见根，则有不稳之象。乙木的状态是不太好的。

八字冬季出生为寒命，又水太旺，则喜土来制水，也喜火调候。则八字火土为用。日支为火，时支为土，则用神在日时。

八字寿元星为巳火，故而巳火一旦受伤，则会损寿。原局有两个亥水冲巳火，又巳火见戌入墓，则巳火的状态非常不好，也代表寿元星受伤非常严重，而且原局没有解救。故而凶多吉少。八字暗藏凶险。

现在走的是己未大运，未戌三刑，戌为乙木和丙火、巳火的墓，大运未土也是乙木的墓，所以现在走的是墓库大运。乙木见未则入墓，乙木无根则会入墓。

2019己亥年，己土引动未土，未戌三刑则开了墓库。且亥水和原局构成三个亥水都去冲日支巳火，则三亥冲一巳。并且没有解救。虽然大运有亥未半合，但却见未戌三刑，而刑来破合，则无救也。

妻子八字不利丈夫（自己感召而来的妻子）+自身命局太凶+家运不善+自身福德太浅。则出现死亡的灾难。

故而一定要平时多积德，为自己积累福报的资粮，到了灾难降临的时候，才有更多的能力去化解，也才会有贵人出现，来帮助自己。

三、癸水为印，癸水是从辰中透出来的，则癸带辰气，故而财印都能入身。也代表你自身有财运，可以得到这个财。年月为正财，时柱为偏财，先正后偏，则一开始会上班，在后面你会有投资，或做点生意的机会。你八字时支为印+偏财，则可以开店求财。

至于你工作运还是可以，毕竟有印禄贴身，也代表有财。不过你八字贵人太多了，反而不贵，走仕途没有发展。

# 大运流年

28-38岁走的丙戌大运，丙为食神，也是从日支寅木中透出的，丙也会引动寅木。但地支戌并没有帮助到寅木，戌反而和原局三个土，构成了辰戌丑未，为四大墓库全，这样的格局主孤独。所以在这十年当中，情感上面都会比较孤独。

从2018年开始正式进入戌运，则戌土起到了最大的作用。戌也为华盖，也为孤独。而且丑戌未三刑，加重了辛金受损，因为戌中也暗藏丁火，都来伤害辛金。这十年火土旺了财，则更为身弱不担财，则财多反而惹祸。并且由于自己不担财，则求财辛苦，而且因为钱财而压力很大。

2019己亥年，在今年己土透出，己土引动丑未土，则引动丑未冲，今年非常不利。下半年走亥水运，则寅亥相合，相对好一些。

2020庚子年，会比较平稳。庚金生了癸水，而且子水也引动癸水，都为印来生日干。则如果有考试，或提升文化，学习方面的，会更进一步。

2021辛丑年，引动太岁，而年月有冲，要注意长辈。辛金出现不凶，因为你八字日干有癸水保护。

在38-48岁走的丁亥大运，丁为伤官，也引动未土，一样有丑未冲，要多注意脾胃方面。你八字土太多了，很容易有胃病。而且水被克，则为妇科，肾脏，泌尿系统方面的问题。亥水合寅木，则旺了禄神，让日干更旺，更能去担财。所以相对财运会更好一些，各方面运气也会更好。

在38岁后，你可以变动一下工作，各方面也都会有一些转机。如果要再婚，最好是在38岁后。

# 人生建议

1.所谓生死无常，谁都不能保证自己就一定能见到明天的太阳。最近明星高以翔意外猝死，更让我感觉到无常的存在。每天都有很多像他这样的人离开人世，我们没有关注到，但并不代表没有发生。只有明白了无常，知道了生命的可贵，我们才会去珍惜生命，珍惜时间，才会去做一些更有意义的事情，而不会白白的浪费生命。生命是非常脆弱的，我们能活着就已经是奇迹了。

一定要记住我说的话，一定要多积功德，为自己培植福报资粮，只有这样才能化解命中的无妄之灾，才能真正做到趋吉避凶，才能得到平安吉祥。

民间一切化解灾难的办法都是助缘，其根本还是要依靠自身的福报来化解。如果自己没有福德，就算大罗金仙也毫无办法，因为神通敌不过因果。命运掌握在我们自己手里，一切都需要自己去努力改变。他人也仅仅是起到助缘的作用罢了。当自己福报深厚时，就相当于身强体壮，就算天气突变，也不会因此而受到伤害。

2.影响我们命运的有四大因素，分别是天时，地利，人和，神助。其中神助是非常重要的，也是很容易被我们忽略的。在奇门遁甲体系中，有天盘，地盘，人盘，星盘，还有神盘。而神盘往往会起到决定吉凶的作用。

神并非是指我们日常所理解的神灵，而是指宇宙间一切暗藏的能量，也可以理解为暗物质，暗能量。这些能量在无形之中影响着我们的命运，影响着我们的人生。

那么如何才能得到神助，才能得到这些无形能量的帮助呢？

那就是积德行善了。易经有云：“积善之家必有余庆，积不善之家必有余殃。”行善积德，自然能得到福报，当灾难加身的时候，也能轻松化解。

八字定性不定量，八字能看出不吉，但不吉的程度以及所体现的具体事情，则会因为自身福报，性格，家庭，工作等不同而表现出来。

从佛家来讲，种善因得善果，种恶因得恶果。而因果通三世。短寿报，一般是因为杀业太重所致。自己的杀业，以及祖上杀业，都会导致后代多病短寿等果报。

凡事必有因，任何事情的出现，一定会有因。这也就是因果。因果即是上帝，因果主宰着我们的L切，而我们又主宰者因，所以命运的主宰还是我们自己，但真正明白这个道理的人太少了，大多数的人都迷，迷而不知啊。

3.至于你现在啊，可以多诵读《地藏经》回向给去世的丈夫。所谓缘来则聚，缘灭则散。你和丈夫的缘分尽了，也自然会分开。多诵经回向给他，也回向给自己累生累世的冤亲债主，父母亲人等。要努力的修持自心，多做布施，广结善缘。你的后半生就一定会越来越好的。

因决定着果，而我们的身口意决定着因。而因果决定着命运，它就是我们命运的主宰。要想改变命运，就要改变因，只要因改变了，结果也自然改变。这就是从因地修行，自然能得善果，能得福报。就算遭遇什么灾难，也可以逢凶化吉，或遇贵人指点帮助，或能接触善法，并能对善法生起信心。
