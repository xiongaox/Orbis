# 来信

尊敬的李老师，您的每一篇文章我都认真拜读过，包括您在大年三十的夜里写给读者的那一篇，从您的文章里，我看到的都是渡人于苦痛的慈悲，是大无私的易学精髓的传播。您说，知天命，尽人事，也就是当我们知道命运大体轨迹了，就要努力去做好当下的每一件事，不管结果，都不执着，不过多贪婪，也不过多妄想。这段话，可谓是字字珠矶，若能悟透之，以此为处事之要领，人生会少多少烦恼，世间会少多少不幸的人！

我想请您帮我女儿分析下她的八字，她是2001年农历五月二十日晚上八点十分出生，上高三。我想通过您的分析，让她知道自己命运的大体轨迹，不做无谓的挣扎，不怀有不甘心的愤懑，做一个知天命尽人事的通达之人。

自上高中以来，她始终在跟自己较劲，然而结果总是跟预期相差很远，她想要的是名列前茅，事实是不过居中而已。她心气高，气自己没用，怨自己蠢笨，把自己折磨成了神经衰弱，焦虑不堪！我苦于无法劝解开导她，无意在网上看到您的文章，推荐给她看，她一看成瘾，找到了精神寄托。

我觉得她很有佛缘，她对于物质需求低到可以忽略不计，对于精神上的要求却近乎苛刻。女孩子爱的东西她都不爱，逛街，化妆，追星，早恋等等，这些在她一样也不喜欢，看书买书藏书是她乐此不疲的事。她说以后不会谈恋爱，不会结婚，还说要皈依佛门，云游四方云云。

# 八字详批

#### 坤造：辛未年，乙未月，甲戌日，甲戌时（空申酉）

#### 大运：丙申，丁酉，戊戌，己亥，庚子，辛丑，壬寅，癸卯

# 命理提要

一、日干为甲木，在未月出生失令，有人说未是木库故而会帮甲木，这个说法是不正确的，因为只有未土挨着寅卯木的时候才有可能变成木，而地支火土最旺，故而未依然是土。地支未土和戌土都是燥热之土，对甲木没有任何帮扶，反而是在不断的消耗甲木之气。故而甲木在地支没有根气，属于虚透之木。天干则甲木得到甲乙木帮扶，但是甲乙木都属于比较弱的，都是虚透之木，所以甲木是非常弱的。八字属于身弱财旺的命。命局财星最旺，故而喜比劫制财，所以最喜见木为用神，其次为水。但是地支不喜见水，因为地支没有水木所以就算见水也无法生甲木，反而会被原局火土给克，所以只能天干见水，而地支更喜见木。八字忌神为火土，也不喜见金。如果金水同时出现，且水透天干，也是可以的。

二、甲戌日出生，坐戌为燥热之土，而且又在未月出生，属于热命。甲木在地支无根，又没有水来生木，且坐热土之上，则甲木为死木，也代表甲木所处的环境并不是很好。夏季之甲木最喜见雨露滋润，但原局是缺水的，水也为印，代表文化。早年走的大运为丙申也是来消耗日干的，故而在学业上面很难取得大的成绩，比较普通平凡一些。故而在考学的时候，并不会太顺心。

身弱财旺的命，一般欲望都比较的大。上学期间主要是在学习成绩结果上面有很高的要求，但是命运比较弱，走的运气也比较弱，所以求不得而生痛苦。以后成年了，就会在工作以及求财上面而有太高要求。至于孩子现在看似对物质要求不大，实则是因为目前还未真正明白物质的重要性，所需一切都有父母给予。当自己不为所需，必然不会为之所求。所以现在孩子说看淡物质等言语，只能算年少时一个阶段性的想法，过了这个阶段自然就没有了。我们每个人的成长，都会在不同阶段有不同的追求，不同的思想，不同的朋友。任何一个想法或追求都不会伴随一生，包括朋友也是如此。不同时期会有不同的人来陪伴自己。

由于身弱而不担财，所以也会因为求财而生烦恼痛苦，自我也会觉得压力特别的大。甲木坐戌是没有根的，也代表不稳定，漂泊的，变动性也特别的大。

三、命局有华盖星，而且土特别的旺，并且戌土也比较的多，所以和宗教缘分的确是非常深厚。在命局当中，戌有寺庙的意思。戌为火库，也就是香火比较旺的场所，故而代表寺庙的意思。但凡是八字戌土太多，或见戌土，都有宗教因缘，且信仰佛教居多。一般来讲，戌为佛，丑为道。戌为火库，火为心灵，.火是温暖的，是阳光，所以佛道给人信心，温暖和阳光。而丑为寒土，是金库，也为筋骨，有杀戮之气，故而丑为道教。所以八字有火库的命，特别是日时为戌，一般和佛教缘分都非常深。

但是八字缺印，所以学习能力并不强。而且甲木也没有根，故而做事情也不容易坚持，思想变化性也非常的大。至于孩子如果想要皈依三宝，是非常好的。现在很多名人，富豪都有皈依三宝，寻求生命的意义，从而让自己生活的更加幸福。皈依后就有更多机会去了解佛法，明白自己内心最真实的想法和渴望。而不会被过多的欲望蒙蔽双眼，因太多无明而生痛苦。

年支巳火为食神+文昌，代表有悟性，而且华盖也代表悟性。并且口才是相当不错的。所以也很适合去从事一些咨询行业的工作。至于孩子如果内心非常想学习心理学，我觉得也是可以的，因为从八字来看也适合去从事这个行业。而且对自己也非常有好处，更加懂得如何自己缓解压力，减少欲望。从行业发展潜力来看，心理学必然会更有出路一些，自己也会做的更加开心，更有成就感。比在铁路上过重复类似轮回的工作要好的多。当然各个行业都需要人去做，只不过能选择自己喜欢的行业是最好的。

**提醒：** 至于孩子的这种想法，也可能是因为关注我而引发这种思想。所以也许会随着时间而慢慢改变或打消这种想法。但如果历经几年而依然坚持这种梦想，这就是内心真正所想，就不是因为我而生此心，而是有我没我都会生此心，我只是她的一个引缘而已，当然有机会我也可以成为她追求梦想道路上面的助缘。

任何一位从小就目标明确，且愿力强大的人，都是携带前世记忆的人，也可以说是带着任务来的，来完成前世没有完成的心愿。比如有的孩子从小就立志要成为一名医生，最后果然成了医生，而且技术也非常不错，天分非常高，学的也非常快。这都是因为前世就学过，或曾经发过愿，来世要做一名医生，去救更多的人。

我们每个人的思想都不同，那么思想从何而来的呢？我们每个人的性格也不同，性格又因何而生？我们每个人的天分也不同，那么天分又从何而来？这都是因为我们是带着识入胎的，这也就是天性。在各种条件具备的情况下，就能开启我们前世的记忆，而明白我们到底该去做什么。

有些人学习一些知识，就和复习一样，一看就会，这都是因为过去世中就学过。或看到一种知识就非常喜欢，也是因为曾经接触过而生欢喜。看到某个人非常喜欢，这也是因为曾经就有过交集。比如很多人喜欢看我的文章，听我的语音，这也是过去世曾结下过这样的缘。

所以不要去阻碍任何一个目标明确，且信念坚定的人，因为这些人都是前世不凡之人。只有强大的愿力和曾经有过优秀成就的人才能在今生表现出超强的天分。所谓的天分也就是前世记忆而已。只不过对于普通人来讲，浑浑噩噩一辈子，来世也照样不知道该干嘛，只是为了一日三餐在奔波劳累着，周而复始，永在轮回。

# 大运流年

9-19岁走的丙申大运，丙火和申金都是来消耗甲木的，所以运势并不算好。大运逢空亡，则多学少成。

2019己亥年，冲了太岁，亥水也为甲木长生，今年要注意一下健康方面的问题才可以。今年在思想上面也会有巨大变动。

19-29岁走的丁酉大运，伤官见官，在婚姻上面的确不太顺利。主要是自己内心会有很多不满。

29-39岁走的戊戌大运，为华盖大运，这十年是最孤独的。但是如果搞学术研究或者是修行，这十年会有非常大的进步。如果是赚钱，就不会那么顺利了。

所以命弱运弱，如果能追求心灵财富，且皈依三宝，那么对自己是最好的。因为命弱运弱的人，一定要减少欲望，才能获得幸福。如果凡事都要去争胜，或过度追求只会给自己带来强大的痛苦。

丈夫：年干辛金为丈夫，在年比较远，日支戌暗藏辛金，但是被丁火伤官所克，所以夫运并不是很好。

子女：巳火食神为子女，巳火入戌墓了，而且时支为华盖星，所以子女缘分也非常弱，而且不利子女，不容易有孩子。不过夫+子同柱，则子女和丈夫可能同时出现，但是都非常迟。属于晚婚晚育的命。

八字夫子运势都不太好，而且时支为华盖星，且有戊戌华盖大运，所以也暗藏孤独之象。但是如果自己不在意这个，那么也不会因此而痛苦。所以从孩子八字来看，在宗教因缘上面的确非常的旺。

# 人生建议

1.现在的人内心痛苦越来越年轻化了。曾经的我们是只有出身社会了才明白什么是压力和烦恼，但现在不是这样了，越来越多的孩子出现了抑郁，焦虑。现在的孩子一生也就只有不到三年的快乐时光，童年也不再像童年那样天真，青年也不再像青年那样激情。什么年龄段该有什么行为想法，也都完全乱套了。

做为父母也不要给孩子压力，多尊重孩子们自己的想法。现在的孩子其实越来越难做回自己了，很多都是父母给安排好了，还不得不依照父母的要求去做。从小如此，长大了还是如此。父母都觉得自己是对的，但是却从未考虑过孩子的真实想法，以及孩子是否真的喜欢。

我们都可以试问一下自己，所从事的行业以及自己的生活方式，真的是自己喜欢的吗？还是为了生活而迫不得已。这都是因为时代所逼，和现实的无奈，为了生活不得不去妥协。但孩子们，现在还有选择的机会，不管以后是否真的去从事这个行业，但这毕竟是自己内心真正所想要的生活。

我想要说的，也就是尊重孩子的选择吧，大学选择专业可以去读心理学，当然要学就一定要在这个领域有所建树，而不能为了学习而学习，要为天下所有内心痛苦的人而学习。将来如果真的能在这个领域学有所成，可以去医院上班或自己成立一个工作室。让烦恼的人不再烦恼，让痛苦的人不再痛苦，这将是非常大的一件功德。消除他人内心的不安和恐惧，这是无畏布施，必将功德无量。孩子若能目标明确，且坚定信念，不怕辛苦的去朝这个方向努力，作为父母应该高兴才是。因为现在的孩子，大多数都是浑浑噩噩的，没有方向，也不知道为什么而活着。

2.至于孩子的婚姻问题，在以后是一个大烦恼。包括子女缘分也不太好。从八字来看孤独的信息的确很强，当然如果自己不在乎这个，也就不再是什么烦恼了。这一块现在就不要去想，因为多想也无益。等孩子出生社会后，如果有缘分你可以再联系我，到时候再做规划。

你现在要做的，就是帮助孩子实现自己的梦想，她以后一定会非常感激你的。我在几岁时就立志要学习命理风水，十多岁就开始拜师学习，期间离不开父母的支持。如果父母当时就阻挡了，像大多数父母一样让孩子去上班，走大家都走的路，或学习一个“体面”的技能，也就不会有今天的我，所以我也非常感激他们。
