# 八字详批

#### 坤造：丙寅年，庚子月，癸卯日，戊午时（空戌亥、辰巳）

# 命理提要

一、日干为癸水，在子月出生得令，为禄神司令，故而自身不弱。且透庚金来生日干癸水，则为偏旺之命。

冬月出生之人为寒命，年干透出一丙火来暖身，且没有辛金、壬水去损害丙火，并且丙火还去制了庚金，起到了制忌神的作用。这种组合被称为："一阳解冻冰，龙吐气成云”。癸在子月出生见丙火，且有正官合身，则命格不差，为吉格。

月支子水去生卯木，而卯木去生午火，又见午火来生戊土，并且有戊癸合身，也为正官合身的组合。这样的组合，一般都是非常利事业的，利工作。天干为财官印全，则工作运非常好，很吉祥，一般都会在国企单位，或为公职，总之为稳定的意思。

癸卯日出生，自坐卯木食神，那么食神为用。食神去生了时支午火财星，又得正官合身，组合是非常好的。

> 用神：木，火，土。天干喜火，地支喜木，火，土。此命最怕见金，因为金会损寅木和卯木，而寅卯木为关键，一旦破坏了寅卯木，都会破坏原局的流通。
>
> 忌神：金，水。天干最怕水，地支最怕金。因为天干丙火不喜受克，当然辛金也是很怕的，因为辛金会合丙火，一旦丙火被合，则整个命局就会变得非常寒冷。

二、我们从组合来分析，可以得知。命局子一生一卯一生一午一生一戊一合一癸水入身。这是一个依次相生流通的关系。但凡是流通之命，一旦有破坏流通的五行出现，就会有很大的不顺。

那么其中最关键的字，是卯木。为什么是卯木？因为如果没有卯木，则会有水去破火，直接动摇官星的元神，也就损害自身了。卯木是通关五行当中，最重要的一个五行。故而卯木不能受伤。其次日支食神也为寿元星，一旦卯木受伤，就会损害健康，影响寿命。

但如果大运见子水，卯木，午火均为大吉，则为上吉之命，必然事业恒通，一帆风顺，且有官运，利仕途发展。但如果见申酉金，则会破局，就比如管道本是流通，但因堵塞，而导致管道破裂，反吉为凶。

当我第一眼看到这个八字时，内心是非常开心的，因为八字组合非常吉祥，流通之命，均为吉命。但当我仔细分析大运之时，才明白凶在何处。

原局月干庚金贴身，且有财星制印，印为学习，也为文凭。且有正官贴身，故而能有工作，并且工作稳定，企业也不错，很有发展的潜力。

原局时干戊土正官为夫，在时干透出则代表丈夫比自己小，日支临食神，也有小的意思。戊癸相合，则夫妻之间感情基础不牢靠。因为戊癸属于无情之合。

三、关于健康方面，从原局来看问题并不大，反而为吉。原局虽然有子卯刑，但也有相生的信息，至于子午因为相隔卯木，而冲克力量较小。但如果流年出现子水就会去损害午火了。而最大的问题，还是因为大运。

26-36岁走的丁酉大运。其中丁火引动午火，午火为偏财可以生官，本为不凶。不过酉金起到了非常坏的作用。因为酉金去冲了卯木，直接破坏了地支的流通，让通变成了不通。酉卯相冲，唯有相合才可解救，但原局没有合酉卯的地支出现，则酉卯冲为无解之冲。

在2017丁酉年的时候，伏吟大运而构成岁运并临，并且均来冲日支，非常不吉。

在2016丙申年，冲太岁寅木，也非常不利。不过卯木被损的问题是最大的。前五年走的丁运多一些，丁运相对为吉，故而前五年表现的问题并不大。

但从31岁开始，也就是2017丁酉年开始，则进入酉金多一些，故而酉金发挥作用，对原局伤害非常大。等待酉金运结束，要到2022年才可以。

酉金去冲卯木，第一是无解，第二是卯木为寿元星，被酉金伤害，直接危害健康。

**寿元星是如何选择的？**

我在之前的来信当中讲过，一般寿元星都是用神，且在原局出现的比较少，一般就一个，如果出现太多则不是寿元星。旺则取食神。衰则取禄，印。其次也可以看财星等。

寿元星的特点，在原局为用，起到了非常关键的作用。其次就是比较少见，而且挨着日干。

而此命卯木就起到了非常重要的通关作用，其次也在日支为挨着自己，故而对自己影响最大。所以健康出现问题，主要还是因为大运酉金来冲卯木，损了用，伤了寿元星，破坏了流通导致的。且癸见酉金也为病地，故而很不利健康。

在2020庚子年，子水出现去刑卯木，也冲了午火，非常不吉的年份。

2021辛丑年，则辛金引动大运酉金，丑也给酉金提供能量，更加去损克日支卯木，更加危险。

如果能熬过2022年，进入丙申大运后，则活下去的希望还是很大的。而最危险的，还是最近两年。因为流年处处紧逼，处处损克。

# 人生建议

看到你的来信，我内心非常沉重，也努力的思考如何才能真正帮助到你。

同一个八字，同样行走到食神受冲的大运，别人可能仅仅是破财，离婚，或生一场大病等。而你却承担的是晚期癌症的果，并很可能会夺走你的生命。每个人都有属于自己的因缘，至于体现出什么，一切也都是自己要承受的果报。

当事情已经发生了，我们只有勇敢的去面对，不管结果如何，都不能放弃生的希望，因为一个人意志力是非常重要的。

1、一定要先消除对死亡的恐惧，当心中没有恐惧过后，才能让内心更加轻松，对健康也才会更有利。保持一个良好的心态，是任何良药都无法比拟的。

建议你买一本《西藏生死书》，能让你对死亡有一个新的认识，也可能因为这本书，让你放下对死亡的恐惧。要明白，每个人都会面临死亡，只是时间早晚而已。

恐惧是最大的恶魔，恐惧会让身体的病灶更加恶劣。因为长期的精神紧张，焦虑，不安，从而导致食欲不振，睡眠不好，让身体抵抗力不断下降。也因为每天都关注自己的疾病，就会把更多的注意力转移到病灶之上，这样只会让疾病更加严重。我们越是关注身体某一个部位，而某一个部位往往就会随之发生反应。这就是意念的影响。

2、其次可以勤修生死观，闭眼为死，睁眼为生。当自己闭眼的时候，观想自己已经死去了，身处黑暗，但有光明。当自己睁眼的时候，观想自己还活着，并要感恩自己还活着。反复这样去练习，就能慢慢看淡生死，也就不会再恐惧死亡。

死亡是每个人都会经历的，但很少有人真正的去思考死亡，也因此导致一旦要面临死亡的时候，就会手足无措，无法从容的对待死亡，而生各种恐惧，不安，焦虑。当我们经常去观想死亡，思考死亡的时候，就会发现自己的心胸能更加宽广，贪嗔痴也会变得更淡。这个世界本就充满着无常，谁也不知道自己的明天是否还会到来。

慧律法师说：“重新认识死亡，拥有正确之生死观，即可知长寿未必可喜，死亡亦不足忧，所应关注者为“死往何去”。所以当下你最需要做的事情，就是重新认识生死，并且能放下恐惧，从容的面对疾病。因为只有这样，在你接受医学治疗的时候，才会有更好的效果，这也是我能帮助你的地方。当自己身患疾病时，我们不能放弃生的希望，同时也不能放弃对疾病的治疗。要身心皆治，病才能康。

黄帝内经讲：“精神内伤，身必败亡；得神者昌，失神者亡”。神就代表我们的心理，而身就代表身体。这句话可以看出，精神是可以决定身体好坏的。心怵惕思虑，则伤神，伤神则恐惧自失。黄帝内经提出了“神形合一”的看法，也就是身体和精神是合二为一的，不管哪一个受损，都会导致另一个受伤。当然神为根本，也就是精神思想为健康的根本。所以善于治病的医生，永远都是从病人的心理入手，因为心病不除，用药不灵。

我说这么多啊，就是希望你能明白，保持轻松从容的心态，是非常重要的。

唯有如此，才能让药物发挥更好的作用。一定要听我的，好好去做，希望能消除恐惧，焦虑，不安。

3、其次就是要努力的去修福。

人之寿尽，分别有四种状态。分别为：“寿尽而死，福尽而死，意外而死，自如而死”。所谓自如而死，就是指一些修行人，可以随时放弃肉身。而大多数的人，基本都是福尽而死。所以修福是非常重要的，当然也要修慧，要福慧双修，才是圆满的。

如何修福？先要行孝。不管将来还能活多久，都要在自己还在时候，多陪陪父母，尽尽自己的孝心。孝感天地，也是积福最快的方法。给父母洗脚，做饭，陪父母谈心，捶背等等，只要发自内心的去做，任何一个行为都是大善。切莫杀生，最好是能做到吃素。

4、改变你过去的生活习惯和饮食习惯。因为过去的习惯让你生病了，那么就要去改变它。过去喜欢吃什么，则不再去吃，过去的脾气性格，也要去改变它。如果能完全转变过来，则一切奇迹都可能发生。

癌症为基因突变，而导致基因变异的因素，和饮食，生活习惯，心理都有很大关系。曾经的习惯使自己的基因变异了，那么就一定去改变它。

5、每天坚持学习和读诵《无量寿经》，并且多念“阿弥陀佛”名号。

回向文：愿以此功德，庄严佛净土，上报四重恩，下济三途苦，若有见闻者，悉发菩提心，尽此一报身，同身极乐国。

为什么要读这部经，因为就算生命结束了，也能有一个更好的去处，不入恶道，不再遭受轮回之苦。

最近两年关口很大，但只要坚强面对，一定会有奇迹的。加油。
