# 来信

我男命，出生于农历1983年2月22日（清明节），晚21点钟。自从一年前一个偶然的机会听到你的文章后，就深深的喜欢上了风水，自此以后你的每篇文章已成为我的必读。也学到了很多风水知识。在此呢还得谢谢李老师！

我呢也不会什么手艺和特长，酿酒时因为年纪小，也因为地理位置在村子中间，阻力大几年后关门。又自己买过面包车送货，后又买大货车拉货，但都失败了，后老婆又开服装店，倒也赚到点小钱，后来叫我去开了分店，因为位置没选好开了不到一个月就关门大吉了。还欠下了外债，只有到处打工还债。

也因为生活的潦倒，老婆在我身上看不到希里，2016年她选择了和我离婚，把我扫地出门，导致我到处找工作，现在工作也不稳定，人生走到现在了还一事无成，我很是担忧。

但是现在和前妻呢感觉又有了一些缓合，以后呢就不清楚了。我呢还是不甘心，想再去创点业。所以呢现在想去开一个蛋糕店再拼一把，但又非常害怕，怕万一再失败就，不知道能不能去做？

# 命理提要

一、日干癸水为自己在辰月出生失令，不过辰为水库地支又见三个亥水，则辰已经成了稀泥土，不但无法很好制水反而有助水的作用。地支一片比劫星，天干丙火为财星，水太旺见一个丙火非常珍贵，但丙火太弱了，而且还被比劫所克，所以丙火一旦出现就被众比所夺，反而不利。

八字最大的忌神就是水，但又不能用土来制水，因为水太旺了土是制不住的，而用神丙火受伤比较严重，又没有木来生火通关，所以最大的用神就是喜木来生火，也喜火来耗身，至于走土运也有机会，但由于水太旺了也容易被反噬，所以在土运也有是非。

八字属于身旺财弱的命，喜食伤来生财为用。命格用神太弱而忌神旺而无制，则命运坎坷，一生难有所成。

二、丙火为财也代表妻子，丙被年干癸水所夺，而且丙坐辰也为比肩库，八字属于群比夺妻，这种命格一来克妻子比较严重，二来婚姻失败或妻子会出轨外遇。癸在年代表其他异性，而且癸水坐亥水是有力的，天干三个癸水都来争夺一个丙火，然一妻怎能嫁三人，故而夫妻有分离之象，妻子会和其他人在一起。

你八字比劫夺财特别的严重，对父母以及妻子都有伤害。并且比劫旺的人，性格也都不是很好，对妻子也不够体贴。所以妻子离开你，不单单是因为你在她嫌弃你“没出息”，更主要的还是她在你身上看不到未来以及你对她的感情。不过这也是命运使然，比劫夺财的命，婚姻都很难长久，如果在一起则妻子会有灾难或身体多病。所以分开反而可以化解相克，对妻子来讲离开你也是一件正确的选择。

丙为财也代表你的财运，一样的被夺了。比劫夺财的命，又财星无根无生，则财星虚透。本身财就不多，还被这么多人分走了，主贫困之命。正财不喜透出，透则不存，正财也代表你辛苦赚到的钱，而比劫贴财，则有点钱就会花掉，存不住钱财，到头一场空。所以你在财运上面都是非常糟糕的，要发财是不太可能的，就算赚点稳定的财都非常困难。比劫旺的人要去做一些辛苦点的工作，偏向体力方面的比较好。

你八字没有食伤来生财，又财星虚透，并不适合做生意，如果你继续执着于生意，那么你的后半生会越来越差，甚至越来越穷。只有找一份工作，为别人做，然后坚持去做，踏踏实实，才能让你的人生稍微稳定一些，吉祥一些。

从命格来看不建议去做生意，所以你要开蛋糕店我也是不建议的。但是你可以去学习一门技术，因为你八字属于身旺无依，必须要有一技傍身，此生才不会贫穷，所以可以学习一门手艺，然后去给别人打工，或者是跟着别人去做，这样对你才是最有利的。烘焙技术非常适合你，因为五行为火，而你的八字也是喜火的，所以你可以去学习，然后就在这个行业发展。

我认识一位烘焙师傅月收入好几万，也就是上班，所以并非上班就没有出路，一定要做生意才可以发财，这种思维是错误的。在当今社会，如果没有足够的能力和运气，或方向错误，做生意还不如一个打工的，而且还会非常的辛苦。

# 大运流年

20-30岁走的癸丑大运，癸水来克丙火无解，丑为湿土也无法制水，所以这十年运势非常的差。由于是空亡大运，则伤害之力减去三分，但依然不吉。

30-40岁走的壬子大运，壬水为劫财直接克丙火，子水为禄神帮身，由于日干已经非常旺了，所以不喜再见水来帮身，一旦走比劫大运，则财星受制，妻财两败。壬水冲丙火，下子就把妻子给冲走了。在2016丙申年的时候，丙火透出来，代表妻子出来了，故而正好受到了壬水的冲克，导致妻子离你而去，婚姻出现严重问题。

2016丙申年也为财星虚透，印来帮身为忌，事事不顺。

2019己亥年，则四个亥水，加上大运也是水为忌神，所以今年运势也不太好。由于正官透出，所以自己想要做点事情，但正官是虚透的，故而事业不太可靠，也不稳定。

2020庚子年，也是非常不顺的年份。

所以从大运+流年来看，最近几年都比较糟糕，也非常不顺。故而切莫去开店，否则到最后钱花了事情没做好，让自己的生活更加困难。运气不好就不要去做投资，要做无本的事情，比如打工之类的，这样对你才是最好的。这十年火被克了非常严重，看似有灾，不过好在这十年为天月二德到，所以也能逢凶化吉。虽然没有吉，但灾难也能减轻不少。

40-50岁走的辛亥大运，四个亥水，发生了自刑，而且丙辛相合，丙火一下子被合走了，但辰土的力量依然存在，所以也不能从，而财星没有了。如果没有辰，则入假从，丙辛一合则能发达。但有辰则不入假从，丙火被合走反而主困苦。

不过运势只是一个方向，关键也要看自己如何去规划自己的人生，如果顺其自然，自己又不努力去修行，改变自己，那么结果必然如命运所示，半点不差。但如果自己愿意去改变自己，合理的规划自己的人生，并且为之而努力，那么自己的人生一定会有很大的改变。虽然不能跳出这个框，但可以在这个框内实现最大程度的吉。

八字为一个人的先天命运，如果不知命改命，那么命运就如八字所定。如果知命而改命，则算命不准，未来也会发生很大的变化。所以我们要做的，就是让八字算不准自己，而不是被八字算准。但要做到这一点并不是一件容易的事情，因为命运困苦的人，往往因为福气比较弱，而无法了解其中的道理，也不知道该如何去改变自己，就算知道了也不能坚持去改变自己。能有改命决心的人，必然也是能做大事的人。

我建议你去看看《了凡四训》，这本书详细的记载了了凡先生改命的全过程，可以了解一下了凡先生是如何改变自己命运的。你的命可以说非常糟糕，后面还有很多未知的灾难和阻碍，一定要好好修行，才能让自己的人生更好一些。至于何为修行？就是不断的修缮自己的言行，把自己给调整到一个好的频道上去，那么你的人生必然会发生很大的改变。

# 人生建议

1、不借他人之口说一些道理，自己永远不会明白。但时机未到，说也无用。我希望你能摆正心态，明白自己到底应该去做点什么，能做点什么。知命则须先知己，自己并非做大事的命，也很难有发财的运。所以不要总是想着去做生意。

一个人如果连上班都做不好，那么做生意肯定也是做不好的。能做事情的人，在任何一个环境下都能应对自如，而你缺乏这样的能力，如果真的去经营一个店铺，到最后也就只有关张大吉的结果。我是非常不建议你去做生意的，不管是什么形式的生意都不要去做。

如果你想要改变自己的未来，我建议你去学习一门技术，因为你的命一定要有技术才能保证一生衣禄不愁。并且要努力改变自己的性格，八字比劫太旺了，非常津的一个人，脾气也不是很好。要努力的去改变自己所有的缺点，每天晚上睡觉之前反思一下自己今天的所作所为，并且用本子记录下来，好的就继续保持，坏的就努力改变。

2、并且要坚持日行一善，不管大小，就算去捡捡地上的垃圾也是一善，从而来增加自己的福德，做的每一件善事也要用本子记录下来，用来提醒自己。

你如果想要改变自己的命运，就给自己定一个目标，一定要做够十万件善事。买一个功德记录本，做了善事就涂一个红点，做了坏事就涂一个黑点。只有坚持行善，才能培养福德。并且也会让你的心境发生很大的改变。当你心境改变过后，你会发生你身边的所有人，事，物也都会跟着发生改变。你会有机会接触更有正能量的朋友，也会接触到更好的机会，自然就会有贵人来帮助到你。心境决定你做事的方法和前进的方向，也决定了你命运的结果。

3、除了行善之外，建议每天至少读七遍《心经》，抄写一遍，每个月去放生一次。前者是为了让你静下心来，后者是为了培养你的善心。所作种种，均是为了改变你的心境，因为境随心转，心量大了，世界也会跟着变大。买一本《了凡四训》随身携带，每天看一遍，来增强自己的信心。

除此之外，要多学习。改变命运的两个方法，一为增功德，二为增学识。所以要多学习，把四书五经都看一遍，易经，道德经等。你会通过学习古典而明白一些人生道理，也能增长你的智慧。这个时候你自然就明白该如何去做了，如何面对自己的今天。如果你内心不能真正明白，我说再多也是无用的，很多事情必须要自己去悟明白，才算真的明白。知道了和懂了是不一样的。

若你能坚持这样去做，命运必定改变。十年之后的今天，你的人生将焕然一新。

4、最后再重复一下，不要开店，最好是去学习一门技术，然后以上班为主。只要你肯这样坚持下去，那么你的后半生一定慢慢好起来的。比劫旺的人不喜欢被管束，喜欢自由，这样的性格配合你的运势，除了去流浪没有其他路子好走了。但如果想要过正常的生活，而且想要自己的未来越来越好，那么就一定要改变这样的心态，踏踏实实的去做好每一件事情。
