# 来信

男性，农历1992年7月7日，卯时，从小到大我都是一个非常自律的人，学习成绩也是很好，父母待我也非常好，用钱从来不克扣我的，所以使我养成花钱大手大脚的习惯。

自从2016年结婚以后，感觉自己的运气非常不好，在今年2月2日找大师看了，说我命中缺土，叫我补土，叫我从事和土有关的工作，所以给了2266元作为补财库的钱，说补了财库我的财运就会好起来，然后装了元宝在财库里，但是她用手机照了里面全是黄金，说我以后挣的也是黄金，我感觉自己也是像洗脑一样，做事情有干劲。

可是到现在为止，我一分钱的收入都没有，现在的我险入万劫不复之地，我想出去打工把之前欠的钱还清，可是又要过年了，不知道该怎么办了。

目前我在云南这个地方做小额金融，今年经济不景气，花钱的地方比挣钱的地方多，压力压的我喘不过气来，很绝望。

> 问题：
>
> 1、我还适合继续做金融吗？
>
> 2、还是如那个大师所说叫我做和土有关的产品？

# 命理提要

一、类似你这样补过财库的人，在我这里就看的数不清楚有多少了，每次看到都是又好笑又好气。看来易学的思想普及是非常重要的，因为自己的不懂才会那么容易上当。你是癸丑日出生，坐未土克身无力，地支丑未两个土，怎么能说你缺土呢？年柱为金水，所以癸水有气，故而为身弱七杀旺的命。那么必然要补救金水才是最理想的，怎么能补土呢？不管从什么角度来看，这种说法都是不合理的。

所以你的命并不缺土，八字当中有两个土，分别为未土和丑土，并且这两个土都是你的七杀，为你命中凶神，既然是凶神，那么必然是不能再见到土了。

那么缺土是怎么看的呢？答案只有一个。瞎猜的。自己根本就不懂看八字。至于说要补土，也是瞎猜的。因为看八字并不是她的专长，她的专长应该是补财库。所以前面说的一切，都是为了让你来做一个补财库罢了。

二、关于补财库我已经在很多地方公开讲了很多次。这是一种非常可恶的骗局。说白了，就是利用老百姓对这方面的无知，加上网上铺天盖地的宣传文章（都是假的），导致很多人宁可信其有不可信其无，也期望能依此就改变自己的命运，所以都愿意去试试。补财库，唯一的作用就是增强部分人的信心，除此之外没有任何作用。如果命理指导出现问题，那么就算增强信心也是徒然，因为努力方向都错了，结果肯定不会好。但是为了增强信心有的时候也是非常重要的。我给大家讲一个我的案例：

一位朋友联系我，说最近想要做一个投资，但是心里没底。我用奇门遁甲测算后再结合他自己的能力情况，以及项目的市场情况综合断定这个事情可以做，而且可以赚钱。因为有运气来做这个事情，而且过程当中会有贵人帮助。但是我讲了后他依然信心不够，我担心因为信心不够而不能把事情做好。于是告诉他一个方法，照做后一定可以赚钱。

方法就是在某日某时的早上起床往东方走，然后取多少米外的一块什么形状的石头，拿到家里西北角放3天，在3天后拿到西边寺庙摆放在大佛脚下。他照做后，信心大增，做事情也非常有动力，最后也是收入不菲，还专程来感谢我，说我的法真有厉害。（前提是要推算出能赚钱，后者只是为了增强他的信心，让他没有多余的顾虑，当然大家也可以说成是迷信）。所以有的时候，一些增强信心的做法也必须要有的。但是很多人利用这个来大发横财，就实在是造业了。

再比如，我一位亲戚生了很严重的疾病，每天都非常担心，郁郁寡欢，气色很差。于是我说帮你化解一下，然后用了一些过程很足的方法，有一个多小时吧。并且我每天让她只要有空就念阿弥陀佛（越是相信效果越好）。大概半个月后，她反馈说身体好多了，并且气色也好了很多。方法只是为了增强他的生存信心，而念佛是为了转移注意力，就不会每天想着病，而是想着佛（佛号的能量是很强的）。大家读《黄帝内经》就知道，心和我们的身体是一体的，不是分开的。如果肾脏不好，你每天想着他就会越来越不好，如果忘记肾脏不好，而内心快乐，自然疾病就会慢慢消除。

所以我们不能否定法事就完全无效，但是也不能过分夸大法事的功能。特别是一些专业从事科仪的人，一定要理性.的看待这个问题，要做到一个助缘作用，而不能迷惑百姓。世间一切法，.都只是助缘而已，决不能干扰因果。至于助缘只是为生起这个人某方面的信心，更主要的还是依靠自己来改变。外力如果能改命，那么我们人人都可以命好，世界上就不会有苦命的人了。因为几千元就能让财源好起来，谁都愿意去做啊！而做法事的意义在什么地方呢？是要利益他人，而不是靠此赚取暴利。只要能真正帮助到一个人，过程又不伤害别人，怎么做都是可以的。这都是功德，就算是欺骗他，也是大福报。

但是现在市面上很多人就利用了这个心理，而到处宣传还受生债，还童子等等各种法事。这都是不合道的，道乃结构规律，违背规律就是逆天而行，必遭天谴。说了这么多，就是为了让大家明白什么是法事，至于我们要注意哪些问题。下面我们继续讨论这个八字。

三、你八字属于身弱之命，要多多补金才可以，一定要从事五行为金的行业，至于五行水的行业也可以。你八字为偏财格，财星有制，所以财运也是可以的，你命局并不差。至于目前不顺，只是当下而已，将来还是很好的，一定要对自己的未来生起信心。

从2019己亥年开始，你运气就会有一个回升。特别是在31岁后走的辛亥大运，后面接着是壬子大运，所以有至少二十年的好运气。所以你命运并不差，至于你现在只不过运气弱点，加上人还算比较年轻，所以不要着急。

自我感觉运气不强的时候，就要多学习，不断的充实自己，积累知识。等待机遇的出现。总之你后面一定不差，将来财运也是非常可观的，好好努力。

人生在20-30岁之间，最重要的不是赚多少钱，而是定位，选择人生发展的方向。这十年是选择方向，所以这个过程当中可能会有很多的改变，但是最终一定要做出一个选择，并且长期坚持。

30-40岁则是奋斗阶段，这个阶段一般不适合轻易改变职业。

至于40-50岁如果还没有什么起色，那么人生基本上就定型了，想要有什么发展，已经非常困难了。当然不排除个别大器晚成的人，不过这毕竟是少数中的少数。

所以你在30岁之前，都不要为了钱财而有太大的烦恼。你应该烦恼的是方向的问题。男怕入错行啊，行业的选择就是方向。方向对了，你一努力就成功了。而方向不对，则努力也是白费。
