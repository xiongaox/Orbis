# 寿元星被制的人

命主生辰: 1979/09/27 4:00 (GMT+8)
性别: 坤造
日主: 丁火
格局: 偏弱之命
令地: 失令, 失地

# 网友来信：

只因为一次8月底的阴雨天，我不小心受凉，就造成了腰部的疼痛。开始是不能久站久坐，不然会双腿发麻，腰部无力。于是去正规医院治疗。可是治疗月余仍然没有明显的改观。期间关系很好的同事出于好意，推荐我去一家私人的正骨诊所诊治。同事及家人都曾去治疗且疗效显著。可是，不幸的事情发生了！我去那个诊所诊治了7次，花了近1万块钱，可是，最终我被治的更坏了！治完之后，我因右腿右侧腰椎和骨盆被拉扯按压的受了伤而剧烈疼痛完全无法站、坐、行走，只能躺着。此后至今，我生活的主旋律就是治病治病治病。四处求医问药，看遍了本市大大小小的医院，但是基本没有有效的治疗。

我今年44岁，当年刚40出头，家里孩子刚初中。受伤前我在单位是部门骨干，肩负部门半数以上的工作量和最重要的一部分工作内容。但是受伤后我丧失了劳动能力，家里的事全部落在老公头上，单位也给我调整了工作岗位，到了无足轻重的闲职部门。这些还都不是最重要的，最重要的是，我完全无法自理，已经是一个废人。最厉害的时候自己穿不了袜子裤子，别说其他的事情了。突然的变故让我痛不欲生无法接受。整个人陷入了严重的焦虑和抑郁。躺在床上身体疼痛的同时，焦虑症和抑郁症让我更加痛不欲生，甚至一度想要自杀脱离苦海。

幸好上天没有完全抛弃我，在多方打听之下，又寻得一位针灸治疗疑难杂症的老中医。直到去了老中医这里针灸，才算终于找到了有点疗效的治疗手段。伴随着针灸治疗有点作用，我又在老公的鼓励和帮助下开始接受焦虑药和抑郁症的治疗。双管齐下，我终于从死亡的边缘被救了回来。往事不堪回首，想当年，一个169厘米的人，因为抑郁厌食而暴瘦到只有80斤，皮包骨头几乎快没有人形。想到这些，我的眼泪又忍不住流了下来。

如今已经3年多的时间过去了，我虽然已经可以行动可以上班恢复了基本的生活能力，但是依然是病痛不断。在壬寅年下半年我的腰疼等各方面问题都得到了比较显著的缓解之后，全国疫情又加剧了，我也阳了。一段时间之后虽然恢复了，但是身体状况又变得虚弱很多。之后不久，癸卯年年初，又在过马路的时候被汽车剐蹭摔倒而脚趾骨折，又在家躺了一个半月。骨折恢复之后，原本的腰疼还没有完全好利索而又增加了因车祸摔伤而带来的小腿和脚的疼痛很久都没有痊愈，同时因为卧床太久，原本就不硬朗的身体也更加虚弱。这不，刚8月份又再一次阳了，并因为牙齿之前也有问题，又引发了严重的急性鼻窦炎，各种吃药治疗又差点要了我半条命，随之而来的是头疼，颈椎胀痛不通，背部疼痛等等，只能继续针灸治疗，艰难的恢复。

时至今日，虽然我已经脱离了只能躺着度日的痛苦，但是每天身上也还是会不是这里疼就是那里疼，而且这几年来，反反复复的生病受伤。所以在这几年里，我一开始是因病求助于懂命理学的其他人帮我看我的问题，后来慢慢的我开始自己研究，我想弄明白，是不是真的有命运这一说，我想知道我的命运怎么就是这么多灾多难各种病痛，我想知道，这样的痛苦什么时候可以结束，我还能不能彻彻底底的好起来，像个正常人一样能跑能跳。我太想远离病痛了。

另外，这几年治病花了不少钱，虽然现在我只想好好的把身体养好，不想那些什么财运富贵事情了，也有人说我身弱不担财，我觉得也是有道理。但是我还是经常会对钱财有不由自主的担心。一个是我的父母一直都很俭省不舍得花钱，我从小到大也很自卑不自信，总是觉得自己不够好不够优秀。现在病了这么久，又担心家里的钱这样花下去，万一不够花了怎么办，以后孩子上学什么的需要用钱怎么办，心里不免焦虑。所以还想请老师帮我看看，我会不会走到贫困潦倒的境地。还有就是我身子弱，可以学易经命理这些吗？会不会对身体有影响呢？

# 八字详批：

#### 坤造：己未年，癸酉月，丁酉日，壬寅时（辰巳空）

#### 大运：甲戌，乙亥，丙子，丁丑，戊寅，己卯，庚辰，辛巳，壬午，5岁运。

# 分析命局：

丁火日主生在酉月失令，坐酉金失地，地支酉酉自刑，耗身力量较强，年干透出己土来泄身，年支未土也是泄身的五行，月干癸水和时干壬水来克身，癸水坐酉金之上有力，克身力量不弱，唯有时支寅木来生扶日主，但在地支被酉金所制，生扶力量不强，依然为身弱之格。

# 分析喜忌：

偏弱以生扶日主的木火五行为用神，以泄耗日主的土金五行为忌神，水虽克身，但在地支生木为吉。酉金当令较旺，伏吟地支，金旺克木，喜见火来帮身克金，同时也喜见木来疏土。天干水旺克火，喜见木来通关生火，单独见火，水火相战，稍有不利。

# 分析事业：

时支寅木为命局唯一用神，寅木得壬水生扶，寅木有元神，为吉利之处，但奈何地支酉金较旺来制寅木，寅木有损，为忌神制用，用神无力，为不足之处，命局唯一的用神受损，故组合不太理想。

而且地支酉金来制寅木，为财星克印的组合，一方面代表操心操劳较多，另外一方面寅木在命局组合中也可以代表寿元星，但寅木印星被财星所制，也会体现在健康方面，容易免疫力不好，抵抗力差，小毛小病较多。同时五行木被制，金木交战，也代表容易有有肝胆、经络、颈椎、腰椎等方面不好之象。而且地支酉酉自刑也代表内心容易纠结矛盾，自我伤害，精神折磨，容易郁闷纠结。

地支酉金偏财伏吟当令，同时又有未土来生酉金，为食神生财的组合，求财的欲望比较强，物欲较重，注重物质享受，偏财较旺也有圆滑的一面，一般也不会满足于按部就班的工资收入，命局食神制杀，能力强，有魄力，工作中可独当一面。

不过身弱财旺，财生七杀克身，也容易因为求财而产生很大压力，因为求而不得导致烦恼忧愁多。地支未土来生酉金，食神生财，财星较旺，而丁火日主太弱，且在地支无根，身弱难担财，泄耗五行过多过旺，也代表做事容易感到疲惫，精力不够，较为劳累。

财星较旺，财星克印，这种组合也代表很容易因为房子、车子、父母、身体等花销较大，容易在这些方面开销。

好在从今年起进入戊寅大运，虽然天干伤官见官，但地支有寅帮身，运势吉凶参半，工作事业上能够有所好转，后面的己卯大运，天干食神制杀，收入虽不差，但也花销大，容易财来财去，关节筋骨四肢方面的问题也需注意，防伤痛，磕碰扭伤。

在未来的职业规划上，有几个建议供参考。一是在原单位虽然是闲职，但现阶段闲职反而更加适合你一些，适合你的身体状况，就不建议再去变动。二是由于财旺成势，条件允许的话能从事一些财务、出纳等方面的工作要好一些。

健康方面，身弱以寅木印星为寿元星，寅木一旦有损，就会导致体质不好，引发健康问题，而且地支酉酉自刑，也容易受伤。你早年走的乙亥大运，丙子大运，地支有亥子水通关，所以腰椎问题不是太容易诱发，过了这步大运，就很容易有这些方面问题，尤其55岁后进入己卯大运，更加要注意这方面问题。

寅木被酉金所制，且酉酉自刑，要注意肝胆、经络、颈椎、腰椎、甲状腺方面问题，丁火较弱被合克，也要注意眼目、肠道、心脑血管等方面问题。地支酉酉自刑，还要注意肺部，肠道等方面问题。

# 分析大运：

**45岁—54岁**

戊寅大运，此大运天干戊土被地支寅木戳脚，天干戊癸相合，癸水被合克，为去杀留官的组合，地支寅木来助身，故整体运势稍好，事业运会逐步好起来。但是与时干伤官见官，也要注意人际关系，预防不受人待见，避免被边缘化，运势吉凶参半。

**55岁—64岁**

己卯大运，此大运天干己土被地支卯木戳脚，天干己土食神透出，地支卯木印星来助身，整体运势一般偏好，整体财运不差，但也容易财来财去，花销较大，地支卯酉相冲，要谨防腰椎、颈椎、肝胆、经络等问题复发。
