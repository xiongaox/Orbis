# 网友来信：

我生在寒士之家，父母每天都要像木偶一样被生活的丝线操控着，努力的工作供养家里5个兄弟姊妹。农村家庭多少有些重男轻女，这也是在我长大之后才发现的。小时候没感觉跟弟弟的待遇有什么明显的差别，初中时父母不止一次提及想让我辍学，只供弟弟上学，无奈我是家里孩子中学习最好的，庚子年勉强完成了大学学业，毕业后母亲一心想让我回到家中工作，听从父母教诲，幸运的一毕业就考上了家中的事业单位，月入不多,生活虽然清贫,日子过得还算安宁。

目前感情和财运方面比较困惑。我感觉我烂桃花挺多的，遇不到心投意合、条件满意的人。前两年母亲四处给我算，说我的喜事今年才动，说是今年结婚，但我现在依旧是单身状态。

关于财运，自己最近有开始基金、股票等相关的理财，但是结果一般，目前还是亏损状态。事业上，庚子年考入事业单位，由于部门比较小位置也比较偏，有跳槽，在考其他的事业单位的打算，不知道会是不是跳槽成功。人总是贪婪的，我也是如此，现在的安宁却不满足，总是想过上更好的日子。

# 八字详批：

#### 坤造：丁丑年，癸丑月，丙寅日，己丑时（戌亥空）

# 分析命局：

丙火日主生在丑月失令，年支和时支丑土伏吟来泄身，坐寅木得地，时干透出己土，也来泄身，月干透出癸水来克身，年干丁火来帮身，但被丑土泄气无力，且被癸水所制，帮身力量较弱，寅木在地支也有被反克之象，故为身弱之格。月干癸水正官和时干己土伤官从月令丑土中透出，为正官格，也为伤官格。

# 分析喜忌：

偏弱以生扶日主的木火五行为用神，以泄耗日主的土金五行为忌神，水虽克身，但在地支生木为吉。丑土当令，伏吟地支，喜见木来疏土，单独见火，帮身的同时也旺了丑土，非为最吉。天干喜见木来通关生火。

# 分析事业：

日支寅木为用，寅木虽在地支可以疏土，为用神制忌，但奈何丑土当令较旺，而且又有三个丑土伏吟地支，土的力量是很旺的，寅木在地支孤立无援，有被丑土反克之象，寅木受损无力。年干丁火也为用，但被癸水所制，同时丁火又被丑土泄气，丑土伏吟，晦火力量较强，从组合来看，不是太理想。

原局为伤官格，丑土伤官星当令，伏吟地支，临华盖，又在时干透出，丑土伤官虽为忌神，但也有寅木印星所制，所谓“聪明不过伤官，伶俐不过七杀”，比较聪明伶俐的一个人，有一定领悟力。伤官较旺，一般都比较有上进心，或者野心，不甘于平庸，内心不太安分，也不容易满足。伤官旺，一般都喜开拓创新，不喜墨守陈规，可以接受新鲜事物，为吉的一面。

不过伤官太旺为忌神，多为小聪明，缺乏大智慧，同时也比较有个性的一个人，比较要强好胜，容易任性、傲慢，有一些情绪化，有时候有一些自命不凡，自我感觉良好，也容易三心二意，做事不够踏实，容易浮躁，自尊心较强，比较好面子，有时候想得多，思虑较多。

月柱癸丑，为伤官克官的组合，比较喜欢自由，不喜被束缚太多，有一些小叛逆，不太服管，也体现为自制力不够强，容易我行我素。

丙寅日出生临孤辰，寅木偏印贴身，相对敏感，疑虑，五行土厚，也会体现为较为固执，加上丙火日主在地支无强根，有时候做事不够坚持，命局丑土伤官得令较旺，伤官泄身太过，也代表求财辛苦，操心操劳较多，付出较多。月柱癸丑伤官克官，要注意口舌是非，与人不和之事。

月令丑土为财墓，三个丑土财墓伏吟地支，财墓不开，所谓财墓一个为贵，多而难富，也代表求财辛苦，难见大财，能满足于一般的财为吉，要懂得知足为好。

结合大运来看，现在走的丙辰大运，财运一般，未来的丁巳大运，戊午大运，财运会比现在好一些，想投资股票等可以考虑在这两步大运，但到了己未大运，求财辛苦，付出较多，但丑未相冲，丑土被冲开，依然有一定财运。

原局伤官格，伤官高透，一般口才不差，这种组合有从商的信息，也适合做一些销售讲解、咨询宣传等方面的工作。从商的话，木火为用，日支寅木为枭神，代表偏业，适合做一些医药、针灸、正骨、推拿、养生，服装等相关方面的工作。印比为木火，木火相生为用主文化，故也适合一些教育文化培训、行政、广告等方面的工作。

命局有伤官克官一般不太适合体质内，不过如果岗位相对偏自由、偏口才、偏文化等，那是可以的，未来的走丁巳大运，戊午大运，晋升的机会也是有的。

# 分析婚姻：

丑土伤官星得令较旺，寅木印星虽制伤官，但制伤官无力，丙火日出生，感情上有时候脾气不太好，有时会比较任性，对另一半会比较挑剔苛刻，也容易有口舌之争，从而不利感情和谐。

在找对象的时候找年纪大自己一些，或者说心智比较成熟一些的，能够更包容自己，能够更好的处理两个人的感情关系，更有利于婚姻稳定，同时也适合晚一些结婚。月柱和时柱临华盖，也有在感情上孤独之象，适合晚婚为吉。

癸水为正官，可以代表丈夫，虽不见财来生官，伤官克官，对另一半要求高挑剔不满，属于克感情婚姻的组合。好在日支婚姻宫为寅木用神，均代表未来丈夫条件和能力不差，对你有一定帮助。他五官端正，额高菱角分明，脸型微圆，肤色微黄。眼睛不大，细长也比较有神，眉毛浓密，嘴唇微厚，175左右。职业方面与金融财经，老师教育，技术等相关。

你之所以觉得你身边“烂桃花”多，是因为你上步大运走的是乙卯大运，为桃花的运气，你从今年起进入丙辰大运，异性缘分就没那么好了，今年癸卯年，地支卯木为桃花，天干癸水夫星出现，是有机会遇到缘分的，接下来留意农历十月、十一月，最好多找人介绍，不然要多等好几年，要到2028年遇到并结婚。

# 分析大运：

**26岁—35岁**

丙辰大运，此大运天干丙火比肩帮身，贵人运较为不错，可以得到他人相助，但所谓“天无二日”，也代表事业上有一定竞争。地支辰土食神泄身，工作依然比较辛苦，财运较为一般，不适合投资过大，容易亏损。

**36岁—45岁**

丁巳大运，此大运干支一气为比劫，比劫帮身，整体运势较为不错，可以得到他人相助，也有一定机遇，财运整体会好起来，收入有所增加，可以适当做一点投资，但寅巳相害，依然有花销破耗，婚姻宫受损，也要注意夫妻关系。

**46岁—55岁**

戊午大运，此大运天干戊土食神透出，戊癸相合，癸水官星被合克，事业或岗位容易发生变动，不太稳定，但地支午火劫财帮身，丙火日主在地支有了根，也代表整体事业运不差，财运也有所提升，贵人运尚可。

**56岁—65岁**

己未大运，此大运干支一气为伤官，伤官来泄身，比较辛苦，但丑未相冲，丑土财墓被冲开，代表有机会得快财。天干己土来制癸水，为伤官克官的组合，要注意口舌是非，与人不和，此大运夫妻关系也比较紧张，要多注意下。
