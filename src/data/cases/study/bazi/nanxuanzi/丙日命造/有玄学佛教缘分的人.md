# 有玄学佛教缘分的人

命主生辰: 1998/04/09 2:00 (GMT+8)
性别: 坤造
日主: 丙火
格局: 食神格
令地: 失令, 失地

# 网友来信：

我很多时候觉得自己与世界格格不入吧，高考完的暑假开始接触玄学，慢慢的过去了好多年，成了我精神的安放之处。

我最大的问题还是自己的心理方面不过关吧，丙申年，丁酉年高考及复读那些年，因为情绪不好，不懂得排解，暴饮暴食慢慢有了口水强迫症，辛丑年到现在逐渐严重。还有自身很敏感，我高中时就有见了异性不自然的状态，甚至不敢看异性眼睛，觉得他们都在看自己。然后从辛丑年到现在越发严重。很难达到正常水平。

我为什么不和别人交流呢？可能我骨子里脆弱、敏感，加上有些许的挑剔。最主要的还是怕受到伤害。因为我是一个重感情的人，不懂得拒绝。不喜欢麻烦别人。

我虽是丙火日主，但是因为土太多，内耗太严重了，很压抑自己，然后今年是工作第二年，我仍然被这些问题占据大脑，很难专心工作，也不与别人交流，得不到一点重视。  仿佛又回到了暗无天日，想要出头却很难，想要证明自己......

我常常想带给我的是什么？自己的一些行为只会让别人看不起吧。我羡慕那些可以自如、从容、不慌不忙的女性。

自身行为举止不太理想，别人只在那看我出丑，工作中冷板凳，对象也没着落。学习也专心不下去。看着别人考公考研等。目前就打算考行业注会证吧，但力不从心。哎，不知道自己的好运何时到来呢？

我始终放不开自己吧，我很多时候在自己的位子上一言不发，我羡慕能自如，展现自己社交魅力的人。也知道了职场和学校的不同，见风使舵的太多了，人行了真的太重要了。

我真的不擅长这样复杂的交织着的....我更多的还是想自己一个人做事吧，做自己喜欢的，不太适应目前的社会吧。很痛苦。

# 八字详批：

#### 坤造：戊寅年，丙辰月，丙戌日，己丑时（午未空）

# 分析命局：

丙火日主生在辰月失令，坐戌土失地，地支辰戌相冲，丑戌相刑，把土冲旺，泄身力量较强，时柱己丑干支一气，也是泄身的五行，年干透出戊土，也来泄身，年支寅木来生扶日主，月干丙火来帮身，但丙火日主失令失地，依然为偏弱之格。年干戊土食神从月令辰土中透出，为食神格。

# 分析喜忌：

偏弱以生扶日主的木火五行为用神，以泄耗日主的土金五行为忌神，水虽克身，但在地支生木为吉。八字辰土当令，辰戌相冲，地支土旺成势，喜见木来疏土，单独见火，也来生土不吉，不喜多见，天干喜见木来制土生火。

# 分析事业：

月干丙火为用，丙火在帮身的同时，也来生戊土和辰土，为用神化忌，稍有不利。年支寅木也为用神，寅木来制戊土和辰土为吉，但地支辰戌相冲，丑戌相刑，土旺成势，寅木势单力薄，有被土反克之象，属于忌神猖獗，用神无力，为不足之处。

原局为食神格，辰土当令较旺，辰戌相冲，把土冲旺，时柱己丑干支一气为伤官，虽有寅木来制食神，但弱木难制厚土，会体现为性格有一些固执任性，食伤旺，不见官杀，也会体现为性格喜欢自由一些，内心不是很安分，比较要强，有时候自制力也不强。

加上丙火日出生，地支辰戌相冲、丑戌相刑，有时候容易急躁冲动，做事也比较缺乏耐心，容易焦虑，自我纠结，自我烦恼，有时候有些理想化，脱离实际。

丙戌日出生，食伤旺，为人也懂得付出，不过食伤泄身太过，印星制食伤无力，也会体现为做事精力不够，容易感到累，加上五行火弱，也比较缺乏积极性。

一般来说食伤代表口才，但五行土的食伤就一般了，加上食伤旺为忌，没有强有力的制化，也会体现为想得多，操心操劳多，容易胡思乱想，自寻烦恼。

加上丙戌日出生临华盖和太极贵人，时柱临寡宿，年支寅木为偏印，性格偏内向，容易自己感到孤独，不合群，久了会社恐，喜欢安安静静一个人，孤独感较强，不喜欢嘈杂，也有怪异的一面。

寅木印星离丙火日主较远，比较缺乏安全感，原局见偏印、华盖、太极贵人、戌土，对神秘文化、易学文化、传统文化等比较感兴趣，戌土为佛教，也有比较深厚的佛教缘分。

丙火为网络，戌土为平台，也可以从事计算机、IT相关方面比较适合你。五行喜木火相生为用，有文化之意，加上食神较旺，印星为用，也可考虑教育文化相关行业，相对更加适合偏自由一些的行业和职业。

所以公务员、事业单位等不是太适合你，与其纠结，不如果断放弃，考编的话可以考虑下教师，喜印能多考证也为佳，或者有考研的想法也可以尽快行动起来，专业可以考虑上述方面，今年癸卯年，明年甲辰年，2025乙巳年，都有不错的考学运，可以重点把握下。

食神较旺，食神旺的人一般都比较爱吃，也容易暴饮暴食，多会长胖，所以在这个方面要多注意为好，多“管住嘴”，加强身体锻炼为好，有益身体健康。食伤旺，地支刑冲较多，也要注意心理健康，容易有抑郁等心理问题。

结合大运走势来看，早年的乙卯大运，甲寅大运，运势不差，但现在走的癸丑大运，以及未来的壬子大运，辛亥大运，庚戌大运，运势均较为一般，并非太理想的运气，所以未来能求稳发展为好，期望值不宜太高。

# 分析婚姻：

原局不见官杀，唯有月令辰土和时支丑土暗藏癸水正官，癸水官星在辰土墓库之中，为夫星入库，加上丙戌日出生临华盖，太极贵人，时柱临寡宿，这种组合代表自己较为孤独，异性缘分较为薄弱，或者缘分来了自己不容易把握住。想落实婚姻感情需要自己多主动为好，能相亲、经人介绍也是一个不错的选择，多为晚婚之命。地支辰戌相冲，婚后也要多注意磕磕绊绊，会为了家庭、孩子等付出较多。

从未来的感情婚姻运来看，2023癸卯年，地支卯木为桃花，天干癸水正官夫星出现，地支卯戌相合，婚姻宫被合动，有一定异性缘分，要主动把握为好，合来解冲，有机会结婚或2024年合住伤官星，引动婚姻宫时有结婚运气，要好好把握，要不然要多等好多年，到2032年，2033年才有机会遇到。
