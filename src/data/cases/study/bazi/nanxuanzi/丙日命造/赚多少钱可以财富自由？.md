# 八字详批：

# 分析命局：

丙火日主生在戌月失令，戌土虽为燥土，暗藏丁火，有一丝火气可以帮身，但戌土被两个子水贴身，热气并不旺，且戌土的本气为戊土，主要起到泄身之用，坐子水失地，时干透出戊土来泄身，时支戌土伏吟，也来泄身，年支子水伏吟来克身，年干和月干甲木来生扶日主，为偏弱之命。时干戊土食神从月令戌土中透出，为食神格。

# 分析喜忌：

丙火日主偏弱，以生扶日主的木火五行为用神，以泄耗日主的土金五行为忌神，水虽克身，但在天干生木为吉，戌土当令较旺，时柱戊戌干支一气为土，且子水伏吟被夹克，故地支喜见木来疏土，天干甲木透出来生丙火，故喜见水来生木，最不喜见庚金来制甲木，火虽帮身，但生土也不太好，好在木火土流通相生。

# 分析事业：

丙火为太阳之火，在秋季出生，五行土旺，土重而无光，丙火生于戌时，夜幕降临，也代表丙火黯淡无光，故而从调候的角度喜见壬水透出来反映丙火的光芒，构成壬丙相照为吉，只可惜不见壬水，地支虽见子水，但被夹克，难以反映丙火光芒，故而贵气少了几分，也代表事业上想取得一定成就不太容易。

食神格的组合，同时戌土食神当令，时柱戊戌也为食神，月干甲木印星贴身，丙子日出生临天德贵人和月德贵人，故懂得付出，性格较为温和，懂得为他人着想，比较仁慈善良，地支子水正官伏吟，不过五行土比较厚，也有死板固执任性的一面，同时子水正官被戌土食神所制，缺乏威仪，有一些懦弱，为不利事业发展的地方。

原局为食神格，食神较旺，食神克正官，内心较不安分，不太安分守己，比较向往自由，不喜欢被束缚太多，子水官星被食神所制，也代表做事很难坚持，时间久了容易倦怠，食神太旺，内心想得太多，想要的也太多，会因为求不得而心生烦恼，也会有些好高骛远。

看事业，有官星首论官星，年支和日支子水为正官，但官星被戌土食神所制，地支又不见财来生官，官星受损无力，原局来看事业运不强，难有太大突破和发展。子水官星在地支不透，且丙火黯淡，求名也不容易。不过，好在年柱甲子官印相生，印来生身，印星贴身为用，可以取得一份相对稳定的工作，也适合上班求财。

食神格，原局身弱，适合依靠一技立身，年月甲木为枭神，很适合偏门学术，有钻研学习的能力，也有社会性学习之意，丙火为互联网，戌土为平台，如果早些年你可以投身互联网技术，出生社会后再学习，然后进大一些的平台，定能有所发展。

甲木枭神贴身为用，丙子日出生临将星，时柱戊戌，命局双戌也有军队的意思，公检法军警，执法辅警，从事偏武职方面的工作也是可以的，当律师若能满足于稳定与平凡，也并非不可。

你现在走的是丁丑大运，地支子丑相合，伤官克官，且丑戌相刑，旺了土气，故而很容易产生职业倦怠，对工作有所不满，土重而无光，官星被合克，也代表事业上难以取得升职发展，刚好对应你从律的八年。

2023癸卯年，地支卯戌相合，卯木来疏土，且作甲木根，总体也是不错的，故而再咬咬牙坚持下，或许现在就是黎明前的黑暗。

原局食神格，食神入门户，丙子日临天德贵人和月德贵人，故很适合围绕服务、餐饮方面求发展。甲木枭神贴身，也适合比较偏门冷门的行业，再加上喜木，又临天月二德和太极贵人，也可以围绕医药养生，针灸推拿等方面去发展事业，但我不是很建议转行，第一方案还是稳住目前的行业，尽人事听天命。

四柱无财，只有地支戌土暗藏辛金正财，不见偏财，戌土为火墓，暗藏丁火，辛金在火墓之中被丁火劫财所克，有劫财克财之象，故财运不强，原局为食神格，食神入门户，多为衣食无忧，难见大财，且花销破耗较多，故而想实现社会上的所谓财富自由很难。结合大运来看，未来走的东方木运，运势尚可，但也有一些小波折。

# 分析婚姻：

四柱无财，戌土暗藏辛金正财，临寡宿，有劫财克财之象，且辛金财星藏而不显，加上全为阳干支，异性缘分不是很好，多为晚婚之命，想落实婚姻需要自己主动追求才有机会，不会太容易。2017丁酉年，地支酉金正财出现，遇到的人多为正缘，酉金临桃花和天喜，长相和气质较为不错。

不过，丙子日出生为阴差阳错日，临太极贵人，以辛金正财为妻，藏而不显且临寡宿，也有夫妻感情冷淡之象，夫妻之间容易产生隔膜，感情和缘分不够深厚，日支婚姻宫为子水忌神，被戌土夹克，婚姻环境不是很好，婚姻幸福感不高。

辛金妻星暗藏于戌土之中被丁火所制，辛金受损，故妻子很容易身体不好，也有妻子条件和出生不好的象，若妻子多病、条件一般，反而有利婚姻的稳定。

你现在走的是丁丑大运，地支丑戌相刑，又子丑相合，虽有动婚之象，但婚姻宫子水被合克，婚后难免也有不如意之处，辛丑年必然是比较煎熬的一年，壬寅年稍好，癸卯年，子卯相刑，婚姻宫被刑伤，也为不利，婚姻变动不是没可能。
