# 身弱财旺的人

命主生辰: 1998/10/06 16:00 (GMT+8)
性别: 乾造
日主: 丙火
格局: 正财格
令地: 失令, 失地

# 网友来信：

我是从小老实到大的，性格内向静敛喜欢独处，小时候亲戚都说我像姑娘似的，我也很无奈天生的性格有什么办法改变呢。

因为我的性格这些年吃了不少苦头，上初中时也是倒霉的很，真是人善被人欺呀，也是那时我染上了sy的坏习惯，上完初中我就跟变了个人一样，不爱交流，不想社交，直到现在我还是老样子，甚至变本加厉，变得社恐起来，我的人生就从初中变了样子，回想以前的时光是多么美好。

感情方面也是白纸一张，这些年倒也有一些露水情缘，不过都停留在表面，没有下一步了，我这性格也是不招人喜欢的，女孩都喜欢自信阳光的其实我也想改变，但是无力回天。

家庭收入也是一般般，母亲在家务农，父亲是开大货的但是父亲他不是勤快人，没攒多少钱。母亲也是因为父亲不求上进争吵不休，我记忆中他们就是从年轻吵到老的，我也是初中毕业就打工去了，干了几年攒了五六万，都拿回家补贴家用了，我花钱是比较省得，因为没有喝酒抽烟这些坏习惯，也不大出去玩。17年母亲又给我生了弟弟，弟弟小我20岁，想想以后真是压历山大…

但是来了就是缘分，无缘不聚吗，去年姥姥去世，姥姥一辈子舍不得吃穿艰苦朴素，只为了子女，时间久了就累病倒了，我很痛心，怎么好人就不长命呢，己亥年至今一直待业在家，主要是我这性格是硬伤，不想跟人社交。

>
> 2：我能有婚姻吗，婚姻状况如何呢，她是什么样的人呢，我找什么样的对象合适，因为我比较注重婚姻家庭，就想过过老婆孩子热炕头的生活，我的性格会不会对婚姻造成影响，婚姻中有要注意的吗？
>
> 3：父母健康有需要注意的吗，父亲是开大货的，因为喝酒脑子也是一团糟，就怕他在路上出点什么事，母亲骨关节不太好经常疼，脾气也是不太好，容易多想想不开，父母上了年纪会有灾吗。

# 八字详批：

#### 乾造：戊寅年，辛酉月，丙戌日，丙申时（午未空）

# 分析命局：

丙火日主生在酉月失令，坐戌土失地，、时支申金来耗身，月干透出辛金，也是耗身的五行，年干透出戊土来泄身，年支寅木来生扶日主，但被酉金所制，又地支寅申海底冲，寅木有损，生扶力量不强，时干丙火来帮身，但依然为偏弱之格，月干辛金正财从月令酉金中透出，为正财格。

# 分析喜忌：

偏弱以生扶日主的木火五行为用神，以泄耗日主的土金五行为忌神，水虽克身，但在地支生木为吉。八字酉金当令，金来克木，喜见水来通关生木，也可见火来制金，单独见木，金木相战，土木相战，稍有不利。天干喜见木来生火。

# 分析事业：

年支寅木为用神，但寅木被月令酉金所制，又寅申海底冲，寅木有损，地支也不见水来生木，忌神制用，用神无力，为不足之处，时干丙火也为用神，但丙火在申金之上虚透无力，在地支无强根，故整体而言，组合较为一般。

时干丙火比肩帮身为用，有一定上进心，懂得团结他人，原局为正财格，月柱辛酉干支一气为正财，天干地支为食神生财的组合，年干戊土食神高透，代表野心和欲望较大，比较注重物质享受，占有欲较强，财多耗身，身弱不能担财，会因为求财产生很大压力和很多烦恼。地支为财星克印的组合，一般都不利学业，较难取得高学历高文凭。

丙火日主在地支无强根，且丙戌日出生，日坐戌土为墓库，临华盖和太极贵人，性格偏内向文静一些，比较喜欢安静一个人，不喜人多或与人打交道，有时候比较缺乏主见，日坐食神，故懂得付出，为他人着想，有奉献精神，本质上比较仁慈善良，但财星较旺，酉戌相害，酉金当令，戌土有损，也有死板固执任性的一面，难免会任性纠结方。

丙戌日出生，日坐戌土为食神，在年干透出戊土，而不见官杀，地支藏而不显，一般自制力较为缺乏，内心也比较崇尚自由，不喜被约束太多，多喜欢偏自由一些的职业，做一件事或一份工作时间久了容易有倦怠心理，加上丙火日主在地支无强根，故做事不易坚持到底，遇到困难容易心生动摇，打退堂鼓。

丙戌日出生，日坐戌土为食神，一般比较追求精神享受，财星旺，也喜欢物质享受，有的时候有些懒。戌土为火墓，为香火之地，又临华盖和太极贵人，年支寅木为偏印，一般都会对国学文化、神秘文化等比较感兴趣，也有这些方面的缘分。

天干地支为食神生财的组合，代表能有一技傍身是最佳选择，若有过硬技术，可依靠技术去求职，丙辛相合，正财合身，能依靠技术上班是最佳选择。命局喜木火，食神生财，可以考虑从事服务业、餐饮、绿化、医药养生、针灸推拿等方面工作，丙戌日出生，也可考虑互联网等方面的技术，你现在年龄也不大，能去抓紧学一门手艺，对未来发展非常有利，你想学习焊工行业，五行属火，为命局用神，可以去做。

时干丙火比肩帮身，也很适合跟着别人去做，适合合作求财，靠自己较为困难。至于开大货车，从你的命局来看不适合你，建议你趁年轻去学习技术。也适合外出发展，出生地的东方，南方，东南方比较旺你。

身弱财旺，丙火日主在地支无强根，求财辛苦，地支寅申相冲，申金财星逢冲，且辛金财透天干，两个丙火争合辛金，代表花销较大，容易破财，要多注意。

结合大运走势看，现在走的是甲子大运，运势不差，未来的乙丑大运，稍有下滑，到了丙寅，丁卯大运，财运会好一些。

# 分析婚姻：

丙戌日出生，日坐墓库，临华盖和太极贵人，相对偏内向的一个人，比较沉默寡言，原局正财格，财星当令较旺，月柱辛酉干支一气为财星，时支申金也为财星，财旺成势，身弱不能担财，反而容易在女孩面前自卑懦弱，望而却步，姻缘来了自己不容易把握住，容易错过。

身弱财星当令较旺，未来多为妻子当家，也代表妻子性格会相对强势一些，会让你感到一定压力。地支酉戌相害，婚姻宫受损，也代表婚姻环境并非太好，磕磕绊绊较多。临华盖和太极贵人，多为晚婚。尤其需要注意的是，先正财后偏财，天干比肩夺财，要注意妻子和自己婚外情缘问题。

2023癸卯年，地支卯酉相冲，酉金妻星被冲动，卯木临桃花，或者2024甲辰年，地支酉辰相合，酉金被合动，有机会遇到缘分。

以正印为母，以偏财为父，时支申金为偏财，得戌土生扶，申金临驿马，也有父亲动中求财的意思，不见正印，以寅木偏印为母，年支也为母亲的宫位，寅木被制，且寅申相冲，寅木有损，代表母亲身体健康欠佳，尤其逢虎年、猴年、蛇年的时候要多注意下。
