# 八字详批：

#### 乾造：丁丑年，癸丑月，乙亥日，丁丑时（申酉空）

# 分析命局：

乙木日主生在丑月失令，坐亥水得地，年支和时支丑土伏吟来耗身，年干和时干丁火来泄身，月干癸水来生扶日主，但被丑土戳脚，生扶力量较弱，日支亥水在地支也被丑土所制，生扶力量不强，故依然为身弱之格。月干癸水偏印从月令丑土中透出，为偏印格。

# 分析喜忌：

偏弱以生扶日主的水木五行为用神，以泄耗日主的火土五行为忌神，五行金虽克身，但在天干地支生水为吉。丑土当令较旺，伏吟地支，最喜见金来通关生水，由于申亥相害，更喜见酉金。命局偏寒，也需要适当的火来暖局调侯。

# 分析事业：

月干癸水和日支亥水为命局用神，但地支亥水被丑土所制，月干癸水被丑土戳脚，为忌神制用，用神无力，癸水和亥水都被制，且不见金来生水，癸水和亥水没有元神，用神被制，而忌神没有强有力的制化，也为不利。

以印星为用神，印代表关心和爱以及贵人，癸水和亥水印星为用贴身为用，本来是好的，但印星被财星所制不吉，同时也代表缺少安全感。而且癸水和亥水为正偏印同见，兴趣容易杂而不专，同时乙亥日出生，日坐驿马，也代表代表容易心思不定，人比较浮躁。

年柱和时柱丁丑伏吟，为食神生财的组合，财为偏财，一般都代表欲望较强，物欲较重，内心比较注重金钱，不太容易得到满足。财多耗身，也会因为求财产生一定压力，为钱财所累。乙木日主在地支无强根，同时财星克印，做事缺乏耐力，遇到困难容易打退堂鼓。

乙亥日出生为十灵日，地支三个丑土伏吟，华盖重重，且丑土一般代表为道教，加上原局为偏印格，癸水偏印贴身，代表会对神秘文化、国学文化、传统文化等比较感兴趣，也有这方面的悟性，可以在工作之余多研究下，但想以此为业不太建议。

年干和时干丁火食神透出，食神本为忌神，但有癸水印星来制，故可以围绕食神发展，从事一些技术方面的工作，而乙木生于丑月为寒木，寒木喜向阳，也可见一点火，软件行业五行属火，是可以做的。除此之外，五行喜水木，可以做一些水木相关的行业，如花卉、服装、医药、水业、饮料、酒水、航运等，会更加有利事业财运，若有转行的想法可以考虑这些行业，但依然要以技术为主。

另外，原局乙木为笔，癸水为墨，丁火为灯，三象俱全，同时命局喜印，丁火食神虽为忌神，但有癸水来制，食神可以代表学生或晚辈，而且地支见三个丑土，丑为印墓，印墓为文化场所、文化汇聚之地，所以从事教育文化相关行业也是适合的，能转行教育文化行业会比较适合，哪怕依靠自己的专业去一些技术学校去作培训也是可以的，丁火食神透出，也有一定口才，这方面也可以考虑。

丑土偏财当令，伏吟地支，年柱和时柱丁丑为食神生财的组合，也有做生意的信息，但身弱财旺，能得到的财较为有限，唯有大运助身，方有更好的财运。

你现在走的辛亥大运，整体运势不差，但马上过了，未来的庚戌大运，己酉大运，戊申大运，财运均较为一般，故而不太建议去做生意，能上班求财比较好。

# 分析婚姻：

地支三个丑土偏财伏吟，偏财当令，身弱财星太旺，但没有强有力的制化，财星虽多反而较难得到这个财，也就是说，在择偶上并不太顺利，遇到异性也容易望而却步，缺乏自信，财星当令，未来多妻子当家，妻子会强势一些。

丑土伏吟地支，临华盖，代表妻缘不深，想得到婚姻感情并不容易，自己多主动些为好，能相亲、经人介绍是个不错的选择。而且丑土伏吟较多，日支婚姻宫为亥水，临驿马，代表婚姻感情容易变动，晚婚一些结婚比较好。

接下来要等到2027丁未年，食神生财，未土妻星出现，且丑未相冲，丑土妻星动，2028戊申年，天喜入命，有遇到和结婚的运气。

在你的身体健康方面，地支丑土伏吟，丑土太旺，故容易有脾胃，皮肤方面问题，现在走的辛亥大运，没有引动丑土动，故病情会好一些，但从后年起进入庚戌大运，地支丑戌相刑，难免病情不稳定，也容易反复，己酉、戊申大运稍好一些，但到了丁未大运，丑未相冲，又有加重的可能性，这两步大运多注意下。
