# 八字详批：

#### 乾造：戊寅年，丁巳月，乙丑日，丙戌时（戌亥空）

# 分析命局：

乙木日主生在巳月失令，坐丑土失地，但丑土暗藏癸水，有一定助身之用，时支戌土也是耗身的五行，并在年干透出戊土，均来耗身，时干透出丙火来泄身，月干丁火也是泄身的五行，唯有年支寅木来帮身，但寅巳相害，寅木有损，帮身力量弱，乙木日主弱而不从，依然为偏弱之格。时干丙火伤官从月令巳火中透出，为伤官格，年干戊土正财透出，也为正财格，但巳火的本气为丙火，所以主要表现伤官格的特性。

# 分析喜忌：

偏弱以生扶日主的水木五行为用神，以克泄耗日主的火土金五行为忌神，地支巳火当令较旺，最喜见水来制火生身，由于巳亥相冲，更喜见子水。天干火土两旺，喜见水来制火生身，但丁壬相合，戊癸相合，助身力量并非太理想，天干地支木虽帮身，但来生火也为不吉。

# 分析事业：

原局为伤官格，巳火伤官当令较旺，月干又见丁火食神，食伤较旺，为命局最大忌神，也为“凶神”，是一定要有制化的，但奈何不见印星来制，唯有伤官来生财，财来耗身，全局唯独年支寅木劫财为用，但不能很好制财，反而被巳火所伤，所以从组合来看，不是太好，只有岁运来弥补命局的不足，方可更加顺遂。

从调候的角度来看，乙木生于巳月，为夏季之木，天干又见丙丁火相随，火势太旺，喜见水来调候，水也为命局的印星，但不见水，唯有日支丑土暗藏癸水，藏而不显，且丑戌相刑，丑土暗藏的癸水有损，所以调候无功，也为不利之处。一般命局太热、太燥或者太寒，都不是太好的组合，定有不如意之事。

为伤官格，伤官较旺而无制，月干又见丁火食神，一般想法非常多，但容易胡思乱想，天马行空，杂乱无章，内心不太安分，做事也不太专注。年支寅木可以看作乙木日主的远根，但寅巳相害，寅木有损，容易能力有限。

伤官太旺而无制，性格难免会任性傲慢，比较爱面子，自尊心强，有时候容易找不准自己定位，认为自己与众不同，自命不凡，取得成绩的时候容易飘飘然，得意忘形而目中无人。

食伤较旺，官杀暗藏，一般都比较喜欢自由，不喜被束缚太多，有一些叛逆，也代表自制力较为缺乏，不太管得住自己。不过好在月干丁火食神透出相随，也有性格温和的一面。

食伤较旺，地支巳火伤官生财，且丑土为偏财，一般都有一定贪欲，不太容易得到满足，求财的欲望较强，有时候容易贪图享受，财星太旺，不见印星，食伤无制，一般学习成绩都不会太好，考学运不是太理想。

伤官格，时干丙火伤官高透，月干见丁火食神，一般口才都不差，且不见官杀，故适合一些偏自由的职业，从事咨询讲解、培训、技术相关职业较为有利。乙木日主被丙丁火贴身，时支戌土为食伤库，身弱喜印，故也适合从事教育文化相关行业，提到的这些方面都可以考虑下。

至于从商之事，伤官生财，有从商的信息或者这个想法，但乙木日主较弱，乙木的远根寅木有损，不能担财，唯有大运助身才可担财。

现在走的己未大运，未来走的庚申，辛酉大运，大运均不来助身，到了壬戌大运、癸亥大运，要稍微好一些。所以不建议经商，即使勉强要做，也要到癸亥大运的时候做要好一些，可以赚到一些钱，否则极易亏损。

# 分析婚姻：

年干戊土为正财，日支丑土为偏财，时支戌土又为正财，正偏财同见，且火旺土相，财星较旺，身弱不能担财，会因为婚姻感情产生一定压力，在异性面前容易缺乏自信，也代表未来妻子多比较强势一些，条件和能力较为一般，对他帮助不大。

先见正财，后见偏财，再见正财，日支婚姻宫为丑土偏财，妻星正财不入主位，代表容易经历失败的感情。乙丑日出生临寡宿，月柱临孤陈，时柱临华盖，均代表有一些孤独，能主动追求为好，地支戌未相刑，婚姻宫被刑伤，也要注意婚后夫妻不和之事。

他现在走的是己未大运，干支一气为偏财，有一定异性缘分。2023癸卯年，天干戊癸相合，地支卯戌相合，妻星被合动，且卯木为桃花，有遇到缘分的机会。2027丁未年，地支丑未相冲，婚姻宫逢冲，且天喜入命，有结婚的机会，只是地支三刑注意节外生枝及一些涉及钱财方面的问题需要商讨。

至于身材之事，八伤较旺，尤其是食神较旺，一般代表比较爱吃，为美食主义者，很容易长胖，接下来走的庚申、辛酉大运，对食伤并没有太多制约，所以多保持现在身材，到了壬戌大运，丁壬相合，丁火食神受制，多会瘦下来。

# 分析大运：

**27岁—36岁**

庚申大运，此大运干支一气为正官，天干乙庚相合，正官合身，地支寅申相冲，寅木用神有损，故总体运势较为一般，事业上压力较大，比较辛苦忙碌，能上班求财为好，且地支寅巳申三刑，要注意口舌是非、与人不和等事。

**37岁—46岁**

辛酉大运，此大运干支一气为七杀，。天干丙辛相合，丙火伤官被合拌，地支巳酉丑三合，巳火伤官也被合拌，故整体运势一般偏好，事业有升职发展的机会，人缘不错，可以得到他人相助，婚姻相对也和谐一些，但求财依然辛苦，付出较多收获有限。

**47岁—56岁**

壬戌大运，此大运天干壬水被地支戌土戳脚，为财星克印的大运，天干丁壬相合，丁火食神被合克，食神有制，总体运势稍好一些，有升职发展的机会，地支戌土引动丑戌相刑，要注意夫妻不和之事，婚姻压力较大，也要注意妻子身体健康。
