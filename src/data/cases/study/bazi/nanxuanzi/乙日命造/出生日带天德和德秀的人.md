# 分析命局：

乙木日主生在亥月得令，坐卯木得地，卯木为乙木日主的禄神，帮身力量不弱，年支子水也来生扶日主，时干透出甲木来帮身，时支申金来克身，月干己土来耗身，天干甲己遥合，合而不化，年干丙火来泄身，但丙火被子水戳脚，泄身力量不强，依然为偏旺之格。

# 分析喜忌：

偏旺以泄耗日主的火土五行为用神，以生扶日主的水木五行为忌神，五行金虽克身，但在地支生水不吉。亥水当令，水旺生木，地支喜见土来制水，尤其喜见燥热之土，不喜见寒湿之土，也同时喜见火来生土。天干喜见火来泄身，火来生土。

# 分析学业和事业：

偏旺以月干己土为用，己土得丙火生扶不弱，月柱亥水被己土盖头，为用神制忌，较为吉利，但由于丙火被子水戳脚，为忌神制用，用神无力，故己土的元神受损，有一些不利，时柱甲申，甲木被申金戳脚，甲木为忌神有制也为吉，所以组合不差。

亥水印星得令较旺，年支又见子水印星，生扶力量不弱，正偏印同见，虽有丙火伤官来泄身，但丙火被子水戳脚，印克伤官，故性格略死板，容易钻牛角尖，比较固执，不太会变通，做事有时候不够果断，思虑重重，容易犹豫不决而错失一些机会，有时候心眼不大，容易斤斤计较，会阻碍学业和事业发展。

丙火伤官较弱且被制，印星旺，有时候容易滋生负面思想和情绪，也有一定依赖心，独立性稍差。不过好在月干己土财星制印，丙火伤官透出，时支申金为官星，也代表有一定上进心和事业心，人也比较要强，自尊心较强。

乙卯日出生临天德贵人和德秀贵人，本性是比较善良的，又见丙火伤官透出，可以奉献付出，可以为他人着想，为吉利之处。

身旺年干丙火伤官透出，月柱己亥，财星克印，时支申金官星入门户，有官方文凭的意思，故可以取得一定学历和文凭，但由于年柱丙子，丙火被子水戳脚，印克伤官，且地支子水和亥水正偏印同见，也就打了折扣，代表多考取比较二流的学校，想考上重点较为困难。

你早年9岁上运后走的是庚子大运，为官印相生的大运，虽地支子水印星旺，但没有损丙火，故学业还算顺利，不过到了辛丑大运，天干丙辛相合，丙火伤官被合绊，故整体运势，包括考学运有所下滑，学业运有起伏。

好在今年是该大运最后一年，马上过了。但依然不可太过乐观，因为从明年起进入壬寅大运，天干壬丙相冲，丙火伤官被冲克，代表运势依然不理想，到了癸卯大运，癸水来制丙火，也非太好的运气，但比之前要稍好一些。

甲辰大运，乙巳大运，天干甲乙木虽为忌神，但也旺了丙火，运势会逐步好起来，属于中晚年有福的人。

比劫较旺为忌，且乙木日主被甲木和卯木比劫贴身，均为忌神，代表事业环境不是太理想，事业上竞争大，容易犯小人，遇人不淑。

天干甲己遥合，为劫财夺财，代表挣来的钱也容易因为各种原因花出去，财星虚透天干不聚财，花销大，平常要注意理财比较好。不过乙木见甲木为藤萝系甲，代表事业上还是有贵人相助。

伤官生财为用，可以考虑从事一些营销、广告、传媒、教育、文化、培训相关的工作，会相对适合你一些，今年癸卯年，为印比的年份，天干癸水印克伤官，故整体运势不是太有利，找工作并没有太好的机会。

2024甲辰年，甲木旺了丙火，相对机会要多一些，可以先稳一年，多方投简历，也可以先就业再择业。

# 分析婚姻：

命局不见正财，唯有时支申金暗藏，藏而不显，月干己土为偏财，不见正财乱局，代表对待婚姻感情比较专一的一个人，伤官生财，也比较关心体贴另一半，但甲己相合，劫财克财，难免有时候有一些直来直去，冷淡僵化的情况，自己在感情相处中要注意。

尤其是乙卯日出生，日支婚姻宫为比肩忌神，也有脾气不和，互不退让之象，地支子卯相刑，婚姻宫被刑伤，也代表感情难免发生冲突矛盾，婚姻环境不佳，要多注意，也要注意自己的性格，学会退让包容为好。
