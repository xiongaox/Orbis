# 八字详批：

#### 坤造：戊寅年，辛酉月，乙酉日，辛巳时（午未空）

#### 大运：庚申，己未，戊午，丁巳，丙辰，乙卯，甲寅，癸丑，9岁运。

# 分析命局：

乙木日主生在酉月失令，坐酉金失地，地支酉酉自刑，克身力量不弱，月干和时干透出辛金，也来克身，年支寅木来帮身，寅木为乙木的羊刃，但在地支孤立无援，且被酉金所制，帮身力量较弱，年干戊土来耗身，时支巳火来泄身，乙木日主在地支有根，弱而不从，依然为偏弱之格。天干辛金七杀从月令酉金中透出，为七杀格。

# 分析喜忌：

偏弱以生扶日主的水木五行为用神，以克泄耗日主的火土金五行为忌神。地支酉金当令，伏吟地支，五行金旺克木，喜见水来通关生木，地支也可见火来制金，由于寅巳相害，更喜见午火。天干喜见水来通关生木，单独见木，金木相战，较为不利。

# 分析事业：

身弱只有年支寅木为用，但寅木在地支也是被酉金所制，为忌神制用，用神无力，寅木为乙木的根，“有根怕根损”，较为不利，原局为七杀格，七杀较旺，逢杀看印，有印化杀为权，也为吉利，但原局不见印星，组合较为不利，不过好在时支见巳火伤官，虽然身弱巳火为忌，但制忌神的五行也可以当用神来看，巳火可以制辛金和酉金，也为吉利之处。

原局为七杀格，七杀较旺，辛酉金七杀包身，事业心较强的一个人。而乙木日主虽在地支有寅木根，但寅木被酉金所制，寅木根损，很难踏踏实实在一个领域坚持太久，容易跳槽、另起炉灶等，七杀也代表阻碍和小人，不管做什么事遇到的困难阻碍多，自己也容易顶不住压力而放弃，导致事业变动也较多。

七杀较旺包身，不见印星来化杀生身，唯有时支巳火来制辛酉金七杀，但巳火较弱，七杀太旺，伤官制杀无力，造成七杀攻身，故精神压力较大，容易有思想包袱，并不轻松，地支酉酉自刑，有时候性格也比较极端，容易急躁冲动，耐心不足，也要注意压抑抑郁。

七杀攻身也比较没有主见，忧虑忧愁多，容易犹豫不决，没有魄力，也会因此错失良机。会比较辛苦，难得清闲，做事一般比较讲原则，自己对自己有一定要求，但有的时候也会因为一根筋，过于死板。

看事业方面，有官杀先论官杀，原局七杀太旺，不见印星来通关，巳火伤官制杀无力，所以总体事业运不强，较难取得太好的发展，难有太理想体面的工作，事业上也易有天花板。

官杀为官鬼，有小人、是非之意，故要防他人算计坑害，凡事不可轻信于人，注意是非口舌之事，有的时候容易冲动上头，别人激，当枪使，这是要注意的。

身弱而难以胜七杀，会因为事业而负担很重，又有戊土财星来滋杀，七杀攻身，故在内心不可将工作、钱财追求太过，尽力就好，否则反而会生是非，给自己带来不利。

喜印而不见印，多和父母缘分不深，一般也较难得到祖上相助，多为白手起家之命，凡事都要依靠自己。

尤其早年走的庚申大运，干支一气为正官，并非太好的运气，所以早年有留守儿童经历，喜印而不见印，运势也不利，故也较难在学业上有所突破，多会半途而废。现在走的己未大运，干支一气为财星，财来滋杀，也非太好的运气。

后面的戊午大运，丁巳大运，大运食伤来制七杀，会比之前稍好一些，丙辰大运，一般偏好，为可喜之处。

你的命局七杀太旺，为命局最大弊端，所以未来的发展可以考虑两个方面，一是身弱喜印而不见印，能想办法留在幼儿园，学校属于印，能从事幼师，会较为理想，可以想办法多争取下。

二是喜食伤来制杀，且巳火来制酉金和辛金，寅木为羊刃，七杀来制羊刃，故有一定管理能力，可以进企业从事管理相关，尤其未来走的食伤南方火运，也适合朝这个方向努力，能在企业管理项目，当项目经理，会是非常理想的发展。

不过你现在因为要带小孩，也没有太多的选择性，所以选择在幼儿园工作是目前相对好的选择，先上路了再看其他机会，很多时候都不是一步到位的。

# 分析婚姻：

乙木日主被辛酉金七杀包身，七杀为忌，没有强有力的制化，不见正官来乱局，代表对待感情较为专一，但七杀攻身，七杀为夫星，会因为婚姻感情而产生一定压力，也代表丈夫条件和能力等较为一般，对你帮助不大，较难嫁贵夫，故也不宜对另一半要求过高。

地支酉金伏吟，酉酉自刑，婚姻宫被刑伤，乙酉日出生，日坐酉金临绝地，有绝情的意思，也代表婚姻压力大，夫妻感情容易冷淡僵化，七杀太旺，一般丈夫都比较强势，脾气不太好，有家暴倾向，是要注意的，地支巳酉半合，伤官制杀，两个人相处久了难免会不满挑剔。

丈夫乾造：**已卯年，丁丑月，丙戌日，时辰未知**，丙火日主生在丑月失令，坐戌土失地，月干丁火来帮身，年支卯木来生扶日主，年干己土来泄身，地支丑戌相刑，泄身力量不弱，为身弱之格，以木火为用神，以土金为忌神，水虽克身，但在地支生木为吉。
丈夫身弱食伤旺，比较任性傲慢的一个人，做事有一些好高骛远，地支丑戌相刑，丙火日出生，日坐戌土，也容易急躁冲动，脾气不太好，地支卯戌相合，丑土相星，先合后刑，婚姻宫被刑伤，也代表婚姻不太有利，夫妻易有矛盾不和。

他现在走的是乙亥大运，天干乙木印星来助身，地支亥水杀印相生，整体运势不差，从今年开始，会逐步好起来，未来的甲戌大运，运势不如现在，但也不差，但到了癸酉大运，壬申大运，运势不太理想，所以趁年轻多打好基础，确定方向为好，建议以技术立身为佳，可以考虑互联网相关。

他的五行土旺，是你的忌神，你的五行金旺，也是他的忌神，喜忌不能互补，在一起对对方运势帮助不大，你们两个人有卯酉相冲，酉戌相害，巳酉丑三合，所以整体合婚匹配度属于中等偏下水平，想一婚到底较为困难，尤其丈夫28岁后进入甲戌、癸酉大运，婚姻运势不太有利，想在一起要互相包容为好。

在你的身体健康方面，五行不见水，要注意肾脏，膀胱，妇科，泌尿系统方面问题。乙木太弱，七杀克身，寅巳相害，容易失眠，熬夜，意外伤害，也要注意肝胆，经络，甲状腺方面问题。酉酉自刑，也要注意抑郁症。戊土被寅木戳脚，也要注意脾胃，皮肤方面问题。

# 分析大运：

**20岁—29岁**

己未大运，此大运干支一气为财星，天干地支财星旺了七杀，七杀来攻身，故整体运势不太有利，没有太好的事业运，会因为求财和事业产生一定压力和烦恼，事业上阻碍较多，机遇缺乏，也要注意小人是非，财运也不太理想，婚姻也有压力。

**30岁—39岁**

戊午大运，此大运为食神生财的大运，天干戊土财星旺了七杀，事业压力依然较大，要多克服，注意小人，求财较为辛苦，付出较多，收获有限，地支午火食神制杀，也有一定事业运，能做管理，有机会做出一定成绩，要好好把握。

**40岁—49岁**

丁巳大运，此大运干支一气为食伤，天干丁火食神制杀，地支巳火伤官合杀，整体运势稍好一些，有机会施展才华，做出成绩，事业上有升职发展的机会，但伤官制杀，也要注意夫妻关系，易有磕磕绊绊。寅巳相害，要注意肝胆，经络等方面问题。

**50岁—59岁**

丙辰大运，此大运为伤官生财的大运，天干丙火伤官透出，丙辛相合，伤官合杀，整体运势一般偏好，事业上依然有升职发展机会，有机会做出一定成绩，地支酉辰相合，辰土财星被合入，能上班求财为佳，但取餐比较辛苦，收获有限。
