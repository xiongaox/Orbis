# 五行缺火的人

命主生辰: 1998/09/02 16:00 (GMT+8)
性别: 坤造
日主: 壬水
格局: 偏印格

# 网友来信：

家里奶奶她的日柱是戊子，父亲是癸水，我叔叔是壬子，我也是壬子，从小喜欢做饭和星座，后来知道可能命局的食神和太极贵人有关。

从小家里人就特别重视我教育的培养，一直以来虽然家境贫寒因为条件有限 母亲任然坚持给我上补习班，初二的时候沉迷韩剧有一些自我放弃，各种环境的作用下我想的很多。从那个时候开始我开朗的性格就变得沉默喜欢毕淑敏老师的书籍 第一本启蒙书籍是心灵的力量，初三的时候刚上年招线却因为想离开父母远。选择了一个较为远的地方住读母亲又为我缴纳了一部分赞助费。

高中时期我以为我可以在新的地方重新起航，却没想到分科选班的时候我选了自己不擅长的理科，高二分科后成绩一落千丈初中的时候还可以班级前10因为只有几十人，高中却又着2000人，班上属于中等靠后的成绩，高二和班上成绩最好的女生成为朋友之后莫名搞僵了关系我开始变得郁郁寡欢，整天忧思愁闷，高三的时候母亲特别辛苦却让我在外面租房子，和我一起的是小时候同班的一个男生大家属于都很了解熟悉的类型。

他住了半年后因为成绩确实不理想他还早恋于是选择了去补习班全日制，在当年全日制是需要花费10多万的费用，母亲看见我学习的过于痛苦便带着我去了那个机构，当年我以为是可以做心理咨询的一个地方所以我便跟着去了，没想到那位咨询老师为了业绩对我进行了欺骗，我不知道补习需要花费的代价，当年高考我差本科线20多分，我们当年是新高考改革的第一届 难度和试卷都属于摸石头过河的类型，因为花了特别多的钱我便不再希望复读，当时心情特别沉重对自己的未来感到迷茫，但那位老师告诉我专科可以去读还有3+2。

于是我去了区县的一个私立学校读了专科认识了一个朋友 她是天秤座的庚金日柱，我们一起互帮互助我是处女座 还有一个金牛座的男生我们三个人一起专升本的时候他们两考上了 不幸可能是习得性无助我没能考上 好友的目标是做老师，而我当时刚毕业还处于混沌期，之前觉得很多话想要表达不敢表达出来所以选择弥补我性格上的缺陷我选择去做了教育咨询 又进入了之前补习的哪个机构，机缘巧合之下我直接就去试岗了没有经过面试 因为当天去的时候大校不在 那天是七夕节

工作中又遇见了坎坷一步一步从小白成长为一梯队的的销售骨干，还拿了年度优秀员工，却发现好景不长，在双减政策之下我发现了公司可能面临倒闭，所以在暑假过完之后就选择了离开，离开之后我想往内求，所以我选择去做瑜伽，静心，然而我也尝试了在网上写文章做自媒体，想自己拍视频却发现我脑子里面的想法很多可是落实到行动上的时候仿佛太松散，喜欢的东西很多。今年我又做了半年艺术教育咨询 发现我有走进别人心理的能力 自小我对神秘学 玄学 都比较感应区 与奶奶交流过 她很喜欢鬼神 复活的小说

近两年自己有研读易经，道德经的过程中我慢慢发现了对于认知高纬度的一些热爱，我当年出身前，因为家中亲戚与医生产生争执所以医生生气告诉父亲孩子现在还没到出来的时候后面重新换了一家医院做检查才发现我要缺氧了

我是一个相信天道轮回的人，有时候发现自己在生活中有一些预知或者是巧合的能力，想做心理咨询 现在在准备心理学的考研学习，命中驿马很多。

> 问题如下：
>
> 1，不知道我该留在出生地还是另外的地方？
>
> 2，月柱 我是偏印 比肩 七杀我的日柱是偏财，不知道我应该从商还是做心理咨询 优势上或者是做玄学 占卜 四柱 或者我感兴趣的事情吗 行动力和火元素有关吗？
>
> 3，七杀身强带空亡日柱红艳煞注定是婚姻难美满的话 事业上我可以扭转乾坤尽可能如何避免失败吗？

# 八字详批：

#### 坤造：戊寅年，庚申月，壬子日，戊申时（寅卯空）

#### 大运：己未，戊午，丁巳，丙辰，乙卯，甲寅，癸丑，壬子，10岁运。

# 分析命局：

壬水日主生在申月得令，坐子水得地，子水为壬水日主的羊刃，帮身力量较强，月干透出庚金来生扶日主，时支申金伏吟，也是生扶日主的五行，年干和时干戊土来克身，但也旺了庚金和申金，间接助身，年支寅木来泄身，但地支寅申相冲，寅木被冲克无力，且寅木空亡，故依然为身旺之格。月干庚金偏印和天干戊土七杀从月令申金中透出，为偏印格，也为七杀格，申金的本气为庚金，所以主要表现为偏印格的特性。

# 分析喜忌：

偏旺以泄耗日主的木火五行为用神，以生扶日主的金水五行为忌神，五行土虽克身，但在天干地支生金不吉。申金当令较旺，伏吟地支，喜见火来制金，同时也喜见木来生火。天干喜见火来制金，也喜见木来疏土生火。

# 分析事业：

年支寅木为命局唯一用神，但奈何地支寅申相冲，寅木有损，为忌神制用，用神无力，为不足之处，且寅申相冲，也为枭神夺食的组合，命局唯一的用神受损，加上五行喜火而不见火，故组合不太理想。

原局为偏印格，壬子日出生临月德贵人，故比较有爱心，且做事比较细腻。但由于偏印旺而为忌神，故内心也容易有一些不好的想法和念头，加上虽然原局食神为用，但组成寅申相冲，枭神夺食，且寅木为食神临驿马，又有七杀贴身克身，代表是容易敏感，多疑，缺乏安全感，疑神疑鬼，胡思乱想，想法杂乱多变，甚至有些和大众格格不入，有些怪异。

原局偏印较旺为忌，加上五行缺火，做事积极性不够，性格也偏内向的一个人，加上寅申相冲，枭神夺食，性格也体现出死板的一面，有时候思维不够灵活，思想比较保守，容易一根筋，走死胡同，缺乏灵活变通，对未来规划能力不强，容易懒惰，且心胸较小，容易因小气而得罪他人，或和人关系搞僵。

印星多为保守，印旺比劫旺为忌，而用神弱，命局杀印相生，所以上班比较好，且寅申相冲，枭神夺食，故不能投资创业，容易考虑不周导致破财，做一些保守的，没什么风险的，稳定求财的，比较好些，如果风险高，或比较不稳定的，都不要去做。

原局偏印重重贴身，偏印本身代表冷门和偏门学术，也有专研的意思，第六感比较强，加上寅木空亡，月时均临太极贵人，故有艺术，心理学，神秘文化，易学，宗教，国学等天分，这种特点也比较适合搞研究之类，能努力取得更高学历对你是好的。其次由于寅木食神为用，也可以去学习一门过硬的技术，进大一些的企业或平台发展为好。

你想考心理学方面研究生是适合的，你现在走的是戊午大运，地支午火财星克印，整体有利考学，今年癸卯年，2024甲辰年，2025乙巳年，2026丙午年，均是不错的年份，要好好把握，争取上岸。

年支寅木临驿马，申金伏吟，也临驿马，地支驿马冲冲，且寅申相冲，驿马逢冲，快马加鞭，代表非常适合外出求财，在家乡较难有太好的机会，或者容易错失良机，出生地的南方，东方，东南方比较旺你。

需要注意的是，驿马本身代表勤劳，但驿马重重，驿马太多，也会适得其反，容易懒惰懈怠，加上印星太旺为忌神，有的时候会比较懒，更加要注意这个问题，所以要在有效提升执行力上下功夫，不管是学习还是工作都要多一些踏实为好。

# 分析大运：

**20岁—29岁**

戊午大运，此大运为财杀相生的大运，地支午火财星克印，整体运势一般偏好，有一定考学运，加上戊土七杀透出，有望提升学历、考取证书、获得名气，要好好把握。不过，地支子午相冲，代表花销较大，也要注意意外伤害。

**30岁—39岁**

丁巳大运，你的命局五行缺火，同时火为用神，此大运干支一气为五行火为财星，对你事业求财是有利的，地支巳申相合，财星克印，天干丁壬相合，正财合身，故求财相对较为稳定。但此大运也不是什么都好，因为大运和原局组成寅巳申三刑，会导致压力较大，容易焦虑，也要注意口舌是非纠纷之事，所以虽然大运为用神大运，但也不是一顺百顺的，而且此大运驿马逢三刑，出行也要注意安全。

**40岁—49岁**

丙辰大运，此大运为财杀相生的大运，天干丙火透出，旺了戊土七杀，七杀旺了印星，地支辰土也旺了申金印星，故整体运势有所走低，事业上升职发展机会不多，可以把握的机遇有限，辛苦忙碌求财的运气。

**50岁—59岁**

乙卯大运，此大运干支一气为五行木伤官，但大运的天干乙木和原局庚金相合，乙庚合而不化，庚金为忌神被合，但乙木也被牵制住，就打了折扣，不过地支卯木伤官泄身，故整体运势转好，可以施展才华，做出成绩，财运有所增加，也有升职发展的机会，但子卯相刑，依然要注意口舌是非之事。
