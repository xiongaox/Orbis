# 巳亥冲的人

命主生辰: 2001/12/05 22:00 (GMT+8)
性别: 坤造
日主: 壬水
格局: 偏旺之命
令地: 失地, 得令

# 网友来信：

我出生百天就随父母来XX发展了，有一个差十岁的弟弟。最近几年家庭变故有些大，家里之前也因为在老家买房子 欠了一些钱。目前这几年父母都在不同城市打工还钱。我出生来到XX 父母一直在做小生意，日子还算可以。但是在XX这快二十年 父母总失去机会 可能一个地方干几年 刚赚钱就拆迁不能干了，也错过买房子的机会。家庭父母运气其实一般 父亲很聪明 但还是总是错失机会。一直算不上富贵 家庭温饱没问题。在己亥年父母因为这边生意实在不行了 回老家了。

后面父母这两年 就各自在不同的城市打工还钱了。这快三年自己一个人在XX生活生产。自己目前没有什么依靠，平时会孤独 无助 全部靠自己，但是生活二十年对这边很熟悉到没有什么问题。因为父母当时不确定因素比较多，要回家什么的。自己学习不争气，读到初中毕业后面就没有读书了。

然后开始工作了。从事美甲行业。最近真的很迷茫。辛丑年四月份换过工作一直工资还可以，工作一直工资不是很高，而且很累 工作因为环境因素很多担子都在自己身上，虽然忙累但不赚钱。壬寅年换大运。我以为会好一些。但是感觉各种真的点背的很。财运上不去。

有想换工作的想法，但还是求稳比较好一点是不是？平时点真的很背 运气就是一般般。想知道自己这两年工作可以换吗，有其他好的机会吗？犹豫我以后有自己干的想法，想知道什么时候可以自己干，但是父母对自己帮助真的不大，所以只能靠自己攒钱，但是自己能力有限，也有人会说我嫁贵夫，想知道未来对象会帮自己事业吗？什么时候可以遇见 条件怎么样？对我帮助会达到什么阶段？会出轨吗？因为我的感情容易有感情竞争、所以很担心家庭不和睦。

# 分析命局：

壬水日主生在亥月得令，坐寅木失地，时支亥水伏吟来帮身，亥水得辛金生扶不弱，年干和时干辛金来生扶日主，月干己土来克身，但己土被辛金泄气，又坐亥水之上虚透，无力克身，年支巳火来耗身，但巳火空亡又被亥水所制无力，故依然为偏旺之格。

# 分析喜忌：

壬水日主偏旺，以泄耗日主的木火五行为用神，以生扶日主的金水五行为忌神，土虽克身，但在天干生金不吉。地支亥水当令较旺，喜见土来制水，尤其喜见燥热之土，而见木火也为吉，相对更喜见午火。天干己土无力，可见火来制金生土，单独见木，土木相战，金木相战，非为最吉。

# 分析事业：

亥水比肩得令较旺，伏吟时支，又见己土官星贴身，事业心较强的一个人，亥水为禄神，禄神重重，也可以吃苦耐劳，亥水也为驿马，驿马重重也主勤劳，但也有辛苦劳碌的意思，难得清闲。壬寅日出生，日坐寅木食神为用，也懂得付出，为一分辛劳一分收获的组合。

年支巳火财星为用，但巳火空亡无力，又巳亥相冲，巳火被冲克，故和父母缘分不深，年月相冲，早年容易离开家里，或发生变动。也代表自己很难得到父辈帮助，尤其印星为忌，财星无力，更是如此，想事业和财运有所起色，更多是靠自己亲力亲为，白手起家。而辛金印星为忌，也代表会有些依赖心，也要克服这方面。

地支亥水禄马相逢，禄神也代表身体，一般精力还比较旺盛，多适合偏体力一些的工作，巳亥相冲，驿马逢冲，快马加鞭，主奔波动荡、东奔西走，也代表为外地求财之命，出生地的东方，南方，东南方比较适合你。

壬寅日出生，日坐寅木食神为用，临天乙贵人、文昌贵人，身旺无依，适合一技傍身，能钻研于一门技术，依靠技术谋生是非常好的。你现在从事美甲，也属于技术，而且指甲五行属木，是你的用神，可以坚持做下去，也要发挥“工匠精神”，唯有精益求精，方可脱颖而出。

月干己土官星可代表事业，己土被辛金泄气无力，又坐亥水之上虚透无力，难以得到年支巳火财星直接生扶，基本上属于无财之官，且己土在地支无根，坐亥水之上，水多也有根基不稳，变动较多的意思，整体事业运不是很强，难找到较为体面的工作，且升职机会不多。

年支巳火为财星，但巳火空亡无力，又巳亥相冲，为比肩冲财，而且寅巳相害，寅木财源和巳火财星有损，地支亥水禄神重重而难富，且亥亥自刑，为财少财薄的组合，难见大财，同时容易因为亲戚朋友而破耗，财来财去，不适合和人合伙求财，在求财上也不可期望值太高。

日坐寅木食神为用，又时干辛金印星入门户，可以考虑自己做点事情，也可考虑开店求财，但也是适合小规模小成本，不适合投入太大。

壬寅年换大运，但岁运并临，天干见三个壬水，引动亥水，必然为忙碌的一年，事业上也有竞争，且寅巳相害，财运不佳。2023癸卯年，地支卯木伤官生财，要稍好一些。2024甲辰年，天干甲己相合，有事业变动之象，可以在2024年后看看机会。

# 分析婚姻：

壬寅日出生，日坐寅木食神，食神在婚姻宫，对待婚姻容易幻想，思虑较多，食神是克官的，也代表在择偶上有一定标准和要求，婚后会为家庭和孩子操心操劳，地支寅巳相害，婚姻宫寅木受损，故婚姻环境较为一般，有一些压力和烦恼。

月干己土官星可代表丈夫，己土坐亥水之上虚透无力，被辛金泄气，且难以直接得到巳火生扶，故不助夫，也代表难嫁贵夫，未来丈夫条件和能力较为一般，对你帮助也是有限的。而且己土官星坐亥水之上，要注意外界干扰，未来能找一个有过恋爱经历的人要好一些。

2024甲辰年，天干甲己相合，己土官星逢合，有机会遇到缘分，但多较难满意。接下来就要等到2027丁未年，财官相生，天干丁壬相合，未土官星跟着别合入，有遇到的运气，2028戊申年，地支寅申相冲，婚姻宫逢冲，有结婚的运气。
