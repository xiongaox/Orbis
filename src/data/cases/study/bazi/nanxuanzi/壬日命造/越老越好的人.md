命主生辰: 1994/09/23 8:00 (GMT+8)
性别: 坤造
日主: 壬水
格局: 偏旺之命
令地: 得令, 得地

# 网友来信：

我出生在一个外人看来很可怜但其实有笑有泪的家庭。双亲身体欠佳，文化程度低，但性格和善，在为人处世上给我树立了很好的榜样。即使家庭经济条件差，也尽力给我创造了很好的教育和成长环境，我也因此对学习较为上心。可惜的是，他们感情逐渐不和，在我刚步入青年时，母亲有了情绪问题，永远离开了我们。

我的内心从此蒙上了晦暗，时常从梦中哭醒，感觉就是，带我来到这个世界的那个人走了，剩下的路只有自己孤独一个。为了压抑这些不能为外人所道的悲伤，我把注意力投放在学习上，所幸成绩还不错，上了大学，读了研究生。但在感情方面，我从小到大喜欢过不少男同学，都只是暗恋，直至前几年认识了前男友，两个人算是投契，但相爱相杀，离离合合多次，最后一次他提出分手，而我无力挽回，接着又是无数个夜不能寐、辗转反侧。

> 1.  感情方面，我能遇到合适的姻缘吗？能的话，大概是什么时间呢？或者我可以做什么努力吗？
>
> 2.  事业方面，我目前主要在公务员或老师这两个方向考虑，不知更适合哪个行业呢？

# 八字详批：

# 分析命局：

壬水日主生在酉月得令，坐子水得地，子水为壬水日主的羊刃，帮身力量较强，月干透出癸水来帮身，癸水坐酉金之上有力，帮身力量较强，年支戌土和时支辰土来克身，但有酉金通关，年干和时干甲木来泄身，但壬水日主得令得地，故依然为偏旺之格。

# 分析喜忌：

偏旺以泄耗日主的木火五行为用神，以生扶日主的金水五行为忌神，五行土虽克身，但在地支生金不吉。酉金当令，金水两旺，地支喜见火来克金，同时喜见木来疏土生火，木火同见为吉。天干喜见木来泄身，木来生火。

# 分析事业：

年干和时干甲木为用，甲木得癸水生扶不弱，为用神有力，忌神化用，也为食神泄秀的格局，较为吉利，所以组合较为不错。但喜火但不见火，且地支土旺酉金，稍有不利。

壬子日出生，日坐子水为羊刃，比劫较旺，人比较要强，不轻易服输，自尊心较强，酉金当令，难免有固执自我的一面，但好在有甲木食神泄秀，也有温和的一面，懂得付出，为他人着想。年柱甲戌和时柱甲辰，食神来制杀，比较喜欢自由，不太喜欢被束缚太多，也代表有时候自制力不够强，容易我行我素。

年干和时干甲木食神挂两头，食神泄秀，食神有力，代表聪明，一般口才较为不错，可以依靠口才来发展事业，你提到的公务员或者教师，这两者教师更加适合你一些。除此之外也适合依靠一技立身，条件允许，能选择设计策划等方面是比较适合你的，食神制杀，也可以考虑从事管理相关方面，行业方面也可从事土建工程、装潢、服装、印刷、医药、绿化方面。

辰土和戌土七杀可以代表事业，被甲木食神所制，对事业运有利，只是没有财星，代表总体事业财运不是很强，尤其甲木食神高透，喜欢自由，所以公务员不太适合，做公务员发展也有瓶颈。

比劫较旺，事业上竞争也较大，容易遇到强有力的竞争对手，能专心于一个领域踏实工作为好，可以首选教育文化方面，唯有实力过硬方可有所发展。

原局不见财星，只有年支戌土暗藏丁火财星，藏而不显，戌土为财库，可以甲木和寅木食神为财，甲木食神入门户，可以得到这个财，加上食神泄秀的组合，故为衣食无忧之命。但地支辰戌相冲，酉戌相害，戌土财库受损，故为小财可得，大财难求之命，也代表花销破耗比较多，不是很聚财。

地支辰戌海底冲，为外出发展之命，能走出去对事业发展有利，出生地的南方，东方，东南方比较旺你。

结合大运来看，你早年走的壬申大运，辛未大运，运势均不太有利，必有坎坷之事。现在走的是庚午大运，天干庚金来冲克甲木，为枭神夺食的大运，整体运势略为低迷，容易错失良机，能尽快找工作为佳。

但今年癸卯年有一定竞争，相对而言，明年比今年要机会多一些，2025年机会更多一些，可以先就业再择业。

接下来的己巳大运，甲己相合，甲木食神被合绊，也非太理想的运气，戊辰大运，运势尚可，56岁后进入丁卯大运，丙寅大运，运势较为理想，你的命格属于越老越好的命，中晚年有一定福气。

# 分析婚姻：

日支坐羊刃劫财忌神，也代表未来夫妻争吵比较多，有时候另一半性格也比较好强，婚姻中容易互不相让，而增添很多矛盾是非，这是要注意的。女命财星为情根，但财星藏而不显，不见财来滋杀，壬子日出生临女孤鸾煞和太极贵人，代表在感情上有一些木讷，不太懂得关心体贴另一半，或者换位思考。

年支戌土和时支辰土被甲木食神盖头，有不见财来滋杀，为无财之杀，且日支婚姻宫为子水忌神，代表未来丈夫条件和能力等较为一般，对你帮助不大，不可要求过高。

戌土和辰土离壬水日主较远，时柱临华盖，壬子日出生临女孤鸾煞，均代表不易守得住缘分，容易错失，要多主动一些为好。2024甲辰年，地支辰土夫星出现，有遇到的运气。
