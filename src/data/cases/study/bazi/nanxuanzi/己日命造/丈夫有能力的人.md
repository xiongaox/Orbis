命主生辰: 1999/10/14 2:00 (GMT+8)
性别: 坤造

格局: 偏旺之命

# 网友来信：

我有两个姐姐，然而大姐在她两岁时不幸落水。从小我的学习成绩一直不太好，总是达不到理想状态。

我于庚子年大学本科商务英语专业毕业，毕业后在一家国企从事系统管理的工作，辛丑年九月份辞职，现一直处于待业状态。辞职后，在网上报课学习了做自媒体的一些技能，还有化妆技巧，想成为一名美妆博主，目前个人的自媒体账号有了一点起色，但还没达到能养活自己的地步。深知女孩子经济独立的重要性，在疫情期间选择了裸辞也是迫不得已，但我也时常会怀疑自己否定自己。目前我的经济压力大，没有稳定的收入来源，一直在用这些年的存款。

我有一个谈了多年的男朋友，我们双方的感情一直以来比较稳定。但壬寅年我们之间多次发生争吵，产生了很多矛盾，根本无法沟通，感情也受到影响。他目前是在国企，辛丑年提拔为车间副主任，工资涨了很多，工作也特别忙，加班多压力大，有时候需陪领导喝酒，陪客户去休闲娱乐场所。本来带他去我家见家长，奈何我们经常争吵，我对我们的感情也没有了信心。

# 八字详批：

#### 坤造：己卯年，甲戌月，己亥日，乙丑时（辰巳空）

#### 大运：乙亥，丙子，丁丑，戊寅，己卯，庚辰，辛巳，壬午，癸未，10岁运。

# 分析命局：

己土日主生在戌月得令，坐亥水失地，年干己土和时支丑土来帮身，地支丑戌相刑，把土冲旺，帮身力量较强，月干甲木本来克身，但甲己合化为土，反而帮身，年支卯木和时干乙木来克身，但八字土旺，甲木又被合化，为偏旺之格。

# 分析喜忌：

己土日主偏旺，以克泄耗日主的金水木五行为用神，以生扶日主的火土五行为忌神，时干乙木和年支卯木为用，天干地支喜见水来助木，由于子卯相刑，地支更喜见亥水，原局亥水被戌土和丑土夹克，也喜见金来通关生水，由于申亥相害，更喜见酉金。

# 分析事业：

戌土劫财当令较旺，地支丑戌相刑，把土冲旺，天干甲己合土，比劫太旺，而乙木和卯木七杀力量不强，且不见食伤来泄身，性格会有一些固执倔强，只要自己认准的事情，不太容易听得进去别人的建议，在灵活性上较为缺乏，也少了一些圆融，比较直来直去的一个人，这样的特点有时候在职场上容易吃亏。

比劫较旺，乙木七杀透出贴身，自尊心较强，有时候也会有一些嫉妒心，比较爱慕虚荣，注重名誉，性格也比较好强好胜，脾气不太好，有时候容易莽撞，不太容易做得到深思熟虑，这也是要多注意的，以后在决策上能三思而后行要好一点。

虽然甲己合土，甲木官星被合化，为用神化忌，但由于甲木正官和乙卯木七杀构成官杀混杂，甲木被合化反而为去官留杀，格局更加纯净，提升了格局层次。但甲木被合化，也助长了比劫之力，身旺七杀弱，故喜见财来滋杀，方有发展的机会，必然会比较平凡。

日支亥水为正财，被己土、戌土和丑土比劫包身，构成比劫夺财，且不见食伤来生财，亥水财星受损严重，在理财上较为缺乏，花销破耗非常多，经济压力也会很大，由于不见食伤财源，不能源源不断来生财，也代表财运时好时坏不太稳定，且很容易因为亲戚，朋友，同事等而破耗，所以要养成存钱的习惯为好，也代表主业能上班求财，依靠稳定的工资财度日为好，自己做求财风险很大，也难以有持续稳定的收入。

身旺不见食伤来泄秀，从事一些直播，文艺，自媒体，传播等创作方面工作不是很适合你，大学学习商务英语专业也不是很适合，自己也缺乏太好的表现力和创新力、灵活度，很难游刃有余，也难以施展你的才华，较难在这些领域做出成绩。而且互联网自媒体等行业五行属火，也是你命局的忌神，也不是太适合。

身旺以乙卯木七杀为用，身旺可以担杀，且乙木七杀贴身，一般而言，长相气质都不会差，自己又喜欢美妆的话，可以去往这方面发展副业，但主要还是以主业为主，不能对这方面抱太大希望，想通过副业安身立命是不现实的。七杀为用入门户，有一定管理能力，给你的建议还是回归老本行，之前在国企从事系统管理是适合你的，未来择业还可以选择相关行业。

你现在走的是丙子大运，天干丙火印星透出，化杀生身，乙木七杀无力，且子卯相刑，卯木七杀被刑伤，故总体事业运是不强的，事业容易变动，且发展受限。2022壬寅年，有财来滋杀，且寅木来疏土，是有一定事业运的，能尽快投简历找工作为佳，2023癸卯年也有不错的机会。

# 分析婚姻：

天干甲己合化为土，但日支婚姻宫为亥水，暗藏甲木官星，而乙木七杀高透，为透杀藏官的组合，杀重官轻，且甲木官星被合化，这种组合很容易在婚前经历失败的感情，或者有婚前同居的经历，日支婚姻宫为亥水，暗藏甲木官星，婚后家庭观念也比较重，比较顾家。

以官杀为用，代表未来丈夫比较有能力，对你事业和家庭有一定帮助，时支丑土临寡宿和太极贵人，也有在感情上孤独之象。以婚姻宫亥水为太极点，被己土、戌土和丑土所制，均为亥水的“官杀”，也有婚姻压力很大之象。

男友乾造：【**丙子，戊戌，戊申，癸丑**】，戊土日主生在戌月得令，坐申金失地，月干透出戊土来帮身，时支丑土也是帮身的五行，丑戌相刑，帮身力量较强，年支子水和时干癸水来耗身，年干丙火来生扶日主，为身旺之格，以金水为用神，以火土为忌神，木虽克身，但在天干生火不吉。他的五行土旺，是你的忌神，你的五行土旺，也是他的忌神，喜忌不能互补，在一起对对方运势没太大帮助，你们的八字子丑相合，卯戌相合，子卯相刑，申亥相害，丑戌相刑，总体合婚匹配度处于中等偏下水平，尤其属相相刑，婚姻宫相害，在一起难免有不和之事，也较难走到最后，勉强在一起婚后矛盾争吵也较多。

# 分析大运：

**20岁—29岁**

丙子大运，此大运天干丙火被地支子水戳脚，为财星克印的大运，天干丙火印星透出，化杀生身，地支子卯相刑，卯木七杀被刑伤，故总体事业运不强，升职发展机会不多，且容易有口舌是非，工作变动。地支子水为桃花，红鸾星入命，也有遇到并结婚的运气。

**30岁—39岁**

丁丑大运，此大运天干丁火枭神化杀生身，事业运依然不是很强，很难在事业上做出成绩，施展才华，得到升迁。地支丑戌相刑，比劫较旺，事业上竞争依然较大，要防小人，比劫旺而克财，总体财运不太好，很容易发生钱财破耗。

**40岁—49岁**

戊寅大运，此大运天干戊土被地支寅木戳脚，天干戊土劫财高透，地支寅亥相合，寅木官星被合入，和命局构成官杀混杂，事业易有变动，不太稳定，亥水被泄气无力，总体财运较为一般，需要辛苦付出，此大运能求稳为好，也要注意夫妻关系。

**50岁—59岁**

己卯大运，此大运天干己土被地支卯木戳脚，天干己土比肩透出，事业上竞争依然较大，地支卯木七杀来制劫财，事业运尚可，有机会升职，要把握机遇，也有事业变动之象，多已退，此大运夫妻感情尚可，可以安度晚年。
