# 三气成象，格局层次较高的人

命主生辰: 1993/01/28 8:00 (GMT+8)
性别: 坤造
日主: 己土
格局: 偏财格
令地: 失地, 得令

# 网友来信：

我出生于小镇上，家庭关系非常和睦。在父母的陪伴和培养下，我一路从镇上考到市里，高考以及保研，庚子年博士毕业，并进入高校成为教师。

回看过去，有一些深植记忆的时间点：第一是辛卯年高考前夕，巨大的压力几乎压垮了我，导致我高考发挥并不理想，去了末流985。第二是丁酉年外婆去世，我与外婆的关系非常亲密。外婆去世后，好多事情都变了，分手、读博，性格也不似之前活泼、外向，变得沉静了，往内收了。三是庚子年博士毕业，焦灼又无力，像磨刀一样磨论文，所幸最后也有惊无险。

这三段时期充满痛苦和迷茫，我逐渐感觉，人生中很多事情并不是努力就可以做成的，我们可控制的东西实在是太少太少了。也正是在这些时刻，我逐渐对易理开始感兴趣，希望通过玄学的角度，给迷茫时期的自己一些心态引导。我经常在网络上搜寻易理方面的探讨帖子，家里也陆陆续续买过一些易理方面的书籍，但是我对自己的命局解读上仍然存在一些疑惑，诚挚的希望得到点拨，扫除心中的疑云：

> 1. 喜用究竟为木火还是金水？我的全盘只有金、水、土三行，且金水土皆为阴阳成对，58岁以前的大运也皆为金水土，不见木火。后来和老公一起看命理书籍，讨论认为这个可能是金水土三行成象格，不宜用木火破格，反倒喜用金水。
>
> 2. 事业发展如何？自庚子年毕业，换大运为伤官，目前所做的研究课题属于工科和医学的交叉方向，想请问，以后如果有想法在学校任教的同时，依靠专业技术开公司，是否适合？
>
> 3. 子女情况。之前算命师傅跟我们讲子息不多，且子女缘浅，宜女儿，不宜儿子。心中忐忑，想请问，我与老公准备在甲辰年要小孩，头胎女儿概率会大一些吗？
>
> 4. 家庭情况。请问我的老公事业如何，与老公的感情如何。未来我们会达到什么样的收入水平和事业水平？

# 八字详批：

#### 坤造：壬申年，癸丑月，己酉日，戊辰时（寅卯空）

#### 大运：壬子，辛亥，庚戌，己酉，戊申，丁未，丙午，乙巳，8岁运。

# 分析命局：

己土日主生在丑月得令，坐酉金失地，时柱戊辰干支一气来生扶日主，年支申金来泄身，年干壬水和月干癸水来耗身，壬水坐申金为长生，耗身力量较强，但己土日主得令，依然为中和偏旺之格。月干癸水偏财从月令丑土中透出，为偏财格。

# 分析喜忌：

中和偏旺以泄耗日主的金水五行为用神，以生扶日主的火土五行为忌神，木虽克身，但见木影响层次，不喜多见，后面会讲到。天干土来制水，喜见金来通关生水，也喜水来耗身，地支土旺，喜见金来泄土之力，也喜水来耗身。

# 分析事业：

原局五行只见土、金、水三种五行，在命理上有一种比较特殊的格局叫三神成象格，也叫三气成象格。所谓三神成象格，就是一个只有三种五行，没有其它两种五行掺杂，而且包括日干五行在内的三种五行能够顺势相生，气势基本均衡的格局。一般取用神就是以此三种五行中相对较弱的五行为用。

从你的组合来看，中和偏旺，金水相对弱一些，所以以金水为用，这也就是为什么不喜见太多木的原因，有了第四种五行的掺杂，且比较旺的时候，就容易破坏了格局。原局来说算是比较好的格局，只要岁运配合得当，一般命格都较为不错，有福可享。

从你行运来看，早年走的壬子、辛亥大运，现在走的庚戌大运，未来转己酉、戊申大运，均为土、金、水的运气，故格局层次较高，可以有一番作为。

中和偏旺，地支申酉金食伤泄秀，酉金食神临文昌贵人和学堂，月柱和时柱临华盖，代表是比较聪明伶俐的一个人，思维较为灵活，有一定领悟力。

《古歌》中讲：食神最喜劫财乡。也为此意，均代表才华可以得到施展，可以在学业和事业上取得一定成就，日坐食神为用，也代表一生衣食无忧，只要食伤不受损，人生并无太大挫折。
你印象深刻的几个时间点，辛卯年，丁酉年，地支卯酉相冲，酉酉自刑，酉金食神有损，故而这两年你会感到不利。

申酉金食伤泄秀，一般性格都比较温和，懂得付出，善解人意，有奉献精神，比较乐观，喜欢助人为乐，内心比较善良。但食伤得比劫生扶并不太弱，所以也容易想得较多、思虑较重、胡思乱想，因而给自己带来一些烦恼，食伤为用，也比较注重精神享受的一个人。

年支申金伤官为用，临天乙贵人，为命局唯一天乙贵人，为真贵人，代表贵人运较为不错，可以得到他人相助，申金伤官在年，代表可以得到父母的疼爱，领导的关照。年柱壬申为伤官生财的组合，且为偏财格，物欲欲望强，财星高透，也有一定虚荣心。

食伤泄秀，三神成象，早年走的壬子、辛亥大运，顺从命局气势，运势较好，早年主要是学习方面，所以可以取得高学历，日坐食神为用，也适合从事教育文化相关行业，从事研究也比较适合，能在高校任教较好。食伤较旺，适合偏理工科方面的专业，研究工科和医学的交叉方向是可以的。

你现在走的庚戌大运，天干庚金伤官透出，伤官生财，地支申酉戌三会金局，旺了食伤，整体财运较为不错，有在主业之外开公司的想法是可以的，而且这步大运，地支辰戌相冲，财库开库，也代表有一定财运，可以着手去做。

接下来的己酉，戊申大运，运势虽不差，但天干有比肩制财，劫财夺财，所以建议能收手为好，最好把主要精力放在研究和事业上。

# 分析婚姻：

己酉日出生，日坐酉金食神为用，代表婚姻感情整体还是较为不错的，夫妻相对较为和谐，但也代表自己会为了家庭和孩子付出较多。现在走的庚戌大运，未来走的己酉大运，地支酉戌相害，酉酉自刑，磕磕绊绊难免，要多注意下，过了这两步大运要好一些。

丈夫乾造：【**壬申，壬寅，戊午，辛酉**】。戊土日主生在寅月失令，坐午火得地，时柱辛酉干支一气来泄身，年干和月干壬水来耗身，年支申金也是泄身的五行，为身弱之命，以火土为用神，以金水为忌神，木虽克身，但在地支生火为吉。他的五行木旺，整体而言，对你五行有利，你的五行土旺，是他的用神，喜忌基本可以互补，在一起的话对对方运势有所帮助，可以旺对方。你们两个人有戊癸相合，酉辰相合，寅申相冲，丑午相害，酉酉自刑，综合合婚匹配度属于大众化水平，在一起总体较为和顺，但磕磕绊绊也在所难免。

丈夫原局见七杀两位，你的见食伤五位，为儿女双全的命格。总体上在生育方面没有太大问题，但相对而言，你的命局较寒，所以在备孕时要加强调理为好。2023癸卯年，卯辰相害，2024甲辰年，辰辰自刑，子女宫有损，这两年备孕，有一定风险，可以选择在2025年备孕，会顺利一些。
