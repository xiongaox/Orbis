# 八字详批：

#### 乾造：丙子年，庚子月，己卯日，辛未时（申酉空）

#### 大运：辛丑，壬寅，癸卯，甲辰，乙巳，丙午，丁未，戊申，11岁运。

# 分析命局：

己土日主生在子月失令，坐卯木失地，年支子水伏吟来耗身，时支未土来帮身，但未土被辛金泄气，又被卯木所制，且地支子未相害，未土有损，帮身力量较弱，时干辛金来泄身，月干庚金也是泄身的五行，年干丙火来生扶日主，但被子水戳脚无力，依然为偏弱之格。

# 分析喜忌：

偏弱以生扶日主的火土五行为用神，以泄耗日主的金水五行为忌神，木虽克身，但在天干生火为吉。地支子水当令较旺，伏吟地支，喜见土来制水，但喜见燥热之土，不喜寒湿之土，也喜见火来通关生土。天干庚辛金来泄身，喜见火来制金生身。

# 分析事业：

身弱以时支未土比肩为用，但未土比肩一方面被辛金泄气，一方面又被卯木所制，被两个子水所伤，未土有损，为忌神制用，用神化忌。年干丙火也为用神，但丙火离己土日主较远，且被子水戳脚，为忌神制用，用神无力，从组合而言，并非最吉。

子水偏财当令较旺，伏吟年支，月干庚金伤官透出，月柱庚子，为伤官生财的组合，均代表野心和欲望较强，较难得到满足，但好在庚金伤官有丙火印星来制，也懂得收敛心性，子水偏财较旺，也代表物质欲望较强，同时年柱丙子为财星克印的组合，很容易外面的花花世界影响，而荒废学业和正业，是要注意的地方。

子水偏财当令，地支子水来生卯木，为财杀相生的组合，己卯日出生，日坐卯木为七杀，会因为求财和事业等产生一定压力，子卯相刑，难免会焦虑。庚辛金食伤相随，也代表对精神世界的追求，有时候难免思虑较重，也代表付出较多，操心操劳多，难得清闲。

身弱以年干丙火印星为用，但丙火印星离日主较远，且年柱丙子，丙火被子水戳脚，为财星克印，故整体而言，不利考学，想取得高学历高文凭较为困难，即使考编也较难顺利。

结合大运来看，早年走的辛丑大运，大运天干辛金和原局，组成丙辛相合，丙火被合拌，而现在走的壬寅大运，大运天干壬水，和原局组成壬丙相冲，财星克印，丙火印星有损，也是不利考学。

结合流年看，2023癸卯年，天干财星克印，依然不利，要等到2024甲辰年，天干甲木旺了丙火印星的时候，有机会上岸。

月柱庚子，为伤官生财的组合，且财为偏财，且己土日主被庚辛金食伤相随，故整体而言，适合偏自由一些的行业，身弱更适合一技傍身，有一技之长，会对你事业发展有利，且有一些做生意的信息。

不过现在走的壬寅大运，未来走的癸卯大运，运势不太有利，能上班为佳。到了甲辰大运，乙巳大运，丙午大运，那个时候大运助身，可以考虑做点生意，有一定偏财运，收入也较为可观，行业上可以考虑电力、电器、互联网、土建等方面。

坚持考编的话，命局以印星为用，更加适合教师一些，不太适合公务员，因为食伤较旺，偏财伏吟，即使勉强考上，时间长了较难适应，自己也会萌生退意。尤其是卯木七杀为忌，没有制化，丙火印星被财星所制，事业发展也有一定上限，想得权较为困难。

但到了41岁后进入甲辰大运，乙巳大运，丙午大运，若在体Z内，依然有升职机会，自己要好好把握，在此之前能把业务技能做强为佳。

# 分析婚姻：

原局不见正财，月令和年支子水为偏财，可以代表妻子，子水偏财当令较旺，得庚金伤官生扶，代表未来妻子性格较为强势，脾气不太好，多为当家主事之人，尤其己卯日出生，日坐卯木为七杀忌神，“日坐七杀抱虎眠”，更加代表如此，所以未来当顺从妻子，方有利家庭的和谐。

地支子水偏财伏吟，临桃花，财星在年月出现，代表早年容易出现感情，但由于财旺为忌，财旺耗身，财星伏吟，也容易经历失败的感情，地支子卯相刑，两个子水来刑伤婚姻宫，也代表会因为婚姻感情产生一定压力，也代表婚姻环境较为一般。

2024甲辰年，地支子辰半合，子水妻星被合动，2026丙午年，地支子午相冲，子水妻星逢冲而动，有遇到缘分定下的运气。
