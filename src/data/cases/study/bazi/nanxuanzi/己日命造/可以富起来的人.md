# 网友来信：

我来自东北，因为早年生活在农村，家里条件一般，从毕业就找工作希望多赚点钱，无奈学历一般，在社会摸爬滚打多年一直也没有起色，从事的行业基本就是以销售为主，自我感觉还是挺会和别人聊天打交道的，工作时候业绩基本都是中上游。

但是工作几年之后发现上班工作是不可能满足我内心对财富的欲望。17年开始慢慢自由职业，后来和朋友合作做生意碰上疫情也维持不下去了。也觉得即使维持下去理念也是不同，也就好聚好散。欠了点债务。从哈尔滨出来之后去过北京成都发展都不错，身边工作的同事高学历留学生很多，自己因为出身和学历内心难免有些自卑。不过好在同事关系和睦，也尽量避免和同事有利益争斗。

因为看了些命理的书籍，也找过有学识的先生了解过，说我的命局身弱比较适合南方火旺之地发展，自己之前也因为机缘巧合来过广州，来了就很喜欢这个城市，从而就决定来这发展了。但是老话说万事开头难。是真难！像无头苍蝇一样，迷迷糊糊一年了还是没有什么起色，难道真是时来天地皆同力吗？没有运气真的是做什么都不太顺利？看着之前的同事同学都过的还可以，内心也是着急。

自己平时爱看看电影看看闲书，看到曹德旺先生写的一本《心若菩提》内心十分佩服曹公的为人事迹，白手起家然后捐款济世。之前想法不成熟觉得有钱之后能满足自己内心的物欲，这些年内心的苦吃的多了才觉得不是那样。看到书中曹公种种奉献精神，还有商人诚信经商的行为就很感动，慢慢也知道了感受到了自己需要的是成就感。克服困难的成就感，被别人认可时候的信任感。所以想过要是自己如果事业有成先从力所能及的小事做起，希望这天能早点到来！

# 八字详批：

#### 乾造：癸酉年，壬戌月，己丑日，壬申时（午未空）

#### 大运：辛酉，庚申，己未，戊午，丁巳，丙辰，乙卯，甲寅，10岁运。

# 分析命局：

己土日主生在戌月得令，坐丑土得地，地支丑戌相刑，把土冲旺，有一定帮身之用，但地支戌土和丑土来生酉金和申金，戌土和丑土泄气，天干一片壬癸水来耗身，且癸水和壬水得酉金和申金生扶有力，虽壬水日主得令得地，但依然为中和偏弱之格。

# 分析喜忌：

中和偏弱以生扶日主的火土五行为用神，以克泄耗日主的金水木五行为忌神。地支戌土当令，土来生金，喜见火来制金生土，见土虽来帮身，但也生金不吉。天干水旺成势，喜见土来制水帮身，单独见火，水火相战，较为不利。

# 分析事业：

戌土劫财当令，日坐丑土为比肩，虽命局中和偏弱，但地支由于丑戌相刑，所以土也不弱，五行土为比劫，性格非常要强，有一定上进心，比劫为用，也比较讲究义气，懂得团结他人干事，以土为用，己土日主在地支有根，相对比较踏实肯干的一个人，可以吃苦耐劳。

比劫为用，天干壬癸水财星高透，一般对他人都比较慷慨，不会在钱的使用上斤斤计较，这样的人一般能够收到别人欢迎，人缘还不错，有一定贵人运。但财在天干，地支无财库，己丑日出生为十恶大败日，也代表缺乏金钱理财观念，花钱容易大手大脚，不太聚财。财透天干，一般也虚荣心较强，比较好面子。

年柱癸酉，食神生财，时柱壬申，伤官生财，且财星较旺，均代表求财的欲望较强，一般的财较难得到满足。命局虽然偏弱，但比劫并不弱，月柱壬戌为劫财克财的组合，代表在求财上易有走捷径，投机的向心力，容易去做一些投机的事情，喜欢求快财，有一夜暴富的心理，土生金旺，也有一些急于求成，这种心态是要克服的。

酉金和申金食伤挂两头，一般而言，口才不错，人有圆滑的一面，所以从事销售相关工作总体是适合你的，也可以去做咨询、培训相关行业。伤官生财，也有一些做生意的信息，比劫为用，适合合作求财，能依靠团队发展较为有利。原局不见官杀，就连暗藏的也没有，按部就班的上班不太适合，比较适合偏自由一些的行业或岗位。

你早年走的辛酉，庚申大运，均为食伤的运气，并非好运，付出较多，收获有限，容易多败少成。2022年起进入己未大运，为比肩帮身的大运，总体运势比前面要，适合合作求财，财运总体有增加，要把握机遇，努力做出成绩，不过近几年运势不是太理想，到了2025年以后运势会逐步好起来。而且也为丑戌未三刑的运气，所以与人合作也要注意拿捏分寸，以防有是非之事。

所以给你的建议是在这之前可以上班，也可以做一些事业的筹备和谋划工作，2025年之后可以着手去做，行业上可以考虑土建、设计策划、互联网、光电等相关。后面的戊午大运，丁巳大运，运势也是不差的，收入可观，可以富起来。方位上，出生地的南方，东北方，西南方都比较旺你，可以选择这些方位发展。

# 分析婚姻：

年干癸水为偏财，月干和时干壬水为正财，正偏财同见，且先见偏财，后见正财，代表早年容易经历失败的感情才能步入正轨，自己也要注意用情专一的问题，年柱癸酉，食神生财，时柱壬申，伤官生财，代表内心可以关心体贴另一半。

伤生财，财星较旺，代表未来妻子性格还是相对强势一些，尤其日支婚姻宫为丑土比肩，婚姻宫本为妻子的位置，确见比肩，也代表难免双方相处有一些争执，要多谦让为好。地支丑戌相刑，婚姻宫被刑伤，日柱临华盖，更加代表两人磕磕绊绊是难免的，不过总体不影响大局。

从未来的感情运来看，你现在走的丑戌未三刑的运气，整体是不利婚姻的。2023癸卯年，天干癸水偏财透出，有一定异性缘分，易遇到偏缘，较难有结果。要等到2027丁未年，天干丁壬相合，壬水妻星被合动，且地支丑未相冲，婚姻宫逢冲的时候，才有机会遇到并结婚。

# 分析大运：

**30岁—39岁**

己未大运，此大运干支一气为比肩，比肩帮身制财，总体运势较为不错，有一定贵人运，可以得到他人相助，财运有所增加。但地支丑戌未三刑，也要注意官非口舌之事，凡事不可太过冒进。婚姻宫被刑伤，代表感情不会太顺利，婚后也难免会有一些压力和烦恼。

**40岁—49岁**

戊午大运，此大运为印比助身的运气，天干戊癸相合，癸水被合克，地支午火旺了比劫，故整体运势依然较好，可以在事业上做出成绩，贵人运较好，收入有所增加，但癸水被合克，花销依然较大，能养成存钱的习惯为好。地支丑午相害，依然要注意夫妻关系。

**50岁—59岁**

丁巳大运，此大运干支一气为印星，大运来助身，故整体运势依然不差，可以把握机遇，做出成绩，整体财运有所增加，生活相对富足，夫妻关系也趋于和顺，可以安度晚年。
