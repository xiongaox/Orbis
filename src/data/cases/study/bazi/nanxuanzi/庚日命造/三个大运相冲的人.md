# 三个大运相冲的人

命主生辰: 1989/06/29 8:00 (GMT+9)
性别: 坤造
日主: 庚金
格局: 正印格
令地: 失令, 得地

# 网友来信：

我出生在农村，家中父母关系和谐，但母亲和妯娌之间不和，所以小时候跟叔伯关系一般，亲情淡漠。家中经济上比周围亲戚较好。小时候学习还不错，自从初中开始下滑，没考上高中。最后勉强考上一个二本。

辛卯年毕业，上半年考公失利，参加招聘考试成绩也很差。下半年参加考公，取得意外好的成绩，顺利就业。工作开始的前几年，经常熬夜班。乙未年调动了岗位。丁酉年结婚，婚后戊戌、己亥、庚子这几年，因父母及丈夫这边长辈的关系，过得倍感压抑，很痛苦。期间积极学习参加考试，拿到几个证书。虽然证书目前没有派上用场，但这几年我成长了很多，心理上也更强大了。己亥年得女。也是己亥年兄长得病，辛丑年病情突然恶化去世。

之后的壬寅年我情绪低落焦虑了很久。工作以来，人际关系还不错，得同事帮助、领导器重。平常工作比较忙碌，而我现在只想有更多的时间陪伴父母孩子，有想调动工作的想法。我接下来的3个大运，都是对冲，不知道是否很不吉利。

> 1. 我未来的财运、事业、健康如何？
>
> 2. 父母身体怎么样？
>
> 3. 子女未来发展如何？
>
> 4. 丈夫（【**庚午，戊寅，壬戌，癸卯**】）运势如何？婚姻是否平顺？
# 八字详批：

#### 坤造：己巳年，庚午月，庚申日，庚辰时（子丑空）

#### 大运：辛未，壬申，癸酉，甲戌，乙亥，丙子，丁丑，戊寅，4岁运。

# 分析命局：

庚金日主生在午月失令，坐申金得地，申金为庚金日主的禄神，帮身力量较强，月干和时干透出庚金来帮身，时支辰土来生扶日主，年干透出己土也是生扶日主的五行，年支巳火来克身，但也来生己土，间接助身，加上“我党”大于“异党”，庚金日主在天干得势又得地，为偏旺之格，年干己土正印从月令午火中透出，为正印格。

# 分析喜忌：

偏旺以泄耗日主的水木五行为用神，以生扶日主的土金五行为忌神，火虽克身，但在天干地支生土不吉。天干三个庚金，土来生金，喜见水来泄身，也同时喜见木来疏土，水木同见为吉。地支喜见木来助火并疏土，见水也为吉，但最好同时见木。

# 分析事业：

偏旺喜见水来泄身，也喜见木来耗身且疏土，但原局不见水也不见木，唯有地支暗藏乙木、癸水和壬水，藏而不显，为不足之处，地支午火当令，年支见巳火，虽可克身，但也旺了己土和辰土，旺了忌神，也为不足之处，但好在月干庚金和日支申金有制，也为吉利。

身旺五行金旺，同时金为比肩，而月令午火为正官，年支巳火为七杀，官杀当令，总体是比较积极努力上进的，事业心较强，人也比较好强，不会轻易妥协服输。身旺庚申日出生，日坐申金为禄神，一般做事比较踏实稳重，可以吃苦耐劳，有利事业发展。比肩较旺，巳申相合，申金禄神被制，也代表事业比较辛苦忙碌。

不过身旺不见食伤来泄身，比肩较旺，且五行金旺，性格会比较刚直，也比较固执，自我意识很强，容易冲动急躁，有时候有一些任性，脾气不太好，自尊心很强，与人相处也比较直来直去，缺少一些灵活和圆滑。原局官杀混杂，做事也难免会心不定，容易三心二意，做事不够坚持。

身旺不见食伤来泄秀，在创造力等方面比较缺乏，又月令午火为正官，年支巳火为七杀，适合上班做一些按部就班、偏稳定的工作要好一些，能进公务员、事业单位、国企央企上班最为理想，故而现在在体制内上班是既可以的，可以坚持下去。

以午火官星代表事业，午火虽当令，但有巳火七杀来乱局，官杀混杂，且己土和辰土正偏印同见，杂而不贵，且五行不见木来生火，为无财之官杀，官杀没有元神，故而事业运不是很强，升职发展空间不大，而且官杀混杂，也代表事业或岗位容易变动较多。

加上比肩较旺为忌神，代表事业上竞争很大，很容易遇到强有力的竞争对手，容易被他人抢风头，或窃取劳动果实，比肩较旺，也代表唯有多吃苦，多付出，才有利事业的发展。

你上步走的是癸酉大运，有癸水伤官来泄身，总体事业运尚可，不过从去年起进入甲戌大运，地支辰戌相冲，旺了印星，整体运势较为一般，事业运有所下滑，但未来的乙亥大运，整体不错，要把握机遇，努力做出成绩，不要怕累，不要怕苦，有升职发展机会，丙子大运，稍有下滑，能退则退为佳。

财运方面，身旺不见财星，唯有时支辰土暗藏乙木财星，藏而不显，庚申日出生，日坐申金为禄神，俗话说：天干没有苦庚申，多为衣食无忧之命，但想见大财较为困难，也多为工作所得的财，即工资财，能懂得知足为佳。
# 分析婚姻：

年支巳火为七杀，月令午火为正官，为官杀混杂的组合，且先见七杀，后见正官，早年容易经历失败的感情，经历失败的感情也相当于化解了一部分，有利现在婚姻的稳定，日支婚姻宫为申金忌神，申金为比肩，难免有磕磕绊绊，要加强忍让包容为好。

现在走的甲戌大运，冲比肩庚金地支印也逢冲，难免有些感情放烦恼顾虑，但到了乙亥、丙子大运，婚姻运势有一些不利，夫妻矛盾会多一些，过了这两步大运，婚姻会趋于和顺。

丈夫乾造：【**庚午，戊寅，壬戌，癸卯**】，壬水日主生在寅月失令，坐戌土失地，月干透出戊土来克身，时支卯木来泄身，年支午火来耗身，年干庚金来生扶日主，时干癸水来帮身，为身弱之命，以金水为用神，以木火为忌神，土虽克身，但在天干生金为吉。丈夫现在走的壬午大运，癸未大运，总体运势较为一般，但也不差，但53岁后进入甲申大运，运势会更好一些。他五行木旺，是你的用神，你的五行金旺，也是他的用神，喜忌可以互补，在一起的话，对对方运势有所帮助，你们的八字寅午戌三合，寅巳相害，寅申相冲，寅巳申三刑，卯辰相害，辰戌相冲，所以整体合婚匹配度属于大众化水平，多忍让包容为佳。

你庚申日柱，女命以食伤代表子女，原局见食伤两位，所以单纯从你命局来看，理论上有一女一儿，八字食伤不显，且时柱子女宫庚辰为忌，代表未来子女发展较为一般，家长要加强教育引导为好，丈夫以官杀为忌，也代表如此，未来可以往事业单位、国企央企等方向培养。

女命以偏印为母，以正财为父，乙木正财暗藏，藏而不显，和父亲缘分相对淡薄一些，逢狗年、兔年、猪年、虎年要多注意父亲身体健康。

原局五行不见水，要注意肾脏，膀胱，妇科，泌尿系统方面疾病。五行金气较旺，物极必反，要注意肺部，肠道方面疾病。不见木，要注意经络，肝胆，关节，甲状腺等方面问题。

# 分析大运：

**34岁—43岁**

甲戌大运，此大运地支戌土被天干甲木盖头，为财星克印的大运，天干甲木财星透出，甲己相合，己土印星被合克为吉，留下辰土偏印，较为纯净，地支辰戌相冲，把印星冲旺，故整体事业运平平，适合求稳过度，也有变动之象辛苦忙碌求财。

**44岁—53岁**

乙亥大运，此大运为食神生财的大运，天干乙庚相合，正财合身，求财相对稳定，多为工资财，但三个庚金争合乙木财星，代表事业上竞争很大，也要注意钱财花销破耗。地支巳亥相冲，亥水七杀逢冲，岗位依然容易有变动，申亥相害，事业比较辛苦，但也有升职提拔的机会，也要注意夫妻关系。

**54岁—63岁**

丙子大运，此大运天干丙火被地支子水戳脚，为伤官制杀的大运，天干丙火七杀透出，旺了印星，地支子午相冲，为伤官克官，要注意事业或岗位变动，能退则退为佳，也要注意口舌是非，与人不和之事，尤其要注意夫妻关系，也要注意丈夫身体健康。
