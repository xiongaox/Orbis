# 网友来信：

我出生在山东的一个海滨小渔村，自幼母亲多病，父亲靠着一身的劳力，辛苦养家，然而天有不测风云，16岁的我突发耳聋，经过多方医治无果，最终成了一名重度耳聋患者。父亲的责骂，母亲的重病，我的无声世界，那段时间大概是我人生的最低谷了。

在亲戚的帮助下，壬午年我从农村来到城市，开始了我的经商生涯，老天终于眷顾了我，开始了我的蜕变。

在政府各界部门的帮助下，我的小店生意兴隆，而我也作为创业典型，取得了大大小小的很多荣誉，从市里，省里，到国家级的荣誉，有时也觉得自己何德何能，不配拥有，可真的好运来了，挡也挡不住。后边的几年，小店交给了父母，我于丁亥年转行，开始了现在的医疗器械生意，到现在开了五家店，赚钱一直也不算多，甚至不如买房子升值赚的多，贷款压力也很大，因为大环境的影响，店里生意一直不景气。

感情方面，我于癸未年，认识了现在的妻子，丁亥年结婚并生子，妻子温柔善良，儿子调皮却可爱，一家三口算是和和美美！

# 八字详批：

#### 乾造：己未年，壬申月，庚戌日，丁亥时（寅卯空）

# 分析命局：

庚金日主生在申月得令，申金为庚金日主的禄神，帮身力量较强，坐戌土得地，年柱己未干支一气来生扶日主，地支戌未相刑，生扶力量较强，月干壬水和时支亥水来泄身，时干丁火来克身，但庚金日主得令得地，“我党”大于“异党”，故为偏旺之格。

# 分析喜忌：

偏旺以泄耗日主的水木五行为用神，以生扶日主的土金五行为忌神，火虽克身，但在天干地支生土不吉，金虽帮身，但在天干地支生水也为吉。土金两旺，由于见壬水和亥水，故喜见木来疏土耗身，壬水和亥水得申金生扶不弱，且丁壬相合，丁亥暗合，壬水和亥水得到保护，故而天干地支见土金也无碍。

# 分析事业：

庚戌日出生为魁罡日，为魁罡格，一般而言，魁罡格喜身旺，不喜见太多财官，身旺为吉。虽然时干见丁火正官，但丁壬相合，丁亥暗合，丁火官星被合克，同时，壬水和亥水食神得到保护，可谓一箭双雕，土对水虽有克性但不大，为近贵的组合。

命书中讲：壬辰庚戌与庚辰，戊戌魁罡四座神，不见财官刑煞并，身行旺地贵无偏。
从22岁后进入己巳大运，和戊辰大运，由于有丁火去合壬水和亥水，故而没有对壬水造成太大伤害，又逢食伤禄来临，为行旺地，故这两个大运可以拥有自己的事业，也可以顺风顺水，取得一定成绩。

魁罡日出生，申金比肩当令较旺，月干壬水食神高透，庚金为阳金，性格会有一些刚强好强，人也非常上进，有自己的想法，但也有一些固执执拗，人比较直来直去，丁壬相合，丁亥暗合，食神都来合官，事业心较强的一个人，食神泄身为用，有时候也有一些温和之气。

原局不见财星，只有年支未土为财库，财库在年，且月令申金为禄神，临驿马，庚戌日出生临金舆，适合外出家乡求财，在家乡发展不是很适合，出生地的北方，东方，东南方比较旺你。月令申金为庚金日主的禄神，临驿马，为禄马相逢，比较有福气的一个人，也代表人比较勤快，肯吃苦，也可以依靠自身努力获得财富。

时干丁火官星高透入门户，可以得到这个官，除工作之外，也有获得名气和荣誉之象，又丁壬相合，也代表自己比较在乎名声，比较好面子，甚至难免有一点虚荣心。食神来合克官星，也比较爱自由，多从事偏自由一类职业，不适合上班。

地支戌未相刑，财库开库，可以得到这个财，时支亥水暗藏甲木偏财，亥水入门户，也为财入门户，可以得到这个财，天干丁壬相合，壬水食神被合入，也可代表财，故而一生财富等级不会低。

结合大运走势来看，现在走的丁卯大运，未来走的丙寅大运，寅亥相合，虽财官旺的大运魁罡格有所破格，但财运会逐步变好，整体财富等级在小富左右的水平。

不过除了大环境的影响外，现在走的丁卯大运，地支亥卯未三合，未土财库有闭库之象，也有财富有所走低之势，地支卯木财星为正财被合入门户，小钱依然不少，但想赚大财有点难。到了丙寅大运会比现在好很多。

年支未土为财库，临天医，八字为魁罡格，食神泄身为用，适合从事和医学有关的行业，你现在从事医疗器械相关行业可以坚持去做。

不过你命局有驿马、金舆，有动中求财之象，能选择经常出差，或者与线上物流配送等方面挂靠是比较好的。

# 分析婚姻：

原局身旺，以壬水和亥水为寿元，虽壬水坐申金之上有力，且丁壬相合，丁亥暗合，壬水和亥水有保护，但己土和戌土印星来制，依然有克性，且有申亥相害，亥水有损，容易有耳朵，肾脏，肺部，肠道，泌尿系统等方面问题。

五行不见木，要注意肝胆，经络，关节，腰间盘突出等方面问题，地支戌未相刑，也要注意皮肤，鼻炎，禅位方面问题。丁壬相合，丁亥暗合，丁火被合克，要注意眼目、血液、肠道、心脑血管方面疾病。

# 分析子女：

你庚戌日柱，男命以官杀为子女星，命局中正官三位，理论上有三个女儿，有儿子多借助妻子的运气。时柱子女宫丁火官星为用，临文昌贵人，故孩子比较聪明伶俐，未来比较有出息，也有晚年有靠之象，有子女之福。

# 分析大运：

**42岁—51岁**

丁卯大运，此大运为财官相生的大运，行财官大运魁罡格有所破格，会有一些拉低层次，总体不如前两步大运那般顺风顺水，但也不会太差。地支亥卯未三合，未土财库有闭库之象，卯木为正财被合入，故较难见到太大的财，能满足与维持生计为好，总体财运也不差。

**52岁—61岁**

丙寅大运，此大运为财杀相生的大运，天干丙火七杀透出，和命局构成官杀混杂，事业有变动之象，地支寅亥相合，寅木偏财被合入门户，财运有一定起色，收入有增加，总体较为理想。但寅申相冲，冲了禄神，故要注意身体健康，尤其是肺部，肠道，肝胆，经络等方面问题。
