# 地支全是财的人

命主生辰: 1999/02/07 6:00 (GMT+8)
性别: 乾造
日主: 庚金
格局: 七杀格
令地: 失令, 失地

# 网友来信：

我广州一个落后的小村庄。我离预产期提早半个月出生，身体从小就身体虚弱，性格也很内向，多愁善感。小时候运势一般，学习成绩也算靠前，后来就越来越倒霉，也许是和换大运有关系吧。上初中后，我的人生跌入了谷底，遭受了严重的校园凌辱，患上了严重的抑郁症，每天都想自s，上学对于我来说就是地狱。那会我没有一个朋友，上课吃饭都是一个人，几乎每个星期都装病请假躲避那些暴力我的人。祸不单行，初三那年，爷爷奶奶相继去世（癸巳年下半年），相隔不到两个月。

上完初中后，上了半年中专就辍学了。来社会后，压力更大了，因为要强迫自己独立养活自己了。打工也是做做停停，失业比上班还多。

> 回过头来想想这二十多年好像从来没有轻松过。我有几个问题想求指点。
>
> 1.我自己看是财多身弱的，赚钱也确实很辛苦，请问我以后的事业财运如何？
>
> 2.我的地支全是寅卯财，都说财多的人婚姻坎坷，花心，女人缘好。可是我这么多年来都是单身呀？性格内向没有和女孩子谈过，说话也几乎没有，身边朋友都少，更别说异性缘了。我未来另一半品性如何？对我有帮助吗吗？我会被她欺负吗？
>
> 3.我没有水，生育是不是困难？以后孩子会好吗？
>
> 4.我目前炒股票期货几年了，目前还是亏的，我能在这方面赚大钱吗？我真的不想打工，不知道是不是以前的校园凌辱让我心理受伤害，人际关系让我好痛苦。

# 分析命局：

庚金日主生在寅月失令，坐寅木失地，年支卯木和时支卯木伏吟，均来耗身，年干和时干己土来生扶日主，但均被卯木戳脚，己土生扶力量不强，月干丙火来克身，丙火得寅木生扶不弱，但丙火来生己土，己土有一定力量，庚金日主失令失地，为偏弱之格。月干丙火七杀从月令寅木中透出，为七杀格。

# 分析喜忌：

偏弱以生扶日主的土金五行为用神，以泄耗日主的水木五行为忌神，火虽克身，但在天干生土为吉。地支寅木当令，伏吟地支，地支卯木伏吟。

# 分析事业：

以年干和时干己土为用，但被卯木戳脚，为财星克印，用神制忌，较为不利，但好在丙火来生己土，旺了己土，己土有元神，为吉利的一面。

另外庚金为矿石金、顽石金，喜见丁火来提炼，方可使金成器，但命局不见丁火，唯独月干见丙火，略有不足，庚金生于正月，春寒料峭，天气尚有余寒，喜见丙火透出暖局，月干见丙火透出可以祛除寒冷，较为吉利。

寅木财星当令，伏吟地支，地支又见卯木财星，正偏财同见，年柱和时柱己卯，己土被卯木戳脚，为财星克印，印星受到财星克制，在学习上面也不是很顺利，阻碍很大。而且印被财克，学习状态不好，容易分心静不下心，而影响学业，很难取得一定学历和文凭，尤其早年走的甲子大运，天干甲己相合，财星克印，更加不利学业，这种组合多会辍学，为不利之处。

地支寅木伏吟，卯木伏吟，正偏财同见，地支一片财，一般内心都不太安分，多不会仅仅满足于工资之财，多会追求贪财想求快财，投机取巧赌博炒股，但并不适合。地支财星太旺而无制，且没有强根，体现为做事没有魄力，比较优柔寡断，性格也偏懦弱，容易错失良机，做事也不易坚持到底，遇到困难容易知难而退。原局七杀格，丙火七杀贴身，印星被制，也比较缺乏安全感，压力较大。

庚寅日出生，为十灵日出生，临太极贵人，月柱也临太极贵人，性格多偏内向一些，但也一般都会神秘文化比较感兴趣，在这方面有一定悟性。年柱和时柱己卯伏吟，地支寅木伏吟，见三个伏吟，伏吟较多，又印星被财星所伤，有时候反应会比别人慢一拍。

年柱和时柱己卯，为财星克印，在求财上有时候会欠缺思考，容易突破道德底线，欠缺仁义，这是要注意的。而且己土印星又为寿元星，被制代表身体健康不太好，小毛小病较多。七杀格，印星被制，用神受损，早年又走的甲子大运，甲己相合，己土被合克，忌神太旺，所以运势较为低迷，很容易遭遇阻碍，忌神太旺也有小人的意思，所以在学校容易遭遇欺凌。

地支寅卯木当令较旺，一片财星，身弱庚金日主在地支无根，不见比劫帮身制财，故为身弱财旺之命，较难担得起财，加上财星克印的组合，代表求财辛苦，付出较多，收获有限，唯有大运助身，方可担财。

结合大运走势来看，现在走的癸亥大运，地支寅亥相合，旺了寅木，接下来走的是壬戌大运，财运均较为一般，但41岁后进入辛酉，庚申大运，比劫帮身制财，财运会好起来，也有贵人相助，为令人欣慰之处。

你现在兼职炒股，从行运来看，现在是很难赚到钱的，尤其地支一片财，身弱不担财，代表容易财来财去，不太聚财。所以现阶段能上班求财为好，也不宜去做生意，财星克印，好运来了的时候可以考虑投资一些固定产，通过这样的方式守住钱财，财星太旺能学习下财务、会计相关，从事相关职业为好，或者依靠技术立身，踏踏实实付出为好。

# 分析婚姻：

天干代表外在，地支代表内心，天干杀印相生，给人感觉会感情被动，而日月支寅木为偏财，年时支卯木为正财，内心是花心的，有些闷骚的类型。以卯木正财为妻，寅木偏财当令，卯木正财不入婚姻宫，内心对待感情很容易心有不专，三心二意，偏财代表偏缘，财星制印，婚姻宫有损，卯木为桃花，也容易有偏缘介入婚姻。

财星当令较旺，未来多为妻子当家，代表妻子较为强势，在婚姻中会让自己感到压力，财星太多，身弱不担财，反而在异性面前容易望而却步，另一半能力和条件一般，对自己帮助不大，且容易消耗自己。

所谓物极必反的道理，没有妻星，或妻星太多，均不利姻缘，所谓独财为贵，不多不少，不偏不倚，反而顺遂，当然也要结合组合来看。

2025乙巳年，天干乙木妻星出现，乙庚相合，正财合身，2026丙午年，地支寅午半合，婚姻宫被合动，且天喜入命，有遇到和结婚的运气。

你庚寅日柱，男命以官杀代表子女，见七杀三位，所以单纯从你命局来看，理论上有三个儿子，儿子缘分稍强一些，但七杀不为喜，代表未来子女发展较为一般，不过时柱临桃花，也代表子女长相和气质不错。原局不见水，在备孕生育方面易有不利，要孩子前先调理。

# 分析大运：

**21岁—30岁**

癸亥大运，此大运干支一气为食伤，天干癸水伤官透出，地支寅亥相合，食神生财，代表求财的欲望较强，不太容易得到满足，食神去合偏财，也多喜欢生意财，但大运不助身，整体财运不太有利，付出较多，收获有限，能上班求财为好。

**31岁—40岁**

壬戌大运，此大运天干壬水被地支戌土戳脚，天干壬水食神透出，壬丙相冲，冲了丙火七杀，故事业不太稳定，很容易发生变动。地支土木相战，财运较为一般，花销较大，不太聚财，依然适合上班。

**41岁—50岁**

辛酉大运，此大运干支一气为劫财，劫财帮身制财，整体财运会逐步好起来，贵人运较为，可以得到他人相助，可以考虑做点生意，搞点投资，但能合作求财为佳。也可以考虑去兼职炒股，可以赚到一些钱，地支卯酉相冲，冲了卯木财星，花销也是有的。

**51岁—60岁**

庚申大运，此大运干支一气为比肩，比肩帮身制财，整体财运依然不差，收入有所增加，生活相对富足，贵人运较好，能选择合作求财为好。地支申金为庚金日主的禄神，也为驿马，寅申相冲，驿马逢冲，走动奔波较多，求财辛苦，婚姻宫逢冲，要注意夫妻关系。
