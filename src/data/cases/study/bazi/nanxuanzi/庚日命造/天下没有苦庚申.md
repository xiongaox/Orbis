# 天下没有苦庚申

格局: 正官格

# 网友来信：

小时家贫，父母都是苦命人，小时过得特别艰难。而且他们都是半路夫妻，结婚后他们生了两个孩子，我是最小的那个。小学时发现我学习成绩很不错以后，他们给了我最大的期望和最严的管教，开始给我立规矩：只能考第一名第二名，考第三名回家就要挨揍，每次一旦考到第三名，我就怀着忧虑害怕的心情回家。小学初中一路上来，因为成绩好，我都是学校里的明星。高中离家远，他们也管不到我了，高中放飞了两年。后来高三父母跟我讲，考不上一本就不用上大学了。高三发奋，勉强读了个武汉的211。后来考研来到东部一所名校，可以让父母脸上有光的那种学校。

研究生毕业做过两年工程师，做过一年半风投， 后来丙申年来一家上市公司，一直做到现在。虽然给的待遇还不错了，工作也不是很忙，但是我一直无法爱上这份工作。还是怀念在风投公司时，身边是多元化的精英，都可以让我学到很多东西。现在的工作，感觉对我有些消耗，没什么长进。而我最爱的，还是研究股市，研究一家家上市公司的公告和研报。股市里是最能反应真理的地方，能长期赚钱，肯定是掌握真理的。这几年资金投入量不大，但总体上看下来，我对结果还是满意的。我想请问的是，从命理上看，我是否有全职股民的基础？

目前的资金量，还是小了一些，我想边工作边积累，40岁以后不想打工了，专职研究上市公司。我虽然表面上看，交际也没什么问题，但我实际上比较孤僻，不爱交往，不爱跟人打交道，也容易在跟人打交道的时候讨厌自己。反而阅读和写作更令我心情愉悦。我感觉人际中很多交流对我来讲都是消耗，这也是为什么我喜欢股市。

我有一个公WU员老婆，是读研时小我两岁的师妹，乙未年结的婚。和我一样，贫家出身，没有嫌弃我家贫，我们算是裸婚的。而且婚后我还得负担自己父母的生活费和医疗费，她从来都没有怨言。丙申年我们有了个男宝宝。

如今，一切都已经妥当。我老婆很知足，一直在讲，够了够了。而我想的是千万以上的财富，并因此而带来的自由和选择。不知道这算不算志大才疏？
