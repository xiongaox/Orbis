# 日支伤官的人

命主生辰: 2002/02/12 10:00 (GMT+8)
性别: 坤造
日主: 庚金
格局: 偏印格
令地: 失令, 失地

# 网友来信：

我出生在一个普通阶级的家庭，母亲的婆家是重男轻女的家庭，她苦于没人照顾我，于是她便辞职带我一路成长，我跟父亲母亲关系都很好，但是跟母亲会更为亲密。上小学五年级之前，我一直是一个成绩很普通的学生，老师们对我的评价都是懵懵的小孩，直到上五年级，开始开窍，学习越来越好，从班里中等变成了前10名，初中上了一个公立学校，后面中考考上了市里最好的高中。高二的时候（也就是丁酉年）是高中时成绩最好的时候，本来以为能考上普通一本的院校，最后高三学习排名下跌，考上了一个普通二本院校，成绩差一本线2分，然后选择了药学类专业学习。

当时的成绩报考的选择比较有限，我听取老师和父母的建议报考了药学类的专业，本来想着上大学认真学习能考个研究生，而大学四年以来除了第一学期，后面成绩都比较不理想，我发现我的专业和化学的关系比较大，而我高中物理比较厉害，化学都是靠补习才成绩上涨的，而且我对这个专业的学科并没有什么兴趣，加上反复的成绩不理想使我渐渐失去了信心。我深深的明白自己不是化学这块料，于是毕业我就直接找工作了。

我找了一份私企的工作，是这个行业里面的大公司，工作地点是在医院。本来驻地是在家附近的，但是因为驻地没项目，所以经常跑各地支援，由于外出支援，还是挣到了不少钱。工作了一年之后，由于已经达到升职要求，但是领导觉得我资历不够不让我升职，我能感觉到她言外之意似乎是让我要不继续各地跑支援要不主动离职。因为这份工作本来我就是有点当备胎一样在干的，想着可以一边干这份工作一边备考公务员事业编，但是事实证明是事与愿违的，加上反复的加班让我感觉如果以后有了家庭干这份工作会顾不上家，我更希望自己能有去生活的空间。于是我想要不要离职备考半年。

> 我想了解的有以下问题：
>
> 1.我是适合公务员和事业编的工作吗，明年我有考试运吗？走的正财大运会不会因为克印星而影响考试？
>
> 2.我是几乎相对于母胎单身，我以后结婚的对象是势均力敌的吗？是不是离我家比较远？什么时候会有对象？
>
> 3.我更适合找什么行业的工作？（什么属性的工作）

# 八字详批：

#### 坤造：庚辰年，戊寅月，庚子日，辛巳时（辰巳空）

#### 大运：丁丑，丙子，乙亥，甲戌，癸酉，壬申，辛未，庚午，3岁运。

# 分析命局：

庚金日主生在寅月失令，坐子水失地，年支辰土来生扶日主，并在月干透出戊土，也是生扶日主的五行，但辰土被寅木所制，戊土被寅木戳脚，生扶力量有限，年干庚金和时干辛金来帮身，时柱辛巳暗合，辛金被合克，帮身力量有限，庚金日主失令失地，但依然为中和偏弱之格。月干戊土偏印从月令寅木中透出，为偏印格。

# 分析喜忌：

中和偏弱以生扶日主的土金五行为用神，以泄耗日主的水木五行为忌神，火虽克身，但在天干地支生土为吉。寅木当令，木来克土，喜见火来通关生土，也喜见金来制木帮身。天干庚金得势，喜见土来生金，金来帮身。

# 分析事业：

年支辰土和月干戊土为用，但辰土和戊土被寅木所制，为忌神制用，稍有不利，年干庚金为用，庚金得辰土和戊土生扶，为吉利之处，只是土的力量上打些折扣，时干辛金也为用神，但时柱辛巳暗合，辛金被合克，也为不足，组合较为一般。

寅木财星当令，寅木来制辰土和戊土，财星克印，印星为用受到财星克制不利学业，难免有波动。而且印被财克，也容易被外界影响分心，影响学业，尤其参加工作之后，更加会因为外面花花世界，因为工作等忽略学习。不过由于原局中和偏弱，土有木来制，且为金日主，也体现为一种机灵。

财星克印，一般比较辛苦忙碌，同时在工作中会比较计较较多，得失心重，而庚金日主在地支无强根，加上辰土和巳火空亡，空亡较多，也代表做事也不易坚持到底，容易半途而废，有时候不够务实，不够踏实。

地支子水来生寅木，为伤官生财的组合，寅木偏财当令较旺，物欲较重，会因为生活中有很多求不得的事情，而让你感到痛苦，烦恼。身弱喜印，空亡较多，适合从事一些相对务实一些的工作，从事教育文化行业是适合你的，能进学校或大一些的平台上班，有利你的运势。

除此之外，寅木偏财当令，财旺耗身，五行喜金，寅木财临驿马，有动财之象，故能选择金融、财会、经济方面的专业或行业最为适合，能进一些金融机构、银行等，或者在企业、单位做财务适合你，也有利你的财运。至于公务员、事业单位，由于庚子出生，日坐子水为伤官，地支子水伤官制杀，适合偏自由一些的行业或岗位，能考教师编或者考证、考资质会更加适合你。

不过现在走的是乙亥大运，为食神生财的大运，地支寅亥相合，旺了寅木，天干乙木财星克印，整体不利考学，今年癸卯年，地支卯辰相害，辰土印星受损，且戊癸相合，戊土印星被合绊，考学运不佳，很容易折戟。2024甲辰年，地支辰土印星填实，考学运稍好，但甲木财星克印，也非最理想，到了2025乙巳年，2026丙午年，旺了印星，考学运相对理想，要把握住。

至于工作方面，你当初学习药学，后面学化学，是不太适合你，现在在医院上班，对于你也是权宜之计，重心可以要放在考试上。

今年癸卯年，对于你也是害太岁的年份，必然过得不太称心如意，但依然不建议今年就辞职备考，能咬咬牙挺一挺，撑到明年考上再辞，或者后年、大后年，是比较稳妥的选择，退一步讲，即使没考上，再找工作机会也多很多。

# 分析婚姻：

原局不见正官，时支巳火为七杀，可以代表丈夫，巳火空亡，且在时柱，临孤辰，故代表异性缘分较为薄弱，不太容易遇到另一半，或即使遇到异性缘分，不太容易成，所以对于你而言，能经人介绍，或者积极相亲，是个不错的选择。

庚子日出生，日坐子水为伤官，伤官在婚姻宫，伤官是克官的，且地支子水来制巳火，为伤官制杀，均代表自己在婚姻感情上有一定标准和要求，择偶的话一般人难入法眼，也要适当降低要求为好，婚后也难免有磕磕绊绊。

2025乙巳年，地支巳火七杀夫星出现，填实巳火，有机会遇到缘分，或者2026丙午年，天干丙火七杀夫星出现，地支子午相冲，婚姻宫逢冲，有遇到缘分并结婚的机会。或者2028戊申年，地支申子辰三合虽不化，但婚姻宫逢合，也有机会结婚。

# 分析大运：

**23岁—32岁**

乙亥大运，此大运为食神生财的大运，天干乙木财星克印，地支寅亥相合，旺了寅木财星，故整体运势较为一般，付出较多，收获有限，容易错失良机，财运较为一般，事业上没有太多升职发展的机会。巳亥相冲，巳火七杀逢冲，事业容易变动，也代表择偶和婚姻不会太顺利。

**33岁—42岁**

甲戌大运，此大运地支戌土被天干甲木盖头，为财星克印的大运，天干甲木财星克印，地支辰戌相冲，故整体运势一般偏好，事业上有一定发展的机会，有一定贵人运，可以得到他人相助，但也难免求财辛苦，花销较大。

**43岁—52岁**

癸酉大运，此大运天干癸水伤官高透，天干戊癸相合，地支酉辰相合，印星均被合绊，故整体运势又有所下滑，容易错失良机，或者机会来了不易把握住，升职发展机会不多，事业竞争较大，所以整体适合求稳过渡。

**53岁—62岁**

壬申大运，此大运天干壬水食神高透，地支申金比肩帮身，贵人运较为不错，可以得到他人相助，地支申子辰三合，夫妻较为和谐，人缘较为不错，收入有所增加，但寅申相冲，驿马逢冲，比较奔波辛苦，寅巳申三刑，也要注意口舌是非。
