# 八字详批：

#### 坤造：甲戌年，丙子月，庚辰日，丁丑时（申酉空）

#### 大运：乙亥，甲戌，癸酉，壬申，辛未，庚午，己巳，戊辰，丁卯，6岁运。

# 分析命局：

庚金日主生在子月失令，子月泄日主力量大，坐辰土得地，年支戌土也是生扶日主的五行，地支辰戌相冲，把土冲旺，有一定生扶之用，时支丑土也来生扶日主，月干丙火和时干丁火来克身，年干甲木来耗身，戌土被甲木盖头，戌土生扶力量有所打折扣，为身弱之格。

# 分析喜忌：

偏弱以生扶日主的土金五行为用神，以泄耗日主的水木五行为忌神，五行火虽克身，但在地支生土为吉。地支子水当令，喜见土来制水，天干木火两旺，喜见土来通关生身，土为通关用神。

# 分析事业：

子水伤官当令较旺，但地支有戌土和辰土来制子水，属于用神制忌神，忌神有制，较为吉利，时柱丁丑，丁火来生丑土，旺了丑土用神，用神有利，也为吉利。丙火七杀为忌，但被子水戳脚，忌神有制也为吉，但年柱甲戌，戌土被甲木盖头，忌神制用，稍有不利，整体从组合而言不差。

命局子水伤官当令，伤官虽为忌神，但年支见戊土印星，日支见辰土印星来制子水为吉，命局也属于金水食伤，都代表为人是比较聪明的，加上甲木偏财虚透，口才一般不差，头脑比较灵活，机灵圆滑。

而庚辰日出生临魁罡贵人，天干丙丁火官杀透出相随，也代表自己事业心较重，有上进心，比较要强好胜，不会轻易妥协服输。

子水伤官当令，年干甲木为偏财，也代表野心和欲望较强，而子水伤官有印来制，也代表有转圜的余地，自己懂得拿捏分寸。

不过戌土和辰土为偏印，时支丑土为正印，正偏印同见，天干又丙丁火官杀混杂，也代表容易心有不专，但好在官杀有制，故而做事还算专注用心，甲木偏财高透，也有一定虚荣心。

庚辰日出生为魁罡格，辰戌相冲，魁罡逢冲，也代表有时候性格脾气不太好，虽雷厉风行，率直果敢，但也容易急躁冲动，与人发生冲突不和，是要注意的地方。

时支丑土印星为用，且临天乙贵人，为命局唯一天乙贵人，贵人运较为不错，可以得到他人相助，为吉的一面。天乙贵人一般不能太多，太多了就好像都想帮自己，但都在观望，结果大家都不出手，天乙贵人太多就打了折扣了。

年干甲木为偏财，偏财虚透，难以直接得到子水伤官生扶，地支无财库，加上庚辰日出生为十恶大败日，均代表开支花销比较多，缺少一些理财观念，容易财来财去，所以你有创业做生意的想法，我是不太建议的，非要做也只能跟着别人做，且别人为主，自己为辅要好点。而且最早要等到46岁后进入辛未大运，一方面辛金劫财助身，有一定贵人运，可以合作，另一方面地支未土出现，有利聚财，过了这步大运，依然建议收手为好。

庚辰魁罡日出生，临国印贵人，子水伤官有印星来制，丙丁火官杀相随，时柱丁丑官印相生，月柱丙子为伤官制杀的组合，均代表自己适合去做管理相关，所以目前从事的岗位是适合你的，由于身弱喜印，故能进一些大一些的平台、公司、企业等，最为理想，未来大运助身，有机会做到管理层。

地支辰戌相冲，能外出发展较为有利，出生地的西方，西北方，东北方，西南方比较旺你。

# 分析婚姻：

月干丙火为七杀，时干丁火为正官，为官杀混杂的组合，先见七杀，后见正官，先杀后官，丁火正官在时柱，均代表早年容易经历失败的感情，丙火七杀为偏缘，也为忌神，代表也容易在感情上遭遇不良人，所以在择偶上也不可不防。

2016丙申年遇到现在男朋友，天干丙火为七杀，多为偏缘，想坚持到最后并非太容易。尤其你现在走的癸酉大运，天干伤官见官，今年癸卯年，天干伤官见官，地支卯辰相害，婚姻宫受损，容易有矛盾不和之事，要多注意为好。若过了今年，就要把握住2025乙巳年，红鸾星入命的时候，有结婚的运气。

# 分析大运：

**26岁—35岁**

癸酉大运，此大运天干癸水伤官高透，癸水来制丁火，为伤官克官的组合，地支酉金通关，旺了子水伤官，故并非太好的运气，事业上很容易有口舌是非，与人不和之事，也容易被欺骗伤害，要多注意为好，地支酉金为桃花，也有一定异性缘分，但伤官克官，婚姻不会太顺利。

**36岁—45岁**

壬申大运，此大运天壬水食神透出，丁壬相合，丁火被合克，为去官留杀的组合，地支申金来助身，故整体运势要比之前稍好一些，事业相对顺利，有变动的想法，可以考虑此大运换大一些平台为好。但申金旺了子水，依然要注意克制野心和欲望。

**46岁—55岁**

辛未大运，此大运为印比助身的大运，天干丙辛相合，为去杀留官，格局变得清纯，地支未土印星来助身，故整体运势较好，事业上可以得到贵人相助，有升职发展的机会，可以做出成绩，也可考虑合作求财，财运有所增加，但地支辰戌丑未会土局，也要注意急躁冲动，与人不和，婚姻矛盾之事。

**56岁—65岁**

庚午大运，此大运天干庚金被地支午火戳脚，天干庚金比肩帮身，依然代表贵人运不错，可以得到他人相助，但甲庚相冲，要注意钱财花销破耗，地支子午相冲，为伤官见官，要注意口舌是非，与人不和，也难免有婚姻家庭不和之事，多注意为好。
