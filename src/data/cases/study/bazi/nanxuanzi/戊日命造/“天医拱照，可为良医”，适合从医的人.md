# 网友来信：

我高考的时候甲午年考了个山东的二本院校，阴差阳错地学了医学。但是我始终认为从医并不是我的归宿，所以大四的时候丁酉年跨专业报考了北京一所学校的管理学专业，一战惨败，但考研的念头却更加坚定了。所以毕业之后戊戌年我没有就业，在家备考，二战又失败了。后来开始找工作，奔波了好几处，要么前三名进面我是第四，要么面试中被淘汰，消沉了很长一段时间。终于在庚子年初春，进入了一所民办学校当老师，工作本身算不上累，只是收入甚微，工资少得可怜，更要命的是平台太低，资源相当有限，我似乎看不到出路在哪里。

# 分析命局：

戊土日主生在子月失令，坐戌土得地，时支卯木来克身，地支卯戌相合，戌土被合克，帮身力量不强，年干和时干透出乙木，也来克身，年干乙木得亥水生扶不弱，时干乙木坐卯木之上有力，年支亥水也来耗身，月干透出戊土来帮身，但戊土坐子水之上虚透，且被年干乙木所制，帮身无力，故为偏弱之命。

# 分析喜忌：

命局偏弱以生扶日主的火土五行为用神，以克泄耗日主的金水木五行为忌神，子水当令较旺，年支又见亥水，地支喜见土来制水帮身，也喜见火来生土，火土同见为吉，天干乙木来制戊土，最喜见火来通关生土，见土虽帮身，但土木相战，非为最吉。

# 分析学业和事业：

戊戌日出生为魁罡日，命书中讲，壬辰庚戌与庚辰，戊戌魁罡四座神，不见财官刑煞并，身行旺地贵无伦。一般来说魁罡格命局喜身旺，不喜身弱，但你的原局身弱，戊土和戌土比肩为用，但被乙木和卯木所制，为用神受制，又不见火来生土，喜火而不见火，格局就有一些打折扣了，也代表会有一些不如意之事。

戊戌日出生临魁罡，子水正财当令，天干乙木正官高透，除了年支亥水偏财外，均为正星，正星较多，也代表为人是比较正直正统，稳重有责任心，做事比较守规矩讲纪律的一个人，自律性强，有一定控制欲，事业心也不弱，非常上进的一个人，非散漫之人，也比较要强好胜，不喜妥协服输，有利事业发展。

不过，命局正星太多，又不见食伤来泄身，为人会有些不够灵活，思维也有一些僵化，在变通性上较为缺乏，做事和说话容易直来直去，不会拐弯抹角，少了一些圆融，也容易错失良机，加上喜印而不见印，在考学方面也有一些短板，会有一些付出与收获不成正比的感觉。

你现在走的是辛卯大运，卯木被辛金盖头，为伤官克官的大运，天干辛金来制乙木，也为伤官克官，故而会有一些不太安分，对现状不满，急于有所改观，人也比较浮躁。奈何大运不得力，考学运不太好，想通过考试改变现状较为困难。

2023癸卯年，太岁和大运天干伤官生财，财生官，官来克身，地支官杀旺，考研上岸较为困难。2024甲辰年，七杀高透，无印化杀，依然较难。

只能等到2025乙巳年，地支巳火印星出现，2026丙午年，天干丙辛相合，难以助身，地支午火印星出现，这两年有一些机会，但由于巳亥相冲，子午相冲，印星逢冲，也不会太顺利，目标院校不可过高，错过这两年短时间没有太多机会，在此之前，一方面不可中断学习备考，一方面安心于现在的单位和岗位为好。

年柱乙亥临天医，“天医拱照，可为良医”，从事医学是适合你的。戊戌日出生临魁罡日，乙木正官挂两头，管理学方向也是适合你的。但财官两旺，魁罡身弱，不见印星来通关，走仕途不是很理想，即使入职也多为平凡的岗位，很难取得太好的发展。

另一方面，从时间上来看，你想考上公务员，前提是先考上研究生转专业，假若在2025年和2026年可以顺利考上，毕业后已经不小了，即使考上，也错过了公务员的黄金发展期，对于同批入职的年轻人，缺乏年龄优势，况且研究生毕业后的几年，均不利考学，公务员基本无缘。照此来看，不如瞄定医学方向，未来毕业后进一些大的平台求发展或许是更好的选择。

子水正财当令，财官两旺，地支卯戌相合，戌土被合克，身弱难以胜财官，会因为求财和求官，产生很大压力和很多烦恼，也很难得到这个财和官，能满足于平凡对事业发展较好。未来走的壬辰，癸巳，甲午大运，大运有助身，财运会慢慢好起来。

相对求财，天干乙木官星高透挂两头，故更加适合求名，不论是现在当老师，还是进入医学领域，要把心思放在如何提升自身技艺上，唯有技艺纯熟，业务过硬，多吃苦多付出才有竞争优势和立身之本，财运也会跟着好起来，当然，能提升学历和多考证也会有很大助力。

# 分析婚姻：

只见乙卯木正官，而不见七杀，没有七杀来乱局，相对较为清纯，在感情上是比较专一的一个人。正官较旺，也比较正统，在和异性相处上懂得把握分寸，不会做出越轨之事，但由于财官两旺，不见印星来通关，也会因为婚姻感情之事产生一定压力和烦恼。

年干乙木官星透出，时柱又为乙卯木正官，月令子水和时支卯木临桃花，故一生很容易经历失败的感情，婚姻感情也容易有所波动，要多注意。戊戌日出生临魁罡，宿寡，也有一些不利，但日支婚姻宫为戌土，总体上婚姻没有太大问题，多忍让包容方有利婚姻的稳定。

你现在走的是辛卯大运，为伤官克官的大运，若有配偶，就要注意不和之事，若单身，卯木官星出现，也有遇到并结婚的运气。2023癸卯年，财官相生，卯木官星临桃花，和命局日柱天合地合，或2024甲辰年，地支辰戌相冲，婚姻宫逢冲，有遇到兵结婚之象。
