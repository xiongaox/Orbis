# 八字详批：

#### 坤造：乙亥年，丁亥月，戊申日，癸丑时（寅卯空）

# 分析命局：

戊土日主生在亥月失令，坐申金失地，年支亥水伏吟来耗身，地支亥亥自刑，耗身力量较强，时干癸水也是耗身的五行，年干乙木来克身，月干丁火来生扶日主，但丁火被亥水戳脚，生扶力量不强，时支丑土来帮身，但戊土日主失令失地，依然为身弱之格。

# 分析喜忌：

偏弱以生扶日主的火土五行为用神，以泄耗日主的金水五行为忌神，木虽克身，但在天干生火为吉。地支亥水当令较旺，伏吟地支，喜见土来制水帮身，但土在制水的同时也会生金，故也同时喜见火来克金生土。天干喜见火来生身，土来帮身，乙木为丁火为元神，也不喜受损。

# 分析事业：

五行为比较流通的组合，地支丑土来生申金，申金来生亥水，亥水来生乙木，乙木来生丁火，丁火来生身，而且一路均为忌神化用，虽然月柱丁亥，丁火被亥水戳脚，但有乙木元神生扶，流通路线较长，所以丁火是有一定力量的，一般这种命格，为熟知的“好命”之人。

当然这个好命不一定就说发大财，而是说人生各方面都会比较顺利，没有什么大起大落。

不过这种五行流通的组合，最怕岁运阻断五行流通，当五行流通被阻断就会有所不利。

你早年走的戊子大运，并没有阻断流通，故而早年较为顺利，丁火印星有力，学业也较为顺利。转己丑大运，也没有阻断流通，运势依然不差。

从2024年起进入庚寅大运，天干乙庚相合，乙木被合克，五行流通有所阻断，所以庚寅大运不是太理想，辛卯大运，没有阻断。但壬辰大运，丁壬相合，又会一会所不利。

所以原局来说是属于命中有福之人，只是结合大运来看，大运有些不利的信息，阻碍还是有的。

另外一个美中不足的地方就是，地支亥亥自刑，难免会有遇到让自己郁闷纠结，想不开的事情，需要注意心情调节，比如买房的这个事情，可以说即使不因为这个事情，也会因为其他事情郁闷纠结。

戊申日出生，日坐申金为食神，临文昌贵人，比较聪明伶俐的一个人，思维比较灵敏，丁火印星贴身为用，一般都比较爱好学习，对知识和文化有所追求，人也比较和善仁义，总的来说是懂得知足的。

原局财来生官，官来生印，印来生身，丁火印星为命局最重要的用神，代表财和官都要通过印星来获得，印星代表学习学校、文凭证书、教育培训等，财和官也代表财富、地位、名誉荣誉等，这也是自己得到这些的方式，而且丁火在取象上有教师、文字、思想的意思，乙木加丁火，有文化之意，所以从事教育文化行业是可以的，可以坚持下去。

除此之外，财官印相生，流通生入日主，年柱和月柱均临国印贵人，也代表比较适合走仕途，从事公务员的话，有一定官运，因为印星贴身，而且官印喜透，财星喜藏，官印透出会更加利官运，这也是之前有人说你有一定官职的原因，但这个官职是广义上的，这代表即使在学校，也有机会提拔升职，从事管理相关，可能性很大。

月干丁火印星为用，也可代表房子、车子等固定资产，月柱丁亥暗合，财星克印，代表会为了这些而破费花销。

2022壬寅年，天干丁壬相合，财星克印，2033癸卯年，天干癸水财星克印，均有为了房子而破费之象，由于印星受损，故也较难买到理想的房子。

身弱财旺，不能担财，代表求财辛苦忙碌付出多，但地支亥水财星通过官印流通生入日主，代表有一定偏财运，可以通过官印获得，但也相对的难求。

天干戊癸相合，正财合身，也代表有工资财，所以整体财运还是不错的，结合大运来看，从明年起进入庚寅大运，财运一般，辛卯大运，财运稍好，壬辰大运，又会有所下滑。

# 分析婚姻：

年柱财生官，正官星在年干生月干印星流通生助日主，正官为夫星代表另一半对你还可以，彼此之间也可以好好去沟通解决遇到的问题。

只是月干丁火被亥戳脚克制，所以有时候彼此也会有些不愿意的沟通，或者沟通效果不好，你自己亥亥自刑，也会有些问题反复纠结，反复拿出来说，时间久了引起矛盾方案，而且地支婚姻宫申亥穿，也会有相应的分歧矛盾，加上亥中带七杀星，地支亥亥自刑，自己也会遇到些烂桃花偏缘，是要注意的。

命局财印相克，也注意彼此感情容易受到长辈的影响干预。而正官夫星在年干，故而找对象的话，宜找个年龄比自己大一些的对象。加上戊申日出生为阴差阳错日，临女孤鸾煞，地支申亥相害，两个亥水来损申金，均代表婚姻环境不太理想，未来在婚姻感情上自己付出较多，婚姻压力较大，夫妻之易友有矛盾不和。

2023癸卯年，夫星得生助，地支亥卯流通，丁火被水戳脚减弱，有遇到缘分的机会要好好把握，能经人介绍为好，2024红鸾星入命，或者2025乙巳年，地支巳申相合，婚姻宫被合动，有结婚的机会。

# 分析大运：

**30岁—39岁**

庚寅大运，此大运地支寅木被天干庚金盖头，为食神制杀的大运，天干乙庚相合，乙木被合克，阻断了流通，乙木为丁火的元神，元神被合克，丁亥暗合，丁火受损严重，故整体事业运、财运、贵人运、健康运均有所下滑，事业上阻碍较多，适合求稳，地支寅申相冲，婚姻宫逢冲，有结婚的运气。

**40岁—49岁**

辛卯大运，此大运地支卯木被天干辛金盖头，为伤官克官的大运，没有阻断流通，故整体运势较为和顺，诸事较为顺遂，但伤官克官的大运，也要注意口舌是非，与人不和等，辛金伤官生财，求财比较辛苦，需要付出。

**50岁—59岁**

壬辰大运，此大运天干壬水被地支辰土戳脚，为比肩制财的大运，天干丁壬相合，丁火印星被合克，阻断了流通且丁火印星有损，命局最重要的用神受损，故整体运势较为低迷，升职提拔机会不多，较难施展才华，做出成绩，且花销较大，也容易因为房子、车子等固定产而破耗。
