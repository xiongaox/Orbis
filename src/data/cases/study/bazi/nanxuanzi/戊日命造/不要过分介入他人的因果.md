# 网友来信：

我出生在粤东地区的一个小镇，从小生活比安逸。小学时比较贪玩，喜欢养猫狗，但是一直不长久。四年级前一直遭受校园暴力，那几年留下了不小的阴影。后来因为学习成绩太差，转学到私立学校。我乖顺了一点，但是仍然玩性不改，最后被学校开除。回到家乡读初中，整天与地痞们混在一起。到丙申年，突然发奋，最终也不至于没书可读。高中也是前期没认真，己亥年努力学了一年。考了广东省内的二本院校学习物流管理。无论中考还是高考，每次都与心愿的学校差几分失之交臂。

家里父母忙于工作赚取，对我们兄弟的管教比较少。但是有幸父母品行淳厚，我兄弟也有所感染。我认为我是一个比较矛盾多虑且十分容易受环境影响而有所懈怠的人，大学之前比较自私，在大学经历一些事之后，这几年也逐渐学会为他人着想。这几年虽有波折，但也成长了很多。

家里还有一个弟弟，小时常被我欺负。现在逐渐懂事，他仍感觉我对他有很大的压迫感。

我癸卯年下半年毕业，面临着许多的选择，对未来充满迷茫。正月的时候，父母想我报名参军，我通过了体检但是没有下定决心。自己也面试了一份不错的物流工作。表姐希望要我来深圳和姐夫创业做外贸。

最终我选择来与姐夫创业。但是以目前情况来看，姐夫没法从原来的公司脱身，且工作很忙，他几乎没有时间带我，我在网上学习并自己搭建渠道。目前独立办公，姐夫发信息给我下达任务。这种情况与我一开始的设想有所出入，且有种与社会脱节的感觉。看着同学们一个个找到自己心仪的工作，我最近常常会感到迷茫与郁闷，是否应该独自进入社会历练几年或许更好？

另外我弟弟今年面临着高考的选择，他执着于学习理疗，但是高考成绩又不理想，不肯静下心来学习。最终可能只考了一个民办的专科。家里建议他认真学习或者复读一年，但他今年变得有点固执，家里的建议他不太听的进去。
