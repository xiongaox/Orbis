# 网友来信：

我的家庭条件一般，出生在农村，从小到大虽说不是很顺利，但是也有点磕磕绊绊，丙申年我通过中考考入了我们县的公立高中，衡水的高中生活比我想象的更艰难，高二那年，中午考完试的我着急去食堂打饭，由于当时学生很多，加上学生们几乎都是跑着去食堂吃饭，我不小心被一个高三复读的男生撞到了，当时他是从南向北跑着的，我是从西向东走着，当时可能由于人多学生着急，加上自己没有在意，那个男生就不小心撞到了我，但是整个人摔倒了并且整个人坐在了左脚上，后来那个男生和另外两个女生扶着我去了医务室，医生给了跌打药，第二天放假回家去镇上的医院拍了片，说没多大事，我也没太当回事以为就是崴着脚了，有一两个星期就好了，回学校一星期左右，脚还不见好，就给家里打了电话，请假去了市里的骨科医院，医生说骨折了，当时怎么也没想到会骨折，后来去了专门的骨科门诊拿了药，脚上穿了一个固定的支架，买了一双拐，就去了学校，那时候觉得每一天都很漫长，从教室到宿舍很远，宿舍在四楼，每次都是自己拄着双拐回宿舍然后再爬四层楼，那时候感觉一点希望也看不见，那一段漫长的高中生活压得我喘不过气来，每天就是在挣扎着，从早上五点半起床，洗漱完拄着拐下四楼，再走很长的路到教室，早上吃饭拄着拐到食堂，食堂和教室离得也很远，几乎和宿舍挨着，中午吃完饭回宿舍又要爬四楼，然后下午一点五十出宿舍回教室，晚上六点吃完饭，同样是拄着拐慢悠悠地去食堂吃饭，然后再回教室上自习上到十点，十点下课后自己又拄着双拐回宿舍，就是这样漫长而又艰难的一天，大约持续了一个多月。

现在回想过去，当时的那段黑暗时光我也不知道自己是怎么过来的，可能是一天天熬过来的。在这之后我比之前开朗乐观了许多，然而，没有过多长时间，大概是戊戌年四月份左右，在学校给家里打电话的时，知道我爷爷出车祸了，是我大姑父晚上拉着爷爷去找活儿时，和一辆大货车脸对脸撞了，知道这件事之后我真的很难相信，只能期盼着他们没事，再到后来学校放月假第一天回家，知道了爷爷腿上的肋条骨没了几根，姑父的腿折了动了手术，第二天我就回学校了，回学校之后我很开心爷爷没事，就踏下心来了。等到戊戌年农历12月25放寒假，我爸来接我时说，你爷爷得肺癌了。后来没几天就肺癌转骨癌了，等到过了年，到了己亥年，爷爷的情况越。越差，正月初六那天我们高三开学，前一天晚上我去看了爷爷，爷爷坐在床上，低着头弯着腰，看起来没有一点力气，像蔫了的茄子一样，到后来我怎么也没有想到那是我和爷爷的最后一面，在学校每星期天我都会往家里打一次电话，在一次打电话中我知道了爷爷去世的消息，爷爷去世那天正好是我们高三百日誓师那天，那天所有同学都志气昂扬，我却怎么也提不起精神来。

后来高考，我考进了河北一所普通的二本院校。大学生活还算悠闲，庚子年底，我遇到了现在的对象，到现在相处得还可以，可是，在辛丑年，我偶然发现了母亲在微信上和一个陌生男人的聊天，聊天内容很暧昧，当时内心百般滋味，我没敢告诉我爸，终究是纸包不住火，2021年夏天的一个早上，我爸给我打来了电话，说你妈找男人了，要离婚。我心里顿时慌了一下，急忙穿衣服出了宿舍，给我爸打了电话回去，他说他没事，拉着我妈去了姥姥家，后来不知道怎么回事就没事了。等到放暑假回家之后，我妈和又那个男人聊天被我爸发现了，闹了好几天，发现那个男人是我妈年轻认识的一个人，他们之前也因为这个吵过架，不过那是在零几年的时候了，后来我爸一直闹，闹着离婚什么的，我姨他们劝了又劝，终于劝没事了。没过多久，他们俩就吵一回架，吵了又吵，闹了又闹，反反复复之后，我妈好像知道错了就没再吵过架。受父母感情的影响，我自己对婚姻的恐惧感增加了不少，担心以后自己的婚姻也会出现类似的问题。

# 分析命局：

戊土日主生在子月失令，坐申金失地，月干透出庚金来泄身，年干辛金也是泄身的五行，年支巳火和时支午火来生扶日主，但巳申相合，子午相冲，巳火和午火生扶力量不强，时干透出戊土来帮身，但戊土日主失令失地，为偏弱之命。

# 分析喜忌：

原局偏弱，以生扶日主的火土五行为用神，以泄耗日主的金水五行为忌神，五行木虽克身，但在地支生火为吉，而子水当令，天干地支见庚申金和辛金来生扶子水，天干喜见火来制金生身，地支喜火来制金，也喜见土来制水。

# 分析事业：

戊土日主被庚申金食神贴身，年干又透出辛金伤官，虽年支有巳火来制辛金，但巳火被月令子水所制，原局身弱，食伤较旺体现为懂得为他人着想，但身弱食伤旺为忌，思虑也较多，容易滋生不少烦恼，身弱食伤旺，也体现为渴望自由发展，不喜被束缚太多，印制食伤无力，容易多想少做，行动力不足，做事不易坚持。

天干庚辛金食伤高透，也体现为人有一定自尊心，也比较好面子，进而也容易滋生虚荣心，戊申日出生，日坐申金为食神，临文昌贵人，又在天干透出，口才不错，能说会道，也喜欢表现自己，向别人展现自己，只是稍有成绩的时候，也容易飘飘然，得意自满。
