# 被算命困住的人

命主生辰: 2001/12/11 16:00 (GMT+8)
性别: 坤造
日主: 戊土
格局: 偏弱之命
令地: 失令, 失地

# 网友来信：

虽然已经成年，但仍感觉自己不是能做决定的普通孩子，从小到大，虽然父母打打闹闹，对我不能悉心照顾，但对于我人生中的重要关头，还是给予了十分大的助力的，现在有几件事，不能与父母分享，既想询问老师意见，也想分享给大家我的经历和感受。

1.我是湖北人，父母未婚先孕孕育了我，父亲并不愿意过早被家庭控制，拒绝承担家庭义务，想要堕掉我，我母亲犹豫舍不得，后这件事被我姑姑告知于我的奶奶，两个人才被绑在一起最后结了婚。因此，我想这就是因吧，他们俩之间感情不合，我的父亲又酗酒家暴，最后在丙申年，我读初二的时候离婚了。两个人都有各自的理由，总之就是没有人选我。后来两个人又聚在一起，名曰为了小孩，一起生活到现在，也算是纠缠到现在，外人看起来平静的生活，其实已经是千疮百孔，母亲最近又说自己觉得自己有抑郁症，我想要带她离开，她又舍不得我弟弟......我在这动荡的生活里，很难享受平静，因为内心总是害怕，总是惶恐，总是不安，这能持续多久呢。

我的第一个问题就来源于此，可能是受家庭影响，又或是命局毫无官杀存在，我对男性存在害怕、不相信的感情，身边也没有好的例子做榜样，目前为止没有任何感情生活，也不敢对男性抱有期待，最近一个月有在网上询问过一个比较知名的老师的意见，他说我是继承了父母的因果，以后也不会有好的姻缘，我对命理也算是懂得一点，确实也不算好，但让我更担心的是，他说我会被家暴，虽然都只是未来的事，但深觉惶恐，难道说，我不能拥有正常的感情生活吗？

2.前几日父母又找了那个老师算，他说我是大富大贵之命（笑），我对自己有几斤几两还是很清楚的，以后能不能成大富大贵不知道，但现在工作却是一点着落都没有，从小就很爱看小说，今年生病期间随意在网上创作了一本小说，得到了不错的收入，可再去认真构思新书，反而没多少流量了，难道说真是无心插柳柳成荫，有心敲门人不应？其实只是运气好，并没有走这条路的天赋？最近在备考公务员考试状态也不算好，本来就偏科的我，逻辑感也是很差，不知道自己该何去何从，老师你看，我这几年的考运能够支撑我坚持下去吗？

3.接下来就是最后一个问题，虽然我是湖北人，但是被父母带到身边生活，也就是现在IP所显示的地方广东，这么多年过去了，父母在珠三角也算是成功立足，但我的读书经历中，却充斥着不安和被歧视的气氛，因为外地人的身份，再加上周围的同学年幼无知，从小就被各种语言暴力和行为上的歧视，不过现在想想，也许还算好运，毕竟没有被真实的殴打过（笑），身边也算是有几个知心好友，但不幸的是，前几日的算M结果中，父母告诉我老家的老师说，我过几年会被好朋友在某个时间段被骗入传销，联想到最近的电影《孤注一掷》，我感到背后一凉，我这仅存的几个朋友之中，难道会背后坑我一刀吗？

总结下来，我感觉自己是越算越乱，越算越烦恼，本来已经下定决心不再算命，毕竟人生的剧本，有些事情似乎躲也躲不过去，但好奇心和害怕又驱使着我不断地去联想，我感觉，自己已经被算命老师们这些话困住了......

# 八字详批：

#### 坤造：辛巳年，庚子月，戊申日，庚申时（寅卯空）

#### 大运：辛丑，壬寅，癸卯，甲辰，乙巳，丙午，丁未，戊申，10岁运。



# 分析命局：

戊土日主生在子月失令，坐申金失地，时支申金伏吟来泄身，月干和时干透出庚金，也是泄身的五行，年干辛金也泄身，整个命局只有年支巳火来生扶日主，但巳火在地支被子水所制，且原局不见木来生火，巳火生扶力量较弱，戊土为阳日主，只要有一点土或火帮扶，就不容易从，依然为身弱之格。

# 分析喜忌：

偏弱以生扶日主的火土五行为用神，以泄耗日主的金水五行为忌神，木虽克身，但在地支生火为吉。八字子水当令较旺，地支申金伏吟，天干庚辛金较旺，天干喜见火来制金生身，地支喜见土来制水，也喜见火来制金。

# 分析事业：

年支巳火是整个命局中唯一的用神，但原局不见木来生火，用神没有元神生扶，巳火力量不强，同时地支子水来制巳火，为忌神制用，用神受损，且巳火用神离日主较远，一般来说，用神离日主越近越好，忌神离日主越远越好，但从你的命局来看，用神弱且远，忌神贴身，组合不太理想。

食伤较旺，戊土日主被庚申金食神包身，且巳火印星来制食伤无力，会体现为比较注重精神享受，比较的好面子，有些叛逆任性，也容易傲慢，有点自视清高，做事容易一意孤行，会有些固执，加上命局不见官杀星，不喜欢被管束，比较喜欢自由。

身弱食伤为忌，印星来制食伤无力，不太会满足，想法会比较多，容易天马行空的乱想，也会因此导致很多烦恼，有的时候想法不切实际，很难落地，不够踏实，导致做事不易坚持，思虑较多，但想的多做的少，行动力不足。戊申日出生临孤辰，内心容易孤独感强。

年干辛金伤官高透，食伤旺，也体现为为欲望和野心较大，不容易满足，性格好强，不服输，说话和做事也很容易得罪人，或言语无情，不懂得委婉。食伤太旺而泄身，是一个操心操劳较多的人，也为劳碌命，难得到清闲，也只有付出多才有更多收获。

食伤较旺为忌神，但年柱辛巳暗合，地支巳申相合，食伤有制也为吉，印为火，命局喜火土故而也可以往文化传播，传媒，服务咨询，教育文化及互联网IT，广告，电力火电，土建相关方面去发展，相对有利。

至于贵人运方面，戊土日主被庚申金食神包身，均为忌神，只有年支巳火印星为用，用神离戊土日主较远，代表贵人运较为缺乏，忌神挨着自己，代表自己所处的环境不太理想，尤其忌神为食伤，是泄身的五行，均代表对自己是一种消耗，会为身边的人和事付出多，操心多，至于被骗去传销的象不明显，注意下就可以了，更多是自己不切实际，好高骛远的欲望，脚踏实地就不会被骗。

食伤较旺，年柱辛巳暗合，地支巳申相合，食伤有制，故而在写作、创作等方面是有一定天分的，身弱食伤旺虽然容易幻想，但也给自己创造了天马行动的空间，这个兴趣爱好可以坚持下去，只是由于食伤太旺为忌神，印星制食伤无力，故代表这种天分也是有天花板的。

至于考公一事，肯定是不适合你的，食伤太旺不见官杀，更加适合偏自由一些的职业，哪怕上班，也适合一些偏自由一些的岗位，所以不太建议走这条路。最早要等到2025年、2026年、2027年的时候，才有比较好的机会。

# 分析婚姻：

食伤较旺，印来制食伤无力，在感情上和婚姻中比较肯付出。不过，食伤较旺，食伤高透为忌，则婚后不爱被束缚和唠叨过多，同时有时也有些急躁不满的情绪，挑剔，会有些分歧争吵矛盾滋生，会对感情造成不利。

身弱食伤旺在对待感情婚姻方面，也容易有些不切实际的幻想，缺少一些现实过日子的因素的考虑，同时原局不见官杀，就连暗藏的也没有，也代表和另一半缘分不是太深，容易冷淡僵化，日柱和时柱临孤辰，异性缘分不是太理想，多为晚婚，至于家暴，没有这个象，但未来会为了家庭操劳较多，不太和谐，争吵矛盾不少。

2025乙巳年，天干乙木夫星出现，地支巳申相合，合动婚姻宫，有遇到缘分并结婚的运气。

# 分析大运：

**20岁—29岁**

壬寅大运，此大运为财杀相生的大运，天干壬水财星透出，地支寅木为七杀，整体运势较为一般，缺乏太好的机遇，寅巳申三刑，寅申相冲，三刑带冲，容易焦虑，压力较大，也容易胡思乱想，要注意下口舌是非，与人不和之事。

**30岁—39岁**

癸卯大运，此大运为官印相生的大运，天干癸水财星透出，戊癸相合，正财合身，求财相对比较稳定，地支卯木官星旺了巳火印星，故整体运势比之前稍好一些，事业有升职发展机会，也有一定贵人运。

**40岁—49岁**

甲辰大运，此大运为地支辰土被天干甲木盖头，地支辰土比肩帮身，整体运势一般偏好，事业上可以得到贵人相助，申子辰三合，人缘也会稍好一些，整体财运有所增加。但甲木七杀来克身，事业也有一定压力。

**50岁—59岁**

乙巳大运，此大运为官印相生的大运，天干乙庚相合，庚金食神被合拌为吉，地支巳申相合，申金食神被合克，此大运运势不差，可以施展才华，做出成绩，有创作、写作的想法也可以把握住此大运，有一定机遇。
