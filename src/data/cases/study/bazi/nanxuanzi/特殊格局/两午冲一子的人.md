# 两午冲一子的人

命主生辰: 1996/06/13 12:00 (GMT+8)
性别: 坤造
日主: 辛金
格局: 从官格
令地: 失令, 失地

# 网友来信：

我家境一直很拮据，但是我父母从来没让我为钱发愁过，家里也有过大的变故，也从来不在我面前讨论。小时候，我跟我姐经常掐架，她不爱和我玩，也不会和我聊她自己的事，这两年，我们的关系好多了，也聊多了，我才知道她承担的家庭压力要比我多得多。我心气挺高，学习上攀比心也重，也可能是不想让母亲失望，就只埋头读书，跟同学交往的少，也不懂怎么社交，我经常缠着母亲絮絮叨叨说学校的事情。

初高中阶段，我还是埋头学习，尤其是在高中，母亲跟我姐妹俩搬到了县城里，给我们每天送饭吃。念及母亲的辛苦付出，我在学习上也丝毫不敢放松。当时学习的动力总的来说有三部分，对学习本身的喜爱，同伴的压力和母亲的期待。老师们对我也挺照顾，但是我仍不知道怎么处理和同学的关系。高三时出现了严重的失眠和便秘情况，家人也并没有在意我的异常。当时经常为了几分或者几个名次的升降心惊胆战，考到年级前三也不欣喜，考不好就会自卑自责。但是我就算求助了，也得不到外界真正的帮助，就全靠一颗麻木的心煎熬过去了。

最后，我去了南方一所211，当时也很失望崩溃，后来就想通了，以我当时的心理素质和不太科学的学习方法，这个结果也是意料之中的。到了大学，我完全没有踏实学习的想法，英语专业需要勤勤恳恳每天坚持，所以专业成绩也是中等水平。

18年毕业后，曾想过学心理学专业，但是考研失败，还是选择了当英语教师，后来，抱着不问结果的心态才考上了一所985学校，学的仍然是英语教学方向。我男朋友和我是一届大学同学，期间经过了我工作他读书的异地考验，现在打算领证结婚了。他是个非常好的男孩子，我妈总觉得我遇到了他很幸运，我其实也很认同，因为我容易焦虑浮躁，有严重的内耗，他很稳定，给我挺多安全感。

我的话有点多，因为我是一个内心百转千回多的人，把这些心理活动写出来会占用很大篇幅，您费心了！

> 我的问题是：
>
> 1.我的喜神和忌神是什么？我这个八字是从杀格吗，如果从了，我的喜神是不是就是官杀和食伤，忌神是印比？结合我的经历来看，在高压状态下，我确实工作效率高些，在没有命令和监督时，我会拖延内耗。但是我的大运是相背的，走了比劫和偏印运，那么官杀也成了忌神，体现在我很难在一个单位坚持下去。比劫为忌体现在我的社交不顺利，自我边界感模糊。现在的我很难像初高中那样不顾别人想法安心搞学习。我会介意别人的看法，会怕在团体中显得能力不足，周围环境总让我觉得压力重重，难以放松，我既内耗到不能专心，又会眼红别人的成绩。和同学和同事的私交中也容易感到受伤。
>
> 2.我适合从事什么职业？我对心理学感兴趣，总觉得现在的学生更需要心理上的疏导，但是我对自己从事这行也没啥信心，除了专业不对口，也有经济原因，做心理咨询的经济投入太大了。另外，心理咨询是不是属于偏印的行业，我感觉自己在看命理玄学，心理学这些内容后，想事情会更深入，但是好像消耗了很多精气神。所以，我对心理学，尤其是玄学，命理学很是敬畏，既想了解，又怕深陷其中。专业对口的工作就是英语老师。但是我的食神子水是不是受冲比较严重，我总怀疑自己能不能当好英语老师，而且要让他们考高分这些事情一直让我很害怕，很抵触。最后是公务员或者一些从事文书类的事业单位岗位。我也不知道自己适不适合。
>
> 3.我的食神被冲，是不是以后可能生女儿，女儿会不会因此受影响呢？我男朋友日柱是辛丑，对我原局里的子午冲会不会有缓解呢？

# 八字详批：

#### 坤造：丙子年，甲午月，辛巳日，甲午时（申酉空）

#### 大运：癸巳，壬辰，辛卯，庚寅，己丑，戊子，丁亥，丙戌，4岁运。

# 分析命局：

辛金日主生在午月失令，坐巳火失地，时支午火伏吟，也来克身，年支子水来泄身，但地支子午相冲，午火当令，子水被反冲受损，泄身力量较弱，月干和时干甲木来耗身，年干丙火也是克身的五行，命局没有一个生扶日主的五行，为从弱之格。午火当令，官杀较旺，为从官杀。

# 分析喜忌：

原局从弱，弱不受生，喜顺从弱势为吉，以克耗日主的木火五行为用神，以生扶日主的土金五行为忌神，水虽泄身，也可顺从弱势，但在天干地支水火相战，有所不利，故也不喜多见。原局顺从官杀之气，喜见财来生官杀，见官杀为吉，而最不喜见印比，见则破格，有所不利。

# 分析事业：

原局从弱，满盘兼为用神，喜顺从弱势。但原局官杀混杂，杂而不贵，从格不纯，所以并非上格，拉低了一些层次。

原局虽然从格，但也要结合大运来看，如果大运破格势破格，用神变忌神，有所不利。

大运走势来看，早年走的癸巳大运，可以顺从弱势，运势不差，转壬辰大运，地支辰土印星出现，以及现在和未来的辛卯大运，庚寅大运，己丑大运，戊子大运，大运走势均有所破格不利，午火七杀当令较旺，伏吟地支，日支巳火为正官，并在年干透出丙火，又得甲木财星生扶不弱，官杀克身，丙辛合为正官合身，代表为人比较正直正统，做事讲规矩，守纪律，有责任心，当然有的时候也会一板一眼，缺乏一些灵活性，有的时候容易在人情世故上吃亏。

原局官杀太旺，官杀混杂，加上大运破格导致用神变忌神，会体现出官杀为忌的效果，平时压力较大，负担较重，内心充满焦虑，容易往坏处想，偏悲观主义，缺乏安全感，有时候性格有一些极端，容易缺乏魄力。

五行火旺，地支子午相冲，有时候容易急躁冲动，遇到事情有时候沉不住气，也有偏懦弱的一面，不够自信，心理素质不好，容易顶不住压力，而心生退意逃避，不利于事业发展。

官杀太旺，子午相冲，两个午火来冲子水，子水食神有损，加上地支午午自刑，也会导致比较固执死板，有时候容易自我纠结，自寻烦恼，钻牛角尖，在变通性上较为缺乏，不够灵活。

当大运破格时，官杀为忌太旺克身，容易头脑昏沉，也会因为心里装不下事，心是较多导致失眠熬夜，且不太有主见，容易轻信于人，要避免上当受骗。天干甲木财星高透相随，一般虚荣心也比较强。

原局五行若较为纯净，大运又不反背，多可入公门，可以求得一官半职，但原局官杀混杂，大运又多反背，故格局层次有一些打折扣，较难获得比较体面的工作。辛巳日出生临国印贵人，同时正官合身，适合上班求财，追求稳定是最佳选择。

原局从官杀，且财来生官，官来合身，财为正财，故想得到这个财，更多需要依靠单位、职位、权力或者名誉、荣誉等，也代表适合上班，而不是太适合创业经商。

原局虽然从格但大运多破格，导致身弱官杀混杂克身，容易事业不稳定，能进一些大一些的平台比较好，借助平台力量，增加自己事业稳定，比如事业单位、国企央企等比较适合。

辛巳日出生，临天医、词馆，同时子水食神临文昌贵人，有一定领悟力。能从事教育文化或医学相关职业也较好，从事英语教师是可以的。

至于心理学咨询方面，总体而不是太适合，当作一个兴趣爱好则可。地支子午相冲，能选择外出求财较为有利，方位上，由于大运多破格，故出生地的西方、西北方、东北方、西南方比较旺你。

辛巳日柱，女命以食伤为子女，命局中食神两位，故单纯从你命局来看，理论上有两个女儿，但地支子午相冲，午火当令，子水食神有损，得到子嗣并不会太容易。

尤其子水太弱，又午午自刑，子女宫有损，更加代表怀孕和生育较为不利，备孕时要多做好调理为好，逢猪年选择备孕较为有利，逢马年、鼠年、牛年、兔年有一定风险，要尽量避开。

食伤不为忌，时柱甲午为用，临桃花，代表未来子女比较聪明伶俐，长相乖巧，发展较好，可以往公务员、事业单位、武职军队等方向培养。

# 分析大运：

**24岁—33岁**

辛卯大运，此大运地支卯木被天干辛金盖头，为比肩克财的大运，天干辛金比肩帮身，运势有所破格反背，从弱变身弱，身弱难以担官杀，造成官杀攻身，故压力较大，容易犯小人，地支子卯相刑，也要注意与人不和之事，子水有损，不利备孕。

**34岁—43岁**

庚寅大运，此大运地支寅木被天干庚金盖头，为劫财克财的大运，天干庚金劫财帮身，运势依然反背破格，官杀攻身，压力依然较大，容易睡眠不好，要注意调整心态，地支寅木旺了官杀，事业上阻碍较多，要努力克服，寅巳相害，也要注意口舌是非。

**44岁—53岁**

己丑大运，此大运干支一气为印星，印星来助身，运势依然破格反背，天干甲己相合，甲木财星被合绊，钱财上花销较大，不太聚财，地支子丑相合，子水被合克，整体财运较为一般，付出较多，收获有限。

**54岁—63岁**

戊子大运，此大运地支子水被天干戊土盖头，为印克食神的大运，天干戊土印星来助身，运势依然反背，事业上比较辛苦，压力较大，求财不易，得到的财较为有限，地支子午相冲，难免有事业或岗位变动，能退则退为佳。
