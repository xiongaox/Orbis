# 五行流通的人

命主生辰: 1987/09/12 21:00 (GMT+9)
性别: 乾造
日主: 甲木
格局: 偏弱之命
令地: 失令

# 网友来信：

我生长在一个农村的贫困家庭，父亲是跟着奶奶改嫁到目前的家族，改嫁后这边的爷爷也很贫穷，然后奶奶因为下雨天意外触电身亡，因为贫穷，父亲晚婚，母亲也是带着大哥二婚改嫁过来的，婚后生了四个儿子，一起五兄弟，我是最小一个。家庭贫穷，父慈母善，父母通过耕田把我们几兄弟拉扯大，我身体也不是很好，自幼体弱多病。爸爸勤朴憨实，妈妈勤洁聪慧，老老实实教育我们要努力学习。

壬午年我通过努力考上了镇上的重点初中，但是天有不测风云，刚上初中才几个月，我母亲就得了中风，经过几个月的治疗，勉强捡回一条命，但是半身不遂，从此母亲就一直卧床，父亲只能一边照顾母亲，一边在家务农，供我读书的重担就落到了我二哥身上，读书期间自己啥农活，啥家务活都能帮家里做。

乙酉年我考上了县重点高中，但是成绩也不是出类拔萃那种，中上水平，同年冬我母亲因为在次脑溢血中风离世。从此我成绩一落千丈，整天郁闷。高三时，班上一女同学了解我情况后对我暗暗鼓励，一回生二回熟后，我早恋了。受到早恋影响，高考勉强上了一个二本线，但是没有去读，选择了去另外一个学校复读，复读一年，成绩也没有提高多少，最终去了一个我们当地的二本院校。

大学期间，也没有尽最大努力去学习，而是整天热衷于奔波在老师以及同学之间的学生会干部，大学成绩也就一般般。从小父母力量有限，读书都是靠兄长帮衬着一路走来，特别是二哥，从小学到大学毕业都是他在关照着我成长。

壬辰年大学毕业去了省内另外一个市参加工作，但是工作性质不是很理想，终日奔波。也许是命苦，癸巳年冬灾难再一次降临我头上，我父亲因脑溢血严重中风住院，兄弟几人东凑西凑治疗了大半年，效果不大，只能回老家卧床静养，在老家没有人照顾父亲，几兄弟协商，让远在深圳打工的三哥回来照顾父亲，然后其他兄弟每月凑钱给三哥支付工资和父亲日常开支。

在壬辰年至甲午年间我频繁跳槽，换了好几份工作，工资都很低，也不满意。乙未年5月通过自己的努力考取了我们县的一家国有企业，还算稳定，但工作也不高，勉强维持生活，就一直工作至今没有换过其他单位了。

回到县工作后，可能是贫穷的原因，也没有女孩子看得上，追了两三个女孩子都没有成功，加上每个月都要把工资的一部分打回去给三哥赡养父亲，每月也是月光光。

丁酉年初我与本单位一女孩子恋爱了，但是对方父母因为我家庭贫困的原因，不同意，阻力重重。

戊戌年春节刚过，噩耗传来，我父亲卧床五年后离我而去了，送走父亲不久后，我打破重重困难，奉子成婚，结婚了，结婚时一无所有，婚房都是租来的，简单置办了几件家具，简简单单办了一场婚礼就这样过日子了。

戊戌年底我迎来了我的大女儿，同年通过分期在市区买了房子和车子。庚子年我迎来了我的二孩儿子，虽然日子过得紧巴巴，但是还算过得去。

戊戌年至辛丑年期间，我工作十分不顺利，经常被直属上司打压，也常常因为打压而与上司顶嘴，这样子上司就开始整我，经常调整我的工作岗位，以致我想方设法参加公司内部岗位竞聘，想调到市一级单位去。

辛丑年秋，我妻子因为看不惯我在公司被打压，就离职通过考试去了市里的一家单位工作。

壬寅年春，我如愿以偿到了同一公司的市级单位的财务部工作，但是工作开始不适应，也经常被直属领导批评，大声叱喝，加上同一部门的同事经常给我打小报告，给我小鞋穿，壬寅年工作上非常痛苦，很是艰难，加上这一年我妻子外出学习，我是一人白天上班，晚上带娃，生活真是水深火热。    以致我一度想换部门换岗位工作。直到时间来到癸卯年夏天，经过磨合，领导对我有了改观，态度也友好了很多，没有了前期的批评责骂，但是身边同事的口舌是非也是不断。因为我并非是财务专业毕业，在财务部门也是只能打打杂工，接触不到核心业务，目前就是做一天和尚撞一天钟。

> 希望能为我未来指点一下迷津。我有几个疑问一直困扰着我：
>
> 1.最近这几年我感觉流年不是很好，有很多小舌，与领导关系不是很和睦，以致工作业绩不好，未来我也是这样子下去吗？是继续在这个财务部门待着好还是要换部门换岗位？
>
> 2.我能力平平、学历平平，没有任何资源背景可依靠，有什么大发展吗？还是一辈子就这样碌碌无为？如果有改观，未来我应该怎么样去未雨绸缪才能好转？
>
> 3.我这边重男轻女思想比较重，我哥哥希望我生三胎，我也有点想法，但是目前各种房贷、车贷、装修贷等等压得我喘不过气来，生活压力相当大，我又不敢，我妻子也不同意，我想了解一下我命中会有三胎吗？命中有几个儿子？
>
> 4.我未来婚姻感情生活如何？
>
> 5.我未来财运如何，会有好转吗？
>
> 6.我自幼身体不是很好，我的寿命大概能到多少岁？

# 八字详批：

#### 乾造：丁卯年，己酉月，甲子日，甲戌时（戌亥空）

#### 大运：戊申，丁未，丙午，乙巳，甲辰，癸卯，壬寅，辛丑，3岁运。

# 分析命局：

日主甲木生于酉月，失令，坐下子水为日主甲木的正印，得酉金生扶，有一定生扶之用，时干甲木来帮身，年支卯木为甲木日主的羊刃，有一定帮身之用，但卯酉相冲，卯木有损，帮身力量不强，年干丁火来泄身，时支戌土和月干己土来耗身，依然偏弱。

# 分析喜忌：

日主甲木身弱，就要生扶，也就是水和木的五行，以泄耗日主的五行为忌神，也就是土和火的五行，金虽然克身，但在地支生水，水来生扶日主，反而间接助身，为吉利之处。酉金当令，喜见水来通关，也喜见木来疏土，天干喜见水来生扶日主。

# 分析事业：

日主甲木，甲木是参天大树，有积极向上生长的特点，为人正直，一般也代表为人比较直接，加上时干甲木帮身，加上年干丁火伤官透出，也是代表比较直爽，说话、办事都比较直接，不太拐弯抹角，加上酉金正官当令，也表示是比较遵守规则原则的一个人，有正直正派的一面，年支卯木为羊刃，也比较要强的一个人。

你的原局来说属于比较不错的组合，五行比较流通。年支卯木来生丁火，丁火来生己土，己土来生酉金，酉金来生子水，子水来生甲木，流通路线较长，且一路流通到日主，且身弱喜流通，代表你一生有一些福气，虽然祖辈多灾，但对于你自己还是比较不错了。

不过这种组合是有利有弊的，就是忌讳五行流通被打断，从你的来看，本身有甲己相合，卯酉相冲的组合，五行流通也有打折扣。

结合大运来看，现在走的乙巳大运，地支巳酉半合，酉金被合拌，未来的甲辰大运，甲己相合，酉辰相合，月柱被合拌，这两步大运五行流通被打断，都不太顺利。

53岁后进入癸卯大运，运势会好很多，也是你人生中最好的大运，故而你真正的好运在中年以后，当然好运来的也比较晚，不过也代表晚年运不错，可以安享晚年。

月干己土正财来生酉金正官，酉金正官来生子水正印，子水正印来生身，财官印相生，均为正星，这种组合适合上班求财，也多为上班求财之命，尤其甲子日出生，位于六十甲子之首，一般都有一定权力欲，多会从政，或者进一些事业单位、国企央企等，只要岁运助身，依然有升职机会。

你目前从事财务岗，不是太适合你，能想办法转向管理岗或者文秘岗，会相对更加适合你一些，你的财官印流通相生，更加适合这些岗位。单位不建议你轻易去更换，能寻求稳定为佳。

人际关系主要是，地支卯酉相冲，子卯相刑，酉戌相害，刑冲破害较多，是人际关系不利的根源，当然也和自身性格有关系，后天要学会处理好。

月干己土为正财，财官印相生，流通生入日主，可以得到这个财，但己土财透天干，甲己相合，两个甲木争合己土，代表钱财花销较大，不太聚财，容易财来财去，要注意理财，避免不必要的开支花销。53岁后大运助身，财运会好起来。

# 分析婚姻：

月干己土为正财，时支戌土为偏财，正偏财同见，且甲子日出生临桃花、红鸾，故而容易在婚姻感情上有二心，这方面是要克服的，尽量和婚外异性保持距离为好。

日支婚姻宫为子水正印用神，且子水得酉金生扶，代表整体婚姻还是不错的，加上月干己土正财为妻，流通生入日主，代表妻子对你有一定帮助。

要孩子一般是结合两个人的看，单独你的看官杀代表子女，你的原局见正官三位，理论上有三个女儿，现在有一儿一女，多也借助妻子的运气有儿子。

# 分析大运：

**33岁-42岁**

乙巳大运，此大运天干乙木劫财透出帮身，有好的一面。但是乙木也为藤萝，缠绕甲木不清，代表事业上容易遭遇小人。地支巳酉半合，命局流通有所阻断，故事业易有阻碍，升职机会不多，能想办法调整下岗位为好，不易跳槽大动。

**43岁-52岁**

甲辰大运，此大运地支辰土被天干甲木盖头，为比肩克财的大运。天干甲己相合，己土财星被合克，且三个甲木争合己土，代表事业上的一种竞争或者有时帮助你的人，在一些利于面前，也会参与竞争，防人之心要有。甲己相合，酉辰相合，命局流通被阻断，运势不太理想，求稳为好，钱财花销大，财运也不理想。

**53岁-62岁**

癸卯大运，此大运印比助身，且在命局没有阻断流通，故整体运势有所提升，事业上有贵人相助，升职发展机会较多，收入也有增加，属于人生的黄金期，能加强努力为好。不过，地支子卯相刑，要注意下夫妻关系
