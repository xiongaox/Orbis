# 分析命局：

甲木日主生在子月得令，坐申金失地，时支亥水也是生扶日主的五行，地支亥子丑三会水局，且得申金生扶较旺，生扶日主力量强，年干和时干乙木来帮身，年支丑土被合化，月干戊土来耗身，但戊土在天干被旺木所制，耗身无力，为偏旺之格。

# 分析喜忌：

甲木日主偏旺，以泄耗日主的火土五行为用神，以生扶日主的水木五行为忌神，五行金虽克身，但在地支生水不吉。地支水旺成势，五行土虽可制水，但在地支也可生金，所以地支单独见土也不是最好的组合，相对来说，更喜见燥热之土，比如戌土未土，而不喜见寒湿之土，比如丑土辰土，更同时喜见火来制金，火土同见为吉，天干一片木，喜见火来通关生土。

# 分析事业：

子水印星当令较旺，戊土财星被劫财所制无力，不见食伤来泄身，性格上会比较固执，比较自我，做事欠缺一些灵活变通，容易一根筋，印星旺也有一定依赖性，自主性和独立性相对缺乏，有时候会有些懒，做事缺乏坚持，另外一方面就是在工作中的人际关系上，眼力劲比较差，有时候听不懂领导的话外之音，不容易得到领导的青睐。

地支亥子丑三会水局，而甲木日主虽旺，但在地支无根，为无根之木，地支水旺，也有水多木漂之象，这种组合代表容易发生变动多，也多为外出发展置业，很难留在家乡，加上时支亥水印星临驿马，也代表会到外地买房定居，出生地的南方，东北方，西南方比较适合你，而东方不太旺你。

甲木在地支无根，水多木漂，这样的组合如果没有大运配合的话，想取得好的成就是比较难。特别是年支丑土财星被合化，地支申金原本是用神，但是用神化忌，天干戊土财星又被乙木劫财所制，也为忌神制用，用神都是被制约的状态，也代表在事业发展中会遇到比较多的阻碍和挫折，而自己不容易克服，加上自己又容易毅力不足，内心浮躁，三心二意，遇到困难很容易知难而退。

结合大运来看，早年走的是丁亥大运，丙戌大运，天干丙丁火食伤通关乙木助财，早年运势不差，财星来制印，也可以取得一定学历。

但大学毕业后已进入乙酉大运，天干乙木劫财克财，地支酉金旺了印星，运势有一些走低，尤其考学运不太理想，所以考公务员基本无缘。

地支为杀印相生的组合，月柱戊子临将星，故相对而言，更加适合从事偏武职的行业，而在现代社会，工程方面可以归入武职，五行以土为用神，如果从事土建方面工程，更加适合你。身旺无依，也适合一技傍身，你能多考职业证书也是非常好的，对于事业发展较为有利。

年支丑土被合化，月干戊土为命局独财，在天干被一片旺木所制，构成劫财夺财，且财透天干，地支无财库，为财来财去之命，赚到的钱很容易因为各种原因花出去，也要注意和身边人的金钱往来，不要去做一些高风险投机的事情，比如赌博，炒股等。

原局也不见食伤来生财，财无财源，也代表难见大财，财运不太稳定，时好时坏，所以能干好本职工作为好，能稳定求财较为有利，投资要尽快收手。

# 分析婚姻：

丑土正财被合化，只见月干戊土独财，以戊土偏财为妻，2012壬辰年，地支申子辰三合，辰土偏财被合入，婚姻宫被合动，有结婚之象。戊土偏财为用，日坐申金七杀，妻子能力一般偏好，比较操持能干，但要注意天干劫财克财，且财无元神，妻贤就要注意妻子身体健康。
