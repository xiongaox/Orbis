# 分析命局：

# 分析喜忌：

从旺以生扶日主的水木五行为用神，以泄耗日主的火土五行为忌神，金虽克身，但在地支生水为吉，旺了印星也可看作顺从旺势。天干木旺，喜见水来生木。如果大运破格，则更加喜见火来泄身，土来耗身，火土同见也为吉。

你是甲木日出生，甲木为参天大树，有向上生长的特点，所以一般甲木的性格都偏直爽和正直，同时甲子又是六十甲子之首，往往都有权力欲望，一般甲子日的人，有事业上有上进心，不甘平庸。

但是，你的地支见三个亥子水，日支又是子水，甲木虽在亥水中有弱根，但地支全是水，水势太旺了，有水多木漂之象，甲木在地支没有强根，也就体现不了甲木的特点，反而是会体现出做事不易坚持，容易放弃，意志不够坚定的问题。

甲子日出生，临月德贵人，本质上比较仁慈善良，亥水印星当令较旺，地支见三个亥水伏吟，日支也为子水印星，印星较多较旺，一般依赖性较强，但容易得到父母等干预，当然也会造成自己性格软弱，缺乏魄力，不能吃苦，做事较为懒散，没有耐性，同时做事较难坚持，容易半途而废，这是要多克服的。

月干丁火伤官泄身，但被亥水戳脚，月柱丁亥暗合，为印克伤官，也代表思维不够灵活，有一些死板，工作上缺乏一些灵活变通。

原局不见财星，就连暗藏的也没有，月干丁火为伤官，以月干丁火伤官为财，丁火伤官高透，且丁亥暗合，丁火有损，丁火也为财源，总体财运较为一般，较难见大财，能满足于一般的财，知足常乐为好。伤官透天干被戳脚，比劫多现，也代表钱财不聚，花销较大。
