# “刑合格”的人

命主生辰: 1995/06/11 4:00 (GMT+8)
性别: 乾造
日主: 癸水
格局: 偏弱之命
令地: 失令, 得地

# 网友来信：

【基础情况】

我在学生时代并没有为自己的人生做一些规划，稀里糊涂地调剂了很难就业及考公考研的小语种专业，毕业后又从事了与专业无关的广告创意类工作。去年时值工作五年，在家乡的小市场里，累积了一定的经验，有还算满意的收入和职位。但由于行业奔波劳累，本土市场上升空间又极其有限，当时有了强烈的的人生瓶颈感；同时年龄日渐增加又叠加市场环境恶化，导致自己的35岁危机感也非常严重。于是去年在“考研再考公躺平”这条路和“到一线城市继续广告行业”的两条路中间纠结了几个月后，最后在今年年初毅然决定到上海来，打算在同行业积累更多一线市场的经验和履历，为30多岁后回老家做准备。

到上海之后，我感受到了和一线城市的巨大差距，甚至第一份工作没过试用期被辞退了，令我感受到了强烈的挫败感。只得暂时选择一个妥协的选项累积并静待机会和出路，目前薪资状况捉襟见肘，工作内容和发展机会都不佳。与此同时，许多生活中的烦心事也让我心力交瘁，例如来上海的短短几个月中，家中亲近的长辈突然壮年患癌又迅速离世、父亲突然身体和精神状况都面临危机，家乡购买的房产又面临烂尾，一波三折...

回顾至今的人生，从十五岁开始就是关关难过关关过；尤其是这轮七杀运刚开始的时候，整个人因为一段感情经历彻底冲毁了价值观，抑郁复发，险些走上绝路，随后又一点点努力，几年时间重新塑造了一个完全崭新的自我。只是走到七杀运的后五年，愈发感觉到压力巨大，还没有了当初推倒重来的勇气。明知自己目前状态非常糟糕，也知道需要沉下心来慢慢累积，但却浮躁到难以静下心来，整个人疲惫焦虑、怨气戾气满身。

# 八字详批：

#### 乾造：乙亥年，壬午月，癸酉日，甲寅时（戌亥空）

#### 大运：辛巳，庚辰，己卯，戊寅，丁丑，丙子，乙亥，甲戌，3岁运。

# 分析命局：

癸水日主生在午月失令，坐酉金得地，但被午火所制，酉金生扶力量不强，时柱甲寅干支一气来泄身，年支亥水来帮身，并在月干透出壬水，也来帮身，年干乙木来泄身，乙木也来泄壬水和亥水之力，地支寅亥相合，合而不化，故依然为偏弱之格。

# 分析喜忌：

偏弱以生扶日主的金水五行为用神，以泄耗日主的木火五行为忌神，五行土虽克身，但在地支生金为吉。午火当令，地支寅木泄身，喜见金来制木生身，也喜见水来制火，由于子午相冲，更喜见亥水，寅申相冲，更喜见酉金。天干喜见金来制木生身，单独见水，帮身的同时也会生木，故不喜多见。

# 分析事业：

日支酉金为用，且酉金来制寅木为吉，为用神制忌，但酉金被午火所制，为忌神制用，稍有不利，年支亥水为用，月干壬水也为用，壬水和亥水来制午火为吉，为用神制忌，较为吉利，但又来生了乙木，为用神化忌，组合一般。

《渊海子平》中讲：浑水寅时格正清，刑愁庚克不能成。运行若不逢蛇地，方得清高有利名。
关于刑合格，一般是癸卯，癸酉，癸亥三日出生于甲寅时，年月如果出现酉金、丑土其中一字为贵，同时原局和大运不能见戊土、己土和巳火、庚申金，见之当破格论，《渊海子平》的意思大致也是如此。

你的可以入刑合格，但奈何早年走的辛巳大运，见巳火破格，转庚辰大运，见庚金破格，现在走的己卯大运，见己土破格，未来走的戊寅大运，见戊土也为破格，大运并非太理想。

但到了丁丑大运，丙子大运，没有破格，且丁丑大运，见丑土为贵，从刑合格格局的角度来看，到丁丑大运后是比较理想的运气。

从旺衰的角度来看，丁丑大运的地支丑土通关旺了酉金，子水来制午火，在一定程度上解救了酉金，且子水来帮身，所以从旺衰角度来看，到丁丑大运运势也不差。

年支亥水劫财为用，月干壬水劫财帮身，比较积极上进的一个人，时柱甲寅干支一气为伤官，伤官高透，有一定野心和欲望，午火偏财当令，午火来制酉金，为财星克印，做事比较难坚持，容易半途而废，有时候也容易马虎大意，印星被制，加上食伤不弱，也比较辛苦劳碌。

身弱时柱甲寅干支一气为伤官，年干乙木食神透出，寅木伤官虽为忌神，但有酉金来制，故可以为“我”所用，所以从事广告、设计、策划相关专业和事业是适合你的，只不过酉金被午火所制，酉金制寅木无力，所以想在这个方面实现太大的突破，做出成就是比较困难的，但以此为业，养家糊口是可以的。

现在走的是己卯大运，地支卯酉相冲，酉金印星逢冲，且天干己土出现，从刑合格的角度来说也破格，所以整体运势并不理想，包括事业运、考学运和财运，心浮气燥也与这有很大关系。

年支亥水虽临驿马，但地支寅亥遥合，驿马被合绊，所以也不建议你去上海，身弱喜印，能在家乡，或者离家乡不远的地方均是不错的选择。当下给你的建议还是可以考虑考研，选择艺术、设计、广告等方向。

但今年癸卯年，地支卯酉相冲，酉金印星逢冲，考学运自然不佳，明年甲辰年要稍好一些，过了明年，2025年，2026年，考学运又有所下滑。而未来的戊寅大运，运势也不太理想，且戊癸相合，为正官合身的运气，能选择上班求稳为好，到了丁丑大运，丙子大运，运势能够有好的转变，有发展提升的机会。

身弱以酉金印星为寿元星，但酉金被午火所制，故容易体质不太好，尤其23岁后进入己卯大运，地支卯酉相冲，冲了酉金印星，更加代表如此，也要注意肺部，肠道等方面问题。午火被制，要注意眼目，心脑血管方面问题。原局不见土，也要注意脾胃，皮肤等方面问题。过了现在的大运，体质会稍好一些。

# 分析大运：

**23岁—32岁**

己卯大运，此大运天干己土被地支卯木戳脚，为食神制杀的大运，天干己土透出，地支卯木为食神，卯酉相冲，酉金印星逢冲，故运势不太理想，阻碍较多，容易心态不好，比较浮躁，做事多败少成，事业运、财运和考学运均较为一般，也要注意身体健康。

**33岁—42岁**

戊寅大运，此大运天干戊土被地支寅木戳脚，为伤官克官的大运，故要注意口舌是非，与人不和之事，凡事要谨慎低调，谨言慎行。天干戊癸相合，正官合身，事业有一定压力，能上班求财为佳，付出较多，收获有限，适合求稳。

**43岁—52岁**

丁丑大运，此大运为财杀相生的大运，地支丑土来通关生酉金，故整体运势不差，事业上有发展的机会，可以把握机遇，做出成绩，收入有所增加，可以得到贵人相助，但丁壬相合，地支丑午相害，午火财星受损，也代表花销也不小。

**53岁—62岁**

丙子大运，此大运天干丙火被地支子水戳脚，为比肩制财的大运，天干丙火财星透出，地支子午相冲，在一定程度上解救了酉金，且子水比肩帮身，故整体运势不差，贵人运好，但子午相冲，午火财星逢冲，也要注意破财之事，或财来财去。
