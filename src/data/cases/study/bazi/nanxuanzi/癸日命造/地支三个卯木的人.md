# 分析命局：

癸水日主生在卯月失令，坐卯木失地，时支卯木伏吟来泄身，年干和月干透出乙木来泄身，月干己土来克身，但己土被乙木和卯木所制，唯有年支亥水来帮身，但亥水被乙卯木泄气无力，为偏弱之格。天干乙木食神从月令卯木中透出，为食神格。

# 分析喜忌：

癸水日主偏弱，以生扶日主的金水五行为用神，以克泄耗日主的木火土五行为忌神，地支五行木旺成势，喜见金来制木，但由于卯酉相冲，相对来说，更加喜见申金，天干木旺克土，也喜见金来制木，而天干由于乙庚相合，辛金为佳，五行金为重要的用神。

# 分析事业：

原局为食神格，地支三个卯木伏吟，临文昌贵人，思维较为灵活，有一定领悟力，但身弱食神太多太旺，且又无制，也代表思维虽然灵活，但容易胡思乱想，想要的太多，想法杂乱，有时候容易空想，做事想法多变，容易三心二意，癸水被乙卯木泄身太过，做事精力不够，容易感到累，且较难坚持，一旦新鲜感过去，就会知难而退，缺乏持之以恒的坚持。

食神太旺，食多为伤，也容易表现出伤官的特性，性格也有一些傲慢任性，自尊心强，好面子，很容易自命不凡，工作上取得一点点成绩，就开始幻想出任CEO的画面，迎娶白富美的画面，容易飘飘然，这是要注意克服的，做事要以平常心去对待，不然容易眼高手低，想得多，做的少，行动力不够，造成高不成低不就。原局来看，五行不见火，就连暗藏的也没有，也代表做事积极性不够。

食神格，乙木食神高透，地支卯木临文昌贵人，一般来说，这样的组合是口才不差的，表达能力较好，但由于食神太多且无制，也容易口无遮拦，言语伤人，因为说话而惹祸，这是要注意的。尤其乙卯木食神来制己土七杀，为食神制杀，也代表比较爱自由，有一些叛逆，不喜欢被管束、被唠叨，因而也容易与人不和。

月干己土为七杀，七杀为忌，有食神制杀为吉，但己土七杀太弱，虚透天干，食神制杀太过，也体现为做事缺乏魄力，人缺乏威严，有一些懦弱，也代表事业变动较多，很难稳定。

以己土七杀代表事业，但己土七杀太弱又被制，事业运不强，适合从事一些偏自由的行业，朝九晚五的工作不适合你，即使找了这种类型的工作，也较难坚持下去或发展受限，公务员事业单位这样的工作并不适合你。

食神太旺，比较追求精神享受，也容易贪图口腹之欲，而身弱食神旺，一般也有一定奉献精神，懂得付出，若能执着于一个领域，也有发展的机会。

食神格，食神较多，很适合从事一些咨询培训、涉及策划、教育文化、传媒、销售解说、技术等方面工作，食神也有晚辈、学生、追随者的意象，可以围绕这些方面去发展，会有不错的发展，考公建议尽早放弃，实现自身价值不是只有公门才可以，任何一个行业，只要成为佼佼者，都可以发光发热。

原局不见财星，就连暗藏的也没有，可以以食神代表财，而原局食神太多，且时柱乙卯食神入门户，可以得到这个财，也代表唯有多付出，踏踏实实去做，别怕吃苦，多奉献自己，才可得财，求财也会非常辛苦，收获较为有限，天干乙木食神高透，也代表花销大，不聚财。

从行运来看，53岁后走癸酉大运、壬申大运，财运会较为不错，但好运好的太旺，也有些有心无力，不过也代表晚年无忧。

# 分析婚姻：

卯木食神当令较旺，伏吟地支，一般而言，对待感情比较主动和执着，一旦遇到喜欢的人，可以大胆追求，也有自己的想法，但食神太多，也容易物极必反，反而有冷漠消极的一面，日支婚姻宫为卯木食神，也代表未来在婚姻上操心操劳较多，付出也较多。

原局不见财星，就连暗藏的也没有，一般来说和配偶缘分不深，也代表遇到缘分会比较晚，地支卯木伏吟三次，且伏吟到婚姻宫，在感情上容易反反复复，分分合合，这是要注意的。以日支婚姻宫卯木为妻，卯木为忌，未来妻子条件一般。

2025乙巳年，食神生财，妻星出现，2026丙午年，丙火妻星透出，有遇到的运气。2027丁未年，地支亥卯未三合，合动婚姻宫，有结婚的运气。

未来对象脸型微方，身高一般，身材匀称，肤色微清白，眉毛纤细，眼睛不大细长比较有神，鼻子挺直有肉，嘴唇微不薄不厚，声音宏亮，身高在160公分左右。

个性方面方面热情大方，做事雷厉风行，不喜欢拖拖拉拉，有主见，自尊心强，做事周到负责，有时也很固执，有些脾气，上进，能力强。职业方面与人力资源，行政，医药护理等相关。

# 分析大运：

**23岁—32岁**

丙子大运，此大运天干丙火被地支子水戳脚，为比肩克财的运气，故而钱财上花销较大，不太聚财，求财比较辛苦，但丙火正财妻星出现，坐子水之上为桃花，也有遇到并结婚的运气。地支子卯相刑，很容易有口舌是非，或者在感情上不顺利，这是要注意的地方。

**33岁—42岁**

乙亥大运，此大运天干乙木食神高透，乙木来制己土，食神制杀严重，故而依然事业变动较多，很难稳定下来，适合做偏自由一些的工作，也要注意和领导同事不和之事，地支亥亥自刑，羊刃自刑，要注意调节心理，容易抑郁想不开，也要注意出行安全，意外伤害。

**43岁—52岁**

甲戌大运，此大运地支戌土被天干甲木盖头，为伤官克官的大运，此大运依然要注意口舌官非之事，凡事要谨言慎行为好。天干甲己相合，己土七杀被合克，事业容易变动，不太稳定，也要注意脾胃，皮肤等方面问题。

**53岁—62岁**

癸酉大运，此大运行金水印比，印比助身为吉，表示事业运和财运总体较为不错，有贵人相助，事业有升职发展的机会，有机会做出成绩，收入有所增加，但地支卯酉相冲，要注意婚姻不和，夫妻矛盾，妻子健康，自己也要注意摔倒绊倒，碰破磕破之事。
