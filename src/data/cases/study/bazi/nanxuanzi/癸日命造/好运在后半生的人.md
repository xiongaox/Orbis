# 好运在后半生的人

命主生辰: 1992/10/24 10:00 (GMT+8)
性别: 乾造
日主: 癸水
格局: 偏财格
令地: 失令, 得地

# 网友来信：

我之前也找别的老师看过，我从丁亥年走壬子大运，老师说我人生好运全在年轻时候，后面就没好运了。我也不知道是对是错。因为我在学生时期时长遭受霸凌，后期高中时候学业更是因为霸凌一落千丈。知道高中补习才好一点。大学之后虽然有所好转但还是大差不差。学习成绩一般，也没有考研考公，成了一个打工人。

我在壬子运最后一年丙申年的冬天还遭遇一场火灾，算得上是死里逃生。后面事业也不是很好，丙申年受到领导打压被迫离职。丁酉年无奈从山西太原来到北京谋求发展。万幸在丙申年遇到了自己的另一半走过了最难的时间。

丁酉年开始我就在北京打拼，做的是教育类销售，收入可以说是就够付房租。戊戌年进入广告行业才算是有所起色。但是工资也是一直比同行业人员低，专业能力也没有太好的学习渠道和环境，能力一般。

直到壬寅年才算整体有所缓解，工资也算一般水准，但是前景堪忧，能力也没啥锻炼机会，一直平平。

所以想问我后续的大运会有所转机吗？因为人到中年，对象还想要在北京买房，感觉对未来很是迷茫。

# 八字详批：

#### 乾造：壬申年，庚戌月，癸酉日，丁巳时（戌亥空）

#### 大运：辛亥，壬子，癸丑，甲寅，乙卯，丙辰，丁巳，戊午，6岁运。

# 分析命局：

癸水日主生在戌月失令，坐酉金得地，年支申金也是生扶日主的五行，地支申酉戌三会金局，生扶力量不弱，月干透出庚金，也是生扶日主的五行，年干壬水来帮身，时柱丁巳干支一气来耗身，癸水日主得令得地，为偏旺之格。时干丁火偏财从月令戌土中透出，为偏财格。

# 分析喜忌：

偏旺以泄耗日主的水木五行为用神，以生扶日主的金水五行为忌神。地支申酉戌三会金局，金旺成势，喜见火来制金，也喜木来生火，由于寅巳相害，更喜见卯木，天干金水两旺，喜见木来通关生火，也喜见火来制金，木火同见为吉。

# 分析事业：

地支申酉戌三会金局，印星是较旺的，虽有时柱丁巳干支一气财星制印，但财星力量不足，印星太旺，不见食伤来泄身，性格有一些敏感，比较多疑，容易想的多，也会有些固执执拗，在变通性和灵活性上较为缺乏，有时候容易钻牛角尖，比较好面子，自尊心很强，容易斤斤计较，依赖性也比较强。

印星太旺，正偏印同见，也代表做事容易纠结顾虑多，做好的决定容易临时的改变，做事不易坚持，容易三心二意，偏软弱保守一些，时干丁火财星透出，也有一定虚荣心。

壬水劫财为忌，一般年干劫财为忌家里条件一般，也容易遭遇不良人，被他人算计欺负等，而且早年走的辛亥、壬子大运，均为比劫旺的大运，所以有校园霸凌的经历，身边小人也多一些，所以有人认为好运在前半生的说法并不正确。

现在走的是癸丑大运，天干癸水比肩透出，地支丑土七杀旺了印星，也并非太好的运气，人生缺乏太多机遇，且自己不容易把握住。

36岁后进入甲寅大运，乙卯大运，运势会比现在好很多，丙辰大运，有利有弊，利大于弊，所以你的命格属于好运在后半生。

从四柱来看，年柱为早年，月柱为青年，日柱为中年，时柱为晚年，命局唯有时柱丁巳为用神在时柱，也代表属于越老越好的命。

印星较旺，年支申金临国印贵人，适合上班求财，也多为上班求财之命，而且原局不见食伤，所以在创新性、突破性、灵活性上较为缺乏，不适合做挑战性较强的工作，做一些按部就班，变化性小的工作标记哦好，从事事业单位、公务员、国企央企、教育文化相关，都是可以的，只要稳定就好。

你目前从事过的销售、广告等行业，五行上虽也适合你，但运不好当下难做开，到走食伤大运时才更适合，总之求稳就是方向。

原局不见食伤来生财，就连暗藏的也没有，财运时好时坏不稳定，时柱虽然丁巳财星，但时干丁火被年干壬水劫财合克，地支巳火财星被地支泄耗，导致巳火财星力量也不足，同时不见食伤来生财，连暗藏的都没有，财运容易时好时坏不稳定，适合上班，求财稳定，会较为有利。

原局正偏印同见，财星制印无力，想买到理想的房子不太容易，2025乙巳年，2026丙午年，可以考虑出手，有一定机会。

你现在走的癸丑大运，天干癸丁相冲，比肩冲财，财运不太有利，容易花销破耗，未来的甲寅，乙卯大运，均为食伤的运气，食伤来生财，财运会逐步好起来，这两步大运有余力也可在主业稳定后发展副业，做点小生意等，丙辰大运，稍有下滑。

# 分析大运：

**26岁—35岁**

癸丑大运，此大运天干癸水被地支丑土戳脚，天干癸水比肩透出，事业上竞争较大，容易遭遇小人，要多注意，癸丁相冲，比肩冲财，财运不太理想，容易花销破耗。地支丑土旺了印星，没有太好的机会和事业运，适合求稳。

**36岁—45岁**

甲寅大运，此大运干支一气为伤官，天干地支伤官生财，故整体运势要比现在好很多，可以施展才华，做出成绩，整体财运有所增加，收入可观。但地支寅巳申三刑，也要注意口舌是非，与人不和，不必要的钱财花销，凡事谨慎低调为好。

**46岁—55岁**

乙卯大运，此大运干支一气为食神，天干地支食神生财，故整体运势依然不差，有升职发展的机会，事业可以小有所成，财富等级不低，好把握机遇，可以在主业稳定后发展副业，有机会赚到钱。

**56岁—65岁**

丙辰大运，此大运为财官相生的大运，天干丙火财星透出，财星克印，事业上有升职发展机会，有机会做出一定成绩，地支酉辰相合，官印相生，能上班求财为佳。
