# 要注意小人的组合

命主生辰: 1999/08/29 8:00 (GMT+8)
性别: 坤造
日主: 癸水
格局: 偏旺之命
令地: 失地, 得令

# 网友来信：

毕业以后，工作变成了我又爱又恨的对象。当同龄人在为了爱情轰轰烈烈的时候，我在被工作虐得死去活来。而使我疲倦的却不是工作本身，而是职场中的人事。

常常有人说我运气好，因为我经常在工作中意外得到一些大人物的青睐，得到一些旁人没有的机会。但神奇的是，我总是会因为各种原因错过这些机会，或者抓住了机会却被机会所伤。

最经典的一次是辛丑年，我被推荐，获得了一份十分体面的工作（实际上工作内容十分劳累），但我仍然十分兢兢业业地完成着自己的工作，和同事相处也是礼貌和谐。后来我寻求个人发展选择离职，我仍然认真做着分内事完成交接，却在在职的最后一天意外得知我的上司一直克扣我的奖金。

我找她对质，她十分错愕甚至质问其他员工是谁泄密了，发现自己完全不占理后，直接大吼我“那你又能拿我怎么办？”

而我的确不能对她怎么样，我也不是鱼死网破的性格。当时伤我最深的是，我不能理解一个总是在我面前念叨女儿的人，是又怎么忍心伤害别人家的女儿的。

除了以上的例子，我在其余工作中也总是会遇到一些人莫名其妙的针对。当然也遇到了值得尊重的优秀前辈对我很好，但职场上的勾心斗角和虚伪还是给我带来了不少的阴影。

而上一份工作总体来说待遇都不错，但休息不多也十分劳心，导致身体也出了些问题。（我从小到大身体比较弱，大小事不断，精力不足）

于是辞职，休息了几个月，如今要重新找工作。

> 综上所述想向请教几个问题：
>
> 1、我在职场中总是出现被针对和被说是非，是否是我自身的原因，我应该改正什么？
>
> 2、我今年在工作方面能得到发展吗？
>
> 3、我的兴趣爱好广泛但的确不精，我往哪一方面深耕事业可以有所成就呢？

# 八字详批：

#### 坤造：己卯年，壬申月，癸丑日，丙辰时（寅卯空）

#### 大运：癸酉，甲戌，乙亥，丙子，丁丑，戊寅，己卯，庚辰，5岁运。

# 分析命局：

癸水日主生在申月得令，坐丑土失地，丑土的本气虽为己土，但暗藏癸水，有一定助身之用，月干壬水来帮身，壬水坐申金为长生，帮身力量不弱，年干透出己土克身，时支辰土也来克身，年支卯木来泄身，时干透出丙火来耗身，但依然为中和偏旺之格。

# 分析喜忌：

中和偏旺以泄耗日主的木火五行为用神，以生扶日主的金水五行为忌神，土虽克身，但在地支生金不吉。申金当令较旺，地支土来生金，故喜见火来克金，同时也喜见木来疏土，木火同见为吉。天干喜见木来通关生火。

# 分析事业：

年支卯木为用，但地卯木被申金所制，且卯辰相害，卯木有损，为忌神制用，用神受损，为不足之处。时干丙火也为用神，但丙火在天干难以得到卯木直接生扶，且被辰土泄气无力，地支土来生金，间接旺了忌神，也为不足，所以组合并非太理想。

申金印星当令，得丑土生扶不弱，虽然有卯木食神来泄身，但被申金印星所制，为印克食神，会体现为性格有一些敏感，比较多疑，也有一些固执执拗，在变通性和灵活性上较为缺乏，有时候容易钻牛角尖，对于一些事情容易闷在心里计较，也比较要面子，自尊心强。

时干丙火财星透出，有一定虚荣心，己土、丑土七杀和辰土正官构成官杀混杂，做事容易心不定，三心二意，缺乏坚持，一般也容易导致工作不稳定，工作岗位变动多。癸丑日出生，临太极贵人和寡宿，印星当令，性格会有偏内敛的一面，在人际关系上容易吃亏。

月干壬水为劫财忌神，代表同辈之人，也代表竞争对手，且挨着日主为忌神，而且壬水坐申金之上，申金又得丑土辰土生扶，，辰土坐上丙火，整体五行一路流通生入壬水，这个壬水是很有力量的，代表事业上有一定竞争大，容易被排挤打压，遭遇小人。尤其年支卯木食神为用，但卯木空亡，又被申金印星所制，也代表很容易错失良机，机会来了自己不容易把握住。

你现在走的是乙亥大运，地支亥水为劫财，壬水在地支有了强根，此大运又旺了壬水力量，也更加代表此大运要注意人际关系，做事阻碍竞争大，未来的丙子大运，子水为比肩，也要注意类似问题。45岁后进入丁丑大运，戊寅大运，有丁壬相合，也有戊土来制壬水，会相对好一些。

丙火来生辰土，地支丑土来生申金，为财官杀印相生的组合，这种组合适合上班求财，也多为上班求财之命，而且卯木食神被制，所以在创新性、突破性、灵活性上较为缺乏，不适合做挑战性较强的工作，做一些按部就班的工作要好一些，加上癸丑日出生，日坐丑土为印墓，故而从事事业单位、公务员、国企央企、教育文化、管理相关，都是可以的，适合稳定就好。

你现在走的是乙亥大运，属于有利有弊的大运，有一定发展的机遇，但也有很大竞争，今年癸卯年，卯木食神填实，找工作也有一定机遇，不过竞争依然是有的。

接下来2024甲辰年，2025乙巳年，2026丙午年，2027丁未年，运势会比现在好一些，可以找到更加理想的工作，且可以做出成绩，也有晋升机会。

时干丙火为正财，财星入门户，可以得到这个财，但丙火财透天干，地支无财库，而且卯木食神财源被制，难以直接生扶丙火财星，代表钱财花销还是不少，能得到的财有限，难见大财，赚到的钱也多为工资财，也代表财运不是太稳定。

结合大运来看，现在的乙亥大运，未来丙子大运，和丁丑大运，总体财运较为一般，到了戊寅、己卯大运，财运好一些。

# 分析大运：

**25岁—34岁**

乙亥大运，此大运天干乙木食神透出，乙木食神生财，地支亥水旺了卯木食神，代表有一定发展机遇，自己可以把握住，可以施展才华，做出成绩，天干食神生财，整体财运有所增加，但地支亥水为劫财，也代表事业竞争大，容易犯小人，是要注意的地方。

**35岁—44岁**

丙子大运，此大运天干丙火被地支子水戳脚，为比肩克财的大运，天干丙火财星透出，壬丙相照，日照江河，适合求名，可以获得一定名气和荣誉。地支子水比肩帮身，事业依然有竞争，要注意小人，子卯相刑，也要注意口舌是非。

**45岁—54岁**

丁丑大运，此大运为财杀相生的大运，天干丁火透出，丁壬相合，壬水被合拌，故事业上竞争变小，为吉利之处，但钱财花销较大，不太聚财，地支丑土旺了申金印星，升职发展机会不多，适合求稳。

**55岁—64岁**

戊寅大运，此大运天干戊土被地支寅木戳脚，为伤官克官的大运，故要注意口舌是非之事，加上地支寅申相冲，申金印星逢冲，事业容易变动，多已退，但戊土来制壬水，事业上竞争减小，整体财运有所增加，为吉利之处。
