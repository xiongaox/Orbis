# 十灵日出生的人

命主生辰: 1989/08/19 10:00 (GMT+9)
性别: 坤造
日主: 辛金
格局: 伤官格
令地: 失地, 得令

# 网友来信：

回忆这三十多年的人生，似乎一直在走弯路。从小就很聪明，从来不补课，数学轻轻松松年级第一，文科也很好，英语老师说英语有天赋题一难就是第一，语文高考也是第一，作文会被同学抢去读。但高中物理老师教的不好，自己任性开始抵触物理，不做作业不听课，物理成绩一落千丈，从尖子生代表学校参加竞赛，到考试不及格。到高三我幡然醒悟开始自学物理，无论人家背单词还是做数学题我都在看物理，最后考了一个蛮高的分数，本来可以去复旦但是志愿没填好最后去了另外一个Top10的大学。

至于为什么志愿没填好，自己当时一门心思补物理之前也没研究过，也没人在身边商量，当时我的“父亲”一如既往的在外面和狐朋狗友吃吃喝喝，母亲则是因为地震要在学校陪学生（这个我很理解），这也是我整个童年的写照，一个工作狂天天加班，一个不务正业不回家，我从小都靠自己，自己学习，下雨没带伞就自己淋雨回家，外婆过来玩的时候遇到下雨给我送伞结果我没碰见还是淋雨回家，大概是对他们也不抱希望了所以出校门根本不会看门口送伞的家长里面有没有我的家人，所以也错过了唯一给我送伞的外婆。他们甚至会为谁去我家长会而争吵，我直接就让他们都不要去。

所有人都说，如果当初不任性，好好学物理，妥妥能去清北拿区状元甚至更多（我们年级第1一直是我们省会城市第2名，但他其他科没我好，原来物理也没我好）。以后的轨迹可能完全不同，遇到更优秀的同学和老师，更丰富的资源，更广阔的平台与更好的机会。

学校差强人意，更坑的是脑子一热读了一点都不喜欢的专业——土木。报土木还是因为地震，看到那么多的房子倒塌，当时我还跟家人说我不要参加高考了我要去震区帮忙，结果家人问我我去能干什么。我一想是啊，原来学了这么多根本没用，我去的话还会成为需要吃喝的累赘。后面我就决定学土木，修震不垮的房子。结果读书了才发现房子垮不是知识技术不到位，而是缺了一个很重要的东西——良心。鲁迅说学医救不了中国人，其实学土木也救不了中国人。而且土木要学十多个力学，虽然自己聪明学起来不难，但真的不喜欢。

当时想转金融，对方院愿意我来，但可能因为成绩好所以我们院不让我走，所以也作罢。其实回想起来，自己也没有很喜欢金融，只是认识些这个专业的前辈说起来就业挺好的。那我喜欢什么呢，国外有一个“文艺复兴者”的概念，就是指一个人兴趣很广泛，我就是这样，我喜欢文史哲、艺术及一切美好的事物。很小的时候我就展现了艺术天赋，学画画的时候老师就这样告诉我家长，但是不久他们就强迫我中断绘画怕影响我学习。我始终记得那天他们来带我走，我在走廊外求他们让我们上了最后一次课。可能我音乐也有天赋吧，唱歌好听也拿了奖（但我记不住歌词哈哈），小时候我还想学乐器，家长不同意，当时隔壁的朋友学古筝，我就去她家学着弹，她妈妈听了就批评她女儿，说她学了几个月还没我学了一下午弹的好，所以我再也没有在她家弹了，免得她再挨骂。

感觉自己的天赋技能点真的很多，就是一手好牌打得稀烂。做过测试说自己左右脑均衡，从小就是数理逻辑和语言创意都很强的那种。但左右脑均衡就容易纠结，还有地支一片冲破也是我内耗多的原因吧。本来不想读研究生家人不同意，就决定出国，但当时很疼爱我的奶奶开始老年痴呆，我很担心我出国了她就不认得我了，再加上我从来就很懂事，不想花家里这么多钱留学，所以最终改变决定选择保研，中间交换到国外的名校一共拿了2个硕士学位。

回国后，父母的离婚拉锯战越战越烈，母亲一天N次给我打电话说想轻生，所以在我本应该找工作的时候，我再一次被家庭绊住，天天担心家里最后放弃留在一线城市选择了家乡体制内的工作。现在看着当初成绩、外语和能力都不如自己的同学都过得比我好，心里虽然不嫉妒也为他们开心，但是也为自己委屈，他们也老说这个工作配不上我让我辞职，就连身边的同事都觉得我屈才让我赶紧走。

从事业上，接受体制内工作前我就知道自己会不喜欢，当时是想回来陪母亲几年，等她情况好了就辞职。但没想到我那时已经因为家里的事情，患上了严重的抑郁症，早有轻生的念头，当时连医生都惊讶我不吃药能撑到现在，只是当时太过关注母亲的情况没注意自己不对劲。然后从开始拒绝治疗到后来看医生吃药，然后就吃到了现在，医生说我基本好了，但我自己觉得脾气还是特别急，生气了连我自己也没办法控制，一旦生气和原来的自己完全不一样。在体制内呆了8年左右，想跳出来又不知道应该做什么。

另外几年前，学了蓍草占卜给自己个人卜卦，是乾变升。占家人（担心历史的“惊涛骇浪”），是中孚变复。个人从政是解变丰。给是否出国卜卦，是泰变大有。留国内，是明夷变既济。去美帝，是未济变解。去欧洲，是同人变坎。

# 八字详批：

#### 坤造：己巳年，壬申月，辛亥日，癸巳时（寅卯空）

#### 大运：癸酉，甲戌，乙亥，丙子，丁丑，戊寅，己卯，庚辰，8岁运。

# 分析命局：

辛金日主生在申月得令，坐亥水失地，月干透出壬水来泄身，时干癸水也是泄身的五行，年支和时支是来克身，地支巳申相合，申金被合克，且申亥相害，申金有损，帮身力量有所打折扣，年干透出己土来生扶日主，依然为中和偏弱之格。月干壬水伤官从月令申金中透出，为伤官格。

# 分析喜忌：

中和偏弱以生扶日主的土金五行为用神，以泄耗日主的水木五行为忌神，火虽克身，但在天干生土为吉。八字申金当令较旺，地支火来克金，喜见土来生金，单独见金，旺了水，且火金相战，稍有不利，不喜多见，天干水旺，也喜见土来制水生身。

# 分析事业：

月令申金为用，但地支巳申相合，申金被合克，又申亥相害，申金有损，为用神无力受损，且申金来生壬水和亥水，旺了忌神，为不足之处。年干己土也为用神，己土得巳火生扶，且己土来制壬水，制了忌神，为吉利之处。

原局为伤官格，月干壬水伤官透出，壬水伤官为忌神，但有己土印星来制，所谓“聪明不过伤官”，同时又是金水食伤，加上辛亥日出生为十灵日，临学堂和词馆，故比较聪明的一个人，有领悟力，且有上进心和事业心，也有利学业发展，可以取得不错的学历和文凭。

月干壬水伤官高透，时干见癸水食神，辛亥日出生，日坐亥水为伤官，均代表比较喜欢自由，不喜被管束约束太多，同时地支巳亥相冲，为伤官克官的组合，也代表有些叛逆，对规则，权威，条条框框等比较抵触反抗。壬水伤官有制，有一定语言天分，口才不错，但也要注意因为言语而遭遇口舌是非之事。

辛亥日出生临驿马，亥水伤官临驿马，且巳亥相冲，驿马逢冲，代表思想变化性较大，不能静得下心，内心比较容易浮躁，驿马逢冲，比较辛苦操劳奔波。加上身弱食伤旺旺，本身也是代表容易天马行空的胡思乱想，想法虽然较多，但容易脱离实际，想法多变，比较难脚踏实地的去做一件事情，也会有些自命不凡，滋生傲慢心，有时候人性脾气大。

地支两个巳亥相冲，又申亥相害，加上伤官临驿马，驿马逢冲，亥水伤官有损，会有许多求而不得导致压抑抑郁，也容易急躁冲动。地支巳火和亥水均临驿马，驿马重重，为外出发展之命，出生地的西方，西北方，东北方，西南方比较旺你，尤其巳火官星临驿马，也有外地工作之象，故不适合在家乡发展。

年干己土为偏印，偏印为一颗神秘星，辛亥日出生为十灵日，临太极贵人，代表会对神秘文化、国学文化等比较感兴趣，天干己土偏印来制壬水伤官，适合从事研究相关的工作，有一定钻研能力，也代表有艺术、创作、语言方面的天分。

你的原局虽然官印相生，一般代表适合体质或者稳定工作，但食伤旺又伤官克官，代表对朝九晚五的工作时间长了会滋生痛苦，自己也较难适应体制内的工作，巳火官星被冲克，代表事业运不是太理想，加上不见财来养官，为无财之官，无财之官非真官，且巳火官星逢冲，也代表在体制内不是太理想，升职存在“天花板”，在这个领域也很难施展才华，做出成绩。

你的命局来说有艺术、创作、语言、国学等方面的天分，虽然过往的光环很耀眼，但毕竟已经在体制工作8年，这个年纪要完全去做其他的也不容易，可以在工作业余可以去研究这方面，也可以借助自媒体发展这方面的潜质找找机会，其次有机会也可以从事教育行业，能去教书，相对更好一些。

# 分析大运：

**28岁—37岁**

乙亥大运，此大运为伤官生财的大运，天干乙木财星克印，地支申亥相害，申金有损，命局用神均有损，故整体运势不太理想，阻碍较多，命局亥水伤官有损，容易抑郁，驿马逢冲，比较奔波辛苦，也要注意口舌是非，印星被制，升职发展机会不多。

**38岁—47岁**

丙子大运，此大运天干丙火被地支子水戳脚，天干丙火透出，旺了己土偏印，故整体运势转好，事业上有升职发展的机会，天干壬丙相照，也有利求名，有望声名远播，取得荣誉，但凡事都是两面性，人红是非多，此大运伤官见官，也要注意官非口舌之事。

**48岁—57岁**

丁丑大运，此大运为杀印相生的大运，天干丁火七杀透出，旺了己土偏印，地支丑土印星来助身，故整体运势依然偏好，有升职发展的机会，贵人运较为不错，可以把握机遇，丁壬相合，和命局官杀混杂，事业容易变动。丑土临华盖，也代表自己修行之心较为强烈。
