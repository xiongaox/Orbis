# 分析命局：

辛金日主生在申月得令，申金为辛金日主的羊刃，帮身力量较强，并在时支伏吟，也来帮身，坐未土得地，月干戊土来生扶日主，年支午火来克身，时干丙火也是克身的五行，年干壬水来泄身，但依然为为身旺之格。天干壬水伤官和戊土正印从月令申金中透出，为伤官格，也为正印格。

# 分析喜忌：

身旺以泄耗日主的水木五行为用神，以生扶日主的土金五行为忌神，火虽克身，但在天干地支生土不吉。地支申金当令较旺，喜见水来泄金之力，也喜木来疏土，水木同见为吉。天干喜见水来泄金之力，也喜水来生木，木来耗身。

# 分析事业：

辛金为珠宝金，不喜土厚，土厚会造成土重金埋，而且辛金要发出光泽，需壬水洗金，再见一点火，更加可以焕发光泽。

从你的原局组合来看，虽然见壬水和丙火、午火，但奈何辛金被戊土和未土贴身，而且年干壬水伤官泄身为用，但被戊土所制，为印克伤官，属于忌神制用不吉，命局正偏印同见，官杀混杂，杂而不贵，所以从组合来看，不是太好。

不过结合大运来看，你现在走的庚戌大运，为印比助身的运气，运势不太理想，略为低迷。后面走的是辛亥大运，壬子北方水运，运势比现在要好些。而癸丑大运，天干戊癸相合，戊土被合拌，对壬水也算解救，运势不差。甲寅大运，运势一般偏好，所以未来的运势总体是向好的，一生命格不为差。

申金羊刃当令较旺，时支申金羊刃伏吟，虽有午火七杀和丙火正官来制羊刃，但依然体现为性格固执倔强，自我意识较强，比较好强，不会轻易妥协服输，也不会轻易听取别人的劝告，有时候脾气不太好，容易急躁冲动，但也懂得约束自己，有一定上进心，为吉的一面。

辛金日主被戊土和未土印星贴身为忌，性格也体现为有一些自私自我，偏保守一些，创新能力不足，做事缺乏魄力，容易虎头蛇尾，不会换位思考。偏印贴身，有一定依赖性，对未来规划性不强，容易目光短浅，心胸不够大，容易敏感多疑，加上月柱和时柱临孤辰，更加代表性格偏内向一些。

年干壬水伤官透出为用，伤官代表思想，但被戊土印星所制，也代表思维不够灵活机灵，在变通性上较为缺乏，学业和事业上不易施展才华，做出成绩，容易被埋没，也容易心情不好，自我纠结。壬水为命局中用神，代表福气，一旦被制，福气也就打了折扣，而且自己也容易错失良机。

地支申金羊刃重重，适合从事一些偏体力方面的工作，申金也临驿马，地支驿马重重，也适合一些多动的工作，你现在从事电梯相关，符合这两个方面，总体来看是适合你的，你有当体育老师的想法，也是适合你的，符合你的命格特征。

除此之外，若有转行的想法，身旺无依，壬水伤官透出泄身，适合一技傍身，从事一些五行水木相关的行业较好。地支午火七杀来制申金羊刃，有一定管理才能，可以进企业从事管理。

天干丙辛相合，正官合身，且辛金日主被印星贴身，又壬水伤官被制，所以并不适合从商、创业、做生意等，为上班求财之命，羊刃重重，也适合多付出多吃苦，事业方可顺遂。

不过不见财星，唯有日支未土暗藏乙木财星，藏而不显，丙火和午火官杀难以得到财星生扶，也代表事业运不强，而且官杀混杂，很难找到非常体面的工作，自己也要放低身段为好。地支驿马重重，适合外出发展，出生地的北方，东方，东南方比较旺你。
