# 火土旺的人

命主生辰: 1997/04/09 14:00 (GMT+8)
性别: 坤造
日主: 辛金
格局: 偏财格
令地: 失地, 得令

# 网友来信：

我出生于较为落后的西南城市。目前是东南沿海一所高校的设计学研究生。从小和父母亲缘淡泊，作为留守儿童，几乎没有怎么经历过完整的家庭关系。父母在我初中时离异，后一直跟随母亲，但也基本上是在寒暑假才会和母亲见面。目前我已经结婚。

本科（管理专业）毕业后从事过两三年的设计工作，后来觉得能力不足，选择考取设计类研究生深造一下，目前正在学习中，到乙巳年9月毕业。但是内心更加向往体制内的工作，所以有通过应届生身份考公务员的计划。

> 主要想和您咨询的是：
>
> 1.之前有测算过命理，得知我是身弱偏财格，按理说是不是不适合体制内的工作，但我命里有国印神煞，是否又代表和体制工作有缘呢？请问考公能否有机会？
>
> 2.下一步大运是杀枭大运，这是我最担心的，因为乙巳年后是大运交接时期，是否会对我求取工作有影响呢？且听说杀枭大运会对人身心有很大影响，目前非常的害怕。请问考公最大的阻力来源？
>
> 3.命理中火土混杂，其他老师给我判的较难通达，不知道老师对于我这样的格局有什么好的建议嘛？（主要还是事业方向）
>
> 4.因为我命理中只有藏干有食神，是否代表着我子女运较浅，不知道未来生育的情况如何？
>
> 5.最近才发现我的地支有三个墓库，不知道这有什么讲究？

# 八字详批：

#### 坤造：丁丑年，甲辰月，辛巳日，乙未时（申酉空）

#### 大运：乙巳，丙午，丁未，戊申，己酉，庚戌，辛亥，壬子，10岁运。

# 分析命局：

辛金日主生在辰月得令，坐巳火失地，年支丑土和时支未土来生扶日主，地支丑未相冲，把土冲旺，生扶力量较强，月干甲木来耗身，时干乙木也是耗身的五行，年干丁火来克身，但丁火和巳火旺了丑土和辰土，依然为偏旺之格。时干乙木偏财从月令辰土中透出，为偏财格。

# 分析喜忌：

偏旺以泄耗日主的水木五行为用神，以生扶日主的土金五行为忌神，五行火虽克身，但在地支容易去生土不吉。地支辰土当令，土旺成势，火来助土，喜见木来疏土，同时也喜见水来制火，水木同见为吉。天干喜见水来生木，也喜木来耗身，火来克身。

# 分析事业：

月干甲木和时干乙木为用神，月柱甲辰，时柱乙未，木来克土，为用神制忌，较为吉利，但天干甲木来生丁火，丁火来生丑土，反而旺了丑土，也为用神化忌，旺了忌神，较为不利，且喜水而不见水，为不足之处。尤其原局官杀混杂，正偏财同见，正偏印同见，杂而不贵，所以从组合而言不太理想。

杀印相生，官印相生，印星较旺，也有土重金埋之象，又不见食伤来泄身，做事也不太擅长变通，有一定依赖性，也容易敏感多疑，烦恼顾虑多，有的时候闷闷不乐，比较缺乏活力。

印星太重，且辛金日主在地支无强根，容易想得多，被外界动摇，缺乏一些主见，错失一些机会。也容易钻牛角尖，反复纠结，陷入“死胡同”，给自己增加一些不必要的烦恼。

原局甲乙木正偏财同见，丑土、未土和辰土正偏印同见，丁火和巳火官杀混杂，一般都较不安分，很容易三心二意，想法多变，做事不容易坚持，比较虎头蛇尾，辛金日主被甲乙木财星贴身，财星高透，也代表有一定虚荣心。

原局不见食伤，且有土重金埋之象，不是太灵活，但有木制土，故而设计还是可以做的，只是命局水木不旺，也不算精通，想做的很出色是困难的，只能算勉强合适。

命局官印相生，杀印相生，也适合管理方面，但命局正偏印，官杀混杂而旺，故而管理也是勉勉强强。

结合你大运走势看，中年后运回落，故而从长远考虑往管理，行政管理能入到体制，或国企，事业单位上班比较稳妥。

官印相生，财杀印相生，辛巳暗合，为正官合身的组合，且巳火临国印贵人，你有考体制内的想法是可以的，也是适合你的，未来可以朝这个方向努力。

不过2025乙巳年毕业，刚好处于丙午大运快结束的时候，以及未来的丁未大运，总体均不利考学，想顺利考试上岸较为困难，最早要到2031年以后，考学运才会稍微好点，不过那个时候年龄已经比较大了，虽没有超过报考年龄，但即使勉强考上，也丧失了竞争优势。

给你的建议是，现在在校是一个优势，未来可以以应届毕业生身份，也是一个优势，想向体制靠拢，就要充分利用自己的优势，能争取下人才引进，一些专项计划，西部计划等较好，这方面的信息自己要多关注，或者毕业时考一下选调生也是可以的，一旦错过这些机会，暂时就要先上班为佳，再徇图求变。

总之能进体制，是你比较好的选择，若不能进，也要努力进一些国企央企，稳定最好。

以官杀代表事业，一般官杀喜透，透则有威严，也有贵气，财星喜藏，藏则丰厚，透则易散。

而天干甲乙木高透，且辛巳日出生为十恶大败日，均代表钱财花销大，不太聚财，但好在时支未土为财库，也代表并非财来财去，能养成存钱的习惯为好。

而官杀混杂，且官杀旺了印星，故事业运并不强，未来升职空间较为有限。

原局见丑土、辰土和未土三个墓库，且丑土和未土为偏印，年柱临华盖，均代表对神秘文化比较感兴趣。

从行运来看，未来走的丁未大运，运势较为一般，以及未来的戊申，己酉大运，均非太好的运气，所以求稳、上班求财是最佳选择。

你辛巳日柱，女命以食伤为子女，命局中食神两位，暗藏于地支，故单纯从你命局来看，理论上有两个女儿，但水暗藏于地支，地支丑未相冲，丑土暗藏的癸水有损，时支未土为枭神，枭神是夺食的，代表得到子嗣并不会太容易，怀孕和生育较为不利，备孕时要多做好调理为好，逢猪年选择备孕较为有利，逢鼠年、狗年有一定风险，要尽量避开。食伤为用，时干乙木也为用神，代表未来子女发展较好，可以往生意、创业等方向培养。

# 分析大运：

**20岁—29岁**

丙午大运，此大运干支一气为官杀，官杀混杂，且地支七杀旺了印星，故整体运势较为一般，容易心有不专，三心二意，事业容易发生变动，事业运不强，除个别年份外，考学运也较为一般，能平稳过度，抓住机遇找工作为好。

**30岁—39岁**

丁未大运，此大运为杀印相生的大运，天干丁火七杀透出，地支未土为印星，丑未相冲，把土冲旺，故事业运不强，没有太多升职发展的机会，能选择外出家乡发展是比较好的选择，出生地的北方，东方，东南方比较旺你。

**40岁—49岁**

戊申大运，此大运印比助身，天干戊土印星透出，地支申金劫财帮身，巳申相合，劫财夺官，代表事业上竞争较大，容易遇到强有力的竞争对手，升职发展空间不大、机会不多，适合求稳过度。

**50岁—59岁**

己酉大运，此大运为印比助身的大运，天干己土印星透出，甲己相合，甲木财星被合绊，代表不太聚财，花销较大，能养成存钱的习惯为好。地支巳酉半合，比肩夺官，事业依然竞争很大，能退则退为佳。
