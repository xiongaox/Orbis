# 网友来信：

我睡眠质量不太好，梦多，不定期会有gui压床的情况，1年多出现过一次，今天又出现了一次，正做梦的时候，又出现了gui压床的情况，脑袋很清醒，但是手脚身体就是动不了，感觉被什么东西压着在似的，是不是要考虑用什么方法辟xie不？

# 八字详批：

# 分析命局：

辛金日主生在寅月失令，坐丑土得地，年支和时支卯木来耗身，地支木旺克土，丑土生扶日主力量不强，月干壬水来泄身，年干丁火来克身，天干丁壬合化为木，反而耗身，时干辛金来帮身，但辛金坐卯木之上虚透，帮身无力，故为偏弱之命。

# 分析喜忌：

辛金日主偏弱，以生扶日主的土金五行为用神，以泄耗日主的水木五行为忌神，火虽克身，但在地支生土为吉，木旺成林，土木相战，地支能有火来通关为吉，火为原局的五行通关用神，木旺为病，也喜见金来制木帮身，单独见土，木土相战不为最吉，火土同见为吉。

# 分析事业：

地支寅卯木财星得令较旺，天干丁壬合化为木，满盘财星，且正偏财同见，物欲较强的一个人，求财的欲望较大，较为贪婪，在金钱上不太容易满足。而命局身弱，难以担财，也容易因为求财而招惹是非生事端，这是要注意的。

地支寅卯木财星太旺而克印，求财上容易缺乏一些原则和底线，欠缺仁义，对金钱追求太过，也容易遭遇是非，甚至破财，财星太旺，也容易贪图享乐，不易吃苦，不太踏实，加上丁火七杀被合化，多喜欢偏自由一些的职业。辛丑日出生，日坐丑土印星为用，但被一片旺木所制，丑土印星受损严重，故而也容易懦弱胆小，信心不足。

财旺克印，在学习上较难专心致志，容易三心二意，学习成效不太好，很难学有所获，比较浮躁，粗心大意，有时候静不下心，耐心不强，壬水伤官被合化，人也不够灵活，容易思想陷入死胡同，读书运不是很好，离开学校的自修学习也不太理想，所以要加强自律，锻炼自己的专注力为好。

日支丑土枭神贴身，故对神秘文化比较感兴趣，也比较有灵性的一个人，第六感和做梦、预感等多比较准，但也容易多疑。而地支财旺坏印，丑土受损，又天干丁壬相合，丁火和壬水合化为木，伤官被合化，故而也体现为压力较大，思虑较多，导致睡眠不好，要注意调节，坚持作息规律，保证充足睡眠。梦魇的原因很多，也有科学解释，不用凡事往辟xie方面想。

满盘财星，财星克印，且不见财库，又天干丁壬合化为木，旺了财星，身弱难以担财，为财来财去之命，求财辛苦，壬水伤官被合化，财运时好时坏，也代表花销非常大，难以聚财，即使赚到钱也很容易很快花出去，印星受损，也很容易破财，除非大运来助身，可以稍微做点投资或生意，否则务必保守为上。

你上一步大运走的是己亥大运，地支寅亥相合，伤官生财，故创业或投资的想法较为强烈，亥水伤官旺了财星，财旺克印，故而财运不济，很容易破财负债，现在走的戊戌大运，干支一气为印星，财运稍好，但由于财印相战，也不是很理想，依然不宜做成本过高的事。

未来走的丁酉，丙申大运，地支比劫帮身制财，财运稍好，可以跟着别人做点生意，或者适当做点金融理财方面也可以，这两步大运有望还清债务，也可以买房。

财旺为忌，能从事金融方面的职业是可以的，因为身弱喜金来制木，金融属金，但你现在走的是戊戌大运，财印相战，炒股的话不可投资太大，印运能多把心思放在学习上为好，也可以考虑做一点属金的行业，如五金、钢铁、建材等方面。

辛丑日出生临天医，故而也可以考虑做点医疗器材器械方面的业务，比较适合你，八字正偏财同见，可以在主业之外发展副业，建议实业为主，炒股为辅。方位上可以考虑出生地的西方，西北方，东北方，西南方。

# 分析婚姻：

寅木正财当令较旺，年支和时支为卯木偏财，正偏财同见，在感情上容易心有不专，三心二意，这是要注意的，不过，寅木正财当令较旺，多为妻子当家，妻子性格多比较强势，自己多也比较惧内，会因为婚姻感情而产生一些压力，不过妻子可以管财，对于你的命格也比较好，而日支婚姻宫为丑土印星用神，本来婚姻还算理想，但是丑土左右被克，也代表妻子在婚姻家庭中不太舒心。

年月丁壬合木，又寅卯木较旺，均为财星忌神，代表早年和青年时期运势较为坎坷，阻碍较多，也代表出生较为一般，地支财星克印，要注意母亲健康，即使是养母也是一样，也要注意婆媳关系，年干丁火七杀可代表儿子，丁壬相合，丁火七杀被合化，要注意儿子身体健康，也代表和儿子缘分不是很深。
