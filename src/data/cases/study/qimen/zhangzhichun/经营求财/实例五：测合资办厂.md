# 实例五：测合资办厂

1995年5月19日，正当河北省对外贸易技术洽谈会期间，台湾夏泉股份有限公司老板杨佐仁住在石家庄天鸿宾馆。当晚10点多钟，他同秦皇岛市外贸局代表草签了合资办纸制餐具厂的意向书以后，请我预测一下这个项目能不能办成。

我用六爻法预测后，又用奇门起局预测。

## 盘内信息

**公元**：1995年5月19日21时0分0秒 阳5局

**干支**：乙亥年丨辛巳月丨庚戌日丨丁亥时

**旬空**：申酉空丨申酉空丨寅卯空丨午未空

**值符**：天柱星丨**值使**：惊门丨**旬首**：甲辰壬

## 分析：
（ 1 ）开门为用神，落8宫为入墓，又逢日干空亡之地，故这事办不成。

（ 2 ）地盘日干庚在7宫为主，上临己为客，己+庚“刑格返名”，格局不好，上乘景门，为门迫，腾蛇主虚诈变动。

（ 3 ）天盘日干庚落坤2宫，逢时干空亡之地，庚+戊为天十乙伏宫，格局不好；丁奇为文书契约，落离9宫空亡。丁奇又为时干，代表所问之事，时干空亡，必然落空。

根据这些信息，我告诉杨老板，别看秦皇岛外贸局的代表现在这么积极，回去就得变卦，这事不会办成。

## 反馈：
后来验证，这项合资办厂的事终于落空。
