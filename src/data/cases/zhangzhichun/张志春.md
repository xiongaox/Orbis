# 张志春介绍

张志春，河北隆尧人，著名作家、易学家。生于1941年1月28日，卒于2013年5月1日。  
1965年毕业于北京大学中文系。先后在大学、党政机关和出版社任职。文、史、哲皆通，尤精周易。

## 基本信息

- **中文名**：张志春
- **出生日期**：1941年1月28日
- **逝世日期**：2013年5月1日
- **出生地**：河北隆尧
- **毕业院校**：北京大学中文系
- **职业**：作家、易学家
- **信仰**：德易同修
- **代表作品**：《神奇之门》《开悟之门》《未知之门》《易学传真》
- **擅长**：奇门遁甲、周易应用研究
- **主要成就**：易学泰斗、奇门宗师、河北省周易研究会首任会长

## 易学贡献

张志春在推动中国易学发展方面扮演了举足轻重的角色。1989年，他以责任编辑的身份推出了邵伟华的《周易与预测学》，打破了建国以来周易应用研究领域的沉寂，有力地推动了周易文化在中国的复兴与发展。

他是河北省周易研究会的首任会长（ 1994-2011 ），被尊称为“易学泰斗，奇门宗师”。他主张“学术并重，扬弃结合，德易同修”的治易思想，对当代易学界的学风建设产生了深远影响。

其最重要的贡献在于对“奇门遁甲”的研究与推广。出版于1999年的著作《神奇之门：奇门遁甲大解谜》，被誉为“揭开了奇门遁甲千古之秘”，是易学研究界首次从理论和实践两个方面彻底通俗化、科学化地阐释奇门遁甲的作品。该书详细介绍了时家、年家、月家和日家奇门的起局与应用，探讨了其历史背景与趋吉避凶的作用，成为后学者的必读经典。

## 主要著作

张志春勤于笔耕，一生著作颇丰，涵盖文学、史学、易学等多个领域，共出版著作16种。

**易学代表作：**
- **《神奇之门》**：奇门遁甲入门与进阶的里程碑之作。
- **《开悟之门》**：进一步深研奇门遁甲的实战心得与高级技法。
- **《未知之门》**：探索易学未知领域的力作。
- **《易学传真》**：阐述易学真谛，弘扬传统文化。

**文学与史学著作：**
- 长篇小说：《她刚十九岁》
- 中短篇小说集：《相逢在海滨》
- 散文集：《神州风采》
- 史学专著：《王韬年谱》

他还为数十种易学书籍作序，并倾力培养和扶持了许多青年易学专家和学者，为易学事业的薪火相传做出了不可磨灭的贡献。

## 学术思想

张志春治学严谨，既尊重传统，又勇于创新。他提倡将易学研究与现代科学相结合，剥离封建迷信的糟粕，挖掘传统文化的精华。他强调研习易学首先要修德，正所谓“德易同修”。

他的奇门遁甲研究，不仅注重预测的准确性，更注重易理的阐释和逻辑的构建，使得这一古老的术数焕发出新的生命力，从“帝王之学”走向了大众视野，成为现代人认识世界、把握机遇的智慧工具。
